# フィードバック履歴の確認

最終更新：2026年10月28日

このページは、これまでのフィードバックで  
何度も出ていることと、進んでいることを  
一覧で確認するためのものです。

判定の軸は、次の1つだけです。

「こう考えて書いた」ではなく、  
この箱だけ読んで、因果が通るか。

---

## 1. 何度も出ていること

| 内容 | 出てきた時期の例 | 10/28の回でも出たか |
|---|---|---|
| 条件・制度・良い点は並ぶが、「なぜそれが必要か」が薄い／結果まで届かない | 5月〜10月（研修比較・専任・マニュアル・人選・全ポジ・他喜力） | いいえ（今回は見出しの集約。なぜ本体は継続課題） |
| 似て見える条件を混ぜる（ゴキゲンと成長環境／人と関わる楽しさ、など） | 9/24、10/7 | いいえ（ゴキゲン分離は次回も確認） |
| 「揃えている／基準がある」など抽象で止まり、具体まで落ちない | 8〜10月（マニュアル・専属・感情・他喜力・比較見出し） | はい（比較見出しが「構造化」等の抽象で硬い） |
| 比較が「ある／ない」や想像しやすい事例で終わりやすい | 8月マニュアル、9/24〜10/13 | 部分的（比較骨格はある。見出しに差の集約がない） |
| 因果の順番が乱れる／同じことの重複・細分化しすぎ | 5〜6月、9/24、10/13 | いいえ |
| 制度名のあとに、運用の具体や結果が足りない | 9/5〜10/22 | いいえ（今回は見出し側の話） |

題材はスープ室→研修→専任トレーナー→マニュアル→比較見出しと変わっています。  
指摘の型は、「なぜ」「切り分け」「経験しないと分からない具体」「結果まで落とす」「条件名と教える中身の一致」「見出し＝本文の集約」が続いています。  
10/26で挨拶箱は通り、10/28は比較箱の見出しを一目で分かる形に寄せる回です。

| できていること | 例 |
|---|---|
| 提出が途切れず、同じ軸の続きとして積み上がっている | 専任トレーナー〜マニュアル〜人選〜比較整理（6月〜10月） |

## 3. これから定着させたいこと

| 確認すること |
|---|
| 比較の見出しだけで、一般と当社の差が言えるか（本文を読まなくても分かるか） |
| 「構造化」「覚えること」など抽象見出しを、分業などの行動の差に置き換えているか |
| 事例は「それはそう」で終わる話ではなく、「経験しないと分からない」話か |
| 「いつもゴキゲン」と「人と関わることを楽しむ」を分けているか |
| 他喜力はお客様と従業員の2方向か。共感の有無で何が起きるかあるか |
| 通った挨拶箱（形だけではない・喜んでもらうため）を崩していないか |
| 本部3人のOKのあとに、なぜ複数人かが入っているか |
| メリットや順番の修正のあとに、新人の結果まで書いているか |
| 順番は、共感 → 育成 → 人選 → 関門のままか |
| 全ポジ・共感は「ある／ない」二列ではなく、教え方→問題→なぜ→だから必要、の一本か |
| 専属一人だけは、複数の限界（接し方は引き継ぎにくい）と問題が残っているか |
| この箱だけ音読して、「なぜ？」で止まらないか |
