# フィードバック履歴の確認

最終更新：2026年9月19日

このページは、これまでのフィードバックで  
何度も出ていることと、進んでいることを  
一覧で確認するためのものです。

判定の軸は、次の1つだけです。

「こう考えて書いた」ではなく、  
この箱だけ読んで、因果が通るか。

---

## 1. 何度も出ていること

| 内容 | 出てきた時期の例 | 9/19の回でも出たか |
|---|---|---|
| 条件・制度・良い点は並ぶが、「なぜそれが必要か」が薄い | 5月〜9月（研修比較・専任・マニュアル・人選） | 出た |
| 見出しと本文の役割がずれる（比較なのに自社メリットだけ、など） | 6〜7月（定着・品質・専任比較） | 今回は人選箱。型としては未解消 |
| 「揃えている／基準がある／関係性」など抽象で止まり、具体まで落ちない | 8〜9月（マニュアル・専属・誰でもなれない） | 出た（関係性） |
| 比較が「ある／ない」になりやすい | 8月（マニュアル有無）→修正方向は出たが再発しやすい | 今回は条件リスト型として同型 |
| 因果の順番が乱れる／同じことの重複が残る | 5〜6月（研修比較・専任理由） | 直近は別箱。型としては注意継続 |
| 制度名のあとに、運用の具体（人数・接し方・記録・合格ライン）が足りない | 9/5・9/14・9/19 | 出た |

題材はスープ室→研修→専任トレーナー→マニュアルと変わっています。  
指摘の型は、「なぜ」「比較の相手側」「抽象→具体」「運用まで落とす」が続いています。

---

## 2. できていること（進んでいる点）

| できていること | 例 |
|---|---|
| 提出が途切れず、同じ軸の続きとして積み上がっている | 専任トレーナー〜マニュアル〜人選（6月〜9月） |
| 前回フィードバックの方向に寄せられる | マニュアルは新人用ではなくトレーナー用（8/24→9/5） |
| 比較軸・箱立ての骨格を出せる | 人依存 vs 基準がある／誰でもなれない／専属 |
| 厳しい条件や関門の方向感は出せる | 9/19の人選・本部全員OK |

方向寄せと箱立てはできています。  
次に定着させたいのは、各箱の直後に「なぜなら」と合格ラインが入っているかの自己確認です。

---

## 3. これから定着させたいこと

| 確認すること |
|---|
| 条件・制度の直後に、「なぜなら（失敗したときの具体）」が入っているか |
| 見出しが比較なら、本文も相手側 → 自社の変化 → 結果、になっているか |
| 「できる／揃えている／関係性」を、例と合格ラインまで分解しているか |
| 人数・接し方・記録・デビュー基準など、現場で回る具体があるか |
| この箱だけ音読して、「なぜ？」で止まらないか |
| 前回話し合った内容が、次の提出の文章に入っているか |

---

## 4. 直近（2026年8〜9月・トレーナー教育基準）

| 日付 | 進んだ点 | 残った点 |
|---|---|---|
| 8/11 | 基準が揃う→新人が迷わない、の方向 | 魅力の置き場・因果の厚み |
| 8/24 | マニュアルは新人用ではない、と整理 | 差の見せ方の具体 |
| 9/5 | トレーナー用マニュアル／基準教育の軸 | 「揃えている」で止まる／運用確認 |
| 9/14 | 誰でもなれないを前へ、の方向 | 会議だけで足りるか／人数・接し方・記録 |
| 9/19 | 厳しい条件・全員OK・専属の骨格 | 条件ごとのなぜ／全ポジの定義／専属の具体化 |

8〜9月は、トレーナー教育の軸で箱が積み上がっています。  
まだ残っている幹は、次の3つです。

- 条件・制度のあとに「なぜ」がない
- 抽象語で止まって、具体例・合格ラインまで落ちない
- 現場で回る運用（人数・接し方・記録・定義）まで書けない

## 提出前の3つだけ

次の提出の前に、これだけ確認してください。

1. この箱だけ音読して、どこかで「なぜ？」と止まらないか  
2. 悩み → なぜ今の手段では足りないか → だからこうする、の順か
