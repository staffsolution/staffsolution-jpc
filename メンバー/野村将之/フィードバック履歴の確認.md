# フィードバック履歴の確認

最終更新：2026年10月7日

このページは、これまでのフィードバックで  
何度も出ていることと、進んでいることを  
一覧で確認するためのものです。

判定の軸は、次の1つだけです。

「こう考えて書いた」ではなく、  
この箱だけ読んで、因果が通るか。

---

## 1. 何度も出ていること

| 内容 | 出てきた時期の例 | 10/7の回でも出たか |
|---|---|---|
| 条件・制度・良い点は並ぶが、「なぜそれが必要か」が薄い／結果まで届かない | 5月〜10月（研修比較・専任・マニュアル・人選・3人OK・教える順番） | 出た（3人のなぜ、新人の結果が空欄になりやすい） |
| 似て見える条件を混ぜる（ゴキゲンと成長環境／人と関わる楽しさ、など） | 9/24、10/7 | 出た（聞きやすさと観察・声かけが別路線） |
| 「揃えている／基準がある」など抽象で止まり、具体まで落ちない | 8〜10月（マニュアル・専属・感情・多機力） | 出た（機嫌取りが仕事より優先、まで落とす） |
| 比較が「ある／ない」や想像しやすい事例で終わりやすい | 8月マニュアル、9/24ゴキゲン、10/7間違えた料理など | 出た（経験しないと分からない事例になっていない） |
| 因果の順番が乱れる／同じことの重複が残る | 5〜6月、9/24は箱の重複 | 今回は並び変更が進み、中身の精度が本題 |
| 制度名のあとに、運用の具体や結果が足りない | 9/5〜10/7 | 出た（メリット・修正のあとの結果） |

題材はスープ室→研修→専任トレーナー→マニュアルと変わっています。  
指摘の型は、「なぜ」「切り分け」「経験しないと分からない具体」「結果まで落とす」が続いています。

---

## 2. できていること（進んでいる点）

| できていること | 例 |
|---|---|
| 提出が途切れず、同じ軸の続きとして積み上がっている | 専任トレーナー〜マニュアル〜人選（6月〜10月） |
| 前回フィードバックの方向に寄せられる | 9/24の並び変更・理由書き足しを反映。前回よりかなり良くなっている |
| 使える経緯を置ける | 2000年頃の失敗と、2023年のサービス劣化から今の形へ |
| 材料は出ている | 専属・全ポジ・共感・本部全員OK・ゴキゲン・教える順番の修正 |

方向寄せと材料出し、流れの変更はできています。  
次に定着させたいのは、事例の質・似た条件の切り分け・「その結果」まで書けているかの自己確認です。

---

## 3. これから定着させたいこと

| 確認すること |
|---|
| 事例は「それはそう」で終わる話ではなく、「経験しないと分からない」話か |
| 「いつもゴキゲン」と「人と関わることを楽しむ」を分けているか |
| 多機力はお客様と従業員の2方向か。共感の有無で何が起きるかあるか |
| 本部3人のOKのあとに、なぜ複数人かが入っているか |
| メリットや順番の修正のあとに、新人の結果まで書いているか |
| 順番は、共感 → 育成 → 人選 → 関門のままか |
| この箱だけ音読して、「なぜ？」で止まらないか |
