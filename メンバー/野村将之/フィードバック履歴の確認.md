# フィードバック履歴の確認

最終更新：2026年10月13日

このページは、これまでのフィードバックで  
何度も出ていることと、進んでいることを  
一覧で確認するためのものです。

判定の軸は、次の1つだけです。

「こう考えて書いた」ではなく、  
この箱だけ読んで、因果が通るか。

---

## 1. 何度も出ていること

| 内容 | 出てきた時期の例 | 10/13の回でも出たか |
|---|---|---|
| 条件・制度・良い点は並ぶが、「なぜそれが必要か」が薄い／結果まで届かない | 5月〜10月（研修比較・専任・マニュアル・人選・全ポジ） | 出た（全ポジを二列比較のままだと因果が長い） |
| 似て見える条件を混ぜる（ゴキゲンと成長環境／人と関わる楽しさ、など） | 9/24、10/7 | 10/13は構造の回（次回も確認） |
| 「揃えている／基準がある」など抽象で止まり、具体まで落ちない | 8〜10月（マニュアル・専属・感情・多機力） | 10/13は型の指示が中心 |
| 比較が「ある／ない」や想像しやすい事例で終わりやすい | 8月マニュアル、9/24ゴキゲン、10/7、10/13全ポジ | 出た（できない／できるトレーナーの二列） |
| 因果の順番が乱れる／同じことの重複・細分化しすぎ | 5〜6月、9/24、10/13 | 出た（AIの枝分かれ・まとめ不足） |
| 制度名のあとに、運用の具体や結果が足りない | 9/5〜10/13 | 出た（専属はズレが生む問題がないとメリットが薄い） |

題材はスープ室→研修→専任トレーナー→マニュアルと変わっています。  
指摘の型は、「なぜ」「切り分け」「経験しないと分からない具体」「結果まで落とす」「まとめと対比の使い分け」が続いています。

---

## 2. できていること（進んでいる点）

| できていること | 例 |
|---|---|
| 提出が途切れず、同じ軸の続きとして積み上がっている | 専任トレーナー〜マニュアル〜人選（6月〜10月） |
| 前回フィードバックの方向に寄せられる | 9/24の並び変更・理由書き足しを反映。前回よりかなり良くなっている |
| 使える経緯を置ける | 2000年頃の失敗と、2023年のサービス劣化から今の形へ |
| 材料は出ている | 専属・全ポジ・共感・本部全員OK・ゴキゲン・教える順番の修正 |
| AI壁打ちで理由の材料を出せる | 10/13全ポジ（協力／なぜ／原因／優先順位） |

方向寄せと材料出し、流れの変更はできています。  
次に定着させたいのは、因果一本の型・まとめと対比の使い分け・「その結果」まで書けているかの自己確認です。

---

## 3. これから定着させたいこと

| 確認すること |
|---|
| 事例は「それはそう」で終わる話ではなく、「経験しないと分からない」話か |
| 「いつもゴキゲン」と「人と関わることを楽しむ」を分けているか |
| 多機力はお客様と従業員の2方向か。共感の有無で何が起きるかあるか |
| 本部3人のOKのあとに、なぜ複数人かが入っているか |
| メリットや順番の修正のあとに、新人の結果まで書いているか |
| 順番は、共感 → 育成 → 人選 → 関門のままか |
| 全ポジ・共感は「ある／ない」二列ではなく、教え方→問題→なぜ→だから必要、の一本か |
| 専属一人だけは、複数の限界（接し方は引き継ぎにくい）と問題が残っているか |
| 細かく分かれすぎた枝をつなぎ、重複を削ったか |
| この箱だけ音読して、「なぜ？」で止まらないか |

## 4. 直近（2026年8〜10月・トレーナー教育基準）

| 日付 | 進んだ点 | 残った点 |
|---|---|---|
| 8/11 | 基準が揃う→新人が迷わない、の方向 | 魅力の置き場・因果の厚み |
| 8/24 | マニュアルは新人用ではない、と整理 | 差の見せ方の具体 |
| 9/5 | トレーナー用マニュアル／基準教育の軸 | 「揃えている」で止まる／運用確認 |
| 9/14 | 誰でもなれないを前へ、の方向 | 会議だけで足りるか／人数・接し方・記録 |
| 9/19 | 厳しい条件・全員OK・専属の骨格 | 条件ごとのなぜ／全ポジの定義／専属の具体化 |
| 9/24 | 経緯は使える。なぜの書き始めがある | 並びが人選先行／全ポジのなぜが分担まで届かない／ゴキゲンが比較でない／期間・3人・正社員か |
| 10/7 | 流れ変更・理由書き足し。前回より大幅に良い | 想像できる事例／ゴキゲンと人と関わる楽しさの混同／3人のなぜ／新人の結果 |
| 10/13 | AIで全ポジの理由材料が出た。ホール教え方の具体あり | 二列比較→因果一本／専属の問題側／細分化のまとめ |

8〜10月は、トレーナー教育の軸で箱が積み上がっています。  
まだ残っている幹は、次のものです。

- 理由はあるが、経験しないと分からない事例になっていない
- 似て見える条件（ゴキゲンと人と関わる楽しさ）の切り分け
- 関門・修正のあとに、新人側の結果まで落とす
- 「なぜ」を二列比較ではなく因果一本にする（全ポジ・共感）
- 専属一人は対比と問題側を残す
