## ■現状（Before）

- 0905で「マニュアルはトレーナーの教育基準」「理解確認・成長記録・引き継ぎ」の方向が出た。今回は、その先の**トレーナー会議・専任トレーナー・育成の仕組み**の箱を見ている。
- 並んでいる論点の方向は正しい側にある。
  - マニュアルはトレーナーが教育の基準にしている
  - 基準を守るための取り組み
  - 複数トレーナーの引き継ぎはしない
  - 専属トレーナーの理由
  - トレーナーは誰でもなれない
- 一方で、「トレーナーは誰でもなれない」が**後ろすぎる**。先に置いた方が、会議・専任の説明が効く。
- 毎月のトレーナー会議で育成していく、と読めるが、**会議だけで育成できるのか**という疑問が残る。基準の理解には時間がかかる／店にマネージャーが少ない／経験と継続学習が必要、と多くの読み手が感じやすい。
- 「ちゃんとできるようになったのを確認してから、新人を最初から最後まで1人のトレーナーにつける」までは書けている。足りないのは、そのあとの**負担と運用の具体**。
  - 1人のトレーナーに何人までつけるのか（人数制限）
  - 一日どのくらい見るのか／マンツーマンかグループか
  - 記録はどう残すのか（前回の約束を忘れないため）
- 比較で「複数トレーナーだと問題が起きるからしない」は既に言えている。次は比較より、**当社の運用の解像度**を上げる段階。
- トレーナー側の育成も薄い。マニュアルを用意したあと、**会社としてどう育成し、力量をどうチェックし、どこまでいったらデビューし、デビュー後に新人を何人・どう見るか**までないと、「基準がある教育」のイメージが完成しない。

---

## ■問題の本質（重要）

- 「専任トレーナーがいる」「会議がある」は制度名の列挙。差になるのは、**誰でもなれない理由 → どう育成するのか → できるとどう確認するのか → 新人を何人・どう見るのか**まで一本で追えること。
- 読み手の先回り疑問は次の2つ。ここを潰さないと、基準教育の話がきれいごとに見える。
  1. **毎月の会議だけで、基準を本当に習得できるのか**
  2. **1人のトレーナーが、ちゃんと見切れる人数・深さなのか**
- 0905で言った「揃えているで止まらない」と同型。会議・専任も、**運用の具体と確認の仕組み**まで落とす。
- 「トレーナーは誰でもなれない」は結論ではなく、**育成と人数制限の前置き**。後ろにあると、会議の説明が「誰でも会議に出ればなれる」ように読まれる。

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| 誰でもトレーナーになれないと伝えたい | 配置が後ろで、会議・専任の前に効いていない |
| 会議で基準を揃えていると伝えたい | 「会議だけで育成できるのか」への答えが無い |
| 1人のトレーナーが最初から最後まで見る | 人数制限・接し方・記録がなく、負担が現実味を欠く |

| 基準がある教育だと示したい | トレーナーの育成・チェック・デビュー基準が無い |

- 0905の「理解確認・記録」を、今回は**トレーナー本人の育成プロセス**と**新人への接し方の運用**に落とす段階。
- 「制度がある」ではなく、**この箱だけ読んで、基準教育が現場で回っていると想像できるか**で見る。

## ■改善内容（What）

### 0. 進め方

```
【維持（OK方向）】
・マニュアル＝トレーナーの教育基準
・複数トレーナーの引き継ぎはしない／最初から最後まで1人
・専属トレーナーの理由を出すこと
・「ちゃんとできるようになってから新人につける」

【直す（今回の本題）】
・「誰でもなれない」を前へ
・会議だけで育成できるのか、への説明
・人数制限・接し方・記録の具体
・トレーナー育成→力量チェック→デビュー→担当人数の流れ
```

### 1. 「トレーナーは誰でもなれない」を前に置く

推奨の並び：

```
① トレーナーは誰でもなれない（基準・経験・継続学習が必要）
② だから会社として、どう育成し、どう確認するか
③ 毎月のトレーナー会議の役割（＋会議以外に何があるか）
④ デビュー後、新人を最初から最後まで1人が担当
⑤ 人数制限・接し方・記録
```

「誰でもなれない」が後ろだと、①の前提が共有されないまま会議の話が進む。

### 2. 「会議だけで育成できるのか」を先回りして答える

読み手の疑問：

```
毎月のトレーナー会議だけで、基準を本当に身につけられるのか？
店にマネージャーが少ない／基準理解には時間がかかる／経験と勉強が必要では？
```

ここに対して、次を実態に合わせて書く。

| 入れると効くこと | 例（実態に合うものを選ぶ） |
|---|---|
| 会議の役割の限定 | 基準の確認・事例共有・ずれの修正 |
| 会議以外の育成 | 先輩トレーナーの同行／実地での教え方チェック／マニュアル学習の宿題 |
| デビュー前の確認 | 一人前と認めるまで、何をクリアするか |
| 時間がかかる前提 | 「すぐ誰でもなれる」とは書かない。だからこそ選抜・確認がある |

「会議があります」だけで終わらせない。**会議は何のための場か／それ以外に何があるか**を分けて書く。

### 3. 新人担当の運用を具体にする（比較より解像度）

複数トレーナー問題の比較は既にあるので、当社側を厚くする。

```
複数のトレーナーがつくと起きる問題
　↓
だから最初から最後まで1人が担当する
　↓
ただし1人に無制限につけない（人数の上限）
　↓
一人ひとりへの接し方（時間／マンツーマンかグループか）
　↓
記録（前回の約束・到達点）を残し、忘れない／引き継がない運用と両立する
```

入れる具体の観点：

| 観点 | 書くとよいこと |
|---|---|
| 人数制限 | 1トレーナーあたり、同時に見る新人は何人までか |
| 接し方 | 一日どのくらい見るか／マンツーマンか／グループか |
| 深さ | 「ちゃんと見る」の中身（実技確認・振り返り・次の課題の決め方） |
| 記録 | 何を残すか（前回の約束、到達点、次にやること） |

「何十人もつけてちゃんと見れるの？」という疑問を、人数制限と接し方で潰す。

### 4. トレーナー育成の一本化（基準教育の完成形）

求職者（または読み手）が「基準がある教育だ」とイメージできる並び：

```
マニュアルを用意する
　↓
会社としてトレーナーをどう育成するか
　↓
力量をどうチェックするか
　↓
どこまでいったらトレーナーとしてデビューできるか
　↓
デビュー後、新人を何人・どのように見るか
```

ここまで書いて初めて、0905の「基準がある教育」が制度名ではなく**運用**として見える。

### 5. セルフチェック（結果だけ）

| チェック | Yes / No |
|---|---|
| 「誰でもなれない」が、会議・専任の前にあるか | |
| 「会議だけで育成できるのか」への答えがあるか | |
| 会議の役割と、会議以外の育成が分かれているか | |
| 人数制限が数字または上限の言い方で出ているか | |
| 接し方（時間／マンツーマン等）が見えるか | |
| 記録の残し方が、忘れ防止として書けているか | |
| 育成→チェック→デビュー→担当人数、まで通るか | |
| この箱だけ読んで、基準教育が現場で回っていると想像できるか | |

## ■改善理由（Why）

- 「誰でもなれない」は、会議と人数制限の正当性の土台。後ろにあると、土台なしで制度だけ並ぶ。
- 読み手は「会議があれば育つ」とは思わない。店のマネージャーが少ない・基準理解に時間がかかる、という現実感の方が先に立つ。だから**先回りの説明が必須**。
- 「1人が最初から最後まで見る」は良い。ただし人数制限と接し方がないと、**専任のメリットが負担の不安に負ける**。
- 0905で求めた理解確認・記録は、新人側だけでなく**トレーナー本人の育成・デビュー基準**にも同じ型で必要。
- 比較（複数トレーナー問題）はもう足りている。次の差分は**当社運用の解像度**。

---

## ■改善後イメージ（After）

- 「誰でもなれない」が先にあり、そのあとに育成・会議・専任が続く。
- 「会議だけで足りるのか」への答えがあり、会議の役割と会議以外が分かれている。
- 1人担当のあとに、人数制限・接し方・記録が見える。
- マニュアル → 育成 → チェック → デビュー → 担当人数、まで通る。
- 読み手が「基準がある教育が、現場で回っている」と想像できる。

---

## ■やりがちなミス

- 「誰でもなれない」を**後ろに残す**
- 「毎月会議がある」だけで、**育成できる根拠**を書かない
- 複数トレーナー比較を厚くしすぎて、**当社の人数制限・接し方**が薄い
- 「ちゃんと見る」と書いて、**時間・人数・マンツーマンか**を書かない
- 記録を「ある」だけで終わり、**何を残すか（前回の約束など）**を書かない
- トレーナーのデビュー基準を書かず、**新人側の話だけ**で完結させる
- 「制度名の列挙」で止め、**運用の一本の流れ**にしない

## ■他の案件でも使えるパターン

### パターンA：選抜条件は制度説明の前に置く

```
誰でもなれない／誰でも担当しない
　↓
だから育成・確認・人数制限がある
　↓
そのうえで会議や専任の話
```

### パターンB：会議・研修は「役割を限定して書く」

```
この場でやること（確認・共有・ずれ修正）
　↓
この場だけでは足りないこと
　↓
足りない分を何で補うか（実地・同行・チェック）
```

### パターンC：専任・マンツーマンは「負担の先回り」とセット

```
1人が最初から最後まで見る（メリット）
　↓
だから人数に上限がある（不安つぶし）
　↓
接し方と記録で、見る深さを示す
```

### パターンD：基準教育の完成形は5段

```
基準（マニュアル）
　↓
育成
　↓
力量チェック
　↓
デビュー条件
　↓
現場での担当人数・接し方
```
