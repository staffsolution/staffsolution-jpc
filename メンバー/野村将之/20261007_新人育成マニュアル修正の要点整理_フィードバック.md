## ■現状（Before）

- 0924で出した「共感 → 育成 → 人選 → 関門」の並び変更と、理由の書き足しが進んでいる。流れを変え、アドバイス・育成期間・人選理由・比較を入れた方向は合っている。前回よりかなり良くなっている。
- 足りないのは、理由の「中身の質」と、似て見える条件の切り分け、結果まで落とすこと。
- 「間違えてはいけない」系の事例が、誰でも想像できるレベルで止まっている。間違った料理を出す、遅いとクレーム、は読み手がすぐ結びつく。経験していないと本当は分からない事例になっていない。
- 「人に喜んでいただくために力をつける（多機力）」が、お客様側に寄っている。従業員側（協力・力を合わせる）と、共感の有無で何が起きるかが薄い。
- 本部マネージャー3人のOKでトレーナーになる、の理由がまだ弱い。なぜ複数人なのかが無い。
- 感情が不安定な場合の問題は書けている方向だが、結論が「機嫌取りが仕事より優先になる」までパンと落ちていない。
- 「いつもゴキゲン」と「人と関わることを楽しむ」が、同じ箱・同じ路線に見えやすい。実は別の話。
- トレーナーを一人に固定するメリットが、列挙と結果まで整理されていない。
- 教える順番を直した話は方向が良い。混乱がなくなった、の先に「その結果、新人はどうなったか」が空欄になりやすい。

---

## ■問題の本質（重要）

マニュアルの説得力は、「正しそうな理由」の数ではなく、次の3つで決まる。

1. **事例の質** … 誰でも想像できる話ではなく、「経験していないと確かに分からない」話か
2. **似た条件の切り分け** … ゴキゲン（聞きやすさ）と、人と関わる楽しさ（観察・声かけ）は別の因果か
3. **結果まで落とす** … 条件や修正のあとに、新人・現場で何が起きるかまで書いているか

0924は「順番と箱の統合」が本題だった。  
今回は、順番が動き始めたあとの**肉付けの精度**が本題。

特に人選条件は、次の対比が一本になると読みやすい。

```
感情が不安定
　→ 仕事の相談より、トレーナーの機嫌取りが優先になる
　→ 仕事に集中できない

いつもゴキゲンで安定している
　→ 聞きやすい／機嫌取りがいらない
　→ 仕事に集中できる

人と関わることを楽しんでいる（別路線）
　→ 人の観察に長けている
　→ 小さな変化に気づいて声をかけられる
```

「ゴキゲン」と「人と関わる楽しさ」を混ぜると、聞きやすさの話と、観察・声かけの話がぼやける。

## ■改善内容（What）

### 0. 今回の直しどころ（全体像）

```
【維持（OK方向）】
・流れの変更（育成と人選の並び）
・理由・比較・アドバイスを書き足していること
・全体として前回よりかなり良くなっていること

【直す（今回の本題）】
・事例を「経験しないと分からない」レベルに差し替える
・多機力はお客様＋従業員の2方向。共感の有無で何が起きるか
・本部3人OKの理由（寄った味方・忖度を防ぐ）を入れる
・感情不安定 → 機嫌取りが仕事より優先、を結論でパンと書く
・いつもゴキゲン と 人と関わることを楽しむ、を分ける
・専属一人のメリットを3〜5個＋説明＋結果
・教える順番の修正 → 混乱なく習得 → 新人の結果まで埋める
```

### 1. 事例は「想像できる」ではなく「経験しないと分からない」

次のような事例は、読み手がすぐ結びつくので弱い。

```
【弱い例（想像しやすい）】
・間違った料理を出してしまう
・早く作らないと遅い、とクレームになる
```

置き換える基準は、次の1行。

```
「経験していないと、確かにそれ分かんないよね」
　→ そう思える事例だけ残す
```

店の実態に合わせて、トレーナーだけが知っている失敗・判断ミスの例に差し替える。正しさより、「現場を知らないと想像できない」かどうかで選ぶ。

### 2. 多機力はお客様と従業員の2方向

「人に喜んでいただくために力をつける」で説明するなら、次の2つを並べる。

```
【お客様を喜ばせる】
・どういう声かけをするのか
・共感がないと、お客様側で何が起きるか

【従業員（スタッフ）を喜ばせる／力を合わせる】
・協力してやってもらう、力を合わせる、とは何か
・共感していないと、協力の場面でどんな問題が起きるか
・共感していると、力を合わせるときどんな対応になるか
```

「お客様に喜んでもらう」だけで終わると、チーム側の多機力が消える。トレーナー選定では、同僚への共感の方が現場で効くことが多い。

### 3. 本部マネージャー3人のOKの理由を入れる

「3人のOKが出ればトレーナーになる」のあとに、なぜ複数人かを書く。

```
【理由のイメージ】
・仲が良い／信頼している一人だけだと、OKを出しやすくなる
・複数人のチェックが入ると、「寄った味方」だけの承認になりにくい
・だから、本部マネージャー3人全員のOKを関門にしている
```

人数（3人）は0924でも必須だった。今回は、人数のあとに**なぜ複数か**を足す。

### 4. 感情が不安定な場合は、結論をパンと書く

情報を足すより、結論を短く前面に出す。

```
【感情が不安定な場合】
仕事でミスしたとき、聞きたいことがあるとき
　→ 仕事のことを聞くことが優先されない
　→ トレーナーの機嫌を取ることが優先される
　→ 機嫌取りが先になり、仕事に集中できない

【感情が安定している場合】
　→ より良い仕事ができるためのアドバイスを聞き入れるのがベース
　→ 感情的にならずに冷静にやれる
　→ 仕事に集中できる
```

「不安定だと困る」で止めず、**何が優先順位として狂うか**まで書く。

### 5. 「いつもゴキゲン」と「人と関わることを楽しむ」を分ける

同じ箱にしない。因果が違う。

```
【いつもゴキゲン／安定して人と接できる】
・聞きやすい
・機嫌取りをしなくてよい
・その結果、仕事に集中できる

【人と関わることを楽しむ（別路線）】
・人のことが好き／観察に長けている
・小さな変化に気づける
・困っていそうなときに声をかけられる
```

0924で「ゴキゲンは比較で短く」とした続き。短くしたあと、観察・声かけの話はゴキゲンに混ぜず、別条件として立てる。

### 6. 専属トレーナー一人のメリットを「個数 → 説明 → 結果」で出す

メリットを横に並べるだけでなく、いくつあるかを先に示してから説明する。

```
【例：メリットが○つある、の型】
1. 複数回の接触で信頼関係を構築しやすい
2. トレーナー側も、相手がどういうタイプか理解しやすくなる
3. （店の実態に合わせて3〜5個まで）

→ その結果
　一つずつ理解しながら進められる
　混乱することなくスムーズに習得できるようになる
```

「メリットがある」で止めず、**その結果どうなるか**まで同じ型で書く。

### 7. 教える順番の修正は「混乱 → 調整 → 新人の結果」まで

教える順番が間違っていた、混乱させてしまっていた、という整理は良い。次を埋める。

```
【推奨の並び】
1. 以前は教える順番がずれ、混乱させてしまっていた
2. 混乱がないように、スムーズに習得できる順番へ調整した
3. ゴールが明確になった（一人で何ができる／間違いなくできる）
4. その結果、新人さんはどうなったか ← ここを埋める
```

「ゴールが明確になった」で止めない。新人側の変化（迷わない、質問のポイントが分かる、現場投入がスムーズ、など店の実態）まで書く。

## ■改善理由（Why）

- 想像しやすい事例は、読み手が「それはそう」で流す。経験しないと分からない事例だけが、教育基準の深さの証拠になる。
- 多機力をお客様だけにすると、トレーナーに必要な「同僚と力を合わせる」が消える。共感の有無で協力がどう変わるかを書くと、人選条件になる。
- 3人のOKは、人数だけでは厳しさが伝わらない。なぜ一人ではダメかを書くと、関門の意味が立つ（0924の「本部3人」の続き）。
- 感情の話は、状態説明より「何が優先されるか」の方が一文で刺さる。機嫌取りが仕事より先、まで落とす。
- ゴキゲンと「人と関わる楽しさ」は、結果が違う。前者は聞きやすさ・集中、後者は観察・声かけ。混ぜると両方ぼやける。
- 専属一人の良さは、メリット列挙だけでは0924以前の「良い点の羅列」に戻る。個数 → 説明 → 結果、で因果にする。
- 教える順番の修正は、仕組みの改善として強い。新人の結果まで書くと、制度変更が「誰のためか」が残る。
- 全体は前回より良くなっている。今回は粗を消す段階で、骨組みをやり直す段階ではない。

## ■改善後イメージ（After）

- 間違えてはいけない理由の事例が、経験者だけがうなずく内容になっている。
- 多機力は、お客様への声かけと、従業員との協力の両方が読める。共感の有無で何が起きるかも並んでいる。
- 本部マネージャー3人全員のOKのあとに、寄った味方だけの承認を防ぐ、という理由がある。
- 感情が不安定な場合は、機嫌取りが仕事より優先になる、と結論が一文で読める。安定している場合は、アドバイスを聞き入れて仕事に集中できる、と対比になっている。
- 「いつもゴキゲン」と「人と関わることを楽しむ」が別条件で、聞きやすさと観察・声かけが混ざっていない。
- 専属一人のメリットが3〜5個示され、その結果スムーズに習得できる、まで続いている。
- 教える順番の修正は、混乱がなくなった先に、新人の結果まで埋まっている。
- 0924の並び（共感 → 育成 → 人選 → 関門）を崩さず、中身だけ厚くなっている。

## ■やりがちなミス

- 「間違った料理」「遅いとクレーム」など、誰でも想像できる事例を理由だと思って残す。
- 多機力をお客様満足だけで終え、従業員側の協力・共感を書かない。
- 本部3人と書いて、なぜ複数人のチェックが必要かを書かない。
- 感情が不安定だと困る、で止め、機嫌取りが仕事より優先になる、まで落とさない。
- 「いつもゴキゲンで人と接するのが好き」を1条件にまとめ、観察・声かけの話を混ぜる。
- 専属一人の良さをメリット列挙だけで終え、その結果を書かない。
- 教える順番を直した、混乱がなくなった、で止め、新人の結果を空欄のままにする。
- 理由を厚くするあまり、0924で直した順番（育成 → 人選）を再び崩す。

## ■他の案件でも使えるパターン

- 事例を足すときは、「それはそう」で終わるか、「経験しないと分からない」かを先に判定する。後者だけ残す。
- 「人を喜ばせる」系の力は、対お客様と対仲間の2方向に分ける。片方だけだと人選条件にならない。
- 関門（複数人の承認など）は、人数のあとに「一人だと何が起きるか」を1行足す。
- 性格・感情の条件は、状態ではなく優先順位の狂い方で書く（何が先になるか）。
- 似て見える長所は、結果が同じかを見る。結果が違うなら別条件にする（ゴキゲン＝聞きやすさ／人と関わる＝観察）。
- 仕組みのメリットは、「○つあります」→ 各説明 → その結果、の型で揃える。
- 制度や順番を直した話は、必ず「直しの対象者（新人など）の結果」まで書く。
