- 多機力の考え方に共感している理由
- 一般的な「寄り添い教育」と多機力の切り分け
- お客様に喜んでもらう理由／声かけ／気配り
- 一緒に働く仲間への意識（多機力の2方向）
- 感情が安定している理由（こちらはOK）
- 1013・1007の続き

---

## ■現状（Before）

- 1013で指示した「印を1本にして枝を減らす」を反映した提出。全体の読みやすさはかなり上がっている。
- 感情が安定している理由（安心して質問できる環境／小さな変化に気づき早めにサポート／そのために感情が安定している必要がある）は、このままでよい。
- 残るのは「多機力の考え方に共感している」理由の箱。ここだけ、多機力そのものとの結びつきが弱い。
- いまの書き方だと、「失敗したときに、どこで間違えたか・何が難しかったかを確認し、できるようになるまで一緒に考える」「一緒にもう一度やってみよう」といった、どの店でも言えそうな寄り添い教育に見える。
- 多機力のベースは、「人に喜んでいただくために力をつける／力を合わせる」。対象はお客様だけでなく、一緒に働くスタッフも含む。その核が、教える理由の先頭に来ていない。
- 壁打ちで出た材料のうち、「仕事のやり方だけでなく、お客様に喜んでいただく理由まで教える」「トレーナー自身のお客様への気配りを教える」は多機力に近い。並びと見出しを寄せると、一般論から抜け出せる。

---

## ■問題の本質（重要）

「多機力に共感しているトレーナーでないといけない」は、**一般的な良い教え方**では証明できない。

```
多機力 ＝ 人に喜んでもらうために力をつける／力を合わせる
　↓
対象はお客様 ＋ 一緒に働く仲間
　↓
だから教える中身も「やり方」だけでなく
　喜んでもらう理由・声かけ・気配り（＋仲間への意識）になる
　↓
だから多機力に共感している人でないと、その教え方ができない
```

「できるようになるまで寄り添う」は大事だが、**多機力専用の理由ではない**。入口に置くと、多機力が他店の一般論に溶ける。

## ■ズレ（思考 or 設計）

| 取れている／近い | まだ薄い／直し方 |
|---|---|
| 印を1本・枝を減らした読みやすさ | 多機力箱だけ、核との結びつきを強化 |
| 感情安定の理由（質問できる／変化に気づく） | 変更不要 |
| 「できるようになるまで一緒に考える」 | 出だしで短くまとめるか、後ろへ。多機力の核にしない |
| お客様に喜んでいただく理由まで教える | **1番目**に持ってくる |
| 歓迎の挨拶・気配り | 見出しに反映。声かけと事前察知を具体化 |
| 他スタッフにも喜んでもらう | 多機力の2方向として残す（1007の続き） |
| AI壁打ちの材料 | 一般論と多機力固有を分けて並べ替える |

- 「多機力に共感していれば、自分の行動だけでなく他の人に意識を向けられる」は方向として近い。ただし、教える理由の並びが一般論だと、読み手に伝わらない。
- 気配りは「お客様から声がかかる前に、求めていることに気づいて動く」。挨拶（歓迎）とセットで、喜んでもらう具体になる。

## ■改善内容（What）

### 0. 今回の直しどころ（全体像）

```
【そのままOK】
・全体の1本化・枝の削減
・感情が安定している理由の箱

【直す】
・多機力共感の「なぜ教えるか」の並びと見出し
・一般的な寄り添い教育を、多機力の核（喜んでもらう）の下に置く
```

### 1. 多機力：推奨の並び（3つに寄せる）

出だしで「できるようになるまで一緒に考える／教える」は、短く前提として置いてよい。  
そのあと、**他店と違うところ＝常にお客様（と仲間）に喜んでもらうため**に寄せる。

```
【なぜ、多機力の考え方に共感している人でないといけないか】

（前提・短く）
失敗したときは、どこで間違えたか・何が難しかったかを確認し、
できるようになるまで一緒に考える。ここまではどの店でも大事。

（多機力だから足すこと）
この店では、仕事のやり方だけでなく、
「どうすればお客様に喜んでもらえるか」まで教える。
もっと言えば、一緒に働くスタッフにも喜んでもらえるかを考える。

そのために、次のような教え方になる。
```

おすすめの3項目（並び）：

| 順 | 見出しの例 | 中身のポイント |
|---|---|---|
| 1 | やり方だけでなく、喜んでもらう理由まで教える | 手順の先にある「なぜ喜ばれるか」を教える。多機力の入口 |
| 2 | 歓迎の気持ち・声かけ・気配りを教える | 挨拶で歓迎を伝える。お客様が求めることを事前に察知し、声をかける前に動く |
| 3 | （必要なら）仲間にも喜んでもらう視点 | 自分の行動だけでなく、他スタッフの場に立つ。1007の従業員側 |

3番を「できるようになるまで一緒に考える」に戻すより、**喜んでもらう（お客様＋仲間）**側に寄せた方が、多機力とマッチする。  
どうまとめるかは壁打ちしてよいが、一般論だけが残らないようにする。

### 2. 気配り・声かけの具体（見出しに載せる）

```
【歓迎・声かけ】
・歓迎の気持ちで接する／挨拶で喜んでもらう声かけ

【気配り】
・お客様が求めていることを事前に察知する
・お客様から声がかかる前に気づいて動く
```

「気配りを教えるため」だけだと抽象。見出しか直後に、上記の具体が入っていると、多機力が映像になる。

### 3. 一般論と多機力固有の切り分け

| 一般的（どの店でも言えそう） | 多機力固有に近い |
|---|---|
| できるようになるまで寄り添う | 喜んでもらう理由まで教える |
| もう一度一緒にやってみよう | 歓迎の挨拶・声かけ |
| 失敗の確認とやり直し | 事前察知の気配り／仲間への意識 |

一般論は消さなくてよい。**先頭と見出しを多機力固有にする**。

### 4. 提出前の自己チェック（この回用）

```
・全体は1本化のままで読みやすいか（今回OK寄り）
・感情安定の箱は触りすぎていないか
・多機力の先頭は「喜んでもらう理由／声かけ／気配り」か
・「できるようになるまで」が多機力の唯一の理由になっていないか
・お客様＋一緒に働く仲間の2方向が残っているか（1007）
・この箱だけ音読して、「多機力だから」が伝わるか
```

---

## ■改善理由（Why）

- 1013の「枝を減らす」は反映できている。次は中身のラベルが、条件名（多機力）と一致しているかを見る段階。
- 「寄り添って教える」だけでは、多機力に共感している必要性の証明にならない。読み手は「いい人なら誰でもよい」と感じる。
- 多機力の定義（喜んでもらうために力をつける／合わせる）を、教える内容の並びそのものに落とすと、共感条件が人選理由になる。
- 1007で指摘した「お客様＋従業員の2方向」は、今回の多機力箱で回収するチャンス。お客様側の理由・気配りを厚くしつつ、仲間側も落とさない。
- 感情安定の箱はすでに因果が通っているので、いじらない。直しどころを多機力に絞ると、提出の負荷が下がる。

---

## ■改善後イメージ（After）

読み手が次の順で理解できる状態。

```
1. 全体は1本で読みやすい（枝が少ない）
2. 多機力共感の箱を開くと、まず「喜んでもらう理由まで教える」が見える
3. 声かけ・歓迎・気配り（事前察知）が具体で続く
4. 一緒に働く仲間への意識も、多機力の一部として残っている
5. 「できるようになるまで」は前提か後ろで、多機力の顔になっていない
6. 感情安定の箱は前回どおり通る
```

音読して、「なぜ多機力に共感している人か？」で止まらない。

---

## ■やりがちなミス

- 多機力の理由を「できるようになるまで寄り添う」だけで終わる
- 喜んでもらう理由・気配りを後ろに置き、一般論が先頭のまま
- 気配りを「気配り」の一語で止め、事前察知・声かけ前の行動を書かない
- お客様側だけ厚くして、一緒に働く仲間側を消す（1007の繰り返し）
- 感情安定までいじって、通っていた因果を崩す
- AIの一般的な教育論を、読まずに多機力の理由として貼る
- 1013で減らした枝を、多機力箱の中でまた細分化しすぎる

## ■他の案件でも使えるパターン

### パターンA：条件名と「教える中身」を一致させる

```
条件の定義（例：多機力＝喜んでもらうために力をつける）
　↓
だから、教える中身もその定義に沿う
　↓
一般的な良い教え方だけでは、その条件の証明にならない
```

### パターンB：一般論は前提、固有は先頭

どの店でも言えることは短く前提に置く。  
その店・その考え方固有の理由を、見出しの1番目にする。

### パターンC：抽象語の直後に映像を置く

| 抽象 | 映像の例 |
|---|---|
| 気配り | 声がかかる前に動く／求めを察知する |
| 歓迎 | 挨拶で歓迎の気持ちを伝える |
| 寄り添い | （一般論になりやすいので、条件名とセットで使う） |

### パターンD：2方向の条件は片方で終わらせない

お客様側を厚くしたら、同僚・仲間側が消えていないか最後に一度見る（多機力・チーム系の条件）。

## ■1013・1007との関係

- 1007：多機力はお客様＋従業員の2方向。ゴキゲンと人と関わる楽しさは別路線。事例の質と結果まで。
- 1013：全ポジ・共感・専属を因果一本／まとめと対比。枝を減らす。
- 今回：枝減らしは反映済み。多機力箱の中身を、定義（喜んでもらう）に合わせて並べ替え。感情安定はOK。
- 引き継ぐこと：1013の1本化は崩さない。1007の2方向（お客様＋仲間）を多機力で回収する。
- 次の提出で見たいもの：多機力の先頭が「喜んでもらう理由／声かけ・気配り」になっていること。一般の寄り添いが顔になっていないこと。
