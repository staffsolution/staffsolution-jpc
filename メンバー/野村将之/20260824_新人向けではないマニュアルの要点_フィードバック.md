# 新人向けではないマニュアルの要点（フィードバック）

## ■分類（タグ）

- 自社リサーチ・情報整理
- マニュアルの位置づけ（新人用ではなくトレーナー用）
- マニュアルに教えさせる教育 vs トレーナーが教える教育
- 教育基準の揃え方
- 「マニュアルがある」という思い込みの先回り
- 教えるために学ぶ深さ
- 0811・0728の続き

---

## ■現状（Before）

- 0811で整理した「人に依存する教育 vs 基準がある教育」の続き。マニュアルを「新人が読む教材」ではなく、「トレーナーの教え方を揃える教育基準」に位置づける気づきが出ている。方向は正しい。
- 一方で、求職者・読み手には「マニュアルがあります」＝「新人がそれを読む」という思い込みが強い。気づきだけでは伝わらず、**その思い込みを崩す比較**が必要。
- いまの分け方が「マニュアルがないケース／あるケース」だと、しっくりこない。差の本質が「有無」になってしまう。
- 「マニュアルに教育を任せることではない」と書くと、読み手は「新人がマニュアルを読んでもいいのでは？」と受け止めやすい。意図と結果がずれやすい。

---

## ■問題の本質（重要）

- 「マニュアルがある」だけでは差別化にならない。多くの店でもマニュアルはある。差は、**誰のためのマニュアルか／誰がそれを使って教えるか**。
- 新人向けマニュアル（見て覚えてね）と、トレーナー向けマニュアル（これを覚えて、これで教えろ）では、学びの深さが違う。人に教える前提だと、間違った覚え方が許されず、教えながら訂正もできる。新人はそこまでの気持ちで読まない。
- だから比較軸は「ある／ない」ではなく、次のどちらかに寄せる。

推奨の比較軸：

```
マニュアルに教えさせる教育
　（新人にマニュアルを渡して覚えさせる）
　　↓ ではなく
トレーナーが教える教育
　（トレーナーがマニュアル＝教育基準を身につけ、それで教える）
```

これで、「マニュアルがあるから基準が揃います」というありがちな説明から一段抜けられる。

---

## ■ズレ（思考 or 設計）

- **気づき（トレーナー用）は正しいが、比較の切り口がまだ「有無」寄り**になっている。
- 「マニュアルに任せない」だけだと、否定が先立ち、**何が違うのか**が見えにくい。
- 0811の「人に依存 vs 基準がある」は残しつつ、今回はさらに一段具体化して、**基準の担い手がトレーナーであること**を比較の正面に出す段階。

---

## ■改善内容（What）

### 1. 比較軸を「有無」から「誰のためのマニュアルか」へ替える

| しっくりこない分け方 | 伝わりやすい分け方 |
|---|---|
| マニュアルがない／ある | 新人のためのマニュアル／トレーナーのためのマニュアル |
| （結果）ある店は多い、差が見えない | （結果）教え方の揃え方と学びの深さが違う |

多くの店との明確な違いとして書くなら、次の言い方が軸になる。

```
新人さんのためのマニュアルに教育を任せることではなく、
トレーナーのためのマニュアルになっている
```

続けて因果を出す。

```
トレーナーによって教える内容や基準が変わらないように
マニュアルで教育の基準を揃えている
```

### 2. 伝え方のベースは「2種類のマニュアルの差」

同じ「マニュアル」でも、使い方が違うことを先に見せる。

| 新人のためのマニュアル | トレーナーのためのマニュアル |
|---|---|
| 「これを見て覚えてね」 | 「これをしっかり覚えて、これをもとに新人に教える」 |
| 読む側の本気度が上がりにくい | 人に教えるために学ぶので、インプットが深くなる |
| 間違いに気づきにくい | 教えながら間違いに気づき、訂正できる |
| 教育が教材任せになりやすい | 教育の主体はトレーナー、マニュアルは基準 |

「マニュアルに教えさせる教育」が一般的だと読者に先に言ったうえで、「そうではない＝トレーナーが教える教育」と対比する。

### 3. 見出し・軸の候補（0811からの微調整）

0811の「教育基準があると新人が迷わない」は残してよい。今回足すのは、基準の運用主体。

候補：

```
マニュアルに教えさせる教育ではなく、
トレーナーが教える教育
```

または、0811の軸を維持しつつ本文で上記の差を先出しする。

「人に依存する教育 vs 基準がある教育」から少し変えるなら、**マニュアルに教えさせる／トレーナーが教える**の方がしっくりくる、というフィードバックどおりでよい。

### 4. XMind用（親子関係がわかる形）

```
マニュアルに教えさせる教育か、トレーナーが教える教育か
├ マニュアルに教えさせる教育（新人用マニュアル）
│  ├ 見て覚えてね、で終わりやすい
│  ├ 新人はそこまでの本気で読まない
│  └ 教える人・内容がぶれやすい／教材任せになる
│
└ トレーナーが教える教育（トレーナー用マニュアル）
   ├ トレーナーが教育基準を身につける
   ├ 人に教える前提で深く覚える／教えながら訂正できる
   ├ トレーナーによって内容・基準が変わらない
   └ 新人が迷わず仕事を覚えられる
```

### 5. 書いてはいけない短い飛び

| NG | OK |
|---|---|
| マニュアルがあるから基準が揃う | トレーナー用マニュアルで教え方の基準を揃えている |
| マニュアルに教育を任せない（だけ） | 任せない＋代わりにトレーナーが基準どおり教える |
| 新人もマニュアルを読む（主役） | 新人は確認程度。主役はトレーナーの教え方 |

---

## ■改善理由（Why）

- 「マニュアルがあります」は業界で聞き飽きた主張。差が出るのは**誰が・何のために使うか**。
- 新人用とトレーナー用の差を先に出すと、読み手の思い込み（＝新人が読むもの）を壊せる。
- 「人に教えるために学ぶ」は、基準が現場で守られる理由の説明にもなる。抽象の「基準がある」より具体。
- 0811の「トレーナーが同じ基準で教える」を、今回は比較コピーの正面に据える段階。

---

## ■改善後イメージ（After）

- 「マニュアルの有無」ではなく、「新人用かトレーナー用か」で差が一目でわかる。
- 多くの店の「マニュアルに教えさせる」との対比が先に立ち、自社は「トレーナーが教える」と読める。
- 「マニュアルに任せない」が否定だけで終わらず、トレーナーが基準どおり教える姿までつながっている。
- 「マニュアルがあるから揃う」というありがち説明から抜けている。
- 0811の因果（基準 → 教え方が揃う → 新人が迷わない）が、比較の切り口と一致している。

---

## ■やりがちなミス

- 気づきはトレーナー用なのに、比較がまた「ある／ない」に戻る。
- 「マニュアルに任せない」と否定だけ書いて、代替（トレーナーが教える）を薄くする。
- 新人も読む前提を主役に戻し、トレーナー用の差が消える。
- 「基準が揃う」で終わり、「人に教えるために深く学ぶ」までの理由を飛ばす。
- 0811の良い因果を捨てて、ゼロから別ストーリーを書き直す。

---

## ■他の案件でも使えるパターン

- 「〇〇があります」は思い込みが強い。**誰のための〇〇か**を比較の軸にする。
- 教材・マニュアル訴求は、有無より**運用主体（誰が使って誰に教えるか）**で差を出す。
- 否定（〜ではない）のあとに、必ず代替の仕組みを同じ長さで置く。
- 「教える側の学びの深さ」は、品質・ばらつき抑制の説得材料になる。
- 前回決めた因果が正しいときは消さず、**比較の切り口だけ一段具体化する**。

---

## ■一言まとめ（本質）

👉 **マニュアルの差は「ある／ない」ではなく「新人用かトレーナー用か」。マニュアルに教えさせる教育ではなく、トレーナーが教育基準を身につけて教える。その差を先に見せる。**

---

## ■0811・0728との関係

- **0728**：人に依存 vs 基準がある。マニュアルの有無ではなく設計思想と運用を見せる。
- **0811**：基準の核は「トレーナー全員が同じ基準を守る」。形式（紙／動画）は主役にしない。
- **今回**：その核を、比較コピーとして「新人用マニュアル／トレーナー用マニュアル」「マニュアルに教えさせる／トレーナーが教える」まで落とす。0811の因果は維持し、切り口を具体化する。
