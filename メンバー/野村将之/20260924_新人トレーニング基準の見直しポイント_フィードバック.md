## ■現状（Before）

- 0919で、条件のあとに「なぜなら」を足す方向が出た。今回の提出は、その理由を書き始めている。方向は合っている。
- 冒頭の経緯は使える。店舗展開を始めた2000年頃、トレーナーを増やしすぎ、片手間になって失敗した。時給が上がり始めた2023年、時給は上がったのにサービスが劣化したので、原因の一つである新人トレーニングを今の形にし始めた。この流れは残してよい。
- 足りないのは、箱の順番と、重なっている中身の統合。
- 「全ポジションの仕事がマニュアルに沿ってできる」のなぜは出始めている。ポジション間のつながり、やり方だけでなく目的、までは書けている。まだ、「ホール希望にはホール担当、キッチン希望にはキッチン担当、と分けて教えれば足りるのでは？」への答えが弱い。
- お店の考え方への共感は出ている。ただし、それがすべての作業のベースだ、という位置が先頭に来ていない。
- 「いつもゴキゲンで人と接するのが好き」は情報量が多い。不機嫌で人と接するのが苦手な場合と比べる形になっていない。
- 「仕事を教えるだけでなく、新人が成長できる環境を作る人」は、ゴキゲンの箱に含められるのに、別の条件として立っている。
- 本部マネージャー全員のOKは出ている。何人いるのかが無い。
- 見出しが「人選と育成」になっている。実際の流れは、先に育てて、そのうえで適性を見て選ぶ。
- 最初から最後まで専属、が、全ポジション必須の理由としてつながっていない。
- 正社員でなければなれないのか、アルバイトでもなれるのかが無い。
- 全ポジションができるようになるまでの期間と、そこまでの指導の仕方が無い。
- 過去に起きた具体的な問題、その都度直したこと、今はその問題がなくなったこと、が薄い。

## ■問題の本質（重要）

基準の説得力は、条件の数ではなく順番で決まる。

今回の箱は、次の4段がこの順でつながると一本になる。

1. **大前提** … お店の考え方に共感している。正社員として入った人は、ほぼここが揃う。
2. **育成** … 全ポジションの仕事を、マニュアルに沿ってできるようにする。ここは時間がかかる。
3. **人選** … その中で、感情が安定していて、人と接するのが好きな人を選ぶ。これは性格に寄るので、見て判断する。
4. **関門** … 本部マネージャーは3人。全員のOKが出ないとトレーナーになれない。

「なぜ全ポジションか」の核は、役割分担できるのでは、という読み手の疑問を先に潰すこと。

潰す材料は、すでに別の箱にある。

- 最初から最後まで、専属の担当がつく
- だから、ホールだけ・キッチンだけでは、その一人が見きれない
- ポジション間のつながりを教えられる
- マニュアルのやり方だけでなく、目的まで伝えられる
- その目的の土台が、お店の考え方への共感である

条件を横に並べたままだと、同じ話が人選・育成・専属に分散する。  
育成してから選ぶ、という一本にまとめると、重複が減って理由が通る。

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| なぜ全ポジションかを伝えたい | つながりと目的は出ているが、「分けて教えればよいのでは」への答えが弱い |
| 専属だから全ポジが必要、とつなげたい | 専属の箱と、全ポジのなぜが離れている |
| 考え方への共感を重視したい | 理念がすべての作業のベース、という位置が先頭に来ていない |
| いつもゴキゲンの理由を厚くしたい | 情報が多く、不機嫌な場合との比較になっていない |
| 成長できる環境を作る人、と定義したい | ゴキゲンの中身と重複した別条件になっている |
| 全員のOKが関門だと伝えたい | 本部マネージャーが3人、という数が無いので関門の重みが薄い |
| 人選と育成の両方を見せたい | 見出しが人選先行で、育ててから選ぶ流れになっていない |
| 基準を揃えてきた実績を見せたい | 過去の具体問題 → 直した → 今はない、まで落ちていない |

0919の「条件のあとになぜ」は維持。今回は、そのなぜを増やす段階ではなく、順番を入れ替えて重なりを1本にする段階。

## ■改善内容（What）

### 0. 今回の直しどころ（全体像）

```
【維持（OK方向）】
・2000年頃の失敗 → 2023年のサービス劣化をきっかけに、今の形にした経緯
・全ポジションはマニュアルに沿ってできる
・お店の考え方への共感
・いつもゴキゲンで人と接するのが好き
・本部マネージャー全員のOK
・最初から最後まで専属

【直す（今回の本題）】
・並びを「共感 → 育成 → 人選 → 関門」にする
・全ポジのなぜに「分けて教えればよいのでは」への答えを入れる
・専属を、全ポジ必須の理由側へ移す
・ゴキゲンは比較で短く。成長環境の定義はここに含める
・本部は3人、と数を書く
・正社員か、アルバイトでもなれるかを明示する
・習得までの期間と、指導の仕方を入れる
・過去の具体問題 → 修正 → 今はない、を1段落足す
```

### 1. 冒頭の経緯は残す

次の2点は、このまま使ってよい。

```
店舗展開を始めた2000年頃
　トレーナーを増やしすぎた
　どちらかというと片手間だった
　↓
失敗が多かった

時給が上がり始めた2023年
　時給は上がった
　サービスは劣化した
　↓
原因の一つが新人トレーニングだった
　↓
今の形で取り組み始めた
```

このあとに、今の形の中身（共感 → 育成 → 人選）へ入る。

### 2. 大前提：お店の考え方に共感している

最初の関門は、技術ではなく共感。

```
お店が大事にしている考え方がある
　↓
それが、すべての作業・ルール・教え方のベースになっている
　↓
ここに共感していないトレーナーが教えると
　やり方は真似できても、判断が違う方向に行く
　↓
だから、トレーナーの前に、この共感が大前提
```

具体が1つあると通りやすい。考え方に沿っていない教え方をしていたとき、現場で何が起きたか。短い事例でよい。

正社員かアルバイトかも、ここで明示する。

```
正社員として入った人は
　ほぼ全員が、同じ考え方で動けるようになっていく
　↓
ここは大前提として、まずクリアしてほしいライン

（アルバイトもトレーナーになれるのかは、事実を1文で書く）
```

共感していない人がトレーナーになると判断がずれる、まで書けていれば、この箱は厚くしなくてよい。

### 3. 育成：なぜ全ポジションか

読み手が先に思う反論を、本文の前に置く。

```
ホール希望の新人には、ホールができる人
キッチン希望の新人には、キッチンができる人
それぞれの道の人に分けて教えれば足りるのでは？
```

そのうえで、分けない理由をこの順で書く。

```
新人には、最初から最後まで専属の担当がつく
　↓
一人のトレーナーが、ホールもキッチンも見る
　↓
だから、1ポジションの専門では見きれない

加えて
　ポジション間のつながりを教えられる
　マニュアルのやり方だけでなく、目的まで伝えられる
　その目的は、お店の考え方に沿っている
```

専属の説明は、ここで使い切ってよい。別見出しで繰り返さない。

育成の中に、次の2つを足す。

- 全ポジションがマニュアルに沿ってできるようになるまで、どのくらいの期間がかかるか
- できるようになるまで、どのように指導しているか

過去の問題は、この近くに1段落で置く。

```
以前、こういう問題が起きていた（具体を2〜3個）
　↓
その都度、教え方と基準を直した
　↓
今は、その問題はなくなっている
```

「失敗が多かった」で止めず、何が起きて、何を直して、今はどうなったかまで落とす。

### 4. 人選：いつもゴキゲンは比較で短く

情報量は今より減らしてよい。比較の型にする。

| | 感情が安定していない人 | いつもゴキゲンで、人と接するのが好きな人 |
|---|---|---|
| 新人の意識 | 教わる内容より、機嫌を損ねない動きになる | 安心して、話の内容を聞ける |
| 表情・空気 | 険しい、ピリピリしている | 安定して、優しく接する |
| 習得 | 感情のほうが強く、内容が頭に入りにくい | スムーズに習得していく |
| 結果 | 成長できる環境にならない | 成長できる環境になる |

「仕事を教えるだけでなく、新人が成長できる環境を作る人」は、右列の結果に含める。別条件にしない。

性格の話だと、ここで一文足す。

```
ここは技術の習得と違い、性格に寄る
　↓
感情の波がある人は、トレーナーには選定しにくい
　↓
働いている様子を見て、感情が安定している人を選んでいる
```

### 5. 関門：本部マネージャーは3人

「全員のOK」の前に、人数を置く。

```
本部マネージャーは3人しかいない
　↓
3人全員のOKが出ないと、トレーナーになれない
　↓
だから、各店でトレーナーになれる人数は絞られる
```

3人、と書けば、関門の説明は短くてよい。人数の多さを長文で補わなくてよい。

### 6. 一本の流れ（この順で書く）

```
経緯（2000年頃の失敗 → 2023年から今の形）
　↓
大前提：お店の考え方に共感（正社員ならほぼ揃う／バイト可否は明示）
　↓
育成：全ポジションをマニュアル通りに
　　なぜ分けて教えないか（専属で最後まで見るから）
　　つながりと目的まで教える
　　期間と指導の仕方
　　過去の問題は直して、今はない
　↓
人選：感情が安定し、人と接するのが好き（比較で短く）
　↓
関門：本部マネージャー3人全員のOK
```

見出しも「人選と育成」ではなく、「育成してから、人選する」に合わせる。

### 7. マインドマップ用（コピペ）

```
0924：育成 → 人選

├ 経緯
│  ├ 2000年頃：増やしすぎ・片手間で失敗
│  └ 2023年：時給は上がったがサービスが劣化 → 今の形
│
├ 大前提
│  ├ お店の考え方が、すべての作業のベース
│  ├ 共感していないと、判断がずれる
│  └ 正社員はほぼ揃う／バイト可否を明示
│
├ 育成（先）
│  ├ 分けて教えればよいのでは、への答え
│  ├ 専属で最後まで見る → 全ポジが必要
│  ├ つながりと目的
│  ├ 期間・指導の仕方
│  └ 過去の問題 → 修正 → 今はない
│
└ 人選（後）
   ├ 不機嫌 vs ゴキゲン（比較・短く）
   ├ 成長できる環境は、この中に含める
   ├ 性格なので、見て選ぶ
   └ 本部3人全員のOK
```

## ■改善理由（Why）

- 0919で条件ごとの「なぜ」を足す段階まで来た。理由を横に増やすと、専属・全ポジ・ゴキゲン・成長環境が同じ話の繰り返しになる。順番を育成 → 人選にすると、重複が1本に収まる。
- 「分けて教えればよい」を先に置かないと、全ポジションはただ厳しい条件に見える。専属で最後まで見る、が答えになる。
- ゴキゲンを厚く書くほど、読み手は結論を見失う。不機嫌だと内容より機嫌を優先する、安定していると習得が速い、の対比だけで足りる。
- 本部が3人、期間、指導の仕方、正社員かバイトか、は制度名のあとに必要な現場の具体。ここが無いと「揃えている」で止まる。
- 2000年頃と2023年の経緯は、なぜ今の基準があるかの入口としてすでに強い。中身の順番が整えば、その経緯が活きる。

## ■改善後イメージ（After）

- 冒頭で、2000年頃の失敗と2023年のサービス劣化から、今のトレーニングに入っている。
- 最初に、お店の考え方への共感が大前提だと分かる。正社員ならほぼ揃うことと、アルバイトの可否も読める。
- 「分けて教えればよいのでは」のあとに、専属で最後まで見るから全ポジションが必要、と続いている。
- 習得までの期間と指導、過去の問題が今はないこと、が育成の中にある。
- ゴキゲンは、不機嫌な場合との短い比較になっている。成長できる環境は、その結果として読めている。
- 最後に、本部マネージャー3人全員のOKで人数が絞られる。
- 見出しから本文まで、育ててから選ぶ順で通読できる。

## ■やりがちなミス

- 理由を足したあと、人選・育成・専属・成長環境に同じ話を分けたまま残す。
- 見出しを「人選と育成」のままにして、本文だけ育成が先、にする。
- 「全ポジションが必要」を、つながりと目的だけで終える。「分けて教えればよいのでは」を置かない。
- 専属を別箱のまま残し、全ポジションの理由に使わない。
- ゴキゲンの説明を厚くして、不機嫌な場合との比較を入れない。
- 「成長できる環境を作る人」を、ゴキゲンと別に立てる。
- 全員のOKと書きながら、本部が3人だと書かない。
- 正社員かアルバイトかを書かず、共感が誰にでも同じ関門に見える。
- 「失敗が多かった」「問題はなくなった」で止め、何が起きて何を直したかを書かない。
- 期間と指導の仕方を、育成の外に置く。

## ■他の案件でも使えるパターン

- 条件が3つ以上あるときは、増やす前に順番を決める。大前提 → 時間のかかる習得 → 見て選ぶ適性 → 人数の関門。
- 厳しい条件の前に、読み手の「分けてやればよいのでは」を1行置く。その答えが、別箱にあることが多い。
- 同じ意味の箱は統合する。定義（成長できる環境）は、比較の結果側に入れる。
- 比較で足りる話は、表か対比の2列で短くする。情報量を増やすほど、理由はぼやける。
- 関門は人数を先に書く。「全員」だけだと、何人中の全員か分からない。
- 経緯（昔失敗した → ある年から変えた）は入口に残す。中身の順番が整ってから、その経緯が効く。

## ■一言まとめ（本質）

👉 **トレーナー基準は、条件を増やす話ではない。お店の考え方への共感を大前提に、全ポジションを育ててから、感情が安定している人を選ぶ。専属で最後まで見るから全ポジションが必要で、本部3人全員のOKが最後の関門。重なっている箱は、この一本にまとめる。**

## ■0919との関係

- **0919**：条件ごとのなぜ、全ポジションは教えられるレベル、専属は関係性ではなく教え方のニュアンス、本部全員のOK。今回は、その材料の順番を変える。なぜを新たに増やすより、育成 → 人選に並べ替え、専属を全ポジの理由へ移し、ゴキゲンは比較で短くする。
- **0914**：誰でもなれないを前へ、人数制限、最初から最後まで専属。今回の「専属だから全ポジション」は、0914の専属を理由側に使う続き。
- **0905**：マニュアルはトレーナーの教育基準。今回の「マニュアルに沿って全ポジション」は、その定義を育成の順番の中に置く続き。
