## ■分類（タグ）

- 自社リサーチ・情報整理
- 一般（個人店）vs 当社の比較
- 見出し＝本文の集約
- 本文を読まずに差が伝わる見出し
- 「覚えること多い／構造化」など硬い見出しの修正
- 分業しているか／していないか、の差の明示
- 1026の続き（他喜力挨拶は固定。今回は比較箱の見出し）

---

## ■現状（Before）

- 一般と当社（基本は個人店のラーメン屋 vs 当社）を、比較の形で情報整理している段階。
- 「一般／当社のまとめ」側に、本文の中身を集約した一言が入っていない。
- そのため、パッと見たときに「何の差の箱か」が一瞬で伝わらない。
- 「フィードバックお願いします」付近の見出し例として、「覚えることは多い」「構造化負担を減らした構造化の違い」などが挙がっているが、**硬い／抽象的**で、本文の実際の差（分業しているか・していないか、など）とずれやすい。
- 比較の材料自体は並んでいる。今回の直しどころは、中身の追加より**見出しの役割**。

---

## ■問題の本質（重要）

自社リサーチの比較箱では、見出しの役割は次の1つ。

```
見出しを見ただけで、一般と当社の差が分かる
　＝ 本文を読まなくても内容が把握できる
　＝ まとめ欄に、本文の集約が入っている
```

見出しが「覚えることが多い」「構造化の違い」のように硬いと、読み手（と後から自分で見返す自分）は、**どの差の箱か**を本文まで降りるまで分からない。  
情報整理の段階では、見出し＝ラベル。ラベルが抽象だと、箱が増えるほど迷子になる。

---

## ■ズレ（思考 or 設計）

| いま起きやすいこと | あるべき状態 |
|---|---|
| 見出しが抽象・硬い言葉（覚える／構造化） | 見出しが本文の差の集約（例：分業している／していない） |
| まとめ欄が空、または一般論のまま | 一般と当社の差が、まとめ一行で見える |
| 本文を読まないと箱の意味が分からない | 見出しだけでも比較の軸が伝わる |

- 比較の骨格（一般 vs 当社）自体は合っている。ズレは**見出しが本文に沿っていない**こと。
- 「構造化」などの専門っぽい語は、差の映像になっていないと、かえって箱を読みにくくする。

---

## ■改善内容（What）

### 0. 今回やること（優先）

```
【直す】
・一般／当社の比較見出しを、本文の内容に沿って書き換える
・まとめ（見出し側）に、本文の集約を入れる

【触らない】
・1026で通った他喜力挨拶箱
・比較の骨格そのもの（一般＝個人店 vs 当社）
```

### 1. 見出しの直し方

本文を先に見て、「この箱の差は何か？」を一言にする。  
今回の感触としては、**分業しているか／分業していないか**の違いが核になりやすい。

**Before（硬い・抽象）の例：**

```
覚えることは多い
構造化負担を減らした構造化の違い
```

**After（本文の集約）の例：**

```
【一般（個人店）】
分業していない／覚える範囲が広い　など（本文どおり）

【当社】
分業している／覚える負担が下がる　など（本文どおり）
```

言い回しは店の実態に合わせる。大事なのは「構造化」という言葉ではなく、**映像になる差**が見出しに出ていること。

### 2. まとめ欄の置き方

一般／当社のまとめの位置に、本文を読んだあとの集約を置く。

```
1. 本文で差を書く（一般側／当社側）
2. その差を1〜2行に圧縮する
3. 圧縮した文を、見出し（まとめ）に入れる
4. 見出しだけ読んで、差が分かるか音読チェック
```

### 3. 提出前の自己チェック（比較見出し）

```
・見出しだけ読んで、一般と当社の差が言えるか
・「構造化」「覚えること」など抽象語だけで止まっていないか
・本文の核（例：分業の有無）が見出しに出ているか
・1026の挨拶箱を触っていないか
```

---

## ■改善理由（Why）

- 自社リサーチは箱が増える。見出しが抽象だと、後から見返しても「何の比較か」が再読コストになる。
- 比較は「ある／ない」や硬い用語より、**行動の差（分業しているか等）**の方が一瞬で伝わる。
- 見出し＝本文の集約、にしておくと、次のコピーや訴求に落とすときも軸がブレにくい。
- 1026で通った箱までいじると因果が崩れる。今回は比較箱の見出しだけに力を使う。

---

## ■改善後イメージ（After）

```
1. 比較の見出しを見る
2. 本文を読まなくても、「一般はこう／当社はこう」が分かる
3. 硬い抽象語ではなく、分業などの差がラベルになっている
4. 自社リサーチの段階でも、情報整理がしやすくなる
```

音読して、「この見出しは何の箱？」で止まらない状態。

---

## ■やりがちなミス

- 「構造化」「負担軽減」など、正しそうな抽象語を見出しに残す
- 本文は分業の話なのに、見出しだけ別テーマの言葉になる
- まとめ欄を空のままにして、差を本文の奥にしか書かない
- 見出しを長くしすぎて、一目で入らなくなる
- 通った他喜力挨拶箱まで一緒にいじる
- 一般＝個人店、という前提を曖昧にして比較軸がぼやける

---

## ■他の案件でも使えるパターン

### パターンA：見出し＝本文の圧縮

```
本文で差を書く
　↓
差を1行に圧縮する
　↓
その1行を見出し（まとめ）にする
```

### パターンB：抽象語を行動の差に置き換える

```
構造化の違い
　↓
分業している／していない（など、映像になる差）
```

### パターンC：見出しだけで比較が成立するかチェック

提出前に、本文を隠して見出しだけ読む。  
「一般と当社、何が違う箱？」と答えられなければ、見出しを直す。

---

## ■一言まとめ（本質）

👉 一般／当社の比較は、見出しに本文の集約を入れる。硬い抽象見出しではなく、分業などの差が一目で分かるラベルにして、本文を読まなくても内容が把握できる状態にする。

---

## ■1026・1022との関係

- 1022：他喜力を一般の寄り添いから切り離し、喜んでもらう理由を先頭へ。
- 1026：歓迎の挨拶箱が「喜んでもらうための心込め」で承認。その箱は固定。
- 今回：比較箱の見出しが本文に沿っていない／抽象で硬い。まとめに集約を入れて一目で差が分かるようにする。
- 引き継ぐこと：挨拶箱は触らない。ゴキゲン分離・他喜力2方向・関門の結果など未解消の幹は、見出し調整と別に継続確認。
