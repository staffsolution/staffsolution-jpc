2026年11月24日

---

## ■分類（タグ）

- 自社リサーチ・身だしなみ記載
- ネイル・ピアスへの軸絞り（1116の続き）
- 「どこまでがOKか」の具体
- 求人傾向（髪型・髪色・ネイル・ピアスOKの応募上位）との接続
- 学生など見た目を重視する読み手
- 今回は承認（バッチリ／次へ進めてよい）

---

## ■現状（Before）

- 1116で指示した「実際に多い制限（ネイル・ピアス）へ絞る」「どこまでOKかを具体にする」方向の提出。
- 提出側の経緯：一般との違いが出にくく、身だしなみを手前に置くか迷っていた。一方で、いま出ている求人傾向では、髪型・髪色・ネイル・ピアスOKの原稿の応募が上位に来るため、深掘りしている、という説明。
- 読み手（学生など）は見た目を重視する人が多い、という前提とも合う。
- 枝はネイルとピアスに絞られている。
- ひと通り読んだ結果、**この箱はバッチリ**。「どこまでがOKなのか」まで書いてある点が特に強い。
- 結論として、この箱は直すところがない。次の項目へ進めてよい。

---

## ■問題の本質（重要）

今回は「直しどころ」ではなく、**なぜこの箱が通ったか**を残す回。

```
身だしなみを「全部語る」
　＝ 髪型・髪色・ネイル・ピアスを同列に並べる
　↓
実際に多い制限へ絞る
　＝ ネイル・ピアス（1116の指示）
　↓
さらに「どこまでがOKか」まで書く
　＝ 読み手が自分の状態と照合できる
　↓
だから求人で見た目を気にする層に刺さる比較になる
```

「ネイルOKです」だけでは弱い。  
**どこまでOKか**まで落ちると、求職者が自分ごとで判断できる。

一般との差が出にくい題材でも、**実態の多い軸＋具体の境界**があれば、記載する価値がある。応募上位の傾向とも一致する。

---

## ■ズレ（思考 or 設計）

| 取れている | 今回の扱い |
|---|---|
| ネイル・ピアスへの軸絞り（1116） | このまま維持 |
| 「どこまでがOKか」の具体 | このまま維持（特に強い点） |
| 求人傾向・見た目重視の読み手との接続 | 記載する判断の根拠としてよい |
| 1116で指摘した「全部同列」 | この箱では解消されている |
| 教育比較の結果載せ・ゴキゲン分離など他箱 | まだ未着手／継続確認。次の提出で見る |

- 今回の箱に、直しのためのズレはほぼない。
- ズレがあるとすれば、**この通った書き方を次の箱で崩すこと**（また全部同列に戻す／OKの境界を抽象に戻す／通った箱までいじる）。

---

## ■改善内容（What）

### 0. 今回の結論

```
【直す】なし（この箱はバッチリ）

【進める】
・次の項目を続けて提出する

【崩さない】
・ネイル・ピアスへの軸絞り
・「どこまでがOKか」の具体
```

### 1. この箱で残す骨格（次回以降の見本）

```
【身だしなみ】

・全部を同列に語らない（多い制限へ絞る）
・ネイル／ピアスなど、実際に多い軸
・「OKです」で止めず、どこまでがOKかを書く
・求職者が自分の状態と照合できる境界がある
```

読み手が「身だしなみに寛容」で止まらず、「自分は応募してよいか」まで届く。

### 2. 次の提出で見るもの（この箱以外）

1116・1106から引き継いで、まだ残っている幹は次。

| 優先 | 確認すること |
|---|---|
| 高 | 残りの教育比較（理解前に現場／現場任せ／人に依存）に、一般側と当社側の結果が入っているか |
| 高 | 「いつもゴキゲン」と「人と関わることを楽しむ」を分けているか |
| 高 | 他喜力の2方向（お客様＋一緒に働く仲間）が消えていないか |
| 中 | 関門・修正のあとに、新人側の結果まで落ちているか |
| 中 | 事例が「経験しないと分からない」話になっているか |

身だしなみ箱は触らなくてよい。他箱を同じ密度で揃える。

### 3. 提出前の自己チェック（身だしなみ系を触るとき）

```
・制限を全部同列に戻していないか
・「OK」のあとに、どこまでOKかの境界があるか
・読み手が自分のネイル／ピアスと照合できるか
・この箱だけ音読して、「自分は応募してよいか」で止まらないか
```

---

## ■改善理由（Why）

- 1116の本題は、身だしなみを実態の多い制限へ寄せ、宣言だけで終わらせないことだった。今回は軸絞りと「どこまでOKか」が通っている。
- 見た目を重視する層（学生など）には、「寛容です」より**境界の具体**の方が判断材料になる。
- 一般との差が出にくい題材でも、求人傾向で応募上位に来る事実があるなら、記載する判断は妥当。迷って消すより、多い軸＋具体で残す方がよい。
- 通った箱までいじると、因果が崩れることがある。承認した箱は固定し、未解消の箱に力を使う。

---

## ■改善後イメージ（After）

いまの状態が、すでにAfterに近い。

```
1. 身だしなみ箱を開くと、ネイル・ピアスに絞られている
2. 「どこまでがOKか」まで書いてあり、照合できる
3. 全部同列の羅列に戻っていない
4. この箱は直さず、他の項目へ進む
```

音読して、「自分は応募してよいか？」で止まらない。

---

## ■やりがちなミス

- 通った身だしなみ箱を、次の提出で髪型・髪色まで全部同列に戻す
- 「ネイルOK」だけ残し、「どこまでOKか」の境界を削る
- 一般との差が出にくいからといって、箱ごと消す
- 承認された箱まで手を入れ、通っていた具体を崩す
- 次の箱で、また「ある／ない」だけで止め、境界の具体を書かない

---

## ■他の案件でも使えるパターン

### パターンA：多い事実へ軸を寄せる

```
思いつく制限を全部並べない
　↓
実際に多い制限（例：ネイル・ピアス）に絞る
　↓
差が一瞬で立つ
```

### パターンB：許可は「境界」まで書く

```
OKです、だけでは弱い
　↓
どこまでがOKか（長さ・色・場所など）を書く
　↓
読み手が自分ごとで判断できる
```

### パターンC：通った箱は固定し、未解消だけ触る

一度「バッチリ」になった箱は触らない。  
力は、まだ結果や境界が足りない箱に使う。

👉 **身だしなみ箱はネイル・ピアスへの絞りと「どこまでがOKか」の具体で通った。この箱は直さず次へ進む。承認した書き方を崩さない。**

## ■1116・1106・1026との関係

- **1116**：多い制限へ絞る／スタンスのなぜ／髪色は実態で、が指示。**今回**はその続きで、軸絞りとOKの境界が通って承認。
- **1106**：分業の教育比較は承認済み。残りの教育比較へ結果を載せる宿題は、この箱とは分けて継続。
- **1026**：歓迎の挨拶箱は承認済み。触らない。
- **今回**：身だしなみ箱はバッチリ。次の項目へ進めてよい。
- 引き継ぐこと：教育比較の結果載せ、ゴキゲン分離、他喜力2方向、関門の結果など未解消の幹は、この箱の修正と分けて継続確認。
