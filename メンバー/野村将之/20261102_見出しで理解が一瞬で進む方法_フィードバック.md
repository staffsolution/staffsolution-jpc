## ■分類（タグ）

- 自社リサーチ・情報整理
- 個人店 vs 当社の比較見出し
- 見出し＝本文の集約（1028の続き）
- 問題（個人店側）＋ベネフィット／結果変化（当社側）を見出しへ
- 「一人でいくつもの仕事を覚えるか」は方向OK。隣のラベルにも同じ厚みを足す
- コピー前の整理段階でも、見出しだけで情報の種類が分かる状態

---

## ■現状（Before）

- 比較の軸として、「一人でいくつもの仕事を覚えるか／分業して一つずつ覚えるか」の見出しは、すでにわかりやすい。
- 一方で、個人店・当社のラベル側には、本文の集約がまだ載っていない箇所がある。
- そのため、軸の見出しは読めても、個人店側で何が起きるか／当社側で何が得られるかが、見出しだけでは一気に入らない。
- 本文にはすでに、次のような材料がある。
  - 個人店寄り：次々と複数の仕事を覚える必要がある → 混乱やミスが起きやすい
  - 当社寄り：一つずつ仕事を覚えてから担当を増やす → 無理なく自信をつけられる
- 材料はある。足りないのは、その材料を見出し（個人店の次／当社の次）に載せること。

---

## ■問題の本質（重要）

見出しの役割は、次の状態をつくること。

```
見出しを読むだけで、本文を読まなくても理解できる
　＝ どの情報の箱かが一瞬で分かる
　＝ 個人店側の問題と、当社側の結果変化が、見出しで対になる
```

比較軸の名前だけがクリアでも、個人店／当社の隣に「何が起きるか／何が得られるか」が入っていないと、読み手は本文まで降りないと差の厚みが分からない。  
自社リサーチの段階でも、見出しだけで整理できる方が次のコピーに渡しやすい。

---

## ■ズレ（思考 or 設計）

| いま起きやすいこと | あるべき状態 |
|---|---|
| 軸の見出しは良いが、個人店／当社の隣が薄い | 個人店の次・当社の次に、本文の集約が入っている |
| 問題だけ／差の名前だけで止まる | 問題（個人店）とベネフィット・結果変化（当社）が対で見える |
| 本文に良い一文があるのに、見出しに上がっていない | 本文の核を見出しへ持ち上げる |
| 「わかりやすい軸名」で完了だと思う | 軸名＋両側の結果まで見出しで揃える |

- 1028で言った「見出し＝本文の集約」の続き。今回は、集約の中身を**問題と結果変化まで**具体にする回。
- ズレは比較の骨格ではない。ラベルの隣の厚み。

---

## ■改善内容（What）

### 0. 今回やること（優先）

```
【直す】
・個人店の次に、本文を集約した問題（混乱・ミスなど）を入れる
・当社の次に、本文を集約した結果変化（無理なく自信など）を入れる
・他の同型の見出しにも、同じ厚みで追加する

【触らない】
・1026で通った他喜力挨拶箱
・比較の骨格（個人店 vs 当社／一人で覚える vs 分業）
・すでにわかりやすい軸見出しの方向性そのもの
```

### 1. 推奨の見出しの載せ方（この箱）

軸はすでに良いので残す。個人店／当社の隣に、本文の集約を足す。

**Before（軸は見えるが、隣が薄い）：**

```
一人でいくつもの仕事を覚えるか／分業して一つずつ覚えるか
・個人店
・当社
```

**After（問題と結果変化まで見出しで見える）：**

```
一人でいくつもの仕事を覚えるか／分業して一つずつ覚えるか

【個人店】
次々と複数の仕事を覚える必要がある
　→ 混乱やミスが起きやすい

【当社】
一つずつ仕事を覚えてから担当を増やす
　→ 無理なく自信をつけられる
```

言い回しは店の実態・本文どおりに合わせてよい。大事なのは次の対。

```
個人店側：一人で覚えることで生じる問題
当社側：分業で一つずつ覚えることで得られるベネフィット（結果変化）
```

### 2. 同じ型を他の見出しにも足す

「こことここにも追加」と指摘されている箇所は、全部同じ考え方。

```
1. 本文の核（問題／結果）を探す
2. 1〜2行に圧縮する
3. 個人店・当社（または一般・当社）の直後に置く
4. 見出しだけ読んで、差が言えるか確認する
```

### 3. 提出前の自己チェック（見出し）

```
・見出しだけ読んで、個人店で何が起きるか言えるか
・見出しだけ読んで、当社で何が得られるか言えるか
・問題とベネフィット（結果変化）が対になっているか
・本文にある良い一文が、見出しに上がっているか
・1026の挨拶箱を触っていないか
```

---

## ■改善理由（Why）

- 見出しで問題と結果変化が分かると、「読みたい」気持ちが先に立つ。コピー前でも情報の種類が一瞬で掴める。
- 個人店側の問題だけ、当社側の良い点だけ、だと対比が半分しか見えない。両方を見出しに上げると一気にわかりやすくなる。
- この「本文を見出しに集約する」型は、コピーライティングに入ってからもそのまま使える。
- 1028で「分業などの差を見出しへ」と出した続き。今回は差の先の問題／ベネフィットまで載せる。

---

## ■改善後イメージ（After）

```
1. 見出しを見る
2. 個人店：複数の仕事を一気に覚える → 混乱・ミス
3. 当社：一つずつ覚えてから担当を増やす → 無理なく自信
4. 本文を読まなくても、差の厚みが分かる
5. 同じ型で他の比較見出しも揃えられる
```

音読して、「個人店はどうで、当社はどうか？」に即答できる状態。

---

## ■やりがちなミス

- 軸の見出しだけ直して、個人店／当社の隣を空のままにする
- 当社側の良いことだけ厚くして、個人店側の問題を載せない（またはその逆）
- 本文にある「混乱やミス」「自信をつけられる」を本文の奥に残したままにする
- 見出しを長くしすぎて、一目で入らなくなる
- 問題と結果の因果（→）を外して、単語だけ並べる
- 通った挨拶箱まで一緒にいじる

---

## ■他の案件でも使えるパターン

### パターンA：軸＋両側の結果を見出しに載せる

```
比較の軸（何の差か）
　↓
悪い側：何が起きるか（問題）
　↓
良い側：何が得られるか（結果変化）
```

### パターンB：本文の核を見出しへ持ち上げる

```
本文に良い一文がある
　↓
1〜2行に圧縮する
　↓
個人店／当社の直後に置く
```

### パターンC：読みたい気持ちを先につくる

```
問題が見える
　＋
結果変化が見える
　＝
本文を読みたくなる見出し
```

自社リサーチでもコピーでも、同じ型で使える。

---

## ■一言まとめ（本質）

👉 「一人で覚えるか／分業か」の軸は良い。個人店の次に問題、当社の次に結果変化を入れ、見出しだけで理解が進む状態にする。本文の集約を見出しへ上げる型は、他の箱にも同じように使う。

---

## ■1028・1026との関係

- 1026：歓迎の挨拶箱が「喜んでもらうための心込め」で承認。その箱は固定。
- 1028：比較見出しを抽象から本文の集約（分業などの差）へ寄せる指示。
- 今回：軸見出しは方向OK。個人店／当社の隣に、問題とベネフィットまで載せて厚みを揃える。
- 引き継ぐこと：挨拶箱は触らない。ゴキゲン分離・他喜力2方向・関門の結果など未解消の幹は、見出し調整と別に継続確認。
