## ■現状（Before）

- 1007で「事例の質・似た条件の切り分け・結果まで」を肉付けする段階に入ったあとの、全ポジション／共感／安定／専属／マニュアル修正まわりの整理提出。
- 全ポジションの理由で、「できないトレーナー／できるトレーナー」に分けて並べている。方向は近いが、読み手への運びとして回り道になっている。
- ホール新人への教え方例（注文を取ったら次のお客様対応をしてね）までは出ている。そのあとの「それだけだと何が起きるか／なぜ起きるか／キッチン未経験だと実感が湧かない」まで深掘りすると、全ポジが必要な理由が一本になる。
- ChatGPT壁打ちで、周りの状況を考えて協力する／なぜそうするかを教える／できない原因を見つけて指導する／忙しいときも優先順位を判断させる、など材料はかなり出た。ここは使える。
- お店の考え方に共感している／していない、安定して人と接する、本部3人OK、マニュアル修正なども、同様に「ある／ない」で枝分かれしやすい。まとめられるものはまとめた方が読みやすい。
- 専属トレーナー一人については、複数トレーナーとの差を残した方がよい。進捗の引き継ぎはできても、その人に合わせた接し方までは引き継ぎにくい、が核。ズレが生む問題がないと、一人にするメリットが薄く感じられる。
- AIの整理は進化しているが、読み込まずに採用するとズレや重複が残る。傾向として細かく分かれすぎる。

---

## ■問題の本質（重要）

「なぜ全ポジションができる人でないといけないか」は、**二者比較表**より **一本の因果** の方が速い。

```
限られたポジションしかできない
　↓
こういう教え方になる（手順だけ／次の客へ、など）
　↓
こういう問題が起きる（キッチン状況を考えていない、など）
　↓
なぜか：自分でキッチンを経験していないと実感が湧かない
　↓
同じ問題を何度も起こす
　↓
だから全ポジションができる状態にしておく
```

「できるトレーナーは各ポジの忙しさを理解しているから大切さを伝えられる」だけだと薄い。  
壁打ちで出た複数理由は、**別ポジションが関係している項目**として、この因果の下に並べる。

一方、専属一人は逆で、**複数だと何が起きるか**を残さないとメリットが立たない。まとめすぎない箇所と、まとめる箇所を分ける。

## ■ズレ（思考 or 設計）

| 取れている／近い | まだ薄い／直し方 |
|---|---|
| 全ポジが必要、という結論 | 「できない／できる」二列比較ではなく、因果一本へ |
| ホール教え方の具体例 | 「それだけだと何が起きるか」を一段深掘り |
| キッチン未経験→実感が湧かない | これを「なぜ」の核として前面に |
| ChatGPTで理由が複数出た | 各項目に「別ポジが関係する」と明示して並べる |
| 共感・安定・3人OK・マニュアル修正 | ある／ない分割をやめ、なぜ必要かにまとめる |
| 専属一人の良さ | 複数だと進捗は引き継げるが、その人への接し方は引き継ぎにくい、を残す |
| ズレが生む問題 | 無いと一人のメリットが感じられない。問題→一人で解決、の順 |
| AI壁打ちの活用 | 細分化しすぎ／重複を、自分の目でつなぐ・削る |

- 「できる場合は各ポジを理解している」だけでまとめると、壁打ちで出た4つの理由が消える。一本の因果の下に、理由を複数ぶら下げる形にする。
- 共感していない／している、の分割は、全ポジの二列比較と同じ型。同じ直し方でよい。
- 専属だけは分割（対比）を残す例外。

## ■改善内容（What）

### 0. 今回の直しどころ（全体像）

```
【まとめる（二列比較をやめる）】
・全ポジションができる理由
・お店の考え方に共感している理由
・安定して人と接する理由
・本部3人OK／マニュアル修正で枝分かれしている箇所

【対比を残す】
・専属トレーナー一人（複数だと何が起きるか → 一人だとどう解決するか）

【AIの使い方】
・材料出しは続ける
・細かく分かれすぎたらつなげる／重複は削る
・必ず自分で読み、違うところは訂正する
```

### 1. 全ポジション：因果一本で書く

推奨の型：

```
【なぜ全ポジションの仕事ができる人でないといけないか】

限られたポジションしかできない場合、
例えばホールの新人に
「注文を取ったら次のお客様の対応をしてね」
と教えるだけになりやすい。

それだけだと、こういう問題が起きる。
（キッチンの調理状況を考えていない、など）

なぜそうなるか。
言葉で教えてもらっても、実感が湧かないから。
自分でキッチンを経験していなければ想像できず、
同じ問題を何度も起こしてしまう。

だから、全ポジションができる状態にしておく。
```

その下に、壁打ちで出た理由を並べる（ホール／キッチンの話が各項目に入っていればよい）。

| 理由の例 | 書くときのポイント |
|---|---|
| 周りの状況を考えて協力しながら働くことを教える | 別ポジの忙しさが関係する、と明示 |
| 手順だけでなく「なぜそうするか」を教える | 経験がないと「なぜ」が空になる |
| 新人のできない原因を見つけて適切に指導する | 他ポジの視点がないと原因が偏る |
| 忙しいときでも優先順位を判断できるように教える | 全体が見えないと優先が教えられない |

「できるトレーナーは理解があるから伝えられる」だけに潰さない。複数理由は残しつつ、入口の因果は一本。

### 2. 共感・安定・3人OK・マニュアル修正：まとめ方

「共感していないトレーナー／しているトレーナー」のように分けている箱は、次に寄せる。

```
なぜ、お店の考え方に共感している人でないといけないのか
　→（共感がないと何が起きるか）
　→（だから共感している人が必要）
```

安定して人と接する、も同じ。  
本部3人OK・マニュアル修正も、複数の枝に分かれているなら、つなげられるものは一本の説明にまとめる。

ChatGPTは細かく分けがち。提出前に「これは同じ話の枝か？」を一度見る。

### 3. 専属一人：対比は残し、問題→解決の順にする

ここはまとめすぎない。

```
【複数のトレーナーがつく場合】
・教育の進捗は引き継げる
・ただし、何度も接する中でわかってくる
　「その人に合った考え方・接し方」までは引き継ぎにくい
　例：どんなときに緊張するか／どんな伝え方が理解しやすいか
・その結果、教え方にズレが生まれやすい
・ズレから、こういう問題が起きる（※ここを書く）

【担当トレーナーを一人にする場合】
・昨日までの新人を知っている人が、今日も続けて見られる
・その人の特性に合わせた声かけ・寄り添いができる
・上記のズレと問題を避けられる
```

ポイント：

- 「進捗は引き継げる」と書いてから、「それでも足りないもの」を出すと対比が立つ
- ズレが生む問題がないと、一人のメリットがいまいち感じられない
- 「コミュニケーションを一から作り直さなくていい」など、同じ内容の重複は削ってよい

### 4. ChatGPT壁打ちの運用

```
1. 材料出し・たたき台は任せる（今回の全ポジ理由は良い）
2. 一通り自分で読む
3. 違うところは訂正する
4. 重複は削除指示を出す
5. 細かく分かれすぎている枝はつなげる
```

情報整理の精度は上がっている。最終の「一本の因果になっているか」は人が見る。

### 5. 提出前の自己チェック（この回用）

```
・全ポジは「できない／できる」二列ではなく、因果一本か
・ホール教え方の具体 → 問題 → なぜ（実感が湧かない）までつながっているか
・壁打ちの複数理由が、一本の下に並んでいるか
・共感・安定などはまとめられているか
・専属だけは、複数の問題 → 一人の解決、が残っているか
・同じことの重複を削ったか
```

---

## ■改善理由（Why）

- 「できる／できない」の二列は、読み手が途中で比較ゲームに入り、結論までの距離が長くなる。因果一本の方が「だから全ポジ」が短い。
- 教え方の具体例があっても、「それだけだと何が起きるか」「なぜ起きるか」がないと、全ポジ必須の説得力が出ない。キッチン未経験→実感が湧かない、が橋になる。
- 壁打ちで出た複数理由は捨てない。入口を一本にしたうえでぶら下げる方が、1007で求めた「結果・なぜ」と両立する。
- 共感・安定などまで全部二列にすると、マニュアルが細分化し、0924で直した読みやすさが戻る。まとめられる箱はまとめる。
- 専属一人だけは例外。進捗引き継ぎと「人への接し方の引き継ぎにくさ」は別物なので、対比を消すとメリットが消える。問題側がないと解決側が薄い。
- AIは整理が上手いが、細分化と重複が残りやすい。最終のつなぎと削りは人の仕事。

---

## ■改善後イメージ（After）

読み手が次の順で理解できる状態。

```
1. 限られたポジションだけだと、こういう教え方になる
2. その結果、こういう問題が起きる
3. なぜか：経験していないと実感が湧かない
4. だから全ポジションができる人でないといけない
5. その下に、協力／なぜ／原因発見／優先順位、などの理由が並ぶ
6. 共感・安定などは「なぜ必要か」にまとまっている
7. 専属一人だけは、複数の限界 → 一人で解決、が対比で残っている
```

細かい枝分かれが減り、音読して「なぜ？」で止まらない。  
ChatGPTのたたき台を、つなぎと削りで整えた提出になっている。

---

## ■やりがちなミス

- 全ポジを「できないトレーナー／できるトレーナー」の表のまま残す
- 教え方の具体はあるのに、「それだけだと起きる問題」を書かない
- 「実感が湧かない」を抜かし、理解しているから伝えられる、だけで終わる
- 壁打ちの複数理由を捨てて、一文に潰しすぎる
- 共感・安定・3人OKまで全部二列比較にして細分化する
- 専属一人をまとめすぎて、複数だと何が起きるかが消える
- 進捗は引き継げる、のあとに「それでも足りないもの」を書かない
- ズレが生む問題がなく、一人のメリットだけが並ぶ
- 同じ内容（作り直し不要／寄り添える等）が重複したまま
- AIの出力を、読まずにそのまま貼る

## ■他の案件でも使えるパターン

### パターンA：条件の「なぜ」は二列比較より因果一本

```
できないとこう教える
　↓
問題が起きる
　↓
なぜ（経験・実感がない）
　↓
だからこの条件が必要
```

### パターンB：複数理由は入口の下にぶら下げる

入口を一本にしたあと、理由1・2・3を並べる。入口自体を理由の数だけ増やさない。

### パターンC：まとめと対比の使い分け

| やり方 | 使うとき |
|---|---|
| まとめる | ある／ないの枝が同じ結論に向かうとき |
| 対比を残す | 「できること」と「できないこと」が同居するとき（例：進捗は引き継げるが、接し方は引き継げない） |

### パターンD：メリットの前に「起きてほしくない問題」

一人にする／基準を置く、などのメリットは、問題側がないと薄く感じられる。問題 → 解決の順。

### パターンE：AI壁打ちの締め

```
出す → 読む → 訂正 → 重複削除 → 細分化をつなぐ
```

整理はAI、一本の因果になっているかの最終確認は人。

## ■一言まとめ（本質）

👉 全ポジ・共感・安定は「ある／ない」二列をやめ、教え方→問題→なぜ→だから必要、の一本にする。専属一人だけは、進捗は引き継げても人への接し方は引き継ぎにくい、の対比と問題を残す。

## ■1007・0924との関係

- 0924：並びを共感 → 育成 → 人選 → 関門。全ポジのなぜが分担まで届かない、が宿題だった。
- 1007：事例の質・ゴキゲンと人と関わる楽しさの切り分け・3人のなぜ・結果まで。今回は、その肉付けの中でも特に「全ポジ／共感／専属」の書き方の型。
- 今回：二列比較を因果一本へ。壁打ち材料は活かす。専属だけ対比を残す。AIの細分化を人がつなぐ。
- 引き継ぐこと：0924の並びは崩さない。1007の「経験しないと分からない事例」「結果まで」。
- 次の提出で見たいもの：全ポジが因果一本になった稿。専属は問題→一人解決が残っていること。共感・安定のまとめ。細かい枝の削除。
