## ■現状（Before）

- 0914で「トレーナーは誰でもなれない」を前に置き、育成・確認・人数制限・専属まで一本にする方向が出た。今回はその箱の中身（人選基準・育成の定義・専属の理由）を見ている。
- 条件はかなり厳しい側に書けている。方向は正しい。
- 足りないのは、厳しい条件のあとに続く**なぜなら**。
  - なぜ全ポジションできなければいけないのか
  - なぜ「いつもゴキゲン」なのか
  - なぜ人選に力を入れるのか
- 「勤続が長い」は、単独の条件より**全ポジションをマニュアル通りにできる**の中に含めやすい。
- 「いつもゴキゲン」と「コミュニケーション」は、**いつもゴキゲンで、人と接するのが好き**にまとめた方が伝わりやすい。
- 育成側の「全ポジションの仕事ができる」は、知識がある、ではなく**マニュアル通りにできて、教えられるレベル**まで落とす必要がある。
- 専属の理由が「新人さんとの関係性までは引き継げない」だと抽象が荒い。進捗は引き継げても、**その人に合った教え方・細かなニュアンス・非言語**までは正確に引き継げない、まで具体化する。

---

## ■問題の本質（重要）

基準を揃える話は、次の3段が揃って初めて説得力が出る。

1. **誰がトレーナーになれるか（人選）** … 条件＋なぜその条件か＋誰がOKを出すか
2. **その人が何を習得しているか（育成の定義）** … マニュアルを完全理解し、全ポジションを教えられる
3. **新人をどう見るか（運用）** … 人数制限／最初から最後まで専属

「厳しい条件」だけ並べると、読み手は「なぜそこまで？」で止まる。  
「専属にする」だけ言うと、「引き継げばいいのでは？」で止まる。

差になるのは制度名ではなく、**なぜその関門が必要で、その結果どこまで基準が揃うか**まで一本で追えること。

---

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| 誰でもトレーナーになれないと伝えたい | 条件は出ているが、各条件の「なぜ」が薄い |
| いつもゴキゲンを重視したい | ストレス耐性→新人への当たり→信頼崩壊／早期離職、までの因果が無い |
| 全ポジションできる人だけにしたい | 「1〜2ポジションでも分担できるのでは？」への答えが無い |
| マニュアルを基準にしたい | 「知っている」と「教えられるレベルまで出来ている」が分かれていない |
| 専属にしたい | 「関係性」止まりで、引き継ぎ不能の中身がぼやけている |
| 基準が揃うと伝えたい | 人選・育成定義・人数制限・専属が、1本の結論にまとまりきっていない |

0914の「誰でもなれないを前へ」は方向OK。今回はその前置きを、**条件リストではなく理由付きの関門**にする段階。

## ■改善内容（What）

### 0. 今回の直しどころ（全体像）

```
【維持（OK方向）】
・トレーナーは誰でもなれない／条件が厳しい
・本部マネージャー全員のOK
・各店1〜2人＋本部マネージャー少数、という結果イメージ
・最初から最後まで専属
・マニュアルを教育の基準にする（0905）

【直す（今回の本題）】
・条件のあとに「なぜなら」を足す
・全ポジション＝マニュアル通りに教えられるレベル
・なぜ全ポジションが必要かの説明
・専属理由を「関係性」から「教え方のニュアンス／非言語」へ抽象化
・運用の実績（何年から／改善／何人育てたか）を入れる
```

### 1. 人選ブロック：条件 → なぜ → 関門 → 結果

冒頭で「誰でもトレーナーになれるわけではない」と書いたら、すぐ**なぜなら**に入る。

**推奨の条件のまとめ方：**

| 残す／言い換える | 扱い |
|---|---|
| 全ポジションの仕事が**マニュアル通りに**できる | 単独条件として厚く書く |
| お店の考え方に共感している | 残してよい |
| いつもゴキゲンで、人と接するのが好き | 「ゴキゲン」＋「コミュニケーション好き」を統合 |
| 勤続年数が長い | 単独条件より、全ポジション習得の中に含める |

**「いつもゴキゲン」の因果（入れる）：**

```
少しでもストレスがかかると新人に当たってしまう
　↓
信頼関係が崩れる／パワハラのように見える／すぐ辞める
　↓
だから人選に力を入れる
　↓
一定期間しっかり見て、適正かどうかを判断する
```

**関門の順：**

```
① 上記の基準を満たしているか
② ただし見方は人によって変わる
③ だから本部マネージャー全員のOKが出ないとなれない
④ その結果、トレーナーは各店1〜2人＋本部マネージャー少数
```

基準を満たしている人は、特に「いつもゴキゲンで人と接するのが好き」なら、**自然とトレーナーになりたい**側に寄る、という流れも入れてよい。

### 2. 育成ブロック：全ポジション＝マニュアル完全習得＋教えられる

「全ポジションの仕事ができる」は、次の定義に置き換える。

```
全ポジションの仕事を、マニュアル通りにできる
　↓
単なる「知っている」ではない
　↓
内容を完全に理解し、完璧にでき、教えられるレベルまで到達している
　↓
知識の習得＋技術の習得が、マニュアルをベースにできている
```

**「なぜ全ポジションが必要か」**も1段落足す。  
1〜2ポジションだけできれば分担できそう、という読み手の疑問を先に潰す。

### 3. 実績の数字・期間を入れる

読み手が「相当なマニュアルができている」と感じる材料を足す。

- 何年何月からこの運用をしているか
- 改善を繰り返した結果、今は修正がほぼない状態か
- 新人のトレーニングを何人規模でやってきたか（数百／数千など実態に合わせる）

そのうえで、「それを完全習得しているトレーナーがいる」とつなぐ。

### 4. 専属ブロック：関係性 → 細かなニュアンス／非言語

「関係性までは引き継げない」は方向は近いが粗い。次の型に寄せる。

```
一人の新人に複数トレーナーをつけると
　↓
教育の進捗の引き継ぎはできる
　↓
だが、何度も接する中でつかんだ
　その人に合った教え方までは正確に引き継げない
　↓
だから最初から最後まで専属の担当トレーナーがつく
```

**引き継げない中身の例（短くでよい）：**

- どんなときに緊張するか
- どんな伝え方なら理解しやすいか
- どんな声かけなら質問しやすいか
- 表情や反応から、どこでつまずいているか

言葉にしやすい情報だけでなく、**実際に接しているから分かる細かなニュアンスや非言語**も含む。  
担当が変わるたびに特徴を1からつかみ直す必要があり、教え方にズレが生まれやすい、まで書く。

### 5. 結論の1本化

最後は次の3点で「教育の基準が揃う」に収束させる。

```
トレーナーの人選（厳しい条件＋全員OK）
　＋
マニュアルを完全習得した育成定義
　＋
人数制限／最後まで専属
　↓
教育の基準が揃う
```

ここまでやっている会社はそうそうない、という位置づけで締めてよい。

### 6. マインドマップ用（コピペ）

```
0919：トレーナー基準統一

├ 人選
│  ├ 誰でもなれない（冒頭）
│  ├ 条件＋なぜ（ゴキゲン／全ポジ／共感）
│  ├ 本部マネージャー全員OK
│  └ 結果：各店1〜2人＋本部少数
│
├ 育成の定義
│  ├ 全ポジ＝マニュアル通り＋教えられる
│  ├ なぜ全ポジが必要か
│  └ 実績（期間・改善・人数）
│
└ 運用
   ├ 人数制限
   ├ 専属（進捗は可／教え方のニュアンスは不可）
   └ だから基準が揃う
```

## ■改善理由（Why）

- 0914で「誰でもなれないを前へ」と決めた。今回はその前置きを、**条件の羅列から理由付きの関門**に変える段階。
- 0905の「マニュアル＝トレーナーの教育基準」を、育成定義側で**教えられるレベル**まで落とすと、基準教育のイメージが完成する。
- 専属の理由を「関係性」のままにすると、引き継ぎ運用で十分、と読まれやすい。**教え方の個人最適と非言語**まで書くと、専属の必然性が立つ。
- 実績（期間・改善・人数）は、マニュアルの厚みを「言っているだけ」から「積み上げた結果」に変える。

---

## ■改善後イメージ（After）

- 冒頭で「誰でもなれない」→すぐ「なぜなら（条件ごとの理由）」→本部全員OK→人数が絞られる、の順で読める。
- 「いつもゴキゲン」が、ストレス→新人への影響→離職、までつながっている。
- 「全ポジション」が、マニュアル完全習得＋教えられる、と定義されている。
- 専属の理由が、進捗引き継ぎは可／その人に合った教え方・非言語は不可、と具体になっている。
- 人選・育成定義・人数制限・専属が、「だから教育の基準が揃う」に一本で収束している。

---

## ■やりがちなミス

- 厳しい条件だけ並べて、「なぜその条件か」を飛ばす。
- 「勤続が長い」を単独条件のまま残し、全ポジ習得と重複させる。
- 全ポジションを「できる」で止め、「マニュアル通りに教えられる」まで落とさない。
- 「1〜2ポジションでも足りるのでは？」への先回りが無い。
- 専属理由を「関係性」だけで終わり、引き継げない中身の例を出さない。
- 人選・育成・運用を別々の良い話として並べ、最後に「基準が揃う」へ収束させない。

---

## ■他の案件でも使えるパターン

- **厳しい条件**を出すときは、必ず直後に**なぜなら（失敗したときの具体）**を置く。
- **制度名（専属／会議／マニュアル）**のあとに、読み手の「それだけで足りるのか／引き継げばいいのでは」を先に潰す。
- **「できる」**は状態がぼやける。**何ができて、どこまでできたら合格か**（教えられるレベル）まで定義する。
- **抽象語（関係性）**は、具体例3〜4個＋非言語、に分解してからまた一文に戻す。
- **基準が揃う**は結論。その前に人選・習得定義・運用の3段を置く。

## ■一言まとめ（本質）

👉 **「誰でもなれない」は条件リストではなく、条件ごとの「なぜ」＋全員OKの関門。全ポジションはマニュアル通りに教えられるレベルまで定義し、専属は「関係性」ではなく「その人に合った教え方・非言語は引き継げない」まで落として、人選・育成・人数制限で基準が揃う、と一本にする。**

## ■0914・0905との関係

- **0914**：誰でもなれないを前へ／会議だけで育成できるか／人数制限・接し方・記録／育成→チェック→デビュー。**今回**はそのうち、人選基準の「なぜ」と、全ポジの定義、専属理由の抽象化を肉付けする。
- **0905**：マニュアル＝トレーナーの教育基準。**今回**は育成側で「教えられるレベルまでの完全習得」に落とす続き。
- **0824**：マニュアルは新人用ではない。今回の「トレーナーがマニュアルを完全に持っている」と同型。
