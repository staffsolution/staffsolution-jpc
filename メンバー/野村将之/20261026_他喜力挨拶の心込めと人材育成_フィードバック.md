## ■現状（Before）

- 1022で指示した「他喜力の先頭を、喜んでもらう理由／声かけ・気配りに寄せる」方向の提出。
- 歓迎の挨拶が、「形だけでやっている挨拶」ではなく、「心を込めて、喜んでもらうために挨拶している」と読める状態になっている。
- その差が伝わる書き方なので、他喜力の核（人に喜んでもらうために力をつける）と一致している。
- ファイル共有の不具合で一度見られない状態があったが、確認できる状態に直したうえで今回のフィードバックになっている。
- 結論として、この箱は直すところがない。他の項目へ進めてよい。

## ■問題の本質（重要）

今回は「直しどころ」ではなく、**なぜこの箱が通ったか**を残す回。

```
形だけの挨拶
　＝ 手順・マナーとして挨拶している
　↓
喜んでもらうための挨拶
　＝ 相手に歓迎が伝わるように、心を込めてやっている
　↓
この差が書いてあると、他喜力（喜んでもらうために力をつける）の証明になる
　↓
さらに、その姿勢を教えると、人材育成にもつながる
```

「挨拶をしている」だけでは、他店でも言える。  
**心を込めて、喜んでもらうためにやっている**まで落ちると、他喜力固有になる。

## ■改善内容（What）

### 0. 今回の結論

```
【直す】なし（この箱は言うことなし）

【進める】
・他の項目を続けて提出する

【崩さない】
・形だけ vs 喜んでもらうための挨拶、の切り分け
・他喜力の核との一致
```

### 1. この箱で残す骨格（次回以降の見本）

```
【歓迎の挨拶／他喜力】

・ただ形だけでやっている挨拶ではない
・心を込めて、喜んでもらうために挨拶している
・その姿勢を教えると、人材育成につながる
```

読み手が「挨拶があります」で止まらず、「だから他喜力に共感している人でないと教えられない」まで届く。

### 2. 次の提出で見るもの（この箱以外）

1022・1007から引き継いで、まだ残っている幹は次。

| 優先 | 確認すること |
|---|---|
| 高 | 「いつもゴキゲン」と「人と関わることを楽しむ」を分けているか |
| 高 | 他喜力の2方向（お客様＋一緒に働く仲間）が消えていないか |
| 高 | 関門・修正のあとに、新人側の結果まで落ちているか |
| 中 | 事例が「経験しないと分からない」話になっているか |
| 中 | 専属一人は、対比と問題側が残っているか |

挨拶箱は触らなくてよい。他箱を同じ密度で揃える。

### 3. 提出前の自己チェック（他喜力系を触るとき）

```
・先頭は「形だけ」ではなく「喜んでもらうために」か
・抽象語（気配り・歓迎）の直後に映像があるか
・一般の寄り添い教育が、他喜力の顔になっていないか
・お客様側だけ厚くして、仲間側を消していないか
・この箱だけ音読して、「他喜力だから」が伝わるか
```

## ■改善理由（Why）

- 1022の本題は、他喜力を一般の寄り添い教育から切り離すことだった。今回の挨拶箱は、その切り分けができている。
- 「余計な仕事はしたくない」が普通なのに、喜んでもらうために心を込める姿勢を教える、と書けていると、他喜力が「いい人」の一般論で終わらない。
- 人材育成への接続（親御さんが子供にバイトさせたくなる、など）は、条件の結果側のイメージ。次の箱でも「教える中身 → 新人／店に何が起きるか」まで落とす見本になる。
- 通った箱までいじると、因果が崩れることがある。承認した箱は固定し、未解消の箱に力を使う。

いまの状態が、すでにAfterに近い。

```
2. 他喜力の定義と教える中身が一致している
3. 姿勢の教育が、人材育成の結果イメージまでつながっている
4. この箱は直さず、他の項目へ進む
```

音読して、「なぜ他喜力に共感している人か？」で止まらない。

## ■やりがちなミス

- 通った挨拶箱を、次の提出で一般論に薄めて戻す
- 「挨拶がある」だけで止め、「喜んでもらうために心を込める」を削る
- 他喜力の2方向のうち、お客様側だけ残して仲間側を消す
- 承認された箱まで手を入れ、通っていた因果を崩す
- 次の箱で、また「できるようになるまで寄り添う」を他喜力の顔にする（1022の繰り返し）
- 抽象の「歓迎」「気配り」だけで映像を書かない

## ■他の案件でも使えるパターン

### パターンA：形だけ vs 目的つき、の切り分け

```
同じ行動（例：挨拶）でも
　形だけやっている／目的（喜んでもらう）のためにやっている
　↓
後者まで書くと、条件名・思想名の証明になる
```

### パターンB：通った箱は固定し、未解消だけ触る

一度「言うことなし」になった箱は触らない。  
力は、まだ条件名と中身が一致していない箱に使う。

### パターンC：姿勢の教育 → 結果の想像まで1本

```
何を教えるか（心を込めた挨拶）
　↓
なぜそれが必要か（喜んでもらうため）
　↓
それを教えると何が起きるか（人材育成／親が送りたくなる店）
```

## ■1022・1013・1007との関係

- 1007：他喜力はお客様＋従業員の2方向。ゴキゲンと人と関わる楽しさは別路線。
- 1013：全ポジ・共感・専属を因果一本／枝を減らす。
- 1022：他喜力を一般の寄り添いから切り離し、喜んでもらう理由・声かけ・気配りを先頭へ。
