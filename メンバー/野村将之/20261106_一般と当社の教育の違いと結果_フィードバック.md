## ■分類（タグ）

- 自社リサーチ・比較見出し（一般 vs 当社）
- 1102の続き。差の名前に、結果まで載せる
- 「一人で覚えるか／分業か」は承認。この箱は触らなくてよい
- 残る教育の比較は、一般側の結果と当社側の結果を見出しへ
- 言い回しは一通り読んで、納得したところだけ変える

---

## ■現状（Before）

- 一般と当社の教育比較は、軸が4つ見えている。
  - 理解する前に現場に立つか／理解してから現場に立つか
  - 現場任せの教育か／専任トレーナーによる教育か
  - 人に依存する教育か／基準がある教育か
  - 一人でいくつもの仕事を覚えるか／分業して一つずつ覚えるか
- 4つ目は、1102で足した問題と結果変化が入っていて、このままでよい。
- 1〜3は、「何の違いか」までは見出しにある。その先の「だから、どうなるか」がまだ見出しにない。
- 本文には、やり方の説明がある。足りないのは、そのやり方の結果を見出しへ上げること。

---

## ■問題の本質（重要）

見出しの仕事は、違いの名前を置くことでは終わらない。

```
何の違いか（比較の軸）
　＋
一般側：そのやり方だと、どうなるか
　＋
当社側：そのやり方だと、どうなるか
```

「現場任せか、専任か」までだと、種類の違いは分かる。読み手は本文まで降りないと、その違いが新人や店に何をもたらすかが見えない。

1102で通った分業の箱は、すでにこの形になっている。同じ型を、残りの教育比較にも使う。

---

## ■ズレ（思考 or 設計）

| いま起きやすいこと | あるべき状態 |
|---|---|
| 軸の名前（理解前に立つ／現場任せ／人に依存）で止まる | 名前の下に、一般の結果と当社の結果がある |
| 当社の手段（専任がつく、基準を揃える）で止まる | 手段のあとが、品質・定着など結果になっている |
| 本文にある「こうなる」が見出しに上がっていない | 本文の結果を1行に圧縮して、見出しへ載せる |
| 通った分業の箱まで、もう一度いじる | 分業の箱は固定。残りの箱だけ結果を足す |

- 1102は「個人店の次に問題、当社の次に結果変化」の回。今回はその型を、他の教育比較へ広げる回。
- ズレは比較の骨格ではない。結果の1行が、見出しに無いこと。

---

## ■改善内容（What）

### 0. 今回やること（優先）

```
【直す】
・理解前に現場に立つか、の見出しに結果を足す
・現場任せか専任か、の見出しに結果を足す
・人に依存するか基準があるか、の見出しに結果を足す
・一般側も当社側も、「やり方 → どうなるか」の2行にする

【触らない】
・一人で覚えるか／分業か（この箱は承認。このまま）
・1026で通った他喜力の挨拶箱
・比較の骨格（一般 vs 当社）そのもの
```

言い回しは、下の例を一通り読んで、納得したところだけ変える。そのまま使えるところは、そのまま使ってよい。全部を機械的に置き換えなくてよい。

### 1. 理解してから現場に立つか

軸の名前は残す。その下に、やり方と結果を載せる。

```
理解する前に現場に立つか／理解してから現場に立つか

【一般】
十分に理解しないまま、現場で仕事を覚えていく
　→ （本文にある結果を1行）

【当社】
仕事の流れを理解し、練習して、できるようになってから現場に立つ
　→ （本文にある結果を1行）
```

動画で名前が付いているのは、ここまでのやり方。結果の文言は本文にある一文を使う。本文に無い結果を、新しく足さない。

### 2. 現場任せの教育か、専任トレーナーか

一般側は「誰が、どんな状態で教えるか」。当社側は、専任がついた結果まで見出しに入れる。

```
現場任せの教育か／専任トレーナーによる教育か

【一般】
現場スタッフが、通常業務をしながら空いた時間で教える
　→ （本文にある結果を1行）

【当社】
専任トレーナーがつく
　→ 品質を維持し、定着率が高まる
```

当社側の「品質を維持し、定着率が高まる」は、この箱で使う結果としてそのまま載せてよい。品質を「成長」に言い換えなくてよい。本文が品質と言っているなら、見出しも品質で揃える。

### 3. 人に依存する教育か、基準がある教育か

同じ型。変わりやすさで止めず、変わった結果を載せる。当社側も「揃えている」で止めず、揃えた結果を載せる。

```
人に依存する教育か／基準がある教育か

【一般】
教える人によって、教え方や基準が変わりやすい
　→ （本文にある結果を1行）

【当社】
教育の基準を仕組みで揃えている
　→ （揃えたあとに、何が起きるか。本文の1行）
```

### 4. 一人で覚えるか／分業か（この箱は触らない）

この箱は、問題と結果がすでに見出しで見える。このままでよい。

```
一人でいくつもの仕事を覚えるか／分業して一つずつ覚えるか

【個人店】
覚えることが多すぎて、混乱やミスが起きやすい

【当社】
分業しているので、品質も上がり、自信もつく
```

1〜3を直すときの完成形は、この箱と同じ厚み。

### 5. 提出前の自己チェック（見出し）

```
・見出しだけ読んで、一般側で何が起きるか言えるか
・見出しだけ読んで、当社側で何が得られるか言えるか
・やり方で止まらず、矢印の先に結果があるか
・結果は本文にある一文か（新しく足していないか）
・分業の箱と、挨拶箱を触っていないか
・音読して、納得した箇所だけ変えているか
```

---

## ■改善理由（Why）

- 差の名前だけだと、種類の違いは分かっても、読み手の中で結果が動かない。結果が並ぶと、どちらで働きたいかの判断が先に立つ。
- 1102で分業の箱が通ったのは、問題と結果変化が見出しにあったから。同じ理由で、残りの教育比較も結果まで上げる。
- 専任の箱は、当社側の結果がすでに言葉になっている（品質の維持、定着率）。見出しに上げるだけで、本文を読まなくても差が言える。
- 人によって基準が変わる箱も同じ。変わりやすい、で止めると「それはそう」で終わる。変わったあとに何が起きるかまで入れて、初めて比較になる。
- 言い回しを全部置き換えないのは、本文とズレた見出しを量産しないため。納得した1行だけ載せる。

---

## ■改善後イメージ（After）

```
1. 見出しを見る
2. 一般：理解しないまま現場に立つ／空いた時間で教える／人によって基準が変わる
3. その直後に、だからこうなる、がある
4. 当社：理解してから立つ／専任がつく／基準を仕組みで揃える
5. その直後に、品質・定着・自信など結果がある
6. 分業の箱は、いまの見出しのまま
7. 4つの比較を、見出しだけで言い分けられる
```

音読して、「一般だとどうなり、当社だとどうなるか」に即答できる状態。

---

## ■やりがちなミス

- 軸の名前だけ直して、結果の1行を空のままにする
- 当社の良い手段だけ厚くして、一般側の結果を載せない（またはその逆）
- 専任の結果を「成長」など別の言葉に言い換えて、本文の「品質」とズラす
- 本文に無い結果を、見出し用に新しく作る
- 通った分業の箱や、挨拶箱まで一緒にいじる
- 例文を全部コピペして、自分の本文と食い違う見出しにする
- 結果を長く書きすぎて、一目で入らなくなる

## ■他の案件でも使えるパターン

### パターンA：違いの名前の下に、結果を対で置く

```
比較の軸（何の違いか）
　↓
悪い側：そのやり方 → どうなるか
　↓
良い側：そのやり方 → どうなるか
```

### パターンB：本文の結果を、見出しへ1行で上げる

```
本文に「だからこうなる」がある
　↓
1行に圧縮する
　↓
一般／当社の直後に置く
　↓
見出しだけで、両方の結果が言えるか確認する
```

### パターンC：通った箱は固定し、同じ型を隣の箱へ広げる

```
1つの比較が「結果まで見えて」通る
　↓
隣の比較は、手段や名前で止まっていないか見る
　↓
止まっている箱だけ、同じ厚みにする
　↓
通った箱は触らない
```

自社リサーチでもコピーでも、同じ型で使える。

## ■一言まとめ（本質）

👉 「一人で覚えるか／分業か」の見出しは、このままでよい。残りの教育比較は、差の名前で止めず、一般側の結果と当社側の結果まで見出しに載せる。納得した箇所だけ変える。

---

## ■1102・1026との関係

- 1026：歓迎の挨拶箱が「喜んでもらうための心込め」で承認。その箱は固定。
- 1102：分業の軸は方向OK。個人店の次に問題、当社の次に結果変化を載せる指示。
- 今回：分業の箱は結果まで入っていて承認。同じ「結果を見出しへ」を、理解前に現場に立つか／現場任せか専任か／人に依存か基準があるか、へ広げる。
- 引き継ぐこと：挨拶箱と分業の箱は触らない。ゴキゲン分離・他喜力2方向・関門の結果など未解消の幹は、見出し調整と別に継続確認。
