## ■分類（タグ）

- 社長インタビュー設計（警備会社）
- 過去の採用施策の洗い出し
- 金額・期間・結果の数字深掘り
- 媒体・SNS・LP・ハローワークの列挙
- 業界不足の思い込み（ビリーフ）
- 欲求・不安・イライラの一次情報
- 0828悩み深掘り・0824ターゲット整理の続き

---

## ■現状（Before）

- 0828のフィードバックを受けて、**社長インタビューの項目を整理し直した**段階。
- 全体の路線（経営の悩み → 求人 → 離職 → 最悪の未来 → 理想）は方向として合っている。
- 「これまで何をやってきたか」系の項目はあるが、**金額・期間・結果（応募数・採用数）**まで数字で突っ込む設計がまだ弱い。
- 媒体・SNS・人材紹介・採用LP・ジョブリスティング・ハローワークなど、**施策の候補一覧**を聞き切る設計も、明示しておくと漏れにくい。
- 「業界全体が人手不足だから仕方ない」系の**思い込み**を拾う問いが、欲求・不安とセットで取れそうな形になっている（ここは良い）。

---

## ■問題の本質（重要）

- 社長インタビューの目的は、AIでは代えられない**検証可能な一次情報**を取ること。特に「過去に何をいくらかけて、何件取れたか」は、コピー・提案・サービス設計の**証拠と痛み**になる。
- 「何をやりましたか？」だけでは抽象で終わる。**金額・期間・応募数・採用数**まで聞くと、施策の失敗・浪費・諦めのリアルが出る。
- 出てこなければ、**施策カテゴリのチェックリスト**で当てはめて聞く（媒体／紹介／SNS／採用サイト・LP／ジョブリスティング／ハローワーク）。「やっていない」も情報。
- 各施策に対して**どう思っていたか・どう考えていたか**まで聞くと、欲求とビリーフが同時に取れる。
- 「業界全体が人手不足だから仕方ない／集められないから別の何かで解決しようとしている」は、**求人に対する無力感の思い込み**。ここが取れれば、ジョブリスティング提案の対比材料になる。
- イライラ・不安は、悩みパートで自然に出やすい。施策の数字深掘りと合わせて、**感情の一次情報**も残す。

---

## ■ズレ（思考 or 設計）

- 項目の整理自体は合っているが、**過去施策ブロック**が「やったことの列挙」で止まりやすい。
- 数字（金額・期間・応募・採用）を**必須の深掘り項目**として明示していないと、社長が「いろいろやりました」で終わる。
- 施策名を聞き手が覚えていないと、「他には？」だけでは**SNS・ハローワーク・LP**などが漏れやすい。
- 思い込み（業界不足だから仕方ない）は路線として合っているので、**ズレではなく強化ポイント**。ここを弱めず、施策失敗の数字とセットで聞く。

---

## ■改善内容（What）

### 0. 今回の方針（全体はOK）

0828で決めた流れはそのまま進めてよい。今回の追加は主に**「過去の採用施策」ブロックの数字深掘り**。

```
【維持】経営全体 → 求人 → 離職 → 最悪の未来 → 理想 → 思い込み
【強化】過去施策：金額・期間・応募数・採用数 ＋ 施策チェックリスト ＋ どう思っていたか
```

### 1. 過去施策：差し支えなければ数字まで突っ込む

**必須で聞く3点：**

| 聞くこと | 例 |
|---|---|
| 金額 | その施策にいくらかけたか |
| 期間 | どのくらいの期間やったか |
| 結果 | 応募は何件／採用は何人（できれば年別・施策別） |

**質問イメージ：**

```
これまでに採用のために何をやってきましたか？
差し支えなければ、いくらくらい・どのくらいの期間使いましたか？
その結果、応募はどのくらい、採用は何人くらいでしたか？
```

出てきた施策ごとに、**金額・期間・応募・採用**をセットでメモする。

### 2. 出てこなければチェックリストで当てはめる

「どんなことをやってきましたか？」で薄いときは、次を**一つずつ**当てはめる。

```
・求人媒体・求人サイト
・人材紹介
・SNS（YouTube／Instagram／TikTok など）
・採用サイト・採用LP
・ジョブリスティング
・ハローワーク
```

各項目で：

1. やったか／やっていないか
2. やったなら金額・期間・結果
3. **どう思っていたか・どう考えていたか**（期待・失望・諦め）

「やっていない理由」も思い込み・優先順位の材料になる。

### 3. 思い込みブロック（この路線でOK）

次の流れは**バッチリ**なので、このまま聞いてよい。

```
業界全体が人手不足だから仕方がない
　↓
求人では集められないものだ
　↓
だから別の何かで解決しようとしている
```

ここから、**欲求（本当はどうしたいか）**と**ビリーフ（人は集まらない）**がセットで取れる。

### 4. 感情（イライラ・不安）

悩みパートで、イライラ・不安は自然に出やすい。施策の失敗数字を聞いたあとだと、より生々しく出やすい。

```
・そのとき、どんな気持ちでしたか？
・いちばんイライラした／不安だったのはどの場面ですか？
```

コピーの感情材料として残す。

### 5. 推奨の挿入位置

0828のフローに、過去施策ブロックをこう差し込む。

```
1. 経営でいちばん悩んでいることは？ → 出し切り → 優先順位
2. 【求人】いちばん困っていることは？ → 出し切り → 優先順位 → 深掘り
3. 【過去施策】何をやったか → 金額・期間・応募・採用 → チェックリスト補完 → どう思っていたか
4. 最悪：採用が減っていったら会社はどうなるか
5. 【離職】…（0828どおり）
6. 【理想】…（0828どおり）
7. 【思い込み】業界不足だから仕方ない、等
```

---

## ■改善理由（Why）

- **金額・期間・結果**があると、「高いのに来ない」「長くやっても採れない」が事実として残り、共感コピーと提案の根拠になる。
- チェックリストがあると、社長の記憶漏れや話し忘れを防ぎ、**施策の全体像**が取れる。
- 「どう思っていたか」を聞くと、事実だけでなく**期待→失望→諦め**のストーリーが取れる（0824の「心の声」）。
- 業界不足のビリーフは、ジョブリスティングや内製化提案の**対比軸**（「業界のせい」vs「求人の作り方」）になる。
- 0828の悩み設計は維持し、今回は**証拠となる数字**だけを足すイメージ。路線変更ではない。

---

## ■改善後イメージ（After）

- 過去施策ごとに、**いくら・どれくらい・何件・何人**が表で揃う。
- やっていない施策も含め、媒体／紹介／SNS／LP／JL／ハローワークの**マップ**ができる。
- 「業界は人手不足だから仕方ない」系の言葉と、施策失敗の数字が**セット**で残る。
- イライラ・不安の生の言葉が、悩みパートと施策パートの両方から取れる。
- この路線で進めれば、欲求・思い込み・感情の一次情報が揃い、次の提案・コピーに直結する。

---

## ■やりがちなミス

- 「いろいろやりました」で止め、**金額・期間・応募・採用**を聞かない。
- 施策名を聞き手側で列挙せず、社長の記憶だけに頼る。
- SNSを「SNS」でまとめ、**YouTube／Instagram／TikTok**の差を聞かない。
- 結果を「あまり来なかった」で止め、**件数・人数**に落とさない。
- 思い込みパートを急ぎ、施策の失敗体験とつないで聞かない。
- 0828の全体フローを捨てて、施策ヒアリングだけにする（悩み・最悪・理想が薄くなる）。

---

## ■他の案件でも使えるパターン

### パターン1：過去施策の三点セット

```
何をやったか
　↓ 金額
　↓ 期間
　↓ 結果（応募数・採用数）
```

業種を問わず、経営者インタビューの「これまで」に使える。

### パターン2：出てこなければカテゴリチェックリスト

媒体／紹介／SNS／自社サイト・LP／広告／公的機関、など。**やっていないも含めて**当てはめる。

### パターン3：事実のあと「どう思っていたか」

数字のあとに感情・解釈を聞くと、欲求とビリーフが同時に取れる。

### パターン4：業界構造の思い込みを明示する

「業界全体が○○だから仕方ない」→「だから別の方法で解決しようとしている」。無力感の構造をそのまま拾う。

## ■一言まとめ（本質）

👉 インタビュー項目の整理は方向どおり進めてよい。過去の採用施策は「やったこと」で止めず、金額・期間・応募数・採用数まで突っ込み、出てこなければ媒体・SNS・LP・ハローワーク等のチェックリストで当てはめ、どう思っていたかまで聞いて欲求とビリーフを揃える。

## ■0828・0824との関係

| 過去FB | 今回との接続 |
|---|---|
| **0828** 採用と離職の深掘り | 全体フロー（悩み→最悪→理想）は維持。今回は**過去施策の数字深掘り**を求人ブロックに足す |
| **0824** ターゲット整理 | メインターゲット社長の「心の声」を、施策失敗の数字＋業界不足の思い込みで具体化する |

0828で「どう聞くか」の骨格、今回で「過去にいくらかけて何件だったか」の証拠層を足す段階。
