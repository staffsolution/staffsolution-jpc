# 危機感の薄さと求人コントロールの深掘り（フィードバック）

2026年9月8日

**フィードバック動画：** <a href="https://www.loom.com/share/910ecdb52f1a4e279d856d203a3d750f" target="_blank" rel="noopener noreferrer">Loomで見る</a>

## ■分類（タグ）

- 社長インタビュー（警備会社・1人目）マインドマップ確認
- **守り・キープ**志向（拡大より稼働率維持・離職の置き換え）
- 年間約120万円の採用費と「一人も来ない時」の数字
- **現状に慣れている／危機感がない**（平均年齢59・10年変わらず等）
- 欲求が弱い・追い詰められても感情が動きにくい
- 次の深掘り：求人の**コントロール**・自社広告・コスト半減／1/3の仮説
- 社長自身がやらない場合の**社員に任せる**選択肢
- 0830・0828・0824の続き

---

## ■現状（Before）

- 1人目の社長インタビューをマインドマップにまとめた段階。0830で求めた「何を求め・何に困っているか」は**かなりよく取れている**。インタビュー自体はすごく良い。
- 出てきた像の要点：
  - **大きくしたいより、今の状態をキープしたい**（攻めより守り）。
  - 警備の**稼働率維持**。離職した分を置き換えられればよい、という感覚。
  - 創業32年。年間**約120万円**かけて採用。1年で面接10名・採用2〜3名程度、の一方で**一人も来ない年もあった**。
  - この現状に**慣れてしまっている**のが危うい。「こんなもの」「どうしようもない」と思っていると、依頼につながらない。
  - 平均年齢**59歳**（10年前から変わっていない）、最高86歳、下は20代。心配していない＝**危機感を感じていない**。
  - 警備は2〜3人でも食っていける商売、という認識。社長自身の理想も「変わらない」。危機感も欲求もほぼない。
  - 外国人採用への関心は薄い。いつでも出る準備ができている／そうなっても別にいい、に近い温度感。
- 0830で強化した「金額・結果の数字」は、120万・面接・採用・ゼロの年、まで**出始めている**。ここは前進。
- 足りないのは、数字の先の**仮説提示と深掘り質問**。「取る／取れないがギャンブル的」な状態を、自社でコントロールする道・コストが半分や1/3になる道を示して、**取り組みますか／取り組みませんか**まで聞くこと。
- 社長本人が動かなくても、**社員にやってもらう**選択肢まで聞くと、提案の入口が残る。
- この感触だと「自分でやる」確率は低め、という読みもある。それでも突っ込んで聞いてよい（競合を増やす可能性はあるが、やらなそうなら情報としても価値がある）。
- 年齢の影響もあるかもしれないが、**追い詰められても強い感情が動かない**のは衝撃的で、ターゲット判定・提案設計の材料になる。

---

## ■問題の本質（重要）

- 社長インタビューの目的は、欲求・痛み・数字だけではない。**「この人は動くか／何があれば動くか」**まで一次情報で取ること。
- 今回のように欲求が弱く危機感が薄い相手では、「困ってますね」で終わると提案が空振りする。必要なのは、**思い込み（こんなもの）を揺さぶる仮説**と、**Yes/Noに近い選択質問**。
- 0830の「業界不足だから仕方ない」と同型。今回はさらに、**慣れている・会社は潰れない・過去に取り戻した**まで出て、軽く見ている構造が見えた。ビリーフは簡単には変わらない前提で、**コントロールできるとしたらやるか**に焦点を移す。
- 提供できる内容（媒体任せではなく自社広告で求人をコントロールする、コストを下げる道がある）を前提に、**もしそれができたらどう思うか**を聞くのが次の一手。

---

## ■ズレ（思考 or 設計）

| 取れている（結果として良い） | まだ薄い／次に足す |
|---|---|
| 守り・キープ志向、稼働率維持 | 「コントロールしたいですか」系の仮説質問 |
| 120万・面接10・採用2〜3・ゼロの年 | 半額／1/3になったら取り組むか、の選択 |
| 危機感がない・欲求が弱い | 業者任せ vs 自社／社員に任せる、の選択肢 |
| 年齢構成・慣れている現状 | 「マジで？」のあとの「どうやるの」への橋渡し設計 |

- インタビュー設計のズレというより、**1回目で見える化したあとの深掘り不足**。0830の数字深掘りは効いている。次は**オファー可能な世界線を見せて反応を取る**段階。
- 「やらないだろう」という読みは持ってよいが、**聞かない理由にはしない**。反応（やる／やらない／社員なら）自体がコンサル設計の一次情報。

---

## ■改善内容（What）

### 0. 進め方

```
【維持・良い】
・インタビュー全体の質（欲求・困りごとが見える）
・120万／面接／採用／ゼロの年の数字
・守り志向・危機感の薄さの可視化

【次のインタビュー／追加ヒアリングで足す】
① ギャンブル感 → コントロールしたいですか
② 業者任せ → 自社で取り組む／自社広告は考えますか
③ 120万が半分・1/3になる道があるとしたら、取り組みますか
④ 社長自身がやらない場合、社員にやってもらうは考えますか
⑤ 「こんなもの」思い込みに対し、別の道があることを短く示す
```

### 1. 追加で聞いてよい質問（コピペ用）

**A. コントロール**

```
取るか取れないかが、もう少しギャンブル的になっていませんか？
これをちゃんとコントロールしたい、と思いませんか？
```

**B. 自社でやる／業者任せ**

```
業者任せではなく、自社で取り組むことは考えませんか？
媒体に載せるだけでなく、自社で広告を出して
求人をコントロールするやり方もあります。
それができたとしたら、どう思いますか？
```

**C. コスト仮説（0830の数字の続き）**

```
今、年間だいたい120万円かけて、
面接は年10名・採用は2〜3名、という感じですよね。
一人も来ない年もあった、とも伺いました。

これが半分や3分の1になる道があるとしたら、
取り組みますか？ 取り組みませんか？
```

**D. 社長がやらない場合**

```
ご自身で取り組まない場合でも、
社員さんにやってもらって取り入れる、
というやり方は考えますか？
```

- Yes/Noに近い聞き方にすると、「まあね」で逃げにくい（説明モードに入らせすぎない）。

### 2. 思い込みへの向き合い方

出てきたビリーフの構造：

```
年間120万かけて一人も来ない時もある
　↓
でも慣れている／こんなもの
　↓
会社が潰れるわけではない／過去に取り戻した
　↓
だから危機感が薄い・欲求が動かない
```

- この思い込みは**すぐには変わらない**前提でよい。
- 変えるのではなく、**「求人をコントロールできるようになるとしたら」**に話を移す。
- 「別な道がある」→「マジで？」→「どうやるの？」の流れは起きうる。そのとき浦川さんの競合を増やす可能性はあるが、**この感触だとやらない**読みも同時に持つ。

### 3. マインドマップへの載せ方（整理用）

| 箱 | 入れる内容 |
|---|---|
| 欲求 | キープ・守り・稼働率維持（拡大ではない） |
| 現状の数字 | 120万／年、面接・採用、ゼロの年 |
| 年齢・体制 | 平均59・10年不変、最高86、心配していない |
| 危機感 | 薄い／追い詰められても感情が動きにくい |
| 次に聞く | コントロール・自社・半額仮説・社員委任 |
| 判定メモ | 動く条件／動かない理由（一次情報として残す） |

### 4. ターゲット・提案への使い方

- 「困っている社長」一括りにしない。**欲求が弱い・慣れている**タイプは、痛みの煽りだけでは動かない。
- 提案の入口は「今つらいでしょう」より、**ギャンブル感の解消・コスト削減・コントロール**の方が合いやすい可能性。
- 社長本人が動かないなら、**社員に任せる／外注ではなく社内で回す**の提案設計も選択肢として残す。
- 「やらない」と分かったこと自体が、**このターゲットに時間を使うか**の判断材料。

### 5. セルフチェック

| チェック | Yes / No |
|---|---|
| 守り・キープが欲求として書けているか | |
| 120万・面接・採用・ゼロの年が数字で残っているか | |
| 危機感の薄さ・慣れている、が事実として残っているか | |
| コントロール／自社／半額／社員委任の質問を次に用意したか | |
| 「やらないだろう」で深掘りを止めず、反応を取る設計になっているか | |

---

## ■改善理由（Why）

- インタビューの質は高い。次に必要なのは情報量ではなく、**動く／動かないの分岐を取る質問**。
- 0830で金額・結果を取る設計にしたおかげで、120万とゼロの年が出た。その数字を使って**半額・1/3仮説**を出せると、思い込みを揺さぶりやすい。
- 危機感が薄い相手に「やばいですよ」だけ言うと、こちらの感想で終わる。**コントロールできる世界線**を見せて選択させる方が、一次情報になる。
- 「やらない」反応も失敗ではない。コンサルのターゲット選定・提案の切り口の材料になる。

---

## ■改善後イメージ（After）

- マインドマップに、守り欲求・120万の数字・危機感の薄さが並んでいる（今回まででほぼ到達）。
- 次のヒアリングで、コントロール／自社／半額／社員委任への**反応（やる・やらない・条件付き）**がメモされている。
- 「こんなもの」と思っている相手に、別の道とコスト仮説を示したうえでの返事が取れている。
- 動く条件が分かる／動かないと分かる、のどちらかで提案設計が進む。

---

## ■やりがちなミス

- インタビューが良いので満足して、**次の深掘り質問を用意しない**
- 「危機感がない＝だめ」で終わり、**コントロール仮説**に移らない
- 120万の数字を書いただけで、**半額・1/3ならやるか**を聞かない
- 「やらないだろう」と先読みして、**社員委任まで聞かない**
- 思い込みを正そうとして説教になり、**選択質問**にならない
- 感想（衝撃・やばい）だけ残して、**判定メモ（動く条件）**を残さない

## ■他の案件でも使えるパターン

### パターンA：欲求が弱い社長への聞き方

```
現状の数字（いくらかけて何人）
　↓
慣れている／こんなもの、の確認
　↓
コントロールできるとしたら？ 半額になる道があるとしたら？
　↓
やる／やらない／誰がやる（本人・社員）
```

### パターンB：ギャンブル感 → コントロール

```
取る／取れないが運任せ
　↓
コントロールしたいですか
　↓
自社広告・自社取り組みの仮説
　↓
できたとしたらどう思うか
```

### パターンC：数字のあとに仮説を置く（0830の続き）

```
金額・期間・結果を取る
　↓
その数字を半額・1/3にした世界線を見せる
　↓
取り組みますか（Yes/Noに近く）
```

### パターンD：本人が動かないときの分岐

```
社長自身は取り組まない
　↓
社員に任せるは考えますか
　↓
外注のまま／社内化、の反応を取る
```

## ■一言まとめ（本質）
