## ■分類（タグ）

- 社長インタビュー（警備・**能登復興需要**の会社）
- 求人代行への関心／求人媒体への懐疑
- 採用費**ゼロ**／機会損失が**年間億単位**
- 今より30〜40人増やしたい（復興需要で通常より多め）
- シニア市場は消えないが、採用は楽にならない
- 他業種との**同じシニア層の奪い合い**
- DXを勧めると離職（新しいことを覚えたくない）
- 営業と求人は社長の仕事（浦川さんと同じ）
- **成果報酬**モデル（ジョブリスティング＋ハロワ）
- 0908（キープ型）との対照／0830・0824の続き

---

## ■現状（Before）

- 0908は「守り・キープ・危機感が薄い」1社目。今回は別会社（能登半島地震の復興需要）のインタビューメモ確認。
- 工事が増えて警備員が必要だが、人手不足で当てられない。媒体に出しても来ない。会社全体が疲弊している。
- 年間の売上規模は**億単位**。復興需要に乗りきれない損失（機会損失）も、浦川さんの見立てでは**年間億単位**。本人たちはそこを考えていない。
- 求人代行への関心は強い。媒体には懐疑的。ハローワークはやっているが来ない。**採用費はいまゼロ円**（人数は必要なのに、お金をかけていない）。
- 現場側は仕事が欲しい一方、DXや新しいやり方を勧めると離職につながる。簡単なやり方にしても「今までのやつでやりたい」。覚える気がない、に近い。
- 「辞めたらその分入ってくる」という感覚がある（前の会社でも同じ発言があった）。もうすぐ80歳、という前提もある。
- 若い警備員が彼女に言われて辞めた、という話が出ている。業界イメージの問題は理解している。一方で「SNSやればなんとかなる」イメージも持っている。
- 「営業と求人は社長の仕事」は、浦川さんと同じ考え方。ここは強い接点。
- 今より**30〜40人**増やしたい（震災復興期だから、通常より多め）。

---

## ■問題の本質（重要）

- 0908型（慣れている・キープ）と、今回型（需要過多・機会損失・代行したい）は、**同じ警備社長でも提案の入口が違う**。今回は「困ってますね」ではなく、**取りこぼしている売上を取りに行く話**が先に立つ。
- 「シニアは増えるから警備の求人は大丈夫」は危険。シニア市場そのものは巨大なまま残るが、**採用が楽になる話ではない**。2号警備（交通誘導）は採用力の差が出る。地方は高齢化率は上がっても、シニアの**絶対数は増え続けない**。
- 本当の脅威は人口減そのものより、**同じシニア層を取りに来る他業種**（大型物流・スーパー・工場・病院・商業施設の「60代70代歓迎・大量募集」）。復興が進むほど、そちらに人が取られる。
- 採用費ゼロで億単位を逃している会社は、媒体の話より先に**代行・成果報酬**が噛み合いやすい。ただし「うまくいく会社だけ契約する」選別が、成果報酬を成立させる条件になる。

| 取れている | まだ薄い／次に足す |
|---|---|
| 復興需要・人手不足・媒体に出しても来ない | 機会損失（億単位）を本人がどう捉えているか |
| 代行したい／媒体は疑っている | 代行への期待の中身（何を任せるか） |
| ハロワはやっているが来ない／採用費ゼロ | ゼロ円の理由（かけて無駄だった／かける気がない） |
| 辞めたらその分入る | 0908と同じ「こんなもの」かどうかの確認 |
| 30〜40人増やしたい | いつまでに／何人足りないと現場が回らないか |
| 営業と求人は社長の仕事 | 社長自身が動くのか、代行に渡すのか |
| SNSでなんとかなる | 思い込みとして残し、否定ではなく結果で返す |

- メモの一部（「四苦八苦」付近）は、こちらの意図がまだ読み取れていない。次の壁打ちか追加ヒアリングで確認する。
- 0908は「欲求が弱い」。今回は欲求（人数を増やしたい・代行したい）がある。同じ深掘り質問を機械的に使わず、**機会損失と成果報酬の反応**を取る。

## ■改善内容（What）

### 0. 維持してよい点

```
【良い】
・復興需要 → 警備が足りない → 媒体では来ない、まで因果が見える
・代行関心／媒体懐疑／ハロワ実施／採用費ゼロ、が同時に取れている
・機会損失（年間億単位）に気づいている（浦川さん側）
・「営業と求人は社長の仕事」で価値観が一致している
・30〜40人という増員数が具体
```

0908の1社目より、**外部に頼んででも解決したい層**に近い（0824のメインターゲット判定と照合できる）。

### 1. 追加で聞いてよい質問（コピペ用）

**A. 機会損失**

```
今、人が足りなくて受けられていない仕事は、
年間でだいたいどれくらいの金額になりますか？

その額を、採用費ゼロのままで見送り続けるのは、
どう考えていますか？
```

本人が「考えていない」なら、その事実自体を残す。説教しない。数字が出れば提案の核になる。

**B. 採用費ゼロの理由**

```
必要な人数に対して、いま求人にお金をかけていない、
という理解で合っていますか？

かけて来なかったから止めたのか、
最初からかける気がないのか、どちらに近いですか？
```

**C. 「辞めたらその分入る」**

```
辞めた分は、またシニアから入ってくる、
という感覚はありますか？

他の業種が同じ60代70代を取りに来たら、
それでも入ってくると思いますか？
```

**D. 代行と社長の仕事**

```
営業と求人は社長の仕事、という考え方はそのままで、
実作業（原稿・ハロワ・広告）だけ外に出す、
というのはどう思いますか？
```

### 2. シニア市場の整理（提案トーク用）

「シニアは増えるから大丈夫」は使わない。次の骨格で話す。

```
【残る事実】
警備はシニアの仕事として認知されている。
65歳以上の人数は大きく、求人が急に消えるとは考えにくい。

【誤解】
だから採用が楽になる／辞めたらその分入る。

【実態】
・75歳以上の割合が増える（働ける層の中身が変わる）
・2号警備は採用力の差が出る
・地方は高齢化率は上がっても、シニアの絶対数は増え続けない
・同じシニア層を、物流・スーパー・工場・病院・商業施設が取りに来る
　（冷暖房ありの室内仕事・大量募集が始まると厳しい）
・復興が進むと、他業種に人が流れる
```

無理に若手を取る、ではない。**元気でまともに働けるシニアを、仕組みで取り続ける会社が残る**。

### 3. 現場のDX拒否は、強みにも弱みにもする

```
【弱みに見える】
新しいやり方を覚える気がない → DXを勧めると離職

【求人では】
今までのやり方で働ける／無理に変えられない
　→ シニアが残りやすい環境、として書ける可能性
```

提案では「変えましょう」より先に、**今のやり方のまま人が足りる状態を作る**側に立つ。

### 4. 成果報酬モデル（今回の本筋）

代行の普通売りより、**初期費用なし・成果報酬**の方が、この会社（採用費ゼロ・代行関心・成果が見える）には合いやすい。

```
【なぜ成果報酬が合うか】
・「これやればうまくいく」が、警備×シニア×環境が整った会社では見えている
・初期費用ゼロ → 採用費をかけていない相手でも始めやすい
・トータルでは通常代行より高くてよい（続く・儲かる・喜ばれる）

【期間の例】
2年間は成果報酬
　↓
その後は買い取り（成果報酬を外す）
```

通常の代行より**少し高め**で成果報酬にする。初期はかからないが、成果が出続けるほど総額は大きくなる、という設計。

一般の求人代行で成果報酬にしなかった理由は、強みを打ち出せない会社・ターゲット設定が崩れる会社で失敗を見てきたから。警備で、シニアターゲットと環境が言える会社なら、ジョブリスティング＋ハロワで**今までの何倍か**は出せる見込み。だから成果報酬にしてもよい、というのが今回の判断。

### 5. 契約する会社を選ぶ（100%に近づける）

成果報酬は、うまくいかない会社と結ぶと破綻する。最初から選別する。

| 結んでよい目安 | 結ばない／お役に立てない、と伝える目安 |
|---|---|
| シニアをターゲットにできる | ターゲットが若手一辺倒で動かない |
| 環境がある程度整っている | 強みを打ち出せない |
| ハロワ＋ジョブリスティングが通る | 予算・条件が厳しすぎる |
| 「この会社なら絶対うまくいく」と言える | 社長が求人そのものに強い抵抗だけある |

「成果報酬なのでお断りします」は失礼になりやすい。**条件が合わずお役に立てない**、の言い方にする。

うまくいく会社だけ契約すれば、依頼は増え、成果後のリターンも大きくなる。

### 6. 料金の組み立て（AIに聞くときの型）

浦川さんができること：

- ジョブリスティングの代行
- ハローワークのサポート

それによって、媒体効果を上げ、採用コストを1/2どころか**1/3〜1/4**まで落とせる可能性がある。ハロワ経由の応募に紐づけて助成金が入る状態も狙える。

AIに投げる質問の例：

```
提供できること：
ジョブリスティング代行と、ハローワークのサポート。
媒体効果を上げ、採用コストを3分の1〜4分の1にできる可能性がある。
ハローワーク経由の応募に紐づけて助成金も入る状態にしたい。

相手：
警備会社。採用費はほぼゼロ。人不足で機会損失が大きい。
初期費用は出したくないが、成果が出るなら払える。

聞きたいこと：
成果報酬の料金体系をどう組むか。
取りっぱぐれない制度（期間・買い取り・上限・最低保証の有無）も含めて。
```

取りっぱぐれ防止は、料金の金額と同じ重さで考える。教材側のモデルは、山本さん側でも後で確認する前提でよい。

## ■改善理由（Why）

- 0908は危機感が薄いキープ型。今回は需要と機会損失がある。同じ「社長インタビュー」でも、提案は**コントロール仮説**ではなく**成果報酬で取りに行く**側に振れる。
- 「辞めたらその分入る」はシニア人口のイメージに支えられている。地方の絶対数・他業種の奪い合いを見せないと、採用費ゼロのまま機会損失が続く。
- 採用費ゼロの相手に通常の初期費用代行を出すと、媒体への懐疑と重なって止まりやすい。初期ゼロの成果報酬は、その抵抗を避けつつ、うまくいったあとの継続収益になる。
- 成果報酬を全社に広げない理由は、過去に求人代行が崩れたケース（強みが出ない・ターゲットがズレる）を見ているから。警備×シニア×環境、に絞ると再現性が立つ。
- 0824の「外部に頼んででも解決したい・20人以上・社長が毎日現場に出ていない」判定と、今回の代行関心・億単位需要は噛み合う。キープ型は別レーンでよい。

## ■他の案件でも使えるパターン

### パターンA：同じ業種でも、社長タイプでレーンを分ける

```
キープ型（0908）：危機感が薄い → コントロール／半額仮説／社員委任
需要過多型（今回）：機会損失がある → 代行／成果報酬
```

同じ質問セットを全社に使わない。

### パターンB：市場が残ることと、自社が採れることは別

```
シニア人口は残る
　↓
だから採用は楽、ではない
　↓
他業種が同じ層を取りに来る
　↓
仕組みを持つ会社だけが残る
```

### パターンC：お金をかけていない相手には、初期ゼロで入る

```
採用費ゼロ／媒体不信
　↓
初期費用のある代行は止まりやすい
　↓
成果報酬（初期ゼロ・成功したら払う）
　↓
期間後に買い取り
```

### パターンD：成果報酬は選別が本体

```
うまくいく会社だけ契約する
　＝ 料金設計と同じくらい重要
お断りは「成果報酬だから」ではなく「お役に立てない」
```

### パターンE：機会損失は、本人の口の数字にする

```
浦川さん側の見立て（億単位）
　↓
社長に「受けられていない仕事は年いくら？」
　↓
その数字で提案する
```
