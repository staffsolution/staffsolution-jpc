## ■分類（タグ）

- 社長インタビュー設計（警備会社）
- 悩みの深掘り・優先順位付け
- 求人と離職のカテゴリ分け
- 最悪の未来 → 理想状態の2段構造
- 社長の生々しい声（AI代替不可）
- 0824ターゲット整理・0110深掘りの続き

---

## ■現状（Before）

- 警備会社社長向けの**インタビュー項目**を整理している段階。
- 項目自体はあるが、**警備員数の深掘り**に入るタイミングが早く、全体の流れがまだ固まっていない。
- 「なかなか人数が増えない」系の質問はあるが、**社長が本当に悩んでいること全体**を先に出し切る設計になっていない。
- 求人・離職・経営・プライベートが**同じ深さで混在**しやすく、聞く順番・カテゴリが整理されていない。

---

## ■問題の本質（重要）

- インタビューの目的は、**AIが書けない「リアルな社長の声」**を引き出すこと。AIも生々しい声は出せるが、**本当かどうか分からない**。実際の社長の言葉が最も信頼できる。
- 社長インタビューは**「人数が増えない」一点から入ると狭い**。先に**経営全体の悩み**を出し、そこから人集め・求人・離職へ**自然に降りる**方が、本音と優先順位が見える。
- **求人の悩み**と**離職の悩み**は別カテゴリ。混ぜると「何が一番困っているか」がぼやける。
- **解決策・理想状態**の質問を、**悩みを聞いている最中**に混ぜると、社長が「答えやすい方向」に逃げ、本音の**最悪の未来**が出にくい。
- 0824で決めた**メインターゲット（20人以上・社長が毎日出ない層）**の悩みを掘るなら、**社長自身の悩み**と**採用ターゲット（求職者）の悩み**を混同しない。

---

## ■ズレ（思考 or 設計）

- **警備員数の深掘り**から入っているが、社長にとっていきなり「人数」より**「経営で何が一番しんどいか」**の方が答えやすい。
- **人が増えない**を起点にすると、離職・求人・マネジメントなど**関連悩みの全体像**が見えにくい。
- 離職について「辞めること」を求人パートで触れる設計になっているが、**離職は独立カテゴリ**として後から詳しく聞く方が整理できる。
- 「やめないように何かやっていますか？」は**解決策・理想状態側**の質問。悩みパートでは**最悪の未来**（このまま減っていったら会社はどうなるか）を聞く。
- 3〜5年の変化を**警備員人数**で聞こうとしているが、先に**応募数の推移→離職数の推移→順増かどうか**の順がしっくりくる。

---

## ■改善内容（What）

### 0. インタビュー全体の2フェーズ

```
【フェーズ1：悩み】全体 → 出し切り → 優先順位 → 上位から深掘り → 最悪の未来
【フェーズ2：理想】カテゴリごとに理想状態 → 会社・社長・プライベートへの変化
```

解決策・「何かやっていますか？」は**フェーズ2**で聞く。

### 1. 入り口：経営全体から攻める

**最初の質問（推奨）：**

```
警備会社の経営において、今いちばん悩んでいることは何ですか？
```

- ここで**人集め・求人**は必ず出てくる（多くの場合トップ候補）。
- それ以外（給与、離職、マネジメント、案件は取れるが人が回らない、など）も**全部拾う**。
- 「他には？」を繰り返して**出し切る** → **優先順位をつけてもらう**（0110と同型）。
- 人集め以外に大きな悩みがあれば、**別サービス化の種**にもなる。

| 聞く対象 | 内容 |
|---|---|
| 社長自身の悩み | 経営・採用・離職・マネジメント・プライベート影響 |
| 採用ターゲットの悩み | 求職者・警備員が抱える悩み（別枠で整理） |

※ 0824の「誰の声か」を先に分けておく。

### 2. 求人カテゴリ：困りごと → 出し切り → 優先順位 → 深掘り

**入り口（人数の前に）：**

```
求人のことで、いちばん困っていることは何ですか？
```

**出てきやすい例（全部出してから優先順位）：**

- 人が全然来ない
- お金（広告費・採用コスト）がかかる
- 自社にマッチした人が集まらない
- すぐ辞めてしまう（→ 離職カテゴリへ接続）
- なかなか人数が増えない

**深掘りの型（0110）：**

```
・具体的にどんなことに困っていますか？
・それはいつ、何がありましたか？（エピソード）
・前にジョブリスティングに取り組んでいなかったら、会社はどうなっていたと思いますか？
```

※ 浦川さんが以前社長から聞いた「取り組んでいなければ会社が…」系の情報は、**現状の深刻さ**を引き出すフックとして使える。

**最悪の未来（解決策を聞く前に）：**

```
このまま採用できる人数が減っていったら、会社はどうなってしまうと思いますか？
このまま何もせずに2年後・3年後・5年後、どうなっていくと思いますか？
```

### 3. 離職カテゴリ：求人と分けて詳しく聞く

求人パートで「すぐ辞める」が出たら、**切り替えて離職専用ブロック**へ。

**推奨の質問順：**

1. 離職について詳しく教えてください
2. 年間でどのくらいの人が辞めていますか？
3. **ここ3〜5年で、応募数はどう変わりましたか？**
4. **離職数はどう変わりましたか？順増していますか？**
5. 「そんなにやめているんですか？」→ エピソード深掘り

※ **警備員の人数**より、**応募数 → 離職数**の順が自然。

**最悪の未来（離職×求人の複合）：**

```
応募がどんどん少なくなり、採用人数が減り、離職が増えていったら、将来どうなりますか？
```

### 4. その他カテゴリ（経営・マネジメント）

警備業は**仕事（案件）は取れる**会社が多い。悩みのトップに来やすいのは：

- 給与・人件費
- 離職
- 人集め・求人
- **マネジメント**（人はいるが回らない、など）

**カテゴリごとにブロックを分け**、求人・離職以外も「困っていること → 深掘り → 最悪の未来」の型で聞く。

### 5. フェーズ2：理想状態（解決策はここ）

悩みと**最悪の未来**を聞き終えてから、理想を聞く。

**求人・離職セット：**

```
・求人（採用）で、理想的な状態とはどういうことですか？何人くらい採用が理想ですか？
・離職率・定着で、理想的な状態とは？
・その理想になったら、会社はどう変わると思いますか？（売上など）
・社長自身はどう変わりそうですか？
・プライベートは？家族・夫婦関係・取引先との関係は？
・夜眠れない、など**リアリティのある生活面**も聞く
```

「やめないように何かやっていますか？」「定着率アップの取り組み」は**理想・解決策パート**で聞く。

### 6. 思い込み（別カテゴリ）

カテゴリ分けしたうえで、例えば：

- 求人に関する思い込み
- 定着率アップに関する思い込み
- 他の解決策（媒体・業者など）への思い込み

**どのカテゴリに属するか**で整理し、聞きやすい順番に並べ替える。

### 7. 推奨の全体フロー（一覧）

```
1. 経営でいちばん悩んでいることは？ → 出し切り → 優先順位
2. 【求人】いちばん困っていることは？ → 出し切り → 優先順位 → 上位を深掘り（エピソード・いつ何が）
3. 最悪：人数・採用が減っていったら会社はどうなるか
4. 【離職】詳しく → 年間離職数 → 3〜5年の応募数・離職数の推移
5. 最悪：応募減＋離職増の将来
6. 【その他カテゴリ】給与・マネジメント等、優先順位上位から
7. 【理想】求人・離職・会社・社長・プライベート
8. 【思い込み】カテゴリ別
```

整理ができたら、再度共有してもらう（壁打ち・順番の最終調整）。

---

## ■改善理由（Why）

- **経営全体 → 求人 → 離職**の順にすると、社長が「なぜ人集めが一番痛いのか」の**背景**（会社存続、売上、マネジメント）まで語れる。
- **出し切り → 優先順位**（0110）を挟むと、コピー・サービス設計で**何を先に刺すか**が決まる。
- 求人と離職を分けると、0824のコンサル設計でも**訴求軸**（採用不足 vs 定着）を切り分けられる。
- 最悪の未来を**解決策の前**に聞くと、恐怖・切迫感の**生の言葉**が取れる（コピーの材料になる）。
- 理想状態で**プライベート・家族・睡眠**まで聞くと、社長の**本音の願望**が出る（0824の「心の声」）。

---

## ■改善後イメージ（After）

- インタビュー項目が**カテゴリ別**に整理され、社長が答えやすい順番になっている。
- 「警備員数」だけでなく、**経営の悩み全体 → 求人 → 離職 → 最悪 → 理想**の流れで、1回のインタビューから**コピー・サービス・提案**に使える情報が揃う。
- 「ジョブリスティングをやっていなければ会社が…」のような**切迫感のある一次情報**が、意図的に引き出せる。
- 求人以外の悩み（マネジメント等）も拾え、**別サービスの種**が見える。
- AIの架空の声ではなく、**検証可能な社長の言葉**として残る。

---

## ■やりがちなミス

- **人数・警備員数**から深掘りを始め、経営全体の悩みを出し切らない。
- 求人と離職を**同じ質問群**に混ぜ、優先順位が付けられない。
- 悩みを聞いている最中に**「何かやっていますか？」（解決策）**を聞いて、本音が弱くなる。
- 「他には？」を十分繰り返さず、**一番大きい悩み**を見逃す。
- 3〜5年の変化を**人数だけ**で聞き、**応募数・離職数の推移**を取り漏らす。
- 理想状態で**会社だけ**聞き、**社長のプライベート・睡眠・家族**まで聞かない。
- **社長の悩み**と**求職者の悩み**を同じリストに混ぜる（0824のターゲット設計と矛盾）。

## ■他の案件でも使えるパターン

### パターン1：経営全体 → テーマ別深掘り

```
いちばん悩んでいることは？（全体）
　↓ 出し切り → 優先順位
　↓ 上位テーマ（求人・離職・○○）ごとに詳細ブロック
```

業種を問わず、社長・経営者インタビューに使える。

### パターン2：出し切り → 優先順位 → 上位から深掘り（0110）

一テーマ内でも「困っていること一覧 → どれが一番？ → エピソード深掘り」の3段。

### パターン3：最悪の未来 ↔ 理想状態

| フェーズ | 聞くこと |
|---|---|
| 悩みパート | このままだと2〜5年後どうなるか（最悪） |
| 理想パート | 理想はどうか、会社・本人・プライベートはどう変わるか |

解決策の質問は**理想パート**に置く。

### パターン4：カテゴリ分けしてから順番を設計

求人／離職／給与／マネジメント／思い込み、など。**属するカテゴリ**でファイルを分け、**相手が答えやすい順**に並べ替える。

### パターン5：推移データは「応募 → 離職 → 人数」

採用課題では、**応募数の3〜5年推移**を先に、**離職数の推移**を次に。人数だけだと因果が見えにくい。

## ■一言まとめ（本質）

👉 警備会社社長インタビューは「人数」から入らず、経営の悩みを出し切って優先順位をつけ、求人と離職を分けて深掘りし、最悪の未来を聞いてから理想・プライベートまで聞く。AIでは代えられない社長の生の声を、カテゴリと順番で設計して引き出す。

| 過去FB | 今回との接続 |
|---|---|
| **0824** ターゲット整理 | メインターゲット（20人以上・社長が毎日出ない）の**社長の悩み**を、教科書ではなくインタビューで引き出す設計。社長の声 vs 求職者の悩みを分ける |
