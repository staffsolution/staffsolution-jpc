## ■分類（タグ）

- 社長インタビュー（73名・求人業者依存）
- 条件改善で採用できる、という強い思い込み
- 現状維持で「仕方ない」／専門家不信
- 採用コストの感覚ズレ（応募単価 vs 成果報酬の上限）
- 9月の特別提案で5名採用→再現性未確認
- 求人担当の従業員がインスタ運用（アカデミー適合の種）
- 言動の不一致（業者任せ vs 社内でやらせている）
- Who除外（変える気なし／丸投げ／経費として見ない）
- 実績ビフォーアフター（やめない仕組み＋純増支援）
- 1名増員シミュ → 成果報酬 → クライアント条件
- 1013・1006・0929の続き（モデルへの転記）

---

## ■現状（Before）

- 社長インタビューを踏まえ、Who（ターゲット）をまとめ直した提出。インタビュー側と、除外条件の確認が中心。
- 73名規模。求人は業者任せ。コンサルは高いから使わない。自分ではアイデアもやり方も分からないが、専門家に頼む考えもない。成果のために大きなお金をかけたくない。
- 年間おおよそ120万円（月10万前後）＋追加料金の可能性。応募は10件前後と少ない。「今どきIndeedは効かない」系の疑いも出るが、ノウハウや成果を伸ばす努力の気配は薄い。
- 70代従業員の退職への心配は薄い。「待遇を良くすれば採用できる」「ダメなら他社も同じ」という強い思い込み。
- 9月に特別な提案を受けて試した結果、採用5名・退職1名。ただし「繰り返し出せる結果」かは未確認。分かっていなければ危険、という整理。
- 「最近は毎日困っている」「同業者に助けてもらっている」「工程を変えてもらった」など痛みはある一方、「うちがこうなら他も同じ」「仕方ない」で止まりやすい。専門家は「高い金額を持っていかれて何も変わらない」と信用していない。
- 成果報酬なら「高い金額を取られない」ので検討余地はある、と言いつつ、採用1名あたり10万円ならやらない／3〜5万ならいいかも、と上限が低い。一方で、年間120万で応募10・採用5なら、採用1名あたりおおよそ24万円前後のコスト感とも読める。感覚と数字が噛み合っていない。
- 人が足りず裏を伸ばせていない感覚は薄い。「やれることはやっている」型。仮説（こうすればうまくいく）を持ちにくい。
- 「50人欲しい／14人採用で売上1億前後」など数字は出るが、やる気とつながっていない。
- インスタは担当の従業員が運用。契約に入っていない／ご自身はやらない。求人担当がいるなら、成果が悪化してテコ入れが必要になったとき、求人内製化アカデミーがマッチしうる。一方で「労力と経費がかかるなら業者に任せた方がいい」と言いながら社内にやらせている、など言動が噛み合わない箇所がある。
- Who除外としてまとめた内容（変える気がない／信用しない／仕組み改善の意思なし／完全丸投げ／支援費を経費と見ない）は方向として合っている、という確認。
- 次に足すのは、やめない仕組み・純増支援の実績ビフォーアフター、まとめ、1名増員シミュ、成果報酬の前に条件（クライアント側に持ってもらうこと）。

## ■問題の本質（重要）

- この社長タイプの核は「困っている」ではなく、**現状を変えるための投資・学習・仮説を持たない**こと。痛みの言葉だけ拾うと、需要過多型と同じレーンに誤って入れる。
- 思い込みのセットはセットで見る。待遇改善で採れる／ダメなら他社も同じ／専門家は高いだけ、が同時にあると、提案は「もっと頑張れ」では刺さらない。刺さるとしたら **ノーリスク（成果報酬）＋同業者の信用＋社内担当がすでにいる** の三点セット。
- 価格感のズレは、感情ではなく**今かかっている採用単価を並べて見せる材料**。10万が高いと言う相手に、いま実質いくら／1名かを見せないと、成果報酬の上限会話が空転する。
- 9月の5名は「成功事例」にしない。特別提案の一発か、再現可能な仕組みかを切り分ける。再現性がなければ、危機感の種にもなる。
- インスタ担当が社内にいるのは、**代行フル依存ではなく「社内1人に仕組みを渡す」モデルの入口**。1013のハロワ社内1人と同じ型。本人がやらない≠社内に担当がいない。
- Who除外は正解に近い。次の仕事は除外リストを増やすことではなく、**残ったWhoに見せる実績と条件**を先に埋めること。

## ■ズレ（思考 or 設計）

| 取れている | まだ薄い／次に足す |
|---|---|
| 業者依存・専門家不信・お金をかけたくない | 年間120万＋追加の内訳、応募→面接→採用の歩留まり |
| 待遇改善で採れる思い込み | 待遇以外で止まっている要因の仮説1つ |
| 9月に5名採用・退職1 | 特別提案の内容／普段年何名か／再現できるか |
| 「毎日困っている」と「仕方ない」の同居 | 需要過多型か、変えない型かのレーン判定 |
| 成果報酬への反応（3〜5万なら） | いまの採用単価との対比表をインタビュー後に埋める |
| インスタは従業員が運用 | 誰が・何を・週何時間か（未記入なら追加ヒア） |
| Who除外の言語化 | 除外後に残るWhoへの実績・シミュ・条件 |
| モデルへの転記意欲 | 実績ビフォーアフターとまとめが空欄のまま |

- 「困っている」だけで1013の需要過多レーンに寄せない。変える気・信用・経費認識をセットで見る。
- 成果報酬の上限だけ聞くと、現行コストとの矛盾に気づかない。並べて見せる側の準備が必要。
- Who除外が上手くいっても、実績と条件が無いと残った相手にも刺さらない。

## ■改善内容（What）

### 0. 維持してよい点

```
【良い】
・Who除外（変える気なし／信用しない／丸投げ／経費と見ない）の方向が合っている
・インタビューから「思い込みの強さ」を読み取れている
・成果報酬（ノーリスク）が検討の入り口になりうる、と見えている
・求人担当の従業員がインスタをやっている、という武器がある
・除外リストを増やし続けず、マッチした層へ寄せる姿勢
```

除外はバッチリ。次は「残ったWhoに何を見せるか」へ進む。

### 1. レーン判定：困っている ≠ 需要過多型

| 型 | 特徴 | この73名 |
|---|---|---|
| 1013需要過多型 | 出たい／人が阻止／「やりたい」 | 近い痛みはあるが、変える気・信用が薄い |
| 今回の型（変えない・不信） | 仕方ない／待遇で解決／専門家不信 | こちらの比重が大きい |
| 提案の入口 | ノーリスク＋同業者信用＋社内担当活用 | 成果報酬の金額感は対比表が必須 |

入口例（この型向け）：

```
いま業者に年120万前後かけて、応募は年10件前後。
採用1名あたりに換算すると、〇〇万円クラス。
それなのに「1名10万は高い」と感じるのは、数字が見えていないから。
初期費用ゼロに近い形で、採ってやめない仕組みを回しませんか。
社内の求人担当の方がいるなら、全部丸投げではなく仕組みを渡せます。
```

### 2. 価格感のズレを表にする（インタビュー後の宿題）

相手の発言と、こちらで計算した現行単価を並べる。

| 相手の感覚 | こちらで並べる数字（要検証） |
|---|---|
| 1名10万ならやらない | 年間広告費 ÷ 年間採用数 |
| 3〜5万ならいいかも | 応募1件あたりの広告費 |
| 業者は仕方ないコスト | 追加料金込みの実額 |

```
【確認したい追加質問】
・年間の求人業者費は120万ぴったりか、追加はいくらか
・その費用で、応募・面接・採用はそれぞれ何件／何名か
・9月の5名は、業者経由か、特別提案経由か
・普段の年の採用数は何名か（5名が異常値か）
```

「よくわからない思考回路」で終わらせず、次の壁打ち用の対比表にする。

### 3. 9月の5名は「再現性チェック」に使う

```
特別提案で一発 → 仕組みではない → 来年も同じとは言えない
普段から出せる設計がある → 純増支援の実績ネタになる
```

分かっていないなら、「いまのやり方では再現できないリスク」として危機感の種にする。成功自慢にしない。

### 4. インスタ担当＝社内1人モデルの入口

```
【取れている】
担当の従業員がインスタをやっている

【追加で取る】
・誰か（役職・年齢感）
・週何時間／何を投稿しているか
・求人原稿・ハロワ更新もその人か
・社長は何を見ているか（数字の報告があるか）
```

本人がやらない前提でも、社内に求人担当がいる会社は、アカデミー／代行のどちらでも「社内に残す」話がしやすい。1013のハロワ社内1人と同じ箱に入れる。

### 5. Who除外は確定。次は実績→まとめ→シミュ→条件

推奨の並び（モデル資料）：

```
1. 警備員純増・やめない仕組みづくりの実績（ビフォーアフター）
2. 警備員純増支援の実績（ビフォーアフター）
3. まとめ（辞めなくなり増えた結果、会社がどう変わったか）
4. だから同じ悩み・同じ環境なら同様の成果が出る可能性がある
5. 具体的にどう支援するか
6. 警備員1名増員の経済効果シミュレーション
7. 成果報酬（ノーリスクでスタート）
8. 守っていただきたい条件（クライアント側に持ってもらうこと）
```

実績ブロックに入れる項目：

| 軸 | Before | After |
|---|---|---|
| 年間採用数 | 何名 | 何名 |
| コスト | いくら／年 | いくら／年 |
| 労力 | 誰が何時間 | 誰が何時間 |
| 応募数 | 何件 | 何件 |
| 退職 | 何名 | 何名（例：5名→1名） |
| 会社の変化 | 断る仕事／残業／売上感 | どう変わったか |

### 6. 成果報酬の前に「条件」を書く

リスクをこちらが持つなら、相手にも持ってもらう必要がある。Who除外と直結する。

```
【条件の例（案）】
・社内担当を1人置く（インスタ／ハロワ更新ができる層）
・月次の打ち合わせに出る
・待遇・現場ルールなど、改善が必要な項目は決裁する
・完全丸投げ（何も決裁しない）は対象外
・支援費／成果報酬を必要経費として認める
```

除外リストに書いた会社は、この条件で自然に落ちる。残ったWhoだけが条件を飲める。

### 7. 次アクション：モデル資料の該当欄を埋める

```
【今回の提出で見たいもの】
・Who除外（今回の内容で確定してよい）
・実績ビフォーアフター（やめない＋純増）とまとめ
・1名増員シミュ（1013の数字種も流用可）
・成果報酬の前に置く条件リスト
・73名インタビューの「価格感対比表」下書き
```

感想メモの更新ではなく、モデルの空欄が埋まった状態。

## ■改善理由（Why）

- 困っている言葉だけで需要過多型に寄せると、変えない・不信の相手に同じオファーを投げ、空振りする。レーンを分けて入口を変える。
- 成果報酬の上限会話は、現行の採用単価と並べないと「高い／安い」が主観のままになる。数字の対比が信用の代わりになる。
- 9月の5名を実績扱いすると、再現できない成功でモデルが薄くなる。再現性チェックに使う方が提案が強い。
- 社内に求人担当がいる事実は、0929・1006・1013で言ってきた「社内1人に仕組みを渡す」と直結する。本人がやらない、で止めない。
- Who除外だけでは売れない。残った相手が見るのは実績の変化と、自分側の条件。並びは実績→まとめ→シミュ→成果報酬→条件。
- 言動の不一致（業者任せと言いながら社内でやらせる）は、深掘り質問の種。矛盾を責めるのではなく、誰が何をしているかの事実を取る。

## ■改善後イメージ（After）

読み手が次の順で理解できる状態。

```
1. この73名は「困っているが変えない・専門家不信」型の比重が大きい
2. 現行コストと成果報酬の上限が対比表で見える
3. 9月の5名は再現性未確認（成功自慢にしない）
4. インスタ担当が社内にいる → 社内1人モデルの入口
5. Who除外は確定。次は実績ビフォーアフターとまとめ
6. シミュ → 成果報酬 → クライアント条件、の順でモデルが埋まっている
```

ビジネスモデル資料を開くと、除外リストの次に実績と条件があり、空欄ではない。

## ■やりがちなミス

- 「毎日困っている」だけで需要過多型と同じ入口コピーを使う
- 成果報酬の上限だけ聞き、現行の採用単価と並べない
- 9月の5名をそのまま成功事例・実績欄に書く
- 本人がやらない＝社内に担当がいない、と誤読する
- Who除外リストを増やし続け、実績・条件の設計を後回しにする
- 言動の不一致を「よくわからない」で止め、追加質問に落とさない
- シミュの前に成果報酬の％だけ決める（順番が逆）
- 条件なしの成果報酬で、変えない・丸投げの会社を取り込もうとする
- 1013のネタ転記をせず、またインタビュー感想だけで終わる

## ■他の案件でも使えるパターン

### パターンA：困っている言葉のあとに「変える気」を見る

```
痛みの言葉
　↓
投資・学習・専門家への態度
　↓
需要過多型か／変えない・不信型か
```

### パターンB：価格感は対比表で処理する

```
相手の「高い」発言
　×
いま実際に払っている単価（応募／採用）
　→
成果報酬の上限会話が初めて意味を持つ
```

### パターンC：一発の採用増は再現性チェック

```
特別施策の結果か
普段の仕組みの結果か
分からなければ危機感の種（自慢にしない）
```

### パターンD：本人がやらない会社の見方

```
本人がやらない
　＋
社内に担当がいる → 仕組みを渡すモデル
社内にもいない → 代行比重か、Who除外寄り
```

### パターンE：モデルの推奨並び

```
実績ビフォーアフター
　↓
まとめ（会社の変化）
　↓
支援内容
　↓
1名増員シミュ
　↓
成果報酬
　↓
クライアント条件（除外と一致）
```

### パターンF：Who除外と条件は同じコイン

除外に書いた項目は、そのまま「守ってほしい条件」の裏返しにする。二重管理しない。

## ■一言まとめ（本質）

👉 Who除外は合っている。次は「困っている」と「変える気」を分け、価格感は対比表で整え、実績ビフォーアフター→シミュ→成果報酬→クライアント条件の順でモデルを埋める。

## ■1013・1006・0929との関係

- 1013：需要過多・「やりたい」・ネタの3箱転記。今回の73名は痛みはあるが変えない比重が強い。同じ入口をコピーしない。
- 1006：Who/What/How・実績分離・月次・社内作業。今回の宿題は実績ビフォーアフターと条件が直結。
- 0929：入口は純増・機会損失。内製化は後出し。インスタ担当がいるならアカデミー興味は後出し側でよい。
- 引き継ぐこと：インタビューを感想で止めない。シミュと社内1人。入口ラベルを内製化に戻さない。
- 今回新しく強調したこと：変えない・不信型のレーン、価格感の対比、9月5名の再現性、Who除外の次は実績と条件。
- 次の提出で見たいもの：除外確定＋実績ビフォーアフターとまとめ＋1名増員シミュ＋成果報酬前の条件リスト。
