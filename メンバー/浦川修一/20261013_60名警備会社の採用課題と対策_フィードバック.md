## ■分類（タグ）

- 社長インタビュー3人目（60名・4営業所・39年）
- 需要過多型（出たいが人が阻止）
- 規模拡大で数値把握が崩れる社長像
- 求人業者120万円／1名、応募は何十件
- 機会損失（10名不足＝現場増の換算）
- 高齢化（平均年齢60歳前後）と規模縮小懸念
- 「業界では無理」思い込み／ノーリスク提案の反応
- SNS・求人内製化興味と「自分ではやらない」
- ハロワは更新作業のみ→社内1人に仕組みを渡す

- 0911需要過多レーン／0908キープ型との対比

## ■現状（Before）

- 社長インタビュー3人目。60名規模・4営業所・創業39年。交通誘導・イベント・列車見張り・施設警備（おおよそ7割／3割）。社長自身は列車見張り・配置打ち合わせ・交通誘導の補佐など現場寄りで、営業はしていない。
- この規模になると、警備員数・離職者数・入社数を社長が把握しきれない。深掘りが止まっている箇所があるのは、そのせいでもある。
- 仕事は出たい。顧客は複数の警備会社に声をかけ、「人手を貸してほしい」系の依頼も来る。出たいのに人が足りず阻止される、という需要過多型。
- 交通誘導は「出すと入ってこない／抑えると入ってくる」感覚があり、交通誘導員が採れない。ターゲット設定ができていない、とメモにある。
- 将来性への危機感は本気。従業員の高齢化・平均年齢60歳前後。規模縮小せざるを得ない、現場負担増、体力負担の大きい仕事は断る、という流れまで見えている。
- 求人は業者任せ。月1時間程度のリサーチ＋ライティング、提携カメラマン。応募は何十件あるが採用は年間1名。業者経由の採用単価は約120万円／1名。ハロワその他を含めても3〜4名。昨年ゼロの年もある。
- 機会損失の見立て：約10名不足。1名あたり年間200現場なら、10名で年間2000現場クラス。金額感は「1億」ではなく、1000万〜2000万レベル、という整理。協力会社で穴を埋めているから、体感としての取りこぼしが薄くなりやすい。
- 人が増えれば事務所改修・待遇改善・資金繰り安定、までイメージはある。冬場に5人増えたら悩む、という発言もあり、季節のバッファ感覚がまだ曖昧。
- SNSは自分ではやらない。インスタは若手に任せたいが、何を投稿すればよいか分からない。求人内製化には興味が乗りそう。一方で「自分でやる方針」がないと、やり方を知っても動かない。ノーリスクなら「やってみてよ」と言いそうだが、条件を飲むかは別ハードル。「そんなにやらなくちゃいけないの」でおじけづく。同業者（浦川さん）がやるなら信用が乗りやすい。
- ハロワは更新作業程度を社内にやらせている。代行するなら、一通りの仕組みをつくり、社内から1人選んでもらって教える形が現実的。
- 決定的な一言：「求人業者に全部頼らなくても、自社で応募を作れる方法があるとしたらやってみたいですか？」→「やりたい」。依頼入りの匂いが強い。
- 「何やってもうまくいかない／この業界だと無理なのでは」という思い込みが強い。「検討しない」は拒否というより、やり方が分からない状態に近い。

## ■問題の本質（重要）

- 3人目は **0908キープ型ではなく、0911需要過多型に近いレーン**。入口は「困ってますね」ではなく、**出たい仕事を人が止めている／採れないと規模が縮む**話。
- 60名規模の社長は、数字の解像度が落ちる。深掘りが浅いのは「やる気がない」だけでなく、**把握しきれない設計**になっている。質問は「正確な人数」より「足りない感覚・断っている仕事・冬夏の差」で取る。
- 応募何十件→採用1名は、そのまま「厳選採用」と読んではいけない。面接まで何件つながったかが分からないと、**選んでいるのか、歩留まりが死んでいるのか**が判別できない。
- 機会損失は「1億」で盛らなくてよい。1000万〜2000万でも、**現場数換算（10名×200現場）と「あまり辞めない」**がそろえば、成果報酬・純増支援の根拠になる。協力会社で埋めているほど、本人の痛みは薄い。数字で見せる側が必要。
- 「やりたい」と言っても、自分で全部やる前提だと止まる。提案の核は **ノーリスク（成果報酬）＋同業者の信用＋社内1人に仕組みを渡す**。求人内製化は興味づけには使えるが、入口ラベルを内製化に寄せすぎない（0929・1006の続き）。
- インタビューのゴールは感想で終わらせない。**ビジネスモデル（Who／What／How）と広告・個別相談のネタ箱に、この会社の言葉をそのまま入れる**。

## ■ズレ（思考 or 設計）

| 取れている | まだ薄い／次に足す |
|---|---|
| 出たいが人が阻止／需要過多 | 断っている仕事の種類・頻度・金額感 |
| 60名・4拠点で数字が把握しきれない | 「足りない感覚」を測る質問セット（正確な人数にこだわらない） |
| 交通誘導が採れない・ターゲット未設定 | 誰を採りたいか／誰を採らないかの仮ターゲット1案 |
| 業者120万／1名・応募何十件 | 応募→面接→内定→入社の歩留まり |
| 10名不足・現場換算・1000〜2000万 | 1名増員シミュにそのまま落とす（1006の宿題） |
| 高齢化・規模縮小・全国2万人不足ニュース | 広告・動画用の一次ネタとして型化 |
| 「やりたい」反応が取れている | 条件（成果報酬・社内担当1名・期間）を飲めるかの確認質問 |
| 自分ではやらない／信用が鍵 | How側：同業者ポジションの見せ方 |
| ハロワは更新のみ | 代行時の「社内1人に教える」をスケジュール行にする |
| 冬場＋5人で悩む | 季節バッファ＝適正在籍のインタビュー項目 |

- 「厳選採用」と書いてしまうと、歩留まり問題が隠れる。数字の読み方を一度リセットする。
- 金額を1億に寄せると、この会社の現実感とズレる。現場数と1000〜2000万で十分強い。
- 求人内製化への興味はチャンスだが、入口コピーを「内製化」に戻すと0929の退行になる。入口は純増・機会損失・業者依存からの脱出。

## ■改善内容（What）

### 0. 維持してよい点

```
【良い】
・需要過多（出たい／人が阻止）がはっきり取れている
・「やりたい」まで到達している（依頼前提の反応）
・業者単価120万／応募は多いが採用は少ない、が同時にある
・10名不足×現場換算で機会損失を語れる種がある
・高齢化・規模縮小・全国不足ニュースなど、使えるネタが多い
・自分ではやらない／同業者なら信用、まで見えている
```

この3人目は、ビジネスモデルの **Who（需要過多で機会損失が出ている警備会社）** の具体例として強い。感想で止めず、モデルに落とす。

### 1. レーン確認：キープ型ではなく需要過多型

| 型 | 入口 | この会社 |
|---|---|---|
| 0908キープ型 | 守り・危機感が薄い | 当てはまらない |
| 0911需要過多型 | 機会損失・純増・代行 | 近い |
| 今回の固有情報 | 60名で数字が薄い／業者依存／「やりたい」 | 追加の武器 |

提案の入口例：

```
仕事は来ている。出せないのは人。
業者に年120万払って1人。
10人足りないと、現場が何千も増えない。
それなら、採って定着させて純増する仕組みを、ノーリスクで回しませんか。
```

### 2. 深掘り質問：数字が取れなくても前に進む

社長が人数を把握しきれない前提で、次を優先する。

```
・いま断っている／他社に回している仕事は月何件くらい感覚か
・交通誘導と施設で、採れ方の差は何か
・応募何十件のうち、面接まで何件くらいだったか
・昨年ゼロの年、現場と売上に何が起きたか
・冬に5人増えたら何が困るのか（仕事がない／教育／資金）
・事務所を直す・待遇を良くする、は具体的に何を指すか
・資金繰りが安定すると、社長にとって何が楽になるか
```

「正確な在籍数」より、**断っている仕事・歩留まり・季節の不安**の方が提案に直結する。

### 3. 「厳選採用」を歩留まりに分解する

```
応募数
　↓
面接数（ここが薄いと厳選ではない）
　↓
内定・入社
　↓
定着（あまり辞めない、が取れている）
```

何十件応募で年間1名は、厳選の可能性もあるが、**面接まで届いていない**可能性の方が高い。次のインタビュー／壁打ちで面接数だけでも取る。

業者120万／1名は、成果報酬や代行の比較材料としてそのまま使える。

### 4. 機会損失をビジネスモデルの数字箱へ

1006で宿題にした「1名増員シミュレーション」に、この会社の換算を入れる。

```
【この会社の種】
・不足感：約10名
・1名あたり：年間200現場（要検証・仮置き可）
・10名：年間2000現場クラス
・金額感：1000万〜2000万レベル（1億ではない）
・補足：協力会社で埋めているので痛みが薄い
・強み：あまり辞めない → 純増が積み上がりやすい
```

盛りすぎない。現場数と金額帯をセットで見せる。

### 5. 「やりたい」を契約条件の確認に進める

興味確認で止めない。次の確認セット：

```
・成果報酬（初期費用ゼロに近い形）なら進めるか
・社内に担当を1人置いてもらえるか（ハロワ更新ができる層）
・支援期間（例：1年）と月次の打ち合わせに出られるか
・自分でSNSや原稿を全部やる必要はない、と伝えたときの反応
```

「やってみてよ」の気楽さと、「条件を飲む」は別。後者まで取れたら依頼確度が上がる。

### 6. 信用設計：同業者×仕組みを社内に渡す

```
【止まるとこ】
やり方を知っても自分ではやらない
「そんなにやらなくちゃ」でおじけづく

【進むとこ】
同業者が伴走する信用
ノーリスク
ハロワ等は社内1人に仕組みを渡して回す
```

1006の「クライアント作業を月次で明示」と直結する。ハロワ更新ができる人を1人選んでもらい、そこに教える、をスケジュールに書く。

### 7. ネタの使い分け（広告／個別相談／モデル）

| ネタ | 使いどころ |
|---|---|
| 出たいのに人が阻止 | 入口コピー・共感 |
| 業者120万で1人／昨年ゼロ | 現状の非効率の証拠 |
| 応募は多いが採用が少ない | 歩留まり・原稿・ターゲットの話 |
| 10名不足×現場換算 | シミュレーション・クロージング |
| 平均年齢60前後・規模縮小 | 恐怖と逃げ道（純増） |
| 全国2万人不足ニュース | 業界共通の証拠 |
| 「やりたい」 | 個別相談の温度感の証拠（匿名化して） |
| 自分ではやらない／同業者なら | 代行・伴走オファーの正当性 |

求人内製化は、興味づけや教育の中盤以降。入口は機会損失／純増／業者依存からの脱出。

### 8. 次アクション：ビジネスモデルへの落とし込み

1006の箱に、この3人目を具体例として差し込む。

```
【Who】
需要過多で、出たい仕事を人が止めている警備会社
（60名前後で数字が把握しきれない層も含む）

【What】
採用して終わりではなく、定着させ純増の仕組みを作り機会損失を減らす
＋業者依存から自社で応募が作れる状態へ

【How】
集客・営業は別途。オファーはノーリスク＋同業者信用＋社内1人育成
```

提出物としては、インタビュー感想ではなく、**モデル資料の該当欄が埋まった状態**を見たい。

## ■改善理由（Why）

- 同じ警備業でも、キープ型と需要過多型で入口が違う。3人目を需要過多レーンに固定すると、0911・1006の提案が一本につながる。
- 60名規模は「数字が取れない」が普通に起きる。正確さにこだわるとインタビューが止まり、提案に使える感覚値（断っている仕事・季節・歩留まり）を逃す。
- 応募数だけで厳選採用と読むと、原稿・ターゲット・面接設計の改善余地が消える。歩留まりに分解すると、代行で触るポイントが見える。
- 機会損失を盛りすぎると信用が落ちる。現場換算と1000〜2000万の現実感の方が、成果報酬のシミュレーションに載る。
- 「やりたい」は温度であって契約条件ではない。ノーリスク・社内担当・自分で全部やらない、まで確認しないと、0929で言った代行モデルが現場で空転する。
- ネタが多い回ほど、感想メモで終わりやすい。広告・個別相談・モデルの3箱に振り分けて初めて資産になる。

## ■改善後イメージ（After）

読み手が次の順で理解できる状態。

```
1. この社長は需要過多型（出たい／人が阻止）
2. 業者120万・応募多い・採用少ない・昨年ゼロ、が現状
3. 10名不足を現場数と金額帯で見せると機会損失が具体
4. 「やりたい」＋ノーリスク＋同業者信用＋社内1人、がオファー
5. 求人内製化は興味づけ。入口ラベルは純増・機会損失
6. この会社の言葉が、Who／What／シミュ／広告ネタに転記済み
```

深掘りは「正確な人数」で止まらず、断っている仕事・面接歩留まり・冬の＋5人の意味まで取れている。  
ビジネスモデル資料を開くと、3人目の具体が空欄ではなく例として埋まっている。

## ■やりがちなミス

- 60名で数字が曖昧なのを「深掘り不足」だけで片付け、質問の型を変えない
- 応募何十件→採用1名を、そのまま厳選採用と書いて終わる
- 機会損失を1億に寄せて、この会社の温度感とズレる
- 「やりたい」で満足し、成果報酬・社内担当・期間の条件確認をしない
- 求人内製化への興味を入口コピーにして、純増・機会損失から離れる
- 自分ではやらない、を性格の問題にして、代行と社内1人育成の設計に落とさない
- 使えるネタが多いのに、インタビュー感想のままでモデル・広告に転記しない
- 0908キープ型と同じ質問セットを機械的に使う
- 協力会社で埋めている事実を無視し、「痛がっていない＝欲求がない」と誤読する

## ■他の案件でも使えるパターン

### パターンA：社長インタビューはレーンを先に決める

```
キープ型 → 守り・危機感の確認（押しすぎない）
需要過多型 → 機会損失・純増・代行・ノーリスク
```

### パターンB：人数が取れないときの代替指標

```
断っている仕事／他社に回している仕事
季節で増えたときの不安
応募→面接の歩留まり
「足りない」の感覚人数
```

### パターンC：応募多い×採用少ないは歩留まり分解

```
応募 → 面接 → 内定 → 定着
どこで落ちているかで打ち手が変わる
```

### パターンD：「やりたい」の次は条件確認

```
初期費用／成果報酬
社内担当者1名
自分で全部やらなくてよいことの明示
期間と定例
```

### パターンE：ネタは3箱に振り分ける

| 箱 | 入れるもの |
|---|---|
| モデル（Who/What/How） | タイプ・提供価値・オファー条件 |
| シミュレーション | 不足人数・現場換算・金額帯 |
| 広告・個別相談 | 生々しい一言・業界ニュース・業者単価 |

### パターンF：信用が薄い相手ほど「誰がやるか」を先に出す

やり方の説明より先に、**同業者が伴走する／社内に仕組みを残す／ノーリスク**を見せる。

## ■一言まとめ（本質）

👉 3人目は需要過多型の良事例。「やりたい」で止めず、歩留まり・機会損失の現実的な数字・ノーリスクと社内1人の条件まで落とし、ビジネスモデルと広告ネタに転記する。

## ■1006・0911・0908との関係

- 0908：キープ型。今回は違うレーン。同じ深掘り質問をコピーしない。
- 0911：需要過多・機会損失・成果報酬。今回はその具体例がもう1社増えた状態。
- 0929：入口は機会損失／純増。内製化は後出し。今回の「内製化興味」も後出し側。
- 1006：Who/What/How、実績分離、1名増員シミュ、月次とクライアント作業。今回のネタは、その空欄を埋める材料。
- 引き継ぐこと：入口ラベルを求人内製化に戻さない。代行＋成果報酬。ハロワは社内作業をスケジュール化。
- 今回新しく強調したこと：60名規模の数値把握の限界、厳選採用の誤読、1000〜2000万帯の機会損失、「やりたい」の次の条件確認、ネタの3箱振り分け。
- 次の提出で見たいもの：この3人目を差し込んだビジネスモデル更新稿（Who例・シミュ数字・オファー条件・広告／相談用の一言リスト）。
