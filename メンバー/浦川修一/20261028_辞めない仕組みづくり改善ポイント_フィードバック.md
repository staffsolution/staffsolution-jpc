## ■分類（タグ）

- やめない仕組み（実績ビフォーアフター）
- 面接チェックシート：改善前→後の「理由」
- バディ制度：なぜ選んだか／何なのか／導入後
- Googleフォームアンケート：なぜ選んだか／取り方
- ベネフィットの深掘り（その結果どうなったか）
- ミスマッチ採用の痛み（時間・金額の損失）
- 1021の続き（実績箱の肉付け）

---

## ■現状（Before）

- 1021で宿題にした「やめない仕組み」の実績ビフォーアフターを提出した段階。
- 導入後の実績の追加、面接〜研修〜仕事に慣れてきてから、の時系列3ステップは方向として良い。
- 一方で、改善前と改善後の変化に対して、「なぜそうしたか」の理由が薄い。
- バディ制度は導入前・導入後はあるが、「数ある選択肢の中でなぜバディか」「バディ制度とは何か（誰が・どの期間・何を重視するか）」が足りない。
- 成長促進・現状把握などの効果は書けているが、「その結果どうなったか」がもう一段届いていない。
- Googleフォームのアンケートも、なぜその手段か／どう取るかが分かれず、実施タイミング・アナウンスが薄い。
- 3つの対策のまとめ実績（導入前と導入後で離職が大きく減る数字）は非常に強い。内容全体としても喜ばれるレベル。次は理由・定義・深掘り・損失の具体でさらに刺さる形にする。

---

## ■問題の本質（重要）

やめない仕組みの実績は、「何をしたか」だけでは弱い。読み手が欲しいのは次の3つ。

```
1. なぜその打ち手にしたか（選択肢の中での選定理由）
2. その打ち手は何なのか（運用の定義）
3. その結果、現場と数字がどう変わったか（もう一段の結果）
```

ビフォーアフターだけ並べると「良いことした」で終わる。  
**改善理由 → 制度の中身 → その結果** まで落とすと、同じ数字が「再現できる仕組み」に見える。

また、ミスマッチ採用で早期離職が減った差が大きいなら、**減る前の痛み（時間・金額の損失）**を深掘ると、「応募を取るだけではない。選んで採用する」の説得力が一気に上がる。

---

## ■ズレ（思考 or 設計）

| 取れている | まだ薄い／足す |
|---|---|
| 時系列3ステップ（面接→研修→慣れてから） | 箱どうしのつながり（待った結果、として接続） |
| 改善前／改善後の中身 | なくした理由・入れた理由・聞く順番の理由 |
| まとめの成果実績 | 対策ごとの成果実績も欲しい |
| バディ導入前の問題／導入後の結果 | なぜバディか／バディとは何か |
| 成長促進・現状把握の記述 | 「その結果どうなったか」の深掘り |
| Googleフォーム実施の事実 | なぜフォームか／取り方／いつ・アナウンス |
| 導入前後の離職差（強い数字） | ミスマッチ採用の損失（時間・金額）の深掘り |

- 骨格と数字は十分強い。ズレは「理由・定義・結果のもう一段」が空いていること。
- まとめ実績だけだと、どの対策が効いたかがぼやける。項目ごとの結果も置く。

---

## ■改善内容（What）

### 0. 維持してよい点

```
【良い】
・やめない仕組みの実績を追加している
・面接→研修→仕事に慣れてきてから、の時系列3ステップ
・導入前後で離職が大きく減る数字（まとめ実績）が強い
・内容全体として、クライアントに喜ばれる水準
```

直すのは「足す」側。骨格は崩さない。

### 1. 面接チェックシート：改善前→後に「理由」を入れる

改善前はこう聞いていた／改善後はこうした、だけでなく、次を足す。

| 入れる理由 | 例 |
|---|---|
| ここをなくした理由 | なぜその質問をやめたか |
| ここを入れた理由 | なぜその質問を追加したか |
| 順番の理由 | なぜこの順番で聞くことにしたか |

```
【改善前】こう聞いていた
【改善後】こう変えた
【なぜ変えたか】なくした理由／入れた理由／順番の理由
【その結果】（この対策単体の成果があればここにも）
```

### 2. 箱のつなぎ：別々に見えないようにする

時系列の途中で「別の話」に見える箇所は、**待った結果／だからこうなった**でつなぐ。

```
1ヶ月待った
　↓
その結果として ○○
```

見出しどうしが並ぶだけでなく、因果で読めるようにする。

### 3. バディ制度：選定理由と定義を足す

導入前の問題 → 導入後の結果、のあいだに次を入れる。

```
【導入前】このような問題があった
【選定】数ある選択肢の中で、なぜバディ制度にしたか
【定義】バディ制度とは何か
　・誰が対応するか
　・どのぐらいの期間か（例：一人につき○週間で解消、など）
　・何を重視するか
【導入後】結果（いまある実績）
```

「一人1週間後にバディ解消」などは、定義側に入れる。

### 4. ベネフィットの深掘り：「その結果どうなったか」

成長促進・現状把握で止まらず、もう一段書く。

| いまの記述（例） | 足す深掘り |
|---|---|
| 教育担当が教えるのが上手くなった | その結果、現場では何が変わったか |
| 新入社員の苦手を把握できるようになった | 苦手を集中して教えられた → 成長が早まった → その結果どうなったか |
| 教えるのが上手いかの判断材料になった | それまで上手い／下手の基準がなかった → その結果どうなったか |

同じ人が二人三脚で付き添う、までは書けている。  
**把握できた → だから何が起きたか** を繰り返し足す。

### 5. Googleフォーム：なぜ選んだか／取り方を分ける

```
【なぜGoogleフォームのアンケートにしたか】
【アンケートの取り方（どういうものか）】
　・毎月第1・第3金曜の、いつのタイミングか（仕事後か等）
　・アナウンスはどうしているか
　・早期把握など、このアンケートで何が見えるか
```

「なぜ」と「どういうものか」を分けた方が読みやすい。

### 6. 成果実績：まとめ＋対策ごと

まとめの実績（3つの対策の総合結果）は今の位置でよい。  
加えて、**項目ごとの対策の結果**も置く。

```
・面接チェック改善 → その結果
・バディ制度 → その結果
・Googleフォーム → その結果
・まとめ（導入前 ○名／導入後 ○名、など）
```

導入前と導入後の差が大きい数字は、そのまま強みとして残す。

### 7. ミスマッチ採用の痛みを深掘る（任意だが強く効く）

応募を取ることも大事だが、**選んで採用する**差がこの数字で見える。  
早期離職の痛みを、時間と金額で置く。

```
例（実態の数字に合わせる）
・16名中9名がミスマッチで3ヶ月以内退職、など実数があるなら使う
・これが1年続くと、時間・人件費でどれだけの損失か
・だから「選んで採用する」と、この差が起きる
```

「もったいない」が数字で伝わる状態にする。

---

## ■改善理由（Why）

- 1021の宿題は実績ビフォーアフター。骨格と数字は出たので、次は「再現できる理由」まで落とす段階。
- クライアントは「何をしたか」より、「なぜそれで離職が減ったか」を知りたい。理由と定義がないと、自社に移植できない。
- 「その結果どうなったか」を一段足すと、成長促進・現状把握が抽象で終わらず、現場の変化になる。
- 離職差が大きいなら、Before側の損失を深掘った方が、同じ数字がもっと刺さる。
- まとめ実績だけだと、どの打ち手が効いたか分からない。対策ごとの結果があると提案資料としても使いやすい。

---

## ■改善後イメージ（After）

```
1. 面接チェック：改善前→後→なぜ変えたか→結果
2. バディ：問題→なぜバディか→何なのか→導入後の結果
3. フォーム：なぜ選んだか／取り方（いつ・アナウンス）→結果
4. 各対策の結果＋まとめの強い数字
5.（任意）ミスマッチ採用の損失が時間・金額で見える
```

音読して、「なぜこの打ち手？」「その結果は？」で止まらない状態。

---

## ■やりがちなミス

- 改善前／後だけ書いて、「なぜ変えたか」を空にする
- バディの結果だけ書いて、選定理由と定義（誰・期間・重視）を省略する
- 「把握できた／上手くなった」で止め、「その結果どうなったか」を書かない
- Googleフォームの「なぜ」と「取り方」を1箱に混ぜる
- まとめ実績だけ置き、対策ごとの結果を置かない
- 強い数字があるのに、ミスマッチの損失側を深掘らず機会を逃す
- 時系列の箱が並ぶだけで、因果のつなぎ語がない
- 1021のWho除外や価格対比など、別宿題まで同時にいじって散らす

## ■他の案件でも使えるパターン

### パターンA：打ち手は「なぜ選んだか／何なのか／結果」の3点セット

```
問題
　↓
なぜこの打ち手か（選択肢の中での選定）
　↓
打ち手の定義（誰・期間・運用）
　↓
導入後の結果
```

### パターンB：効果語のあとに「その結果」を1段足す

```
○○できるようになった
　↓
その結果、現場／数字ではこう変わった
```

同じ型を2〜3回繰り返すと、抽象が映像になる。

### パターンC：まとめ実績＋項目別実績

総合のビフォーアフターは残す。  
加えて、対策A／B／Cごとの結果も置くと、再現の説明がしやすい。

### パターンD：強い改善数字のときは、Beforeの損失も書く

```
減った離職数（Afterの自慢）
　＋
減る前にかかっていた時間・金額（Beforeの痛み）
```

両方あると、「選んで採用する」の重要性が伝わる。

## ■一言まとめ（本質）

👉 やめない仕組みの骨格と数字はとても良い。次は改善理由・制度の定義・「その結果どうなったか」と、対策ごとの成果を足し、必要ならミスマッチ採用の損失まで深掘る。
