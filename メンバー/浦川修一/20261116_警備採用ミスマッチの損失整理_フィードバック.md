## ■分類（タグ）

- やめない仕組み／ミスマッチ採用の痛み（損失）整理
- コスト数値化（法定研修・現場研修・人件費・交通費）
- 痛みの因果一本化（コスト → 辞めさせられない → 既存負担 → 受注できない）
- 機会損失の数字（いちばん大きい）
- ハローワーク紹介停止・労基／悪質判定の損失
- 社労士「退職勧奨を避ける」の理由
- 採用判断ルールの共有（血液型なども含む）
- 1103・1028の続き（損失・実績の深掘り）

---

## ■現状（Before）

- 青字まわりで、警備員配置の組み合わせが余計に労力になる、という痛みを書いている。
- 数値化が進んでいる。法定研修20時間、現場研修4日間、経費13万＋、かかった時間・人件費・交通費など。ここはわかりやすい。
- 13万は新人にかかった経費。教育担当の人件費と交通費は別枠。時間もコストとして捉える、という整理ができている。
- 一方で、既存警備員への負担が会社の損失につながる形が、まだ弱い。直接的な苦情はなかった、とあるため、事実だけで押し切れない箇所がある。
- ミスマッチ判明後も簡単に雇用契約を終了できない、ハローワーク紹介が止まる可能性、社労士から退職勧奨を避けるよう言われる、などの材料はある。理由と順番のつなぎがまだ揃いきっていない。
- 後半の「さっきの痛みとつながる」箱はインパクトが大きく、方向は良い。採用判断ルールの共有を足す話も出ている。

---

## ■問題の本質（重要）

ミスマッチ採用の痛みは、経費の羅列だけでは伝わらない。読み手が欲しいのは次の一本。

```
コストが無駄になる
　↓
ミスマッチが判明しても、簡単に雇用契約を終了できない
　↓
配置が難しくなり、既存警備員の負担が増え、疲弊する
　↓
戦力になっていないのに人数だけ増える
　↓
仕事があるのに受注できない（機会損失）
```

いちばん大きいのは機会損失の数字。研修費13万は入口。その先に「受注できない」「信頼が落ちる」「離職につながる」まで落ちると、痛みが会社全体の話になる。

ハローワーク紹介停止も、「ハロワを重要だと思っていない社長」には刺さらない。警備ではハローワークとジョブリスティングの組み合わせが最適、という前提を置いたうえで、「紹介が止まる＝大きな損失／悪質判定は絶対に避ける」まで持っていく。

## ■ズレ（思考 or 設計）

| 取れている | まだ薄い／直す |
|---|---|
| 研修時間・経費・人件費・交通費の数値化 | 時間＝コスト、の扱いを明示する |
| 新人経費13万と教育担当コストの分離 | 痛みの順番が一本になっていない |
| 辞めさせられない／配置が難しい、の材料 | 既存負担 → 疲弊 → ひどい結果、まで落とす |
| 直接苦情はなかった、という正直さ | 事実が薄いなら調査・あるあるで補う |
| 機会損失が大事、という感覚 | 機会損失の数字を痛みの頂点に置く |
| ハロワ紹介停止の言及 | 「別にいい」と思われないよう、重要性と損失をセット |
| 社労士の退職勧奨回避 | なぜそう言われるかの理由 |
| 後半のつながり箱は良い | 採用判断ルールの共有を追加 |

- ズレの本体は、材料はあるのに「コスト → 辞められない → 既存疲弊 → 受注できない」の因果がまだ一本でないこと。
- 苦情がない箇所を空欄のままにせず、調査して「どんな問題が起きるか」まで落とす。

## ■改善内容（What）

### 0. 今回やること（優先）

```
【直す／足す】
・痛みの順番を一本にする（下の流れ）
・機会損失の数字を、いちばん大きい損失として入れる
・既存負担 → 疲弊 → ミス／事故／信頼低下／離職の恐れ、まで落とす
・事実が薄いところは、ネット調査などで問題例を補う
・ハロワ紹介停止＝大きな損失（悪質判定は絶対避ける）まで書く
・社労士が退職勧奨を避ける理由を足す
・採用判断ルールの共有を追加（血液型などの例も参考）

【触らない／維持】
・法定研修・現場研修・13万＋の数値化の方向
・後半の「痛みとつながる」箱の骨格（良い）
・時間をコストとして捉える考え方
```

言い回しは一通り読んで、納得したところだけ変える。違う箇所は実態に合わせて直す。

### 1. 痛みの全体構成（この順番）

```
1. コストが無駄になる
　（法定研修20時間／現場研修4日／新人経費13万＋／教育担当人件費／交通費／時間＝コスト）

2. ミスマッチが判明しても、簡単に雇用契約を終了できない

3. 警備員の配置が難しくなる
　→ 既存警備員の負担が増える
　→ 疲弊する
　→ ミス・事故・顧客からの信頼低下・離職につながる恐れ

4. 戦力になっていないのに人が増えている
　→ 仕事があるのに受注できない（機会損失）
```

「配置が難しくなる」で止めない。負担増 → 疲弊 → ひどい結果、まで持っていく。

### 2. 機会損失を頂点に置く

```
【いちばん大きい】
採用に関わるコストの先にある、受注できない機会損失の数字

【入口のコスト】
新人経費13万＋教育担当＋交通費＋時間
```

機会損失が「でかい」と分かっているなら、そこに特化して厚くしてよい。研修費だけの話で終わらせない。

### 3. 既存負担の具体（苦情がなくても）

直接的な苦情がなかった場合でも、空欄にしない。

```
・既存警備員に負担を与え、会社の損失につながる形で書く
・事実が薄いなら、調査して「どんな問題が起きるか」まで落とす
・ミス／事故／信頼低下／離職の恐れ、など結果側までつなぐ
```

AIに聞くのはよい。そのうえで、自社の実態と矛盾しないか確認する。

### 4. ハローワーク紹介停止の書き方

```
【弱い書き方】
紹介が止まる可能性がある
　→ 「ハロワを使わなければいい」と思われる

【強い書き方】
警備では、ハローワークとジョブリスティングの組み合わせが最も適している
　→ 紹介が止まるのは大きな損失
　→ 労基／ハローワークに悪質と判断されることは絶対に避ける
```

重要性を先に置いてから、停止のリスクを書く。

### 5. 社労士の「退職勧奨を避ける」に理由を足す

```
社労士から、できるだけ退職勧奨しないように言われる
　→ （なぜそう言われるのか。社労士の理由を入れる）
```

理由がないと、「言われたから」で終わり、痛みの因果に乗らない。

### 6. 後半箱と採用判断ルール

```
【維持】
痛みとつながる後半の箱。インパクトは大きい。方向OK。

【追加】
採用判断ルールの共有
（血液型など、判断材料の扱いも含め、必要な修正は入れる）
```

### 7. 提出前の自己チェック

```
・コスト → 辞められない → 既存疲弊 → 受注できない、の順か
・機会損失の数字が、痛みの頂点にあるか
・「配置が難しい」で止まっていないか
・苦情なし箇所を、調査で補っているか
・ハロワ停止に、重要性と損失がセットか
・社労士の一言に理由があるか
・採用判断ルールの共有が入っているか
```

---

## ■改善理由（Why）

- 数値化した研修費はわかりやすいが、会社が本当に痛いのは「人が増えたのに受注できない」側。機会損失を頂点にすると、ミスマッチ防止の必要性が一気に立つ。
- 辞めさせられない、だけでは抽象。既存が疲弊し、ミスや信頼低下までつながると、現場の痛みになる。
- 苦情がなかったことを正直に書くのはよい。ただし空欄のままでは弱い。調査で「起きうる問題」まで落とすと、説得力が残る。
- ハロワ紹介停止は、ハロワの価値を知らない相手には刺さらない。最適な組み合わせだと先に置いてから損失を言う。
- 社労士の注意も、理由がないとルールの暗記になる。なぜ避けるかが入ると、痛みの一本に乗る。

---

## ■改善後イメージ（After）

```
1. 痛みの箱を開く
2. まず研修・人件費・交通費の無駄が見える
3. 次に、判明しても簡単に切れない、が見える
4. 既存が負担・疲弊し、ミスや信頼低下までつながる
5. 頂点に、仕事があるのに受注できない機会損失の数字がある
6. ハロワ紹介停止は「大きな損失／悪質判定は避ける」まで書いてある
7. 社労士の注意に理由がある
8. 後半のつながり箱と、採用判断ルールの共有が続く
```

音読して、「なぜミスマッチが会社を壊すか」に、コストと機会損失の両方で即答できる状態。

---

## ■やりがちなミス

- 研修費13万だけで終わり、機会損失まで上げない
- 「配置が難しい」で止め、既存の疲弊・結果まで落とさない
- 直接苦情なしを理由に、負担の具体を空欄のままにする
- ハロワ紹介停止だけ書いて、「使わなければいい」余地を残す
- 社労士の注意を、理由なしで並べる
- 痛みの順番を入れ替え、受注できないが途中で消える
- 後半の良い箱まで一緒に崩す
- AIの一般論を、自社実態と照合せずそのまま貼る

## ■他の案件でも使えるパターン

### パターンA：損失は「入口コスト → 切れない → 現場疲弊 → 機会損失」

```
かかったお金・時間
　↓
簡単に終わらせられない
　↓
残った人が疲弊する
　↓
売上機会を逃す
```

### パターンB：事実が薄いときは「調査で結果側を補う」

```
自社に直接苦情がない
　↓
起きうる問題を調べる
　↓
ミス／信頼／離職など結果に接続する
　↓
自社実態と矛盾しないか確認する
```

### パターンC：相手が軽く見そうなリスクは「重要性 → 損失」の順

```
その手段がなぜ大事か（例：ハロワ＋求人内製化）
　↓
それが止まる／傷つくと何が失われるか
　↓
だから絶対に避ける
```

警備以外の採用支援でも、同じ型で使える。
