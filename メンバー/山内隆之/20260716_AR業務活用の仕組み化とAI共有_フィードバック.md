# 講師プロフィール「現在の活動」——個人利用から仕組み化への訴求整理（フィードバック）

2026年7月16日

**フィードバック動画：** <a href="https://www.loom.com/share/be526b9d941d4ef7a4ed5492704a6e71" target="_blank" rel="noopener noreferrer">Loomで見る</a>

---

## ■分類（タグ）

- 講師プロフィール・現在の活動
- AI業務改善プロジェクト（0710の続き）
- 「繰り返し作業にも使えます」の前提ズレ
- 活動例の実態合わせ（メール・文字起こし・要約）
- 個人利用 → 会社の仕組み化・ノウハウ蓄積
- 複数社員利用のインパクト（説明削減・基準底上げ・成果）
- 分量はこの程度でよい

---

## ■現状（Before）

- 対象はサービスLPではなく、**講師プロフィールの「現在の活動」**。0710で決めた「AI業務改善プロジェクト」を、プロフィール文言に落とし込む回。
- 「半自動化」という言い方自体はOK。
- 「多くの会社が該当する内容を踏まえて、業務改善・仕組み化のプロジェクトをやっています」と持っていく方向もOK。
- いまいちしっくりこない点は次のとおり。

### 1. 「繰り返し作業にも使えます」がピンとこない

提出文に近い表現：

> AIはメール対応やデータ集計、会議メモの整理など、繰り返し作業にも使えます

問題：

- 「繰り返し作業に**も**」と書くと、「まだ繰り返し作業には使えていない」前提に聞こえる。
- 実際、多くの会社はメール対応・データ集計・議事メモ整理などを**すでにAIでやっている**。
- 「そこまで載せていないのに『にも』と言う」ので、読み手の頭とズレる。

本当のギャップはここ：

| 多くの会社がやっている | まだやれていない |
|---|---|
| 社員が個別にAIを使う（メール・要約など） | ルーティンをAIで半自動化する |
| | 会社として仕組み化する |
| | 何ができるか・どう組み込むかがわからない |

### 2. 活動例が実態より上

提出側の並び（イメージ）：

> メールの文章を作ったり、データを整理したり、アイデアを出したり

実態に近いのは：

> メールの文章を作ったり、文字起こししたり、要約したり

「データ整理・アイデア出しまでやれている会社は多くない」。並べると共感が弱くなる。

### 3. 「仕組み化します」で止まり、結果のインパクトが見えない

- 「社内の情報・知識・ノウハウを蓄積します」までは書けても、**それで何が起きるのか**が一見でわからない。
- 一人利用なら「何人分の仕事ができる」は比較的言える。
- **複数社員で使う場合**のインパクト（同じ説明の削減／基準の底上げ／営業成績など）が弱い。

---

## ■問題の本質（重要）

- プロフィールの「現在の活動」は、サービス説明の短縮版ではない。読み手が「うちもその状態だ → だからこの人に頼む」と**3秒でつながる文**にする必要がある。
- 書き方の骨格は0710と同じでもよいが、プロフィールでは次の順が必須。

```
多くの会社はここまでやっている（個人利用）
　↓
でもここまではやれていない（半自動化・仕組み化・ノウハウ蓄積）
　↓
どうやるかわからない／本当にできるかわからない
　↓
ヒアリングして整理し、組み込めるようサポートしている
　↓
その結果どうなるか（一人／複数社員で違うインパクト）
```

- 「AIも使えます」「繰り返し作業にも使えます」は、**すでに使っている層**に対して一段下の話になる。依頼動機が立たない。
- 経営者が欲しいのは効率だけではない。**効率＋成果（ノウハウ共有で基準を上げ、成績につなげる）**まで落とすと刺さる。

---

## ■ズレ（思考 or 設計）

| 書いてあること | 読み手が感じること |
|---|---|
| 繰り返し作業にも使えます | うちはもう使ってる。で？ |
| データ整理・アイデア出し | うちはそこまでやってない／関係ない |
| 仕組み化・蓄積します | だから何が変わるの？（インパクト不明） |
| 一人の時短イメージ中心 | 全社で効かせたい経営者に届かない |

- 0710で「質問するAI → 動かすAI」と整理したのに、プロフィールだけ「AIも使えます」に戻ると、**同じ案件なのにストーリーが戻る**。

---

## ■改善内容（What）

### 1. 「にも使えます」をやめ、ギャップ型にする

**やめる：**

```
AIはメール対応やデータ集計、会議メモの整理など
繰り返し作業にも使えます
```

**にする（推奨の並び）：**

```
【多くの会社の現状】
メール対応・文字起こし・要約など、
社員が個別にAIを使っている

【まだやれていないこと】
・ルーティン作業の半自動化
・会社としての仕組み化
・社内ノウハウの蓄積・共有
・何ができるか／どう組み込むかがわからない

【このプロジェクトでやること】
ヒアリングで業務を整理し、
AIで代わりにできるところ・半自動化できるところを特定。
仕組みとして組み込めるようサポートする
```

分量は**この程度**でよい。長くしない。

### 2. 活動例を実態に合わせる

| 削る／弱める | 残す・置き換える |
|---|---|
| データを整理したり | メールの文章を作ったり |
| アイデアを出したり | 文字起こししたり |
| （先進的な使い方の列挙） | 要約したり |

そのうえで一文足す：

```
しかしその多くは、社員が個別にAIを使っているだけ。
会社としてルーティンを半自動化したり、
社員みんなでノウハウを蓄積する仕組みにはなっていない。
```

### 3. 結果のインパクト——一人と複数を分けて書く

**一人で使う場合（明確）：**

- ルーティンをAIに任せ、一人で複数人分の処理に近づける

**複数社員で使う場合（ここを厚く・簡潔に）：**

```
社員みんながAIを使い、社内の情報・知識・ノウハウを整理・蓄積する
　↓
同じ説明・同じ確認を繰り返す時間が減る
　↓
長く使えるノウハウが社内に残り、共有される
　↓
一定のクオリティ・基準を底上げできる
　↓
例）営業なら：時間が増え、成績にもつながりやすい
```

経営者が求めているのは「効率だけ」ではなく、**成果につなげるノウハウをみんなで共有できること**。そこまで1本でつなぐ。

### 4. プロフィール用・完成イメージ文（コピペ下書き）

言い回しは山内さんの口調に合わせてよい。骨格はこのまま使う。

```
多くの会社では、AIでメール作成や文字起こし・要約までは使われています。
一方で、ルーティン作業の半自動化や、社内ノウハウの蓄積まで
仕組み化できている会社はまだ少ないのが実情です。
何ができるのか、どう組み込めばよいのかもわからない、という相談が多いです。

日々の業務をヒアリングし、AIで代わりにできる部分を整理。
半自動化と仕組み化までサポートし、
社員全員でノウハウが残り、同じ説明を繰り返さずに済む状態をつくります。
結果として、社内の基準を底上げし、営業など本業の成果にもつなげやすくします。
```

※サービス名は0710どおり **AI業務改善プロジェクト**。プロフィールだけ別名にしない。

### 5. 0710との対応表

| 0710で決めたこと | 今回プロフィールでの落とし込み |
|---|---|
| 質問するAI → 動かすAI | 「個別利用」→「半自動化・仕組み化」で書く |
| 3段（現状→ギャップ→提供） | プロフィールでも同じ3段。分量だけ短く |
| あるある事例 | メール・文字起こし・要約（データ整理・アイデア出しは避ける） |
| ベネフィット＝大事な仕事へ | ＋複数人なら「説明削減・基準底上げ・成果」まで |

---

## ■改善理由（Why）

- 「にも使えます」は、すでに使っている層の**既知の話**になり、依頼理由が消える。
- 活動例を実態に合わせると、「うちもそう」→「でも仕組み化までは…」とギャップが見える。
- 「蓄積します」だけで止めると、経営者は投資対効果を想像できない。**時間・品質・売上**まで落とすと刺さる。
- 一人と複数を分けると、「社長の時短」だけでなく「組織の底上げ」として読める。0710のターゲット（もっとできるはずの層）にも届く。

---

## ■改善後イメージ（After）

- プロフィールを読んだ人が、次の順で理解できる。

```
うちはメール要約くらいはやってる
　↓
でも全社の仕組み・ノウハウ蓄積にはなってない
　↓
やり方もわからない
　↓
この人にヒアリングしてもらえば組み込める
　↓
説明が減り、基準が上がり、成果にもつながる
```

- 「半自動化」の言葉は残り、**前提のズレだけが消えている**。
- 0710のサービス文と、プロフィールの「現在の活動」が同じストーリーでつながっている。
- 分量は短く、壁打ちで「この程度でいい」と確認したボリューム感になっている。

---

## ■やりがちなミス

- 「繰り返し作業にも使えます」で、読み手より一段下の前提で書く
- データ整理・アイデア出しなど、まだ普及していない使い方を「みんなやっている」ように並べる
- 「仕組み化・蓄積」と書いて、**だから何が変わるか**を飛ばす
- 一人の時短だけ書いて、複数社員のインパクトを省略する
- 0710で短くした訴求を、プロフィールだけ長く・別ストーリーにする
- 「AIも便利です」系の一般論に戻す

---

## ■他の案件でも使えるパターン

- **「〇〇にも使えます」**より **「多くはここまで。次は仕組み化」** の2段
- 活動例は**ターゲットの今**に合わせ、理想の使い方は**提供内容**側に置く
- ベネフィットは **状態 → 社内に何が残る → 品質・成果** まで1本
- 一人利用と複数利用で、言えるインパクトを分ける
- サービス訴求とプロフィールは、言い回しを揃えて矛盾をなくす

---

## ■一言まとめ（本質）

👉 「繰り返し作業にも使えます」をやめ、**個人利用の先（半自動化・仕組み化・ノウハウ蓄積）**を短く書く。活動例はメール・文字起こし・要約に合わせ、複数社員では「同じ説明が減る → 基準が上がる → 成果につながる」まで落とす。

---

## ■2026-07-10との関係

- 0710：サービス名の1本化、3段構成、あるある事例、ターゲットの両方
- 今回：同じプロジェクトを**講師プロフィールの現在の活動**に載せるときの、**前提のズレ修正・活動例の実態合わせ・複数人インパクトの追加**
- 0710の骨格は維持。プロフィールは短く、同じ因果で書く
