## ■現状（Before）

- 0908で、「諦めなくていい」は間接なので捨て、ベースを**正社員で稼ぎながら自力で免許＋指名される美容師**にし、6000件のあとに他店差・教え方・一般技術との差を埋める、と決めた。
- その後の案では、ヘッドに「高卒から正社員で美容師を目指す新しい進路」系が入っている。方向は近いが、**何を約束しているかがふわっとする**。
- 案が2つあるが、**同じことを話している**。載せるなら、もう一方は別の情報である必要がある。
- 「正社員で働き、自分で学費を稼ぐ。免許を取り、指名される美容師へ」まで書けている。0908の直接化は反映されている。
- ただし「指名される」単体だと、**一般的な美容室と同じ約束**に聞こえる。
- 6000件側は、「状態・薬剤・工程を自分で考える／判断できる」まで書けているが、**他の縮毛矯正・髪質改善店との差が見えない**。

---

## ■問題の本質（重要）

- ヘッドの仕事は「新しい進路です」とラベルを貼ることではない。読み手が一拍考えずに受け取れる**強い約束**を、ストレートに置くこと。
- 0908の「指名される美容師」は、ふわっとした「悩みに応える」より直接的だった。今回はその先。どの店でも言える結果語の前に、**誰のどんな痛みを解いて指名されるか**を置く。
- 他店と当社では、お客が求めていること自体が違う。他店は「より美しく・かっこよく・かわいくなりたい」という願望を叶える。当社の縮毛矯正・髪質改善は、コンプレックスで苦しんでいる人を救う仕事で、医療に近い。
- 6000件の価値は件数そのものではない。「自分で考えて判断できる」でもまだ抽象。価値は、**悩みをパターンに分け、それぞれのプロセスを体系化したこと**。その通りにやれば、ほぼ悩みを解ける、まで言えて初めて他店差になる。

## ■改善内容（What）

### 1. 「新しい進路」を、強い約束に置き換える

ふわっとしたラベルはヘッドにしない。0908と同じで、できることをストレートに言い切る。

```
【弱い（ふわっと）】
高卒から正社員で美容師を目指す新しい進路

【強い（約束）】
正社員で働き、自分で学費を稼ぐ。
免許を取り、苦しむお客を救える美容師へ
```

「新しい進路」は説明には使えるが、ヘッドの主役にはしない。読んだ瞬間に約束が立つ言い方にする。

### 2. 2案があるなら、同じ話を重ねない

2つ載せるなら、役割を分ける。同じ約束を言い換えただけなら、1つにまとめる。

```
【重ねない】
案A：正社員で働き、学費を稼ぎ、免許を取る
案B：正社員で美容師を目指す新しい進路
→ 同じ話

【分ける例】
案A（約束）：稼ぎながら自力で免許 → 救える美容師へ
案B（中身）：6000件で体系化した技術が身につく
```

スペースが足りないなら、約束を1本にして、中身は下のブロックへ落とす。

### 3. 「指名される」の前に、救う路線を置く

「指名される美容師」は残してよい。ただし単体だと一般店と同じ。**誰を、何から救うか**を先に置く。

```
【一般店と同じに聞こえる】
免許を取り、指名される美容師へ

【差が出る】
コンプレックスで苦しむお客を救う技術を身につけ、
指名される美容師へ
```

「指名」は結果。差は、その指名が「きれいにしてほしい」ではなく「苦しんでいる人を助ける」から来る、と読めること。

### 4. 他店と当社で、お客の求めが違うことを先に出す

ここが今回のポジション。他店を貶すのではなく、求めているものが違う、と対比する。

| 他の美容室に多い | 当社（縮毛矯正・髪質改善） |
|---|---|
| より美しくなりたい | コンプレックスで苦しんでいる |
| かっこよく・かわいく・きれいになりたい | 長年の髪の悩みを解消したい |
| 願望を叶える腕を磨く | 苦しむ人を救う技術を磨く |
| 美容・デザイン側 | 医療に近い側 |

```
【他店】
より美しく、かっこよく、かわいくなりたい。
その願望を叶える腕を磨いていく。

【当社】
髪のコンプレックスで苦しんでいる人を救う。
縮毛矯正・髪質改善は、きれいにする仕事というより、
苦しみを解く仕事に近い。
```

お客が求めていることが違う、と分かると、「指名される」の意味も変わる。求職者には「自分がどんな美容師になるか」が映像で見える。

### 5. 6000件を「考える・判断」ではなく、パターンと体系化で書く

「状態・薬剤・時間・工程を自分で考えて判断できる」は方向は正しいが、まだ難しい。他の縮毛矯正・髪質改善店でも言えそうに聞こえる。

6000件があるから言える中身は、次の因果。

```
13年・6000件以上の施術記録
　↓
髪の悩みは、いくつかのパターンに分けられる
　↓
パターンごとに、どのプロセスで施術すればよいかが体系化されている
　↓
その通りにやることを身につける
　↓
ほぼ、悩みを解決できるようになる
```

言い回しの例（店の実態に合わせて調整）：

```
【弱い（抽象）】
状態・薬剤・工程を自分で考えて判断できる美容師へ

【強い（具体）】
6000件以上の記録から、髪の悩みはパターンに分けてある。
パターンごとの薬剤・時間・工程が体系化されているので、
その通りにやることを身につければ、
苦しむお客の悩みをほぼ解ける美容師になれる。
```

「判断できる／考える」を消す必要はない。**何を、何に基づいて判断するのか**（パターンと体系化されたプロセス）を先に置く。

### 6. 他がやっていないことを、1つ出す

差のもう一本は、「他がやっていないこと」を具体で出すこと。0908の「一般の縮毛矯正・髪質改善との差」の続き。

```
【数字だけで止める】
13年・6000件以上の実績がある

【他がやっていないことまで書く】
他店では現場で何年もかけて感覚を積むことが多い。
当社は6000件をパターンとプロセスに落としてあるので、
感覚頼みではなく、型として身につけられる。
```

「他がやっていないこと」が書けないときは、無理に悪口を足さない。書ける事実（パターン分類・プロセスの型）だけでも差は立つ。

## ■改善理由（Why）

- 「新しい進路」は正しいラベルだが、高卒チラシでは解釈コストが残る。0908で捨てた「諦めなくていい」と同じ穴。約束を先に言い切った方が、救う路線まで読んでもらえる。
- 「指名される」は0908で採用した直接語。ただしどの店でも言える。差は結果語ではなく、**救う対象が他店と違うこと**。
- 縮毛矯正・髪質改善を「きれいにする技術」のまま書くと、他店の願望実現と同じ土俵に戻る。苦しむ人を救う、と置くと、6000件も「きれいの練習量」ではなく「救済の型」に読める。
- 「自分で考えて判断できる」は、優秀そうに聞こえるが再現性が見えない。求職者（と保護者）が欲しいのは天才ではなく、**型があれば自分にもできる**こと。6000件の体系化は、その答えになる。
- 他がやっていないことを出すと、0908で飛んでいた「他店差・教え方」が埋まる。

## ■改善後イメージ（After）

```
【ヘッド（強い約束・1本）】
正社員で働き、自分で学費を稼ぐ。
免許を取り、苦しむお客を救える美容師へ。

【ポジション（他店との差）】
他店：より美しくなりたい願望を叶える
当社：コンプレックスで苦しむ人を救う
　　　（縮毛矯正・髪質改善は医療に近い）

【6000件の中身】
悩みはパターンに分けてある
　→ パターンごとにプロセスが体系化されている
　→ その通りにやることを身につける
　→ ほぼ、悩みを解ける
　→ だから指名される（救った結果としての指名）

【2案を載せる場合】
同じ話は重ねない。約束と、体系化の中身で役割を分ける
```

- 「新しい進路」はヘッドの主役ではない。
- 「指名される」は残っているが、救う路線のあとに置いてある。
- 6000件のあとに、パターン・プロセス・ほぼ解ける、まで1本でつながっている。

## ■やりがちなミス

- 「新しい進路」「新しい働き方」などラベルをヘッドにして、約束を下に落とす。
- 2案を並べて、同じ約束を言い換えただけにする。
- 「指名される美容師」で止め、誰の痛みを解くかを書かない。
- 他店と同じ土俵（より美しく・きれいに）で技術を語る。
- 「状態・薬剤・工程を自分で考える」で止め、パターンと体系化まで落とさない。
- 6000件を置いて、「ほぼ解ける」「他がやっていないこと」を飛ばす。
- 他店を貶す文にして、求めているものが違う、という対比を壊す。

## ■他の案件でも使えるパターン

### パターンA：ラベルではなく約束をヘッドにする

```
「新しい○○」「新しい進路」（ラベル）
　↓
「○○できる。さらに○○へ」（約束）
```

読み手が考えなくてよい言い切りを、一番上に置く。

### パターンB：結果語の前に、誰の痛みかを置く

```
指名される／選ばれる（どの店でも言える結果）
　↓
誰の、どんな苦しみを解いた結果としての指名
```

結果語は残してよい。対象が違うと、同じ結果語でもポジションが変わる。

### パターンC：願望実現 vs 苦しみ救済

```
他：なりたい姿を叶える（美容・デザイン）
自：今苦しんでいる状態を解く（救済・医療に近い）
```

同じ業界でも、お客の求めが違うなら土俵を分ける。

### パターンD：件数を「型」に落とす

```
数字（6000件）
　↓
パターンに分けてある
　↓
プロセスが体系化されている
　↓
その通りにやれば、ほぼ解ける
```

「自分で考える／判断できる」は、型のあとに置く。型が先、判断は後。

### パターンE：2案は役割を分ける

```
同じ話の言い換え → 1本にまとめる
違う話（約束／中身／証拠） → 並べてよい
```
