## ■現状（Before）

- 高卒向け採用チラシの草案ができており、AIでデザインも整っている段階。
- 訴求の中心に、**教育・訓練給付金で学費負担を軽減できる**、**通信制で教育している**、といった**条件・制度訴求**が前面に出ている。
- 見た目は「いい感じ」だが、**強豪チェック（競合が同じ条件を出していないか）**の前に、汎用的なメリットが並んでいる。
- 以前から作っていた**ヘッドコピー（独自性のある軸）**より、今回の草案の方が条件訴求寄りになっている可能性がある。

---

## ■問題の本質（重要）

- 採用チラシで**条件（給付金・学費負担・教育体制）だけ**を前面に出すと、**条件合戦**に入る。競合が「給付金もらえて、残りの学費も全額負担」と出てきた瞬間、**同じ軸では勝てない**。
- 「通信制でちゃんと教育している」は、**通信制教育をしている美容室ならどこも言える**。差別化にはならない。
- チラシの役割は「情報を載せること」ではなく、**他店では選べない理由を一瞬で伝えること**。
- 0501・0107で整理してきた**「他社はこう／当社はこう」**の設計が、採用チラシではまだ当てはまっていない。

---

## ■ズレ（思考 or 設計）

- **デザイン完成度**と**選ばれる理由の独自性**を混同している。見た目が整っている＝採用で選ばれる、ではない。
- **制度・条件訴求**を差別化の主役にしているが、制度は**競合も同じことを言い始めやすい**（給付金、学費支援など）。
- **以前のヘッドライン**（店独自の軸）より、AIが組み立てやすい**汎用条件**に寄っている。
- 0428・0501で固めた**6000人データ・レシピ表・失敗リスク最小**などの「言いにくい強み」が、チラシでは薄い。

---

## ■改善内容（What）

### 0. 先にやる：競合チェック（強豪が同条件を出しているか）

チラシを出す前に、**同エリア・同ターゲット（高卒）**の求人で次を確認する。

| チェック項目 | 競合に同じ訴求がある？ | あれば |
|---|---|---|
| 教育・訓練給付金で学費軽減 | | 条件合戦リスク大 → 主訴求から外す |
| 学費全額／大部分負担 | | より強い条件合戦 → 主訴求から外す |
| 通信制で教育 | | どこも言える → 差別化軸にしない |
| 働きながら美容師になれる | | 業界共通 → ベース扱いにとどめる |

**結論：** 競合が出している条件と同じ軸で勝負しない。チラシの主役は**柴田さんの店だけが言えること**に置く。

### 1. 訴求の2層構造：ベース＋プラスアルファ

**ベース（業界共通・最低限の安心）：**

```
通常申請で、お金をかけずに美容師になれる
（＋必要なら「働きながら」は補足程度）
```

**プラスアルファ（他店が言いにくい／言えない）：**

- 6000人以上の生地データに基づく**レシピ表**で教育・施術の再現性がある
- **失敗リスクを最小限に抑える**独自メソッド（0428・0501で整理済みの軸）
- 縮毛矯正など、**店の専門性・実績**（0107の数値・事例）
- 以前作っていた**ヘッドコピー**に含まれていた、店固有の約束・方針

| 載せ方 | ベース | プラスアルファ |
|---|---|---|
| チラシの主見出し | ×（補足） | ○（ここに置く） |
| サブコピー | ○（安心材料） | ○（具体の強み） |
| 条件・制度 | 脚注・小さく | 差になるならのみ |

### 2. 以前のヘッドコピーを軸に戻す

- 今回の草案より、**前から作っていたヘッドライン**の方が独自性がある可能性が高い。
- チラシの主役は**新規にAIが書いた条件文**ではなく、**すでに検証・整理したヘッドコピー**を使う。
- 「給付金」「学費軽減」は**ベースの補足**に降ろす。

### 3. 採用LPからチラシへ転用する順序

デザインより先に**テキストの幹**を固定する。

**推奨フロー：**

1. **採用LPのファーストビュー** … 主訴求・ヘッドコピーをそのまま核にする
2. **「あなたはこんな悩みありませんか？」** … 高卒向けに言い換え・調整する
3. 上記テキストを確定してから、**AIにデザイン**を依頼する

**高卒向け「悩み」の例（方向性）：**

```
・美容師になりたいけど、学費が不安
・専門学校に行く時間・お金がない
・働きながらちゃんと技術が身につくか不安
・どの店を選べばいいか分からない
```

※ 悩みは**高卒の実際の言葉**に合わせて調整。LPの顧客向け悩みをそのまま流用しない。

### 4. 「どこも言える／言えない」判定表

チラシに載せる前に、各フレーズをこの表で振り分ける。

| フレーズ例 | 判定 | チラシでの扱い |
|---|---|---|
| 教育・訓練給付金で学費軽減 | どこも言える | 小さく／ベース補足 |
| 通信制で教育している | どこも言える | 載せない or 最小限 |
| 6000人データのレシピ表で教育 | 言いにくい | 主訴求候補 |
| 失敗リスクを最小限に | 店次第（中身があれば強い） | 主訴求候補 |
| 以前のヘッドコピーの独自約束 | この店だけ | **最優先で主見出し** |

### 5. 出してみる vs 直してから出す

- **とりあえず出して反応を見る**のも一手（デザインはできている）。
- ただし、**強い競合が同条件を出しているエリア**では、条件訴求のままだと**選ばれにくい**リスクが高い。
- 出す前に**競合チェック＋主訴求を独自性に差し替え**しておく方が、長期的に使い続けられるチラシになる。

---

## ■改善理由（Why）

- **条件合戦**は、資金力のある競合（学費全額負担など）が有利。同じ軸で戦うと負けやすい。
- 0501で「カウンセリングは一般店 vs 当店の比較で書く」、0107で「他社はこう／当社はこう」と整理したのと同じ発想が、**採用チラシにも必要**。
- 「通常申請でお金をかけずに美容師になれる」は**ベースの安心**として残し、**選ぶ理由**はプラスアルファ（データ・メソッド・専門性）に置くと、競合が条件を上げても**軸がブレない**。
- テキスト確定 → デザインの順にすると、AIの見た目の良さに引っ張られず、**訴求の幹**が先に固まる。

---

## ■改善後イメージ（After）

- 高卒の読み手が、**3秒で「この店は他と違う」**と感じる。
- 主見出しは**柴田さんの店だけが言える強み**（以前のヘッドコピー＋6000人データ・失敗リスク最小など）。
- 給付金・学費は**「それもある」程度の補足**にとどまり、条件合戦の主戦場にならない。
- 採用LPとチラシで**訴求軸が一致**し、LPを見た人がチラシでも同じ「選ぶ理由」を確認できる。
- 強豪が条件を上げてきても、**独自性の軸**で使い続けられるチラシになる。

---

## ■やりがちなミス

- AIのデザインが整っているので、**競合チェックを飛ばす**。
- **給付金・学費負担**を主見出しにする（競合も言い始めやすい）。
- 「通信制で教育している」だけを差別化にする（**どの店でも言える**）。
- 以前作った**独自性のあるヘッドコピー**を捨てて、汎用条件訴求に寄せる。
- 顧客向けLPの悩みを、そのまま**高卒採用**に流用する（ターゲットの悩みが違う）。
- デザイン先行で、**テキストの幹**が後回しになる。

---

## ■他の案件でも使えるパターン

### パターン1：ベース訴求＋プラスアルファ

```
【ベース】業界共通・最低限の安心（小さく載せる）
【プラスアルファ】この店だけが言える強み（主見出し）
```

採用・集客・LPすべてで使える。条件は「足切りライン」、差別化は「選ぶ理由」。

### パターン2：「どこも言える／言えない」チェック

載せる前に1行ずつ判定する。

- 競合3社が同じことを言える → 主訴求にしない
- 競合が言いにくい／言えない → 主訴求候補

### パターン3：LPファーストビュー → チラシ転用

1. LPで固めた主訴求・ヘッドコピーを核にする
2. ターゲット向けに「悩み」ブロックだけ言い換える
3. テキスト確定後にデザイン（AI可）

### パターン4：条件合戦に入る前の競合チェック

チラシ・広告・求人票を出す前に、**同条件を出している強豪がいないか**を確認。いたら主軸を**独自性**に切り替える。

👉 高卒チラシは「給付金・学費・通信制教育」で勝負しない。ベースは「通常申請で費用を抑えて美容師になれる」、**選ばれる理由は柴田さんの店だけが言える強み**（以前のヘッドコピー・6000人データ・失敗リスク最小）で出す。

## ■0501・0107・0428との関係

| 過去FB | 今回との接続 |
|---|---|
| **0107** 自社リサーチ・他社比較 | 採用チラシでも「他社はこう／当社はこう」を当てはめる。条件訴求だけでは比較にならない |
| **0428** 6000人データの因果 | チラシのプラスアルファ候補。条件ではなく**データ・再現性**で差を出す |
| **0501** LP幹整理・他社vs当店 | 採用LPファーストビューをチラシに転用。幹は減らし、**独自性1本**を主役に |

今回は、LP・集客で積み上げてきた**独自性の軸**を、高卒採用チラシでも**条件合戦に入らず**使う段階。
