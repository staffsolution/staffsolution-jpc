## ■分類（タグ）

- 高卒採用チラシ（0903路線の**前提修正**）
- 標準モデルは**5年**（就労2年＋通信3年）
- 「3年で指名される」表紙訴求は**使わない**
- 5年を前面に出すか／面接で話すかの判断
- 差別化は免許年数ではなく**髪のコンプレックス解消技術＋6000件**
- ヘッドライン設計（自力で免許＋喜ばれる美容師）
- 保護者目線（「親の援助に頼らず」は避ける）
- 0903・0902の続き

---

## ■現状（Before）

- 0903では「3年で指名される美容師へ」をヘッドに足し、縮毛矯正・髪質改善・3年6000件路線で確定する方向だった。
- その後、重要な制約が共有された。**高校卒業後に2年働き、給付制度の要件と学費・生活の土台を整え、その後通信制で3年学ぶ。美容師免許までの標準モデルは5年。**
- そのため、「3年で指名される」を表紙の主役に使う前提が崩れた。
- チラシのターゲットは、高卒で美容師になりたいが、親の援助がなく専門学校に通えず、美容師を選択肢から外しそうな人。働きながら資格取得できる、が刺さる層。
- 一方で、美容専門学校は2年、通信は3年。その前に2年働く必要があると、**合計5年**になり、印象が一気に厳しくなる。
- 競合の高卒チラシで「3年で資格取得」と出されると、こちらが5年を前面に出すと選ばれにくくなる懸念がある。

---

## ■問題の本質（重要）

- **約束できる年数と、訴求したい年数が食い違うと、チラシは信用を落とす。** 「3年で指名」は強いが、標準が5年なら使えない。
- **5年をどう出すか**が本題。前面に出すと「5年も下働き？」と読まれやすい。隠して面接で話す手もあるが、チラシ上では別の主役が必要。
- 差別化は「何年で免許が取れるか」だけでは弱い。同じ通信制路線が出てきた瞬間に終わる。**プラスアルファ（どんな美容師になれるか）**が必要。
- 「5年間ウィッグ練習だけ」に見えると、指名される美容師には到達できない印象になる。書ける事実の範囲で、**技術の価値**を主役にする。

## ■ズレ（思考 or 設計）

| 0903までの設計 | 今回分かった事実 | ズレ |
|---|---|---|
| 3年で指名をヘッドに | 標準は5年（就労2＋通信3） | 約束の年数が合わない |
| 3年6000件の時間軸 | 6000件自体は強い材料 | 「3年」表記の使い方を再検討 |
| 資格取得が主軸 | 競合も通信・資格で並びうる | 年数比較だけでは負ける |
| 「親に頼らず」系の表現 | チラシは保護者も見る | 親を刺激する表現はリスク |

- 「2年で学費と生活の土台」は、条件なしだと**2年間の下働き**に聞こえる。
- 「2年で100万円貯金」が言えるなら材料になるが、**実家通学など条件付き**なら条件を明記する。一人暮らし前提だと厳しい印象になる。

---

## ■改善内容（What）

### 1. 「3年で指名される」は表紙の主役から外す

```
【使わない】
3年で指名される美容師へ（表紙・ヘッドの約束）

【理由】
標準モデルが5年のため、約束と実態がずれる
```

0903の「3年指名ロードマップ」方針は、**年数の約束としては一旦棚上げ**。育成の中身（何を学ぶか）は残してよいが、「3年で指名」の約束としては書かない。

### 2. 5年の出し方：主役にしない／小さく説明する

5年をヘッドにすると、「5年かかるのか」「下働き5年か」と読まれやすい。

推奨：

```
ヘッドライン（主役）
　↓
説明文（小さい文字）で「免許取得まで5年」
　↓
さらに下で差別化（6000件・縮毛矯正・髪質改善）
```

面接で深く説明する前提でも、チラシ上は**小さく事実として置く**方が、後から「隠していた」印象を減らせる。完全に伏せるなら、面接で必ず説明する運用が必要。

### 3. ヘッドラインの主役を「自力で免許＋喜ばれる美容師」に替える

推奨の骨格：

```
正社員として収入を得ながら、
自分の力で美容師免許を目指せる。
さらに、髪のコンプレックスに悩む人に
心から喜んでもらえる美容師へ。
```

- 「働きながら／自力で」は残す。はっきり書いた方がよい。
- 「親の援助に頼らず」は、保護者がチラシを見る前提では失礼に聞こえやすい。**「自分の力で」「自力で」**に寄せる。

### 4. 差別化は「年数」ではなく「技術の価値＋実績」

免許取得までの年数で競合と比較すると、3年表記の店に負ける。だからヘッドの下で、次を明確にする。

| 材料 | 役割 |
|---|---|
| 髪のコンプレックスを解消できる技術（縮毛矯正・髪質改善） | 「どんな美容師になれるか」 |
| 6000件以上の施術実績から学べる | 実績・信頼の根拠 |
| 長年悩む人に本当に喜んでもらえる | 求職者のやりがい・意味 |

```
ヘッド：自力で免許＋喜ばれる美容師
　↓
小さく：免許取得まで5年
　↓
続ける：6000件以上の施術実績から学ぶ
　　　　縮毛矯正・髪質改善
```

「5年で指名される」は、ウィッグ中心の練習しか言えないなら書かない。デビュー直後・実客施術の実績を紙に書けないなら、無理な約束にしない。

### 5. 「2年の土台づくり」を書くなら条件を付ける

書く場合の注意：

| 書き方 | 読まれ方 |
|---|---|
| 2年で学費と生活の土台を整える | 下働き2年、に聞こえやすい |
| 2年で100万円の貯金を目指せる（実家通学の場合 等） | 条件付きなら現実味が出る |
| 条件なしの貯金・生活安定 | 一人暮らしだと厳しい、と疑われる |

一人暮らし前提でないなら、**その条件を入れる**。言えないなら、金額表現は控えめにする。

### 6. 0903から残すもの／変えるもの

| 残す | 変える |
|---|---|
| 縮毛矯正・髪質改善路線 | 「3年で指名」ヘッド |
| 6000件の実績訴求 | 「3年」を約束の主役にすること |
| 働きながら自力で資格 | 年数の出し方（5年は小さく） |
| 深い悩み→喜ばれる美容師 | 「親に頼らず」表現 |
| お客様の声・可読性 | 育成ロードマップの「3年指名」約束部分 |

---

## ■改善理由（Why）

- 強い約束は、事実より先に出すとチラシ全体の信用を落とす。標準が5年なら、「3年で指名」は主役にできない。
- 高卒チラシは本人だけでなく保護者も見る。援助を否定する言い方は、味方であるはずの親を遠ざける。
- 競合が「3年で資格」と出しても、こちらは**年数勝負をしない**。技術の深さ（コンプレックス解消）と6000件で差別化する方が、真似されにくい。
- 「5年」は隠すか小さく書くかの判断。隠すなら面接運用が必須。小さく書くなら、ヘッドの主役を別（自力・喜ばれる美容師）に置く。

---

## ■改善後イメージ（After）

```
【ヘッド】
正社員として収入を得ながら、自分の力で美容師免許を目指せる。
さらに、髪のコンプレックスに悩む人に心から喜んでもらえる美容師へ。

【説明（小さめ）】
免許取得まで5年

【差別化】
6000件以上の施術実績から学ぶ
縮毛矯正・髪質改善
```

- 「3年で指名」は表紙に出ない。
- 5年は事実として小さく置き、印象の主役は「自力で免許」と「喜ばれる美容師」。
- 競合の年数表記に対しても、技術価値で並ばない土俵に立てる。

---

## ■やりがちなミス

- 事実が5年なのに、0903の「3年で指名」をそのまま残す。
- 5年をヘッドの主役にして、「下働き5年」に読ませる。
- 年数だけで勝負し、競合の「3年資格」に負ける。
- 「5年で指名される」を、ウィッグ練習中心の実態を超えて約束する。
- 「親の援助に頼らず」など、保護者を刺激する表現を残す。
- 2年の貯金・土台づくりを、条件なしで書く。
- 0903までの良い路線（縮毛矯正・6000件・自力）まで一緒に捨てる。

## ■他の案件でも使えるパターン

### パターンA：約束の年数は事実に合わせる

```
強い約束（○年で○○）
　↓
実態の年数と一致するか確認
　↓
一致しないなら、約束を下ろし、別の主役（技術・意味・仕組み）へ
```

### パターンB：不利な数字は主役にしない

```
不利・重い数字（例：5年）
　→ ヘッドには置かない
　→ 小さく事実として置く／面接で話す
　→ ヘッドは別のベネフィット
```

### パターンC：年数比較で負けるなら土俵を変える

```
競合：短い年数で資格
自社：年数では負けうる
　→ 差別化は「どんな専門技術を、どんな実績から学べるか」
```

### パターンD：保護者も読む媒体の言葉選び

```
本人向けに刺さる言い方
　× 親の援助を否定する表現
　○ 自分の力で／収入を得ながら
```

👉 **「3年で指名」は表紙から外す。標準は5年なので、ヘッドは「自力で免許」＋「髪のコンプレックスを解ける美容師」にし、5年は小さく事実として置く。差別化は年数ではなく6000件と縮毛矯正・髪質改善。**

## ■0903・0902との関係

| 過去FB | 今回（0906）との接続 |
|---|---|
| **0903** 3年で指名をヘッドに／育成ロードマップ | **年数の約束は撤回**。技術路線と自力訴求は維持 |
| **0902** 具体ヘッド・6000件期間・ベネフィット | 維持。6000件は差別化の核として再配置 |
| **0901** 深い悩み→指名 | 「喜ばれる美容師」としてヘッド第2文に残す |

0903は路線確定のつもりだったが、**標準5年という制約で約束の年数だけ修正**。技術・自力・深い悩みの軸は継続。
