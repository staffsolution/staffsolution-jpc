## ■分類（タグ）

- 高卒採用チラシ（0906路線の**文言選定**）
- 「諦めなくていい」は間接的 → **できることを直接言う**
- ベース案：正社員で稼ぎながら自力で免許＋喜ばれる（指名される）美容師
- 6000件・13年記録 → **他店差・教え方の橋渡し**が飛んでいる
- 5年はチラシ必須ではない（面接で可）
- 保護者向け：生活を整える力／2年で100万円貯金
- お客様向けベネフィットを求職者向けに差し替える
- 縮毛矯正・髪質改善の**一般との差**が5年学ぶ理由になる
- 0906・0903の続き

---

## ■現状（Before）

- 0906で「3年で指名」は表紙から外し、ヘッドは「自力で免許」＋「髪のコンプレックスを解ける美容師」、5年は小さく／面接、差別化は6000件と縮毛矯正・髪質改善、と方針を固めた。
- その後の文言案では、「学費などの理由で美容師を諦めなくていい」系の表現が入っている。方向は近いが、**何ができるかが直接書いていない**。
- 「悩みに応える美容師」など、意味は通るが一段やわらかい言い回しも混ざっている。
- 6000件以上の施術記録のあとに、「他店との違いは何か」「どう教えてもらえるのか」への橋が薄く、数字から技術価値へ飛んで見える。
- 「朝が楽になる／選べる髪型が増える／自分の髪が好きになれる」など、**お客様向けのベネフィット**が、高卒採用チラシの求職者向けブロックに混ざっている。

---

## ■問題の本質（重要）

- 高卒向けチラシは、読ませて考えさせるより、**できることをストレートに言い切る**方が刺さる。「諦めなくていい」は優しいが、「どういうこと？」と一度考えさせる。考えさせた時点で、次の文へ進みにくい。
- 差別化の核は「6000件」「縮毛矯正・髪質改善」そのものではなく、**他店で長くかかる技術が、どう違う形で身につくか**まで見せること。数字のあとに教え方・差分がないと、自慢の数字で止まる。
- チラシの読み手は高校生と保護者。お客様がどう楽になるかは、**求職者が「自分が身につける技術の意味」として読める形**に翻訳する必要がある。

---

## ■ズレ（思考 or 設計）

| 書いてある／置きそうな表現 | 読み手の反応 | ズレ |
|---|---|---|
| 学費などで諦めなくていい | 「どういうこと？」と考え始める | 結果（何ができるか）が先に出ていない |
| 悩みに応える美容師 | ふんわり好意的 | 「指名される美容師」より直接性が弱い |
| 6000件・13年の記録 | 数字は強い | 他店差・教え方への橋がない |
| 朝が楽／髪型が増える／髪が好き | お客様目線で刺さる | 高卒求職者・保護者の読み物になっていない |
| 紙の悩みを解ける＝喜ばれる | 方向は正しい | ベネフィット（だから何が得られるか）が薄い |

- 0906の骨格（自力・技術価値・5年は主役にしない）は合っている。今回の論点は**骨格の上の言い切りと、6000件からの因果の埋め方**。

---

## ■改善内容（What）

### 1. 「諦めなくていい」より、できることを直接書く

間接表現はベースにしない。結果を先に出す。

```
【弱い（間接）】
学費などの理由で、美容師を諦めなくていい

【強い（直接）】
正社員として働き、給料を得て学費を自分で稼ぎながら、
美容師免許を自力で取得できる
```

考えさせない。読んだ瞬間に「自分にもできるかも」が立つ言い方にする。

### 2. ベース文はこの並びで固める

推奨の骨格（0906の続き＋今回の選定）：

```
正社員として働き、給料を得ながら学費を自分で稼ぐ。
自分の力だけで国家資格（美容師免許）を取得できる。

さらに、
「好きな髪型を諦める」悩みを解決する技術を身につけ、
指名される美容師へ。
```

- 「人形モデル（ウィッグ）で練習」は残してよい。ただし「ウィッグ」だけだと分からない人もいるので、必要なら「人形モデル（ウィッグ）」と併記する。
- 「悩みに応える美容師」より **「指名される美容師」** の方が直接的でよい。
- 「好きな髪型にできない」だけでなく、「自分の髪が好きになれない」まで含めると悩みの強さが出る。

### 3. 保護者向けの材料は足してよい

ベースに載せられるなら追加する。

| 材料 | 効き方 |
|---|---|
| 自分の生活を整える力まで身につく | 高卒採用・保護者目線で安心材料になる |
| 2年間で100万円を貯めるのを目指せる（条件があるなら明記） | 「任せたい」につながりやすい |

0906どおり、貯金表現は**実家通学などの条件**が言えるときだけ厚くする。

### 4. 5年はチラシに必須ではない

「5年かかります」は、このブロックに無理に入れなくてよい。面接で仕事の流れとして説明する運用でもよい（0906の「小さく／面接」方針と同じ）。スペースをヘッドや技術差に使う。

### 5. 6000件のあとに「他店差」と「教え方」を埋める

いま飛んでいるのはここ。

```
13年・6000件以上の施術記録
　↓（ここが空白だと数字で止まる）
他店との違いは何か／どう教えてもらえるのか
　↓
縮毛矯正・髪質改善が、一般のそれと何が違うのか
　↓
だから「指名される美容師」の技術になる
　↓
（結果として）5年学ぶ意味も立つ
```

入れられるなら、次を短く足す。

```
【他店でよくある】
縮毛矯正・髪質改善に、現場で5年かけてやっと追いつく

【当社】
13年・6000件以上の施術記録から、
一般的な縮毛矯正・髪質改善とは違う技術の型を学べる
```

「どんな技術なのか」を、一般の縮毛矯正・髪質改善との差で1〜2行書く。差が書けると、長い育成期間の理由にもなる。

### 6. お客様向けベネフィットを求職者向けに差し替える

次はお客様向けなので、高卒採用ブロックでは使わない／翻訳する。

```
【お客様向け（このまま置かない）】
朝が楽になる
選べる髪型が増える
自分の髪が好きになれる

【求職者向けに翻訳する例】
髪の悩みを解ける技術が、喜ばれる理由になる
その技術を「得意」と言える美容師になれる
```

「紙の悩みを解決できる＝喜ばれる」までは方向正しい。さらに、**だから求職者にとって何が得られるか**（得意分野・指名・やりがい）まで1段出す。

### 7. ヘッドに「取得してどうなるか」を足せるなら足す

スペースが許すなら、免許取得だけでなく、**取得後にどうなるか**までヘッドに入れる。無理なら本文側で補う。コントロールはレイアウト次第。

---

## ■改善理由（Why）

- 間接表現は優しさが出るが、高卒チラシでは**解釈コスト**が仇になる。「できる」を先に言い切った方が、次の差別化（技術）まで読んでもらえる。
- 6000件は証拠として強い。ただし証拠のあとに**差分と学び方**がないと、「すごい数字」で終わり、求職者の「自分がどう育つか」につながらない。
- お客様ベネフィットは、お客様向けLPでは正しい。読み手が高校生・保護者の媒体では、**自分が身につける技術の意味**に翻訳しないと的外れに見える。
- 「指名される美容師」は結果が映像化しやすい。「悩みに応える」は正しいが、一段抽象度が高い。
- 一般の縮毛矯正・髪質改善との差が見えると、長い育成（5年）の理由が「下働き」ではなく「深い技術を取る時間」に読める。

---

## ■改善後イメージ（After）

```
【ヘッド〜導入（直接）】
正社員として働き、給料を得ながら学費を自分で稼ぐ。
自分の力で美容師免許を取得できる。
さらに「好きな髪型を諦める」悩みを解く技術を身につけ、
指名される美容師へ。

【保護者向け（任意・条件付き）】
生活を整える力／2年で100万円貯金を目指せる（条件明記）

【差別化（数字→差→技術）】
13年・6000件以上の施術記録
　→ 他店で長くかかる縮毛矯正・髪質改善との違い
　→ 一般とは違う技術の型を学べる
　→ だから指名される美容師になれる

【5年】
チラシ必須ではない。面接で説明でも可
```

- 「諦めなくていい」は主役にしない。
- お客様向けの「朝が楽」などは、求職者向け文に置き換わっている。
- 6000件のあとに、他店差・教え方・技術の差が1本でつながっている。

---

## ■やりがちなミス

- 「諦めなくていい」「寄り添う」など優しい間接表現を、直接の「できる」より前に置く。
- 「悩みに応える美容師」で止め、「指名される」まで言い切らない。
- 6000件を置いて、他店差・教え方・一般技術との差を飛ばす。
- お客様向けベネフィット（朝が楽・髪型が増える等）を、高卒チラシにそのまま載せる。
- 「喜ばれる理由」まで書いて、求職者側のベネフィット（得意・指名）を出さない。
- 5年を無理にヘッド付近へ戻す（0906で主役から外した方針と矛盾）。
- ウィッグ／人形モデルの用語を、読み手が分からないまま置く。

## ■他の案件でも使えるパターン

### パターンA：間接 → 直接に置き換える

```
「○○しなくていい」（否定・回避）
　↓
「○○できる」（結果・能力）
```

優しさより、読み手が一拍考えなくてよい言い切りを優先する。

### パターンB：数字のあとに橋を置く

```
実績数字（例：6000件）
　↓
他との違い／どう身につくか
　↓
だから自分にとって何が得られるか
```

数字だけで止めない。

### パターンC：読み手別にベネフィットを翻訳する

```
お客様向け：朝が楽／髪が好き
求職者向け：その技術を得意にできる／喜ばれ指名される
保護者向け：稼ぎながら学べる／生活を整える／貯められる
```

同じ事実でも、媒体の読み手で文を変える。

### パターンD：ふわっとした肩書きより結果語

```
悩みに応える美容師（抽象）
　→ 指名される美容師（結果が映像化しやすい）
```

## ■一言まとめ（本質）

👉 **「諦めなくていい」は間接なので、「正社員で稼ぎながら自力で免許＋指名される美容師」と直接書く。6000件のあとに他店差・教え方・一般技術との差を埋め、お客様向けベネフィットは求職者向けに翻訳する。5年はチラシ必須ではない。**
