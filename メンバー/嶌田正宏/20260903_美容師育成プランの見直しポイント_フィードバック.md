# 3年で指名される育成プランの訴求強化（フィードバック）

2026年9月3日

**フィードバック動画：** <a href="https://www.loom.com/share/366142a86d9e4c938031d4f02590a84d" target="_blank" rel="noopener noreferrer">Loomで見る</a>

---

## ■分類（タグ）

- 高卒採用チラシ（0902反映版・**路線確定**）
- 2案比較 → **縮毛矯正・髪質改善・3年6000件**路線を採用
- ヘッド追加案：「3年で指名される美容師へ」
- **3年間で何を学び、どう指名まで行くか**の因果
- 店内試験 → お客様担当のタイミング説明
- 短期間で身につく・早くデビュー（求職者の不安払拭）
- 0828〜0902の続き・微調整

---

## ■現状（Before）

- 0902のアドバイスを素早く反映。**路線はほぼ確定**でよい。
- 2案のうち、**縮毛矯正・髪質改善・3年間6000件以上**の方が、お店の特徴とマッチ。真似しにくい独自性。**こちらの路線で進めてよい。** 文字も濃く読みやすい。
- ヘッドは「働きながら自力で美容師資格を取得し」まで入っている。**もう1行足したい**：「3年で指名される美容師へ」系（文字サイズ・スペース調整で入る想定）。
- 「美容師資格を取得できるだけでなく」以降の**追加ベネフィット**（指名・専門技術）も、ヘッド〜サブで見える化したい。
- 技術ブロック（縮毛矯正・6000件等）は**良い**。
- 弱いのは、**「3年で指名される」約束の中身**。「3年間で何を学び、資格取得と並行してどう指名美容師になれるのか」が、読み手にはまだ見えにくい。
- **店内試験→お客様担当**の説明が、求職者目線では分かりにくい。
  - 資格がなくても担当できるのか？
  - 店内試験合格後、カットはできなくても他工程でお客様を担当しながら身につける、という意味か？
- 求職者（特に高卒・業界未経験）の**潜在不安**：ずっと下働き？なかなかデビューさせてもらえない？
- 刺さる層：**同年代より早く美容師になり、早く結果を出したい**。ここをプラスアルファで伝えられるとよい。
- **技術＋短期間で身につけられる**が言えるなら、さらに強い。

---

## ■問題の本質（重要）

- 0830〜0902で決めた路線（自力で資格・深い悩み・縮毛矯正・6000件）は**機能している**。今回は**微調整**と**育成プランの因果**が中心。
- 「3年で指名される美容師」は**強い約束**になるが、**中身（何を・どの順で・いつお客様を担当するか）**がないと、逆に「本当？」「下働き？」の不安を生む。
- 通信制で**働きながら資格取得**は分かっても、**いつ・どう現場デビューするか**は未経験には想像できない。**店内試験→担当**の流れを、資格の有無と切り分けて書く。
- 0902で「6000件に期間を」と指摘 → **3年6000件**は既に良い。**次は「3年で指名」のロードマップ**。
- 独自性（縮毛矯正・髪質改善・6000件）は**この路線で確定**。あとは**時間軸（3年）とデビュー不安**の払拭。

## ■ズレ（思考 or 設計）

| 0902までで決めたこと | 今回の状態 | 残り |
|---|---|---|
| 具体ヘッド（資格取得） | 入っている | 「3年で指名」を足す余地 |
| 6000件＋期間 | 3年6000件でOK | 維持 |
| 深い悩み→指名 | 技術ブロックは良い | 3年でどう至るかが薄い |
| お客様の声 | 良い | 維持 |
| 求職者の不安 | 未記載 | 下働き・デビュー時期 |

- 店側には店内試験・補助業務の流れが**当たり前**。求職者には**「いつお客様を触れるか」**が最大の関心。
- 「技術は良い」＋「短期間で身につく」＋「3年で指名」の**3つを1本の因果**にまだつなげきれていない。

---

## ■改善内容（What）

### 0. 方針：この路線で確定・微調整のみ

```
【採用する案】
縮毛矯正・髪質改善・3年間6000件以上（文字濃い方）

【足す・直す】
① ヘッドに「3年で指名される美容師へ」（サイズ調整で）
② 3年間の育成ロードマップ（学ぶこと→資格→店内試験→担当）
③ 店内試験・お客様担当のタイミング（不安払拭）
④ 短期間で身につく・同年代より早く結果（言える範囲で）
```

### 1. ヘッド〜サブ：もう1行足す

**現状：**

```
働きながら、自力で美容師資格を取得し
（＋ 美容師資格を取得できるだけでなく …）
```

**追加案（文字サイズ・行間調整で）：**

```
働きながら、自力で美容師資格を取得し、
3年で指名される美容師へ。

美容師資格を取得できるだけでなく、
（縮毛矯正・深い悩みを解く技術 等）
```

- 0902の「道を掴む」から**具体ヘッド**へは進んでいる。次は**約束（3年・指名）**を入口に載せる。

### 2. 「3年で指名」の中身：ロードマップ

**読み手の疑問：**

```
3年で本当に指名される美容師になれるの？
その間、ずっと下働き？デビューはいつ？
```

**推奨の並び（店の実態に合わせて調整）：**

```
【1〜2年目イメージ】
働きながら資格取得（通信制）
＋ 縮毛矯正等の専門技術を段階的に学ぶ
＋ 6000件のデータから学ぶ土台

【途中】
人形・モデル試験合格
　↓
店内試験合格
　↓
（カット以外など）実際のお客様を担当しながら身につける

【3年目イメージ】
資格取得
＋ 指名される美容師として活躍できる状態
```

- **「3年間で何を学び、資格と並行してどう指名に近づくか」**を、箇条書きまたは短い段落で。
- 技術ブロック（6000件・縮毛矯正）はそのまま。**時間軸の箱**を足す。

### 3. 店内試験・お客様担当：不安を先回り

**書くべきこと（意味の整理）：**

| 項目 | 読み手に伝えること |
|---|---|
| 店内試験 | 店の基準をクリアしたら、次のステップへ |
| 資格前 | カット以外など、**実際のお客様を担当しながら**学べる（店のルールに合わせて具体化） |
| 人形・モデル試験 | その前段階 |

- 「資格が取れるまで3年間ずっと見学だけ」ではない、と**明示**する。
- 0902のベネフィット（コンプレックス→変化）と**別軸**で、**育成・デビュー不安**を払拭。

### 4. プラス訴求：短期間・同年代より早く

**言えるなら足す：**

```
・専門技術（縮毛矯正等）が短期間で身につけやすい設計
・同年代より早く現場デビューし、早く結果を出したい人向け
```

- 業界経験者でなくても、「早く一人前になりたい」は**高卒の本音**になりうる。
- **技術＋短期間＋3年指名**を1本のストーリーに。

### 5. 維持するもの（0902まででOK）

- 縮毛矯正・髪質改善・3年6000件の路線
- お客様の声・実写真（読めるサイズは0902通り）
- 「親に頼らず」は入れない判断
- 深い悩み→ベネフィット→指名の技術ブロック

---

## ■改善理由（Why）

- 路線確定後の**最後の微調整**は、**約束の中身**と**デビュー不安**。ここが弱いと、良いチラシでも「結局下働き？」で止まる。
- 「3年で指名」はヘッドに載せる価値があるが、**ロードマップなし**は信用を損なう。0902の具体ヘッドの延長。
- 店内試験は**店の言葉**。求職者語彙に翻訳（いつ・誰を担当できるか）が0829の続き。
- 6000件・3年は**既に強い**。育成時間軸とセットにすると、**データで育てる店**の印象が完成する。

---

## ■改善後イメージ（After）

```
働きながら自力で資格が取れる。
3年で、縮毛矯正の専門技術と6000件のデータから学び、
指名される美容師を目指せる。

途中から（店内試験後など）お客様を担当しながら身につけられる。
ずっと下働きだけ、ではない。

同年代より早く現場に立ち、深い悩みを解く美容師になれる。
```

- **2案のうち縮毛矯正・3年6000件路線**で確定。ヘッド＋育成因果＋デビュー不安払拭が足された状態。

---

## ■やりがちなミス

- 路線は合っているのに、**「3年で指名」だけ載せて中身を書かない**
- 店内試験を**店内部の用語**のまま出し、求職者が「資格前に触れるの？」と分からない
- 技術・6000件は良いが、**時間軸（いつ何するか）**がない
- ヘッドに「3年指名」を足すスペース調整をせず、**サブだけ**に約束を置く
- 0902までの良い部分（具体ヘッド・6000件期間・お客様の声）を、微調整で**削ってしまう**

## ■他の案件でも使えるパターン

### パターンA：強い約束＝ロードマップ必須

```
約束（3年で○○）
　↓
【年次・段階】何を学ぶか
　↓
【中間】試験・店内基準・お客様担当のタイミング
　↓
約束の根拠（データ・技術・実績）
```

### パターンB：業界用語→求職者語彙

```
店内試験
　→ 店の基準をクリアしたら、お客様を担当しながら学べる段階へ
```

### パターンC：潜在不安の先回り

```
「ずっと下働き？」「いつデビュー？」
　→ 途中からお客様担当／○年目のイメージ
```

### パターンD：2案確定後は微調整に集中

路線が決まったら、**ヘッド1行・時間軸・不安払拭**だけ直す。全体を作り直さない。

## ■一言まとめ（本質）

👉 縮毛矯正・3年6000件路線で確定でよい。ヘッドに「3年で指名」を足し、3年間で何を学びいつお客様を担当するかのロードマップと、下働き・デビュー不安の先回りを入れて仕上げる。
