## ■分類（タグ）

- 自社リサーチ・採用ページ／マインドマップ
- **他クリニックでは → 当院では → その結果** の型の徹底
- 余裕のある体制（多め採用）→ リフレッシュ休暇・業務調整・勤務短縮の因果
- レセプト等の「通常はどうか」を未経験者向けに補足
- 週4・週5など働き方の**誰が・どんなケースで選ぶか**
- 理念（人の心に光を灯す）の具体化と**合わない価値観の対比**
- セミナー（オンライン＋リアル）の学び体験
- AI壁打ちに振り回された感の整理
- 0717・0425・0403の続き

## ■現状（Before）

- 0717で整理した「患者とスタッフ両方を大切にする／あえて余裕のある体制」の方向で、デジタルサーチ（採用ページ・マインドマップ）を進めている。
- **他のクリニックでは → 当クリニックでは → その結果こうなっている**の流れを意識している点は正しい。ここを崩さない。
- AI壁打ちの影響で、情報が散らばったり、同じ話が複数箇所に出たりしやすい状態（「AIに振り回された感」）。中身自体は良いものが多く、**型に載せ直す段階**。
- 赤い箇所（会社情報まわり）では、スタッフ・患者向けの具体があると説得力が出る。**一般的な運営はこう／うちはこう**が書けている箇所は非常に良い。
- 「全体に関わる」ところで具体が薄い／別の箱で「実際そうなっている」と説明している、のズレがある。どちらかに寄せてよい（自社リサーチなら後者の具体を前に出す方が強い）。
- **重要：** 入社直後からリフレッシュ休暇2日、緊急性の低い業務の後日調整などが、**スタッフを多めに採用しているからできる**、という因果がまだ弱い。
- レセプト等の緊急性の低い業務は、未経験者には「通常どうなるか」が分からない。通常→当院→結果、の対比が必要。
- 電話対応・レセプト等のベネフィットを、**見出し側にも入れる**と分かりやすい。
- リフレッシュ休暇は「取れる」だけでなく、**どういう状況・ケースで取っているか**（急な用事、実際のスタッフ事例）があるとよい。
- 平日夕方・土曜に働けない人を正社員にできないクリニックがある、に対し、当院は人員余裕で**正社員のまま勤務時間を短縮**できる、は強い。週4（例：週24時間）などはパート並みに見えるほど柔軟で、**結果としてすごい**。ここは分けて見せる。
- どの働き方を、**結婚・出産・子育て・介護などどんなケースで選ぶ人が多いか**、スタッフ事例・声があると、より刺さる。
- 理念に沿った診療・運営の具体を、理念ブロックに付け足せる。
- 研修・セミナー：「いつ・どのくらいの時間帯か」「強制か任意か」が気になる。オンラインだけでなく**リアルでみんなで行く**体験、学びに行ってよかった声があると、団結・楽しさまで伝わる。
- 「理念に共感した人が集まる」は抽象のまま止まりやすい。**共感する価値観**と、**医療現場でありがちな合わない価値観**（効率・機械的・スピード・給料最優先など）の対比が欲しい。合わない人が集まるとどうなるか → だから面接前に確認して採用、までつなぐ。
- スタッフが多いことで働きやすい、も「どういうことか」の具体がまだ足せる。重複箇所はドッキング可能。
- 全体として**すごく良い感じ**。あとは「2年・理念」など抽象を、イメージできる具体に落とす仕上げ。

## ■問題の本質（重要）

- 0717の幹は「余裕のある体制」。今回は、その幹から生える枝を、**施策名の列挙ではなく、他院対比→当院→結果／ベネフィット**で見せること。
- 「リフレッシュ休暇がある」「週4ができる」は事実。読み手が欲しいのは、**なぜそれが可能なのか（多め採用・余裕）**と、**自分のライフイベントで使えるか**。
- 未経験者は業界の「当たり前（レセプトの忙しさ等）」を知らない。**通常はどうか**を書かないと、当院の差が分からない。
- 理念は抽象になりやすい。刺さるのは、**理念に合う人／合わない人（否定ではなくマッチしない）**の対比と、その結果（トラブルが少ない・協力し合える）まで一本でつなぐこと。
- AIで増えた箱は、同じ話を2箇所に置かない。**1つの違い＝1型（他→うち→結果）**に載せる。

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| 余裕のある体制を伝えたい | 休暇・調整・週4が「制度の列挙」に見え、多め採用との因果が弱い |
| 具体を出したい | 良い具体がある一方、通常（他院）側が抜けて差が見えない箇所がある |
| 理念共感の職場を出したい | 「共感した人が集まる」で止まり、合う／合わない価値観の対比が薄い |
| 学び・成長を伝えたい | セミナーの強制／任意・時間帯・リアル体験・声が不足し、オンラインだけに見える |
| 働き方の柔軟さを伝えたい | 週4・週5の数字は強いが、「誰がどんなケースで選ぶか」が弱い |
| AIで壁打ちして整理した | 同じ話が散らばり、型に載せきれていない |

- 0717の「他→うち→だから」型は方向として正しい。今回のズレは**型の欠け（通常側・ケース・対比）**と**因果の途切れ（多め採用→できること）**。

## ■改善内容（What）

### 0. 進め方

```
【維持】
・他クリニックでは → 当院では → その結果、の意識
・余裕のある体制（多め採用）という幹（0717）
・週4・週5など働き方の数字・具体スケジュール
・リフレッシュ休暇・業務の後日調整など、既にある強い事実

【直す】
① 各施策を「多め採用・余裕があるからできる」に接続
② レセプト等：通常はどうか → 当院 → 結果／ベネフィット（見出しにも）
③ 休暇・働き方：どんなケース・スタッフ事例・声
④ 理念：合う価値観 vs 合わない価値観（否定せずマッチしない）→ 採用確認
⑤ セミナー：時間帯・任意か・リアル同行・学びの声
⑥ 重複箱のドッキング（同じ話は1箇所）
```

### 1. 共通フォーマット（0717の型をそのまま使う）

```
【違いN：見出し（ベネフィットが一言で分かる）】

■ 他のクリニックでは
  （未経験者にも分かる「通常」）

■ 当クリニックでは
  （余裕のある体制・多め採用を前提にした具体）

■ だから
  （働きやすさ・定着・応募者が想像できる結果）
```

- 見出しにベネフィットを入れる（例：電話・レセプトが特定の人に集中しない、急な用事でも休める、など）。

### 2. 多め採用 → できることの因果を明示する

**つなぐ例：**

```
スタッフを多めに採用し、人員に余裕を持たせている
　↓
入社直後からリフレッシュ休暇を2日間取得できる
緊急性の低い業務を後日に調整できる
働き方が変わっても正社員のまま勤務時間を短縮できる
　↓
だから、ライフイベントがあっても働き続けやすい
```

- 「こういうことができるのは、ちゃんとスタッフを多めに採用しているから」を、各施策の直前か直後に置く。
- 「未来に共感する人を多く採用した結果」と制度の話が混ざるなら、**採用方針の結果**と**体制があるからできる制度**を分けて整理する。

### 3. レセプト等：未経験者向けに「通常」を足す

```
レセプトなどの緊急性の低い業務は、
他院では〇〇になりやすい（特定の人に集中／残業／後回しできない 等・実態に合わせる）
　↓
当院では後日に調整できる
　↓
その結果、現場の負担が偏りにくい／急な休みにも対応しやすい 等
```

- 未経験の方は「通常どうなるか」が分からない、という前提で書く。

### 4. リフレッシュ休暇・急な用事：ケースとスタッフ事例

| 足すもの | 例 |
|---|---|
| どういう時に取るか | 急な用事、リフレッシュが必要なタイミング 等 |
| スタッフ事例 | 「うちのスタッフさんの場合、〇〇のときに取得している」 |
| 声（あれば） | 実際にどう感じたか |

### 5. 週4・週5など働き方：数字＋誰向けか

- 週4・週24時間などの数字はそのまま強い。**パート並みの時間でも正社員のまま**、が結果として伝わるように分ける。
- 土曜日が入るパターン（例：3時〜5時）も良い具体。残す。
- 足す：**結婚・出産・子育て・介護などで、この働き方を選ぶ人が多い**、スタッフ事例・声。

```
【ケース例】
・子育てで夕方に帰りたい → この勤務パターン
・介護で週4にしたい → この勤務パターン
```

（実態の言い回しに合わせる）

### 6. 理念ブロック：具体＋合わない価値観の対比

理念（人の心に光を灯す、等）は抽象なので、次をセットにする。

```
【理念に沿った診療・運営の具体】
（実際にこうしている、を1〜2例）

【合う人】
この理念・価値観に共感する人

【合わない人（間違っているのではなくマッチしない）】
効率・機械的な速さ・スピード最優先・給料最優先 など
医療業界でありがちなタイプも含めて対比

【合わない人が集まると】
こういうトラブル・空気になりやすい

【当院では】
理念に共感する人だけが集まる状態を目指す
応募者の価値観・仕事観を面接前に確認して採用する

【だから】
トラブルが少なく、協力し合いながら働ける
```

- 「光を灯す理念＝どういうクリニックか」が読み手に伝わる対比を必ず入れる。

### 7. セミナー・学び

| 確認して書く | 内容 |
|---|---|
| いつ・どのくらいの時間帯か | 勤務時間内／外など |
| 強制か任意か | 読み手が気にする点 |
| オンライン以外 | リアルセミナーにみんなで行く、普段行かない場所 |
| 声 | 「学びに行ってよかった」 |
| 補足 | オンラインだけだと「本当に学べる？」と感じる人もいる → リアルや実感で補う |

- 「楽しく学べる」は言ってよい。団結力・普段行かない場所、もベネフィット。

### 8. 重複のドッキング

- 「スタッフが多いから働きやすい」の説明と、休暇・週4・業務調整など**同じ原因（余裕）から出ている枝**は、1つの違いの下にまとめるか、相互参照せず重複を削る。
- 理念の話が複数箱にあるなら、**理念ブロック1つに集約**。

### 9. セルフチェック（結果だけ）

| チェック | Yes / No |
|---|---|
| 各違いが「他→うち→結果」になっているか | |
| 休暇・調整・週4が「多め採用のおかげ」とつながっているか | |
| レセプト等に「通常はどうか」があるか | |
| 働き方に「誰が・どんなケースで」があるか | |
| 理念に合う／合わない価値観の対比があるか | |
| セミナーに時間帯・任意か・リアル・声があるか | |
| 同じ話が2箱に散らばっていないか | |

## ■改善理由（Why）

- 0717で幹（余裕のある体制）は立った。今回は枝を**制度名ではなく、差と因果とケース**で見せる段階。
- 未経験者は業界の「通常」を知らない。通常側がないと、当院の柔軟さが「当たり前」に見えて弱くなる。
- 「多め採用」と「休暇・週4」が別々だと、0717の幹が活きない。**同じ原因から出た結果**として見せると一本になる。
- 理念は言葉だけでは人によって解釈が分かれる。**合わない価値観を具体化**すると、共感する人だけが反応しやすくなる（採用のフィルタにもなる）。
- AI壁打ちは材料集めには有効だが、最終は**1違い＝1型**に載せないと読み手が迷う。

---

## ■改善後イメージ（After）

- 赤い箇所も、一般的な運営 → うちのやり方 → 実際そうなっている、で説得力がある。
- リフレッシュ休暇・業務調整・週4短縮が、「スタッフを多めに採っているからできる」と読める。
- レセプト等は通常の大変さ → 当院の調整 → ベネフィット、が未経験者にも分かる。
- 働き方は数字だけでなく、子育て・介護などのケースとスタッフ事例でイメージできる。
- 理念は具体例＋合う／合わない対比＋面接前確認 → 協力し合える職場、まで一本。
- セミナーはオンラインだけでなく、リアル同行・時間帯・任意か・声まで見える。
- 重複が減り、0717の幹の下に違いが並んでいる。

---

## ■やりがちなミス

- 制度・数字だけ並べて、**多め採用との因果**を書かない
- 「当院ではこう」だけ書いて、**他院の通常**を省略する（未経験者が差を取れない）
- 理念を抽象のまま残し、**合わない価値観の対比**を避ける
- 合わない人を「悪い人」と書く（**マッチしない**に留める）
- 働き方の数字は出すが、**誰がどんなケースで選ぶか**を書かない
- セミナーを「参加できる」だけで終わり、**時間帯・任意・リアル・声**を省略する
- AIで出した箱を残し、**同じ話が2箇所**にある
- 見出しが制度名のまま、**ベネフィットが入っていない**

## ■他の案件でも使えるパターン

### パターンA：余裕の幹 → 施策の枝（0717の続き）

```
人員に余裕がある（多め採用）
　↓
だからできること（休暇・調整・勤務短縮）
　↓
ライフイベントでも働き続けられる
```

### パターンB：未経験者向け「通常」対比

```
業界の通常（未経験者は知らない）
　↓
当院のやり方
　↓
その結果のベネフィット（見出しにも）
```

### パターンC：働き方は数字＋ケース

```
週4・週5などの数字
　↓
結婚・出産・子育て・介護など、誰が選ぶか
　↓
スタッフ事例・声
```

### パターンD：理念は具体＋反対側

```
理念の具体（診療・運営の一例）
　↓
合う価値観
　↓
合わない価値観（否定せずマッチしない）
　↓
合わない人が集まると起きること
　↓
面接前確認 → 協力し合える結果
```

### パターンE：AI壁打ち後の整理

```
材料は残す
　↓
1違い＝他→うち→結果、に載せ直す
　↓
重複はドッキング
```
