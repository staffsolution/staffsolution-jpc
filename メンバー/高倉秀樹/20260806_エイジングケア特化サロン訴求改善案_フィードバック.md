## ■現状（Before）

- 0727でヘッド路線を確定し、サブ・共感・「なぜ続けられるか」の因果を埋める段階に入ったあとの続き。
- 「あなたはこのような思いを抱いていますか？」の共感パートは、方向としてよい。
- 動画がポイントになることは前回（0727）でも触れた通りで、今回もその認識は合っている。
- 一方で、「なぜエイジングケア特化サロンでは人生経験と共感力が強みになるのか」の説明ブロックは、**説得力がまだ足りない**。
- 自社リサーチの情報を入れようとしているが、**骨格（中見出し）が先に立っていない**ため、詳しい話が先に出てしまいやすい。
- 「ただし、エイジングケア特化サロンならどこでも無理なく働けるわけではない」の注意書きが、**この位置で詳しく書きすぎ**ている。後段で説明する内容と重複しやすい。
- 理由①は上のブロックにまとめられそうで、理由②〜⑤の方がこのブロックの本体としてしっくり来る印象。
- 中見出し同士の**因果（AといえばB、BといえばC）**が、まだ意識的にはつながっていない。

---

## ■問題の本質（重要）

- 「人生経験と共感力が強みになる」は結論のラベルであって、読み手が欲しいのは**なぜそう言えるのか**の骨格である。
- 大見出しが「なぜ〜なのか」なら、本文の役割は長文の解説ではなく、**中見出しを読むだけで理由の流れがわかること**。
- 自社リサーチは「材料」であって「設計図」ではない。先に中見出しの骨格を作り、その枠にネタを当てはめる順が正しい。
- エイジング世代が求めているのは流行の髪型だけではない、という対比は有効だが、そこで詳しく語りすぎると本題（人生経験・共感力）に入る前に疲れる。リードは短く、**本当に重視していること → どうしてなのか（理由1・2・3）**へ渡す。
- 「特化サロンならどこでも」への注意は必要だが、ここで全部説明すると後段の店固有理由と被る。この位置は**簡潔な警告＋後続への橋**にとどめる。

## ■ズレ（思考 or 設計）

| やりたいこと | 起きやすいズレ | 結果 |
|---|---|---|
| 人生経験・共感力の強みを伝えたい | 結論ラベル＋詳しい説明が先に来る | 「なぜ」が中見出しで見えない |
| 自社リサーチを活かしたい | 骨格なしでネタを流し込む | 話が長く、説得力が散る |
| 流行ヘアとの違いを出したい | リードで詳しく語りすぎる | 本題に入る前に疲れる |
| どこでも通用しないと注意したい | この位置で店固有理由まで書く | 後段と重複し、焦点がぼける |
| 動画の強みを出したい | 「仕組みがある」で止まる | 「売り込み接客が不要」まで落ちない |

- 0727で求めた「特化一般ではなく当店の理由」は正しい。今回の焦点は、その**前段の説得ブロック（人生経験・共感力）の骨格**を先に固めること。
- 共感パート自体はOK。直す主戦場は「なぜ強みになるのか」ブロックの構造。

## ■改善内容（What）

### 1. 動画まわりの訴求は「売り込み接客が不要」路線でよい

前回（0727）でも動画がポイントだと確認した通り。今回さらに明確なのは、次の言い方である。

```
動画が追加提案・価値説明をしてくれる
　↓
あなたは売り上げのための売り込み接客をしなくてよい
　↓
「売り込みのセールスは一切必要ありません」
```

- 「接客に力を入れなくても販売の接客はしなくていい」という路線は、無理なく長く働く約束とつながる。
- サブヘッドや仕組みブロックで使うときは、抽象の「仕組み化」ではなく、**動画が説明を肩代わりする映像**まで落とす（0727と同じ）。

### 2. 「なぜ人生経験と共感力が強みになるか」は骨格→ネタの順

大見出し（このままでよい方向）：

```
なぜエイジングケア特化サロンでは
人生経験と共感力が強みになるのか
```

**推奨の並び：**

1. **短いリード**（対比だけ）
2. 「本当に重視しているのはこれです。どうしてなのかをお伝えします」
3. **中見出し＝理由①②③…**（中見出しを読むだけで「どうしてか」がわかる）
4. 各中見出しの下に、自社リサーチの具体を当てはめる

**リードの型（詳しく語らない）：**

```
流行のヘアスタイルを提案することは、美容師として大事な仕事です。
ただ、エイジング世代のお客さまが求めているのは、流行の髪型だけではありません。

すごく重視しているのは、こういうことです。
どうしてなのか、をお伝えします。
```

ここで「こういうこと」の中身を長々と解説しない。すぐ理由ブロックへ渡す。

### 3. 先に中見出しだけ出す（骨格づくり）

本文を書く前に、中見出しだけ並べて「読むだけで因果が通るか」を確認する。

壁打ち・提出用の問い：

```
大見出し：
「なぜエイジングケア特化サロンでは人生経験と共感力が強みになるのか」

この下に置く中見出し案を、因果がつながる順で3〜5本出してください。
条件：
・中見出しだけ読んでも「どうして強みになるか」がわかる
・A→B→C→Dのように、前の見出しが次の見出しを呼ぶ並びにする
・流行ヘアとの対比のあとに続く内容にする
```

**中身の方向性（壁打ちのヒント）：**

| 方向 | イメージ |
|---|---|
| 年代への寄り添い | 同じ年代・人生経験があるから、気持ちに寄り添える |
| 「その人だから行きたい」 | 見た目が良くなるだけより、毎回あの人に悩みを聞いてもらいたい |
| 気兼ねなく話せる | カウンセリングほど大げさでなくても、気兼ねなく話せるのが通う理由の一つ |
| だから強みになる | 人生経験・共感力が、リピートと信頼の核になる |

※言い回しは店の実態・スタッフの声に合わせて選ぶ。ポイントは**骨格を先に固定**すること。

### 4. 自社リサーチは骨格のあとに当てはめる

```
① 中見出しの骨格を決める
② 各中見出しに合う自社リサーチのネタを選ぶ
③ 合わないネタは、このブロックに無理に入れない
```

- 「リサーチがあるから書く」ではなく、「この中見出しを証明するためにリサーチを使う」。
- 理由①が上のブロック（共感やサブ）と重複するなら、上にまとめて、このブロックは理由②以降を本体にしてよい。

### 5. 注意書きは簡潔にして次のコンテンツへ橋渡しする

詳しく説明しなくてよい位置。後段で「当店だから続けられる理由」を書く前提なら、ここは短く警告するだけにする。

**簡潔版のイメージ：**

```
ただし、エイジングケア特化サロンならどこでも、
無理なく長く働けるわけではありません。

間違ったところを選んでしまうと、こうなってしまいます。
注意してください。
```

- 「こうなってしまいます」の中身は、1〜2行で十分な場合もある。詳細は次のセクションで展開する。
- 0727の「特化一般ではなく当店の理由」と役割分担する。ここは**選ぶ側への注意**、次は**当店の根拠**。

### 6. 中見出しは因果でつなぐ

並べたあと、必ず次を確認する。

```
AといえばB
BといえばC
CといえばD
```

- 「並んでいるだけ」ではなく、「前の見出しが次の問いを生む」並びになっているか。
- この整理ができれば、ブロック全体がしっくりつながる。

---

## ■改善理由（Why）

- 大見出しが「なぜ」なのに中見出しが弱いと、読み手は長い本文を読む前に「結局どういう理由？」で止まる。
- 自社リサーチを先に流し込むと、情報量は増えるが**説得の順番**が崩れる。骨格→証拠の順の方が、0727で求めた因果の厚みと一致する。
- リードで流行ヘアとの対比を詳しくやると、本題の人生経験・共感力に入るエネルギーが削られる。対比は入口、理由は中見出し側。
- 注意書きを厚くすると、「どこでも通用しない」の説明と「当店なら続く」の説明が同じ場所で戦い、どちらも薄くなる。
- 動画→売り込み不要は、「無理なく長く」を現場映像で証明する一本の線になる（0727のサブヘッド方針の具体化）。

---

## ■改善後イメージ（After）

- 共感パートはそのまま活きている。
- 「なぜ人生経験と共感力が強みか」ブロックは、短いリードのあと、**中見出しを読むだけで理由の流れがわかる**。
- 自社リサーチは各中見出しの証拠として収まっており、話が散っていない。
- 注意書きは短く、「次で詳しく」への橋になっている。
- 中見出しが A→B→C→D でつながり、ブロック全体が一本の因果で読める。
- 動画まわりは「説明を肩代わり → 売り込み接客が不要」まで落ちている。

---

## ■やりがちなミス

- 大見出しが「なぜ」なのに、中見出しがなく本文の長文だけで説明する。
- 自社リサーチを先に書いてから、あとで見出しを付ける。
- リードで流行ヘアとの違いを詳しく語り、本題に入るのが遅れる。
- 「特化ならどこでも、ではない」をこの位置で店の仕組みまで書いてしまう。
- 理由①が上と重複しているのに、同じ話をもう一度厚く書く。
- 中見出しが並列の箇条書きになり、因果でつながっていない。
- 動画の強みを「仕組みがある」で止め、「売り込みが不要」まで落とさない。

---

## ■他の案件でも使えるパターン

- **大見出し＝なぜ**なら、先に**中見出しの骨格**を作り、ネタはそのあと。
- **リードは短く対比だけ**。詳しい説明は理由ブロックへ渡す。
- **リサーチは設計図ではなく材料**。骨格に合うものだけ当てはめる。
- **注意書きと本論は役割分担**する。注意は短く、根拠は次セクション。
- **中見出しは因果チェック**（A→B→C→D）を必ず通す。
- **仕組み訴求**は、何が肩代わりされて何が不要になるかまで落とす。

## ■一言まとめ（本質）

👉 **「なぜ人生経験と共感力が強みか」は、詳しい説明を先に書かず、中見出しの骨格を先に作り因果でつなぐ。リードは短く、リサーチは骨格に当てはめ、注意書きは簡潔に次へ橋渡しする。**

## ■0727・0717・0716との関係

- **0716**：ブランクをプリヘッドから外さない。**今回**も共感パートはその方針の延長でOK。
- **0717**：ストレートなベネフィット、「無理なく長く」。**今回**の動画→売り込み不要は、その約束の現場側の証明。
- **0727**：ヘッド固定、サブで具体、共感は二カラム、理由は当店固有まで。**今回**はその前段にあたる「人生経験・共感力が強みになる理由」ブロックの骨格と中見出し因果を固める段階。
