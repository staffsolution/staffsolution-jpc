## ■現状（Before）

- 0918で指示した「一般的なイメージから先に伝える」流れが入っている。方向はよい。短くパンパンと目に飛び込む表現の方針も乗っている。
- 内容そのものはよくなっている。問題は、まだ回りくどい言い回しと、同じ意味の繰り返しがあることである。
- 例：「大人女性が求めているのは、年齢による変化をただなくすことだけではありません」は正しいが、頭に入るまで時間がかかる。もっとストレートでよい。
- メインターゲットは、同じく40代・50代の美容師である。そこに「あなたも分かりますよね」の投げかけが弱い。
- 「私のことをわかってくれる → 選ばれる理由になります」の見出しは、本文を読まないと「スピードではなく、こっちが重視される」が伝わりにくい。
- 「だからこれまでの人生経験と共感力が強みになります」の本文はボリュームが多い。途中の中見出し、または見出し分けが必要である。
- 大見出しの直後に、リードが長く続き、次の見出しが遠い。リードは短くし、そのあと見出しで区切る形にしたい。

---

## ■問題の本質（重要）

- 0918で「エイジングケア＝老化対策・若返り」という先入観を先に置く骨格は通った。今回はその骨格を、**読み手が一瞬で分かる言葉**と、**同世代美容師への語りかけ**に落とす段階である。
- 読み手は説明を丁寧に読む人ではない。誰もがわかる言葉（若返り）で差を出し、重複を削って、スピーディーに伝える。
- ターゲットも40代・50代の美容師なので、「一般論の説明」だけで終わらせない。「あなたもそうですよね」と投げかけると、共感 → 自分も伝え方が分かる → ここで自分らしく働けそう、という想像が立つ。共感しない人は読まなくなるが、それでよい。
- 見出しは、本文の要約である。見出しを読んでいるだけでも内容が伝わってくる状態にする。「わかってくれる」系の見出しは、スピードではなく傾聴・共感が選ばれる理由だ、と一目で分かる形にする。
- 1ブロックが長いときは、中見出しで区切る。大見出し → 短いリード → 見出し → 本文、のリズムを崩さない。

## ■ズレ（思考 or 設計）

| 意図 | 結果 |
|---|---|
| 老化対策だけではないと伝えたい | 「年齢による変化をただなくすこと」など回りくどくなり、一瞬で入らない |
| 丁寧に説明する | 同じ意味が繰り返し、スピード感が落ちる |
| 一般イメージとの差を出す | 同世代への「あなたもそうですよね」がなく、自分ごと化が弱い |
| 選ばれる理由を伝えたい | 見出しだけでは「スピードよりこっち」が分からない |
| 人生経験が強みだと書きたい | 本文が長く、途中で区切れず読みにくい |
| リードで橋渡ししたい | リードが長く、次の見出しまで遠い |

- 0918は「先入観を置く」段階だった。今回は、その先入観の置き方を**ストレートな言葉**と**語りかけ**に磨き、見出し構造で読ませる段階である。

---

## ■改善内容（What）

### 0. 方向はそのまま、言い方と構造を直す

次は変えない。

- 一般イメージから先に入る流れ（0918）
- 「その人らしい綺麗さを一緒に作る」幹（0825）
- 短くパンパンと目に飛び込む方針
- ファーストビューの2約束（大人女性に選ばれる／無理なく長く）

直すのは、表現のストレートさ、重複、語りかけ、見出し、リードの長さである。

### 1. 「それだけではない」をストレートな言葉にする

回りくどい言い回しを、誰もがわかる言葉に落とす。

| いま回りくどい例 | ストレートにする方向 |
|---|---|
| 年齢による変化をただなくすことだけではありません | 単純に若返りたい、ということだけではない |
| ことだけではありません（長い前置きのあと） | 若返り、ということでしょう？　——それだけではない |
| 年齢とともに出る変化への対策…（説明が長い） | 白髪染め・髪質改善・若々しく保つ、を先に置き、すぐ差へ |

イメージ（言い回しは店の実態に合わせる）：

```
もちろん、それもエイジングケアの一つです。
ただ、大人女性が求めているのは、
シンプルに若返りたい、ということだけではありません。
```

または、さらに短く：

```
単純に若返らせる、ということでしょう？
——それだけではありません。
```

「誰もがわかる言葉 → すぐ差」の順にする。説明の丁寧さより、頭に入る速さを優先する。

### 2. 重複を削り、スピーディーにまとめる

内容はよい。同じ意味を言い換えて繰り返している箇所を削る。

| 残す | 削る・まとめる |
|---|---|
| 一般イメージ（白髪染め・髪質改善・若々しく保つ） | 同じイメージの言い換えが続く段落 |
| 「それだけではない」→ 当店の定義 | 定義の前後で同じ結論を二度言う文 |
| 傾聴 → わかってくれる → 選ばれる → 人生経験 | 各段の言い換えだけの肉 |

壁打ちの問い：「よりスピーディーに伝えたいことが伝わる形にすると、どの文が消えるか？」

### 3. 40代・50代美容師への語りかけを入れる

メインターゲットは、同じく40代・50代の美容師である。「一般の人がこう思う」だけで終わらせず、「あなたもそうですよね」を入れる。

イメージ：

```
エイジングケアって聞くと、一般的には
白髪染めや髪質改善、
髪や頭皮を若々しく保つことを
イメージするかもしれません。

でも、それだけではないですよね。
あなたも、そうですよね。
```

語りかけの役割は次の3つである。

```
① あなた自身も分かっていますよね
　↓
② だから共感できる／伝え方のイメージがつく
　↓
③ このエイジングケア特化サロンなら、自分らしく働けそう
```

共感する人は次を読む。共感しない人は読まなくなる。それでよい。絞り込むための投げかけである。

### 4. 見出しだけで内容が伝わるようにする

見出しを読んでいるだけでも内容が伝わってくる状態にする。

特に「私のことをわかってくれる → 選ばれる理由になります」系は、次が分かる見出しにする。

| 弱い見出し | 見出しで伝えたいこと |
|---|---|
| 私のことをわかってくれることが選ばれる理由になります | スピードではなく、わかってくれることが選ばれる |
| （抽象的な「大切にしていること」） | 若さ・スピードより、傾聴と共感が重視される |

見出しの役割チェック：

```
この見出しだけ読んで、
「スピードよりこっちが重視される」が分かるか？
分からなければ、見出しを直す（本文で補わない）。
```

### 5. 大見出し → 短いリード → 次の見出し

「なぜエイジングケア特化サロンでは、人生経験と共感力が強みになるのか」の直後は、次の順にする。

```
① 大見出し（人生経験と共感力が強みになるのか）
　↓
② 短いリード（年を重ねたあなたへの語りかけ）
　↓
③ 次の見出し（当店の定義／わかってくれる／人生経験 など）
　↓
④ 本文
```

リードが長いと感じるなら、短くする。リードで入れる内容の方向：

```
でも、年を重ねてきたあなたは、
きっと感じているのではないでしょうか。

若い頃から、髪の悩みも、求める綺麗さも変わってきたこと。
単純に若々しく保つだけでいいわけではない、ですよね。
```

そのあとで、自然につなぐ：

```
当店のエイジングケアは、
その人らしい綺麗さを一緒に作る美容です。
```

リードは橋渡しだけ。定義・傾聴・選ばれる理由の全文をリードに詰め込まない。

### 6. 人生経験ブロックは中見出しで区切る

「だからこれまでの人生経験と共感力が強みになります」の本文が長い場合は、途中に中見出しを入れるか、見出しを分ける。

区切り方の例：

```
【見出し】スピードではなく、わかってくれることが選ばれる
　本文：傾聴 → 信頼 → 選ばれる

【見出し】だから人生経験と共感力が強みになる
　本文：若さ・スピードより経験／同じ年代層ならなおさら
```

1見出しの下に長い因果を全部載せない。見出しを読めば次の段の役割が分かるようにする。

### 7. 推奨の並び（0918骨格＋今回の磨き）

```
① エイジングケアと聞いて想像すること（白髪染め・髪質改善・若返り）
　↓
② 「それだけではないですよね。あなたもそうですよね」（語りかけ）
　↓
③ 短いリード（年を重ねたあなたは感じている／若々しく保つだけではない）
　↓
④ 当店＝その人らしい綺麗さを一緒に作る（0825の幹）
　↓
⑤ 人それぞれ → 説明より聞く
　↓
⑥ 【見出し】スピードではなく、わかってくれることが選ばれる
　↓
⑦ 【見出し】だから人生経験と共感力が強みになる
```

## ■改善理由（Why）

- 「年齢による変化をただなくす」より「若返り」の方が、読み手の頭にある映像と一致する。差を出す前の言葉は、説明的であるよりストレートである方が効く。
- 同じ意味の繰り返しは、正しい内容でも読む速度を落とす。0918の骨格が通った今は、肉を足すより削る段階である。
- ターゲットが同世代美容師なら、一般論より「あなたもそうですよね」の方が、自分ごとになる。共感した人だけが次を読む設計でよい。
- 見出しが弱いと、本文を読ませる前に離脱する。特に「選ばれる理由」は、スピードとの対比が一目で分かる見出しにする。
- リードが長いと、大見出しのあとに壁ができる。短い語りかけで幹へつなぎ、詳しい因果は見出しの下に置く。

---

## ■改善後イメージ（After）

- 一般イメージが「若返り」など一瞬で分かる言葉で置かれ、「それだけではない」がすぐ続く。
- 「あなたもそうですよね」があり、同世代の美容師が自分ごととして読める。
- 重複が削られ、伝えたいことがスピーディーに通る。
- 見出しだけ読んでも、「スピードではなく、わかってくれることが選ばれる」「だから人生経験」が伝わる。
- 大見出しのあとが短いリードになり、その次に見出しが来るリズムになっている。
- 人生経験ブロックが中見出しで分かれ、長い本文の壁が無い。
- 共感した人が「ここで自分らしく働けそう」と想像できる。

---

## ■やりがちなミス

- 「年齢による変化をただなくす」など回りくどい言い回しで、若返りとの差がぼやける
- 正しい内容を言い換えて繰り返し、スピード感を落とす
- 一般イメージだけ書いて、「あなたもそうですよね」の語りかけを入れない
- 見出しが抽象的で、スピードよりこっち、が本文を読まないと分からない
- 大見出しのあとに長いリードを置き、次の見出しが遠い
- 人生経験と共感力の因果を1見出しの下に全部載せ、途中で区切らない
- 語りかけを増やしすぎて、説明口調に戻る（投げかけは短く）
- 0918の骨格（一般イメージ → 幹）を崩して、また結論から入る

## ■他の案件でも使えるパターン

### パターンA：先入観の言葉は、読み手が使う言葉にする

```
業界用語・丁寧な言い換え
　↓
読み手が口にする言葉（例：若返り）
　↓
「それだけではない」
```

差を出す前の言葉が難しいと、差も届かない。

### パターンB：同世代ターゲットには語りかけを入れる

```
一般的にはこう思われがち
　↓
でも、それだけではないですよね
　↓
あなたも、そうですよね
　↓
だから共感できる／自分もやれそう
```

説明で納得させるより、わかっている同士の確認で前に進める。

### パターンC：見出しは本文の要約

```
見出しだけ読んで、次の主張が分かるか？
　↓
分からなければ見出しを直す
　↓
本文で補完しない
```

特に「比較・対比（スピード vs 傾聴）」は見出しに出す。

### パターンD：大見出し → 短いリード → 見出し

```
大見出し（なぜ〜なのか）
　↓
短いリード（語りかけ・橋渡しだけ）
　↓
中見出し（役割ごとに分割）
　↓
本文
```

リードに全文を載せない。長い因果は中見出しの下へ。

## ■一言まとめ（本質）

👉 0918の骨格はそのまま、「若返り」などストレートな言葉と「あなたもそうですよね」の語りかけで自分ごとにし、見出しだけでスピードより傾聴、が伝わる形に整える。長いリードと長い本文は、短いリード＋中見出しに分割する。

## ■0918・0825との関係

- **0825**：幹を「自分らしい綺麗さ」に一本化。働き方はあと。
- **0918**：幹の前に、エイジングケア＝老化対策・若返りの先入観を置く。聞く → 選ばれる → 人生経験。
- **今回**：0918の骨格は通った前提で、表現をストレートにし、同世代への語りかけを足し、見出しとリードの構造で読ませる。内容の方向転換ではなく、伝わり方の磨きである。
