## ■現状（Before）

- 0717までの方向性を受けて、ファーストビュー〜その次のブロックまで大きく前進した提出。
- **プリヘッド**「10年以上のブランクがある方も、今の働き方を変えたい現役美容師さんも。」はしっくり来る。
- **ヘッドライン**「エイジングケア特化の当店なら、大人女性に選ばれる美容師として、無理なく長く働き続けられます。」も路線として良い。この方向で進めてよい。
- **サブヘッド**は「若さやスピードではなく、大人女性に寄り添う／人生経験を生かす」まで書けているが、「だから無理なく長く続けられる」への結びがまだ浅い。
- 「あなたはこのような思いを〜」パートで、ブランク復帰層の悩みと、働き方を変えたい現役の悩みが**同じ塊の中で混在**している。
- 「なぜエイジングケア特化だと〜」の見出し側は、業態の説明に寄りやすく、**当店だから長く続けられる理由**まで落ちきっていない。

---

## ■問題の本質（重要）

- ファーストビューのビッグプロミスは「無理なく長く働き続けられる」。サブヘッドの役割は、その**なぜ**を短く具体で補うこと。寄り添いや人生経験の話だけで止まると、ヘッドの繰り返しに見える。
- 「高単価」は、ブランク層が一気に抵抗しやすい。無理なく働ける理由は、単価より**少人数担当・仕組み・説明の効率化**側で示す方が刺さる。
- 共感パートは、ターゲットが2系統いるなら**先に分けて見せ、あとで共通項で束ねる**。混ぜたまま時系列で並べると、どちらにも中途半端に読まれる。
- 「エイジングケア特化＝人生経験が活きる」だけでは不十分。特化サロンのすべてが長く働けるわけではない。**当店の働き方・仕組み**まで書いて、初めて「無理なく続けられる」が成立する。

## ■ズレ（思考 or 設計）

| やりたいこと | 起きやすいズレ | 結果 |
|---|---|---|
| 長く働ける理由を補強したい | 寄り添い・人生経験の言い換えで止まる | ヘッドの繰り返しに見える |
| 仕組みの強みを出したい | 「頑張りだけに依存しません」など抽象語 | 何が楽になるか想像できない |
| ブランクも現役も拾いたい | 悩みを1ブロックに混在させる | どちらにも刺さらない |
| 特化サロンの必然性を出したい | 業態一般の説明で終わる | 「なぜ当店か」が弱い |

- AIで路線に気づけたこと自体は大きい。自分の案件だと視点が固まりやすいので、案出しはAI・他者の力を使い、最終のしっくり感は自分と現場で選ぶ、が正しい使い方。
- 「これ以上のヘッドがあるだろうか」と感じるほどしっくり来ているなら、ヘッドは固定して、**サブ・共感・理由**の因果を埋める段階に移る。

---

## ■改善内容（What）

### 1. ファーストビューは今の路線で確定してよい

方向性の確認：

```
プリヘッド
　10年以上のブランクがある方も、
　今の働き方を変えたい現役美容師さんも。

ヘッドライン
　エイジングケア特化の当店なら、
　大人女性に選ばれる美容師として、
　無理なく長く働き続けられます。
```

- 0717で求めた「ストレートなベネフィット」「エイジングケア特化の接続」が入っている。
- ここから先は、ヘッドをいじり続けず、**サブヘッド以下の因果**を厚くする。

### 2. サブヘッドは「なぜ無理なく長くか」を具体で補う

いまのサブヘッドの骨格（若さ・スピードではない／寄り添う／人生経験）は方向として良い。足りないのは、**一人ひとり向き合う働き方 → 無理なく長く続けられる**の橋渡し。

| 入れない方がよい | 入れるとよい |
|---|---|
| 高単価（ブランク層が一気に抵抗しやすい） | 少人数担当制で一人ひとり丁寧に向き合える |
| 「頑張りだけに依存しません」だけの抽象 | 動画マニュアル／説明の仕組みで、施術と接客に集中できる |

表現の候補（しっくり来るものを選ぶ）：

```
・少人数担当制なので、一人ひとり丁寧に向き合えます
・わからないところは動画マニュアルでいつでも確認できる
・お客様への説明は動画で効率化。あなたは施術と接客に集中できます
・毎回同じ説明を繰り返さなくても、動画がお店の価値を伝えてくれます
```

サブヘッドでやることは「きれいなまとめ」ではなく、ヘッドの「無理なく長く」を**映像で想像できる理由**に落とすこと。

### 3. 共感パートは二カラムに分けてから共通項で束ねる

「あなたはこのような思いを抱いていませんか？」は、悩みが混在していると読みにくい。見せ方は次がよい。

```
【見出し】あなたはこのような思いを抱いていませんか？

　┌─────────────────┬─────────────────┐
　│ もう一度美容師として   │ 今の働き方を変えたい   │
　│ 働きたい方           │ 現役美容師の方         │
　├─────────────────┼─────────────────┤
　│ ・子育てが落ち着き、   │ ・人数やスピードの       │
　│   また美容師として    │   働き方に疲れてきた    │
　│   働きたい           │ ・同じテンションで      │
　│ ・長いブランクで      │   働き続けるのがしんどい │
　│   務まるか不安       │ ・忙しくてお客様に      │
　│ ・技術・会話の不安    │   向き合えない         │
　└─────────────────┴─────────────────┘

【共通】
立場は違っても共通しているのは、
人数やスピードを求められる働き方ではなく、
一人ひとりのお客様に丁寧に向き合いながら、
無理なく美容師を続けていきたい、ということ。

【接続】
それを実現できるのが、
当店のようなアンチエイジングケア特化の美容室です。

【CTA】
少しでも興味のある方は、見学にいらしてください。
```

- 分けることで「自分のことだ」が両層に立つ。
- 束ねることで、メインターゲット（ブランク）を外さず、現役も同じ価値観で拾える（0716の方針と整合）。

### 4. 「なぜ続けられるか」は業態一般ではなく当店の理由にする

次の見出し周りは、次の問いに答える形にする。

```
なぜ、年を重ねても（ブランクがあっても）
無理なく続けられるのか？
```

注意点：

- 「アンチエイジングケア特化だと人生経験・共感力が求められる」だけでは足りない。
- 特化サロンの**すべて**が長く働けるわけではない。
- ここで入れるべきは、**高倉さんのお店だから続けられる理由**（少人数・仕組み・働き方・現場の実態）。

流れのイメージ：

```
共感で「丁寧に向き合い、無理なく続けたい」が立つ
　↓
当店のような特化サロンなら、それが仕事の中心になる
　↓
さらに当店では、○○・○○があるから無理なく長く続けられる
　↓
CTA
```

## ■改善理由（Why）

- ヘッドがしっくり来ている今は、言葉を磨き続けるより、**ヘッドの約束を下段で証明する**方がLP全体が強くなる。
- サブヘッドが浅いと、読み手は「きれいごとでは？」で止まる。少人数・動画・仕組みなど、現場で想像できる理由が必要。
- 「高単価」は売り手側の強みでも、ブランク層の入口では不安トリガーになりやすい。無理なく働ける根拠としては優先度を下げる。
- 共感を混ぜると、ブランク層も現役層も「半分自分ごと」で終わる。二カラム→共通項の方が、0716の「ブランク主・現役は下で拾う」と矛盾しない。
- 「特化だから続く」は業態の一般論。採用で刺さるのは**この店の働き方**。0717・0703で積み上げた「エイジングケア特化だから人生経験が活きる」の先に、店固有の理由を足す段階。

---

## ■改善後イメージ（After）

- ファーストビューは今のプリヘッド・ヘッドラインで確定し、迷いが減っている。
- サブヘッドを読むと、「寄り添う」だけでなく、**なぜ無理なく長く働けるか**が具体で見える。
- 共感パートは、ブランク復帰／働き方を変えたい現役が横並びで分かり、そのあと共通の願いで一本につながる。
- 「なぜ続けられるか」ブロックは、特化サロン一般ではなく、**当店の仕組み・働き方**まで落ちている。
- 全体として、ヘッドの約束 → 理由 → 共感 → 当店固有の根拠 → CTA、の順で読める。

---

## ■やりがちなミス

- ヘッドが良いのに、完成度を求めてヘッド案出しを続け、サブ以下の因果が空のままになる。
- サブヘッドで「人生経験」「寄り添い」を言い換えて終わり、「長く続けられる理由」を書かない。
- 「高単価」を無理なく働ける根拠の先頭に置く。
- 「頑張りに依存しない」「仕組み化」など抽象語のまま置き、何が楽になるかが見えない。
- ブランクと現役の悩みを1段落に混ぜ、時系列だけで並べる。
- 「エイジングケア特化＝人生経験」で止め、当店固有の続けられる理由を書かない。

---

## ■他の案件でも使えるパターン

- **ヘッドが決まったら固定**し、次はサブで「なぜその約束が本物か」を具体化する。
- **ベネフィットの根拠**は、単価・理念より先に、働き方・人数・仕組みなど想像できる事実で支える。
- **ターゲットが2系統**なら、悩みは分けて見せ、価値観の共通項で束ねてから自社へ接続する。
- **業態の強み**と**自社の強み**を分けて書く。業態だけで「続く」は言わない。
- AIは路線発見に使い、最終文は「しっくり来る／現場が言える」で選ぶ。
