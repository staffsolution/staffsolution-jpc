## ■分類（タグ）

- LP・ストーリーボード
- 人生経験と共感力ブロック
- 「自分らしい綺麗さ」を見出しに入れる
- リードでBelief→幹→具体までまとめる
- ヒアリングベース（先生スタンスを避ける）
- 大切にしたい・変えたい・残したいの具体例
- 「自分の考えを押し付けず」を上の確かめに統合
- 「その気持ち」の抽象を具体へ／繰り返し削減
- 1014・1008・0918・0825の続き

---

## ■現状（Before）

- AIと壁打ちし、お店のエピソードや具体例を入れた提出になっている。イメージしやすさは上がっている。方向はよい。
- 対象は「なぜエイジング特化サロンでは、人生経験と共感力が強みになるのか」のコピー。
- 出だしで「エイジングケアと聞くと〜／当店は若返りではなく、自分らしい綺麗さを一緒に作る美容です」と書けている。
- 一方で、Belief（思い込み）への返しと、「自分らしい綺麗さが何よりも重視していること」と、その具体が、リードの中で一本にまとまりきっていない。
- 「何が気になり、どんな仕上がりなら嬉しいのか」「お客様と一緒にその方に合った綺麗さ」は方向はよいが、その人が好きなこと・嫌なこと・思う綺麗さが何か、を一緒に考えて施術する、という芯がまだ弱い。
- 「スタイルを決める前に、大切にしたいこと・変えたいこと・残したいことを確かめます」に、事例が足りない。
- その書き方が、先生がアドバイスしているスタンスに寄りやすい。未経験・長いブランクの人にはハードルが高く見える。
- 「自分の考えを押し付けず、相手の立場で考える」は大事なのに、下の段落に孤立していて、上の「確かめます」に反映されていない。
- 「ここまで読んでその気持ちわかると感じたことはありませんか」の「その気持ち」が抽象的。同じ内容の繰り返しにもなっている。
- 全体として、もう少し整理して短くできる。
- コンセプトである「自分らしい綺麗さ」（必要なら「若返りではなく」）が、見出し側に十分入っていない。

---

## ■問題の本質（重要）

- 1014で「見出しだけで思い込みを外す」「聞く内容の具体」まで磨いた続きである。今回の本題は、**コンセプトを見出しに載せる**ことと、**ヒアリングの流れを先生口調ではなく確認ベースで通す**ことである。
- 「自分らしい綺麗さ」は0825で決めた幹である。リードに書くだけでは足りない。**見出しを読んだだけで、当店が何を売っているかが分かる**状態にする。
- リードの役割は、思い込みを置く → それだけではない → 幹（自分らしい綺麗さ）→ 具体、までを一度で通すこと。次の「どうやって実現するか」へスムーズにつなぐ。
- 「大切にしたい・変えたい・残したい」は、教える内容ではなく、**聞いて確かめる内容**である。未経験・ブランク層が見ても「自分にもできそう」と感じる書き方にする。
- 「押し付けない」は別段落に置かず、確かめの中身として統合する。人生経験は、いろいろなタイプの人に出会ってきたから、違いを理解できる、という説明に落とす。
- 「その気持ち」のような抽象語は、40代以降の自分が同じ経験をしてきたから共感できる、まで具体化し、繰り返しは削る。

## ■ズレ（思考 or 設計）

| 意図 | 結果 |
|---|---|
| 自分らしい綺麗さを伝えたい | リードにはあるが、見出し側が弱い |
| Beliefを外してから幹へ行きたい | 思い込み・幹・具体が散り、一本の流れになっていない |
| 一緒に綺麗さを作ると伝えたい | 「好き・嫌い・その人の綺麗さ」まで落ちていない |
| 確かめてからスタイルを決めると伝えたい | 事例がなく、先生のアドバイス口調に寄りやすい |
| 押し付けないと伝えたい | 下の段落に孤立し、上の確かめとつながっていない |
| 同世代への共感を出したい | 「その気持ち」が抽象で、繰り返しが残る |
| 具体を足して読みやすくしたい | 具体は良いが、全体がまだ長い |

- 1014は見出しでの思い込み外し・対比・聞く内容が本題だった。今回は、その先で**幹を見出しに固定し、ヒアリングのスタンスと統合**まで進める段階である。

## ■改善内容（What）

### 0. 方向はそのまま、磨く場所を絞る

次は変えない。

- 自分らしい綺麗さの幹（0825）
- 一般イメージ（若返り）から先に入る流れ（0918）
- 「あなたもそうですよね」の語りかけ（1008）
- AI壁打ちで出した、お店のエピソードを含む具体例（削りすぎない）

直すのは、見出しへの幹の載せ方、リードの一本化、ヒアリングのスタンス、具体例の置き方、「押し付けない」の統合、「その気持ち」の具体化、ボリューム整理である。

### 1. 見出しに「自分らしい綺麗さ」を入れる

コンセプトは見出しで伝える。リード任せにしない。

| 弱い（リード頼み） | 見出しで載せる方向 |
|---|---|
| なぜ人生経験と共感力が強みになるのか（幹が見えない） | 当店は自分らしい綺麗さを提供するから、人生経験と共感力が強みになる |
| 若返りではない、が本文だけ | 見出し側にも「若返りではなく」を入れてよい |

イメージ（言い回しは店の実態に合わせる）：

```
当店のエイジングケア特化サロンは、
若返りではなく自分らしい綺麗さを一緒に作るから、
人生経験と共感力が強みになる
```

他に入れられそうな見出しがあれば、そちらにも「自分らしい綺麗さ」を散らしてよい。幹なので、見出しで見失わない。

### 2. リードを「Belief → それだけではない → 幹 → 具体」で一本化する

出だしで全部まとめきる。

```
① エイジングケアと聞くと、こう思う（Belief）
　↓
② それだけではない
　↓
③ 当店が何より重視しているのは、自分らしい綺麗さ
　↓
④ 具体的にはこういうこと（好き・嫌い・その人の綺麗さ）
　↓
⑤ それを実現するために、次の流れでやる
```

「何が気になり、どんな仕上がりなら嬉しいのか」は、次のように芯を出す。

```
その人が何を好きで、何が嫌なのか
　↓
その人が思う綺麗さは何か
　↓
それを一緒に考えて施術する
```

この芯をリードで伝えたあと、「だから、スタイルを決める前に確かめる」へつなぐ。

### 3. 「大切にしたい・変えたい・残したい」に具体例を入れる

抽象の三語だけでは弱い。事例を入れる。

| 抽象だけ | 具体を足す方向 |
|---|---|
| 大切にしたいこと | 残したい長さ／自然な色味／今の雰囲気 など |
| 変えたいこと | うねり／ボリュームの位置／暗さ など |
| 残したいこと | トップの空気感／顔周りの柔らかさ など |

「最初はこうしたいと言っていたが、話を聞いたらこちらの方が近いのでは」という提案の例は入れてよい。差が出るのは、教えることではなく、聞いたあとの提案である。

### 4. 先生スタンスをやめ、ヒアリングベースにする

未経験・長いブランクの人にとって、アドバイス口調はハードルが上がる。

```
先生が教える／アドバイスする
　↓
まず聞いて確かめる
　↓
聞いた内容に合わせて、適切な施術を提案する
```

基本の流れは次で固定する。

```
大切にしたい・変えたい・残したいを聞く
　↓
「そういうことなら、最初におっしゃっていたAより、Bの方が近いのでは」
　↓
一緒に決めて施術する
```

### 5. 「自分の考えを押し付けず」を、上の確かめに統合する

下の段落に孤立させない。確かめの中身として書く。

```
人によって大切なことは違う
　↓
自分の好みを押し付けない
　↓
この方はどんな仕上がりを望んでいるか、相手の立場で考える
　↓
それが「確かめます」の中身
```

人生経験の活かし方も、同じ場所に寄せる。

```
いろいろなタイプの人と出会ってきた
　↓
押し付けると合わない、という違いを知っている
　↓
だから理解できる／確かめられる
```

「これまでの出会い・経験で知った考え方や好みの違い」は残してよい。置き場所を、上の確かめ側へ移す。

### 6. 「その気持ち」を具体化し、繰り返しを削る

「ここまで読んでその気持ちわかると感じたことはありませんか」は、どの気持ちかが分からない。

| いま | 寄せる方向 |
|---|---|
| その気持ち（抽象） | 髪の変化・同世代の悩みなど、何の経験か分かる言葉 |
| 同じ説明の繰り返し | 40代以降なら同じ経験をしてきた → だから共感・理解できる、に一本化 |

まとめ方の骨格：

```
あなた自身も40代以降なら、同じような経験をしてきたのではないでしょうか
　↓
だからこそ、お客様の悩みに共感し、理解できる
```

「あなた自身が感じてきた髪の変化」は具体として残してよい。抽象の問いかけと重複する部分は削る。

### 7. ボリュームを整理する

具体例とエピソードは残す。削るのは次である。

| 残す | 削る |
|---|---|
| お店の出来事を含む具体 | 同じ結論の言い換え |
| ヒアリング→提案の流れ | 先生口調の重複説明 |
| 見出しの幹（自分らしい綺麗さ） | リードと本文での二重説明 |

### 8. 推奨の並び（1014骨格＋今回の磨き）

```
① 見出し：若返りではなく、自分らしい綺麗さ（幹を載せる）
　↓
② リード：Belief → それだけではない → 幹 → 具体
　↓
③ 好き・嫌い・その人の綺麗さを一緒に考える
　↓
④ スタイル前に、大切／変えたい／残したいを確かめる（具体例つき）
　↓
⑤ 聞いたうえで提案する（先生ではなくヒアリングベース）
　↓
⑥ 押し付けない・違いを理解する、は④⑤に統合
　↓
⑦ 40代以降なら同じ経験がある → だから共感できる（短く）
　↓
⑧ だから人生経験と共感力が強みになる
```

## ■改善理由（Why）

- 「自分らしい綺麗さ」はコンセプトである。リードだけだと、見出しだけ読む人に幹が届かない。
- Belief・幹・具体が散ると、次の「どうやって実現するか」へ進めない。リードで一度通す必要がある。
- 先生スタンスは、未経験・ブランク層の離脱につながる。差は教えることではなく、聞けることである。
- 「押し付けない」は理念の貼りものにすると弱い。確かめの手順の中に入れると、行動として伝わる。
- 「その気持ち」は読み手が想像で埋める表現である。同世代への共感は、経験の内容が見えたときに初めて自分ごとになる。
- 具体を足したあとでも、同じ結論の言い換えが残ると、また長くなる。1014のボリューム注意の続きである。

---

## ■改善後イメージ（After）

- 見出しだけ読んでも、「若返りではなく、自分らしい綺麗さ」が分かる。
- リードが Belief → 幹 → 具体 → 次の流れ、で一本につながる。
- 「好き・嫌い・その人の綺麗さ」が、一緒に考える芯として見える。
- 「大切にしたい・変えたい・残したい」に具体例があり、ヒアリング→提案の流れが分かる。
- 先生のアドバイス口調ではなく、聞いて確かめる書き方になっている。
- 「押し付けない」が上の確かめに入り、人生経験の活かし方とつながっている。
- 「その気持ち」のような抽象がなく、40代以降への共感が短く通る。
- 具体は残りつつ、繰り返しが減って読みやすい。

---

## ■やりがちなミス

- 幹（自分らしい綺麗さ）をリードだけに置き、見出しが「なぜ強みになるか」だけになる
- Belief・幹・具体を別々の段落に散らす
- 「大切にしたい・変えたい・残したい」を抽象のまま置く
- ヒアリングなのに、先生が教える口調で書く
- 「押し付けない」を別段落に孤立させる
- 「その気持ち」など、何の経験か分からない問いかけを残す
- 同じ共感の説明を二度書く
- 具体を全部残そうとして、言い換えまで残す

## ■1014・1008・0918・0825との関係

- **0825**：幹を「自分らしい綺麗さ」に一本化。
- **0918**：幹の前に、エイジングケア＝若返り・老化対策の先入観を置く。
- **1008**：ストレートな言葉と「あなたもそうですよね」。
- **1014**：見出しでの思い込み外し・対比軸・聞く内容の具体・易しい言葉・ボリューム。
- **今回**：幹を見出しに固定し、リードの一本化とヒアリングのスタンスまで通す。方向転換ではなく、伝わり方と書き方の精度上げである。
