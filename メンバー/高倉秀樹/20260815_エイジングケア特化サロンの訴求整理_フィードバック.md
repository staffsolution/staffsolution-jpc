## ■現状（Before）

- 0806で求めた「なぜエイジングケア特化では人生経験と共感力が強みになるか」の骨格づくりを受けて、自分で「いい線にいっている／これならいける」と感じるところまで進めた提出。その感覚まで自分で持てていること自体が大事。
- ロジカルにつながっている印象はよい。情報量が増えたら分ける、骨格を柔軟に動かす、という姿勢も正しい。
- 一方で、読み手の多くは**エイジングケア特化サロンがどういう店なのか**をまだ知らない。その説明がないまま「人生経験と共感力が強みになる」へ入ると、理由の土台が見えない。
- 「年齢を重ねても無理なく働き続けられる」側の理由に、「一人のお客さまに最初から最後まで丁寧に向き合える」がまだ十分乗っていない。
- ヒアリングで悩みを引き出したあと、**その人にどのメニューを出すか**の具体（あるある事例）が薄い。
- 「特化サロンならどこでも楽しく働けるわけではない」への注意は方向として正しいが、**当店の環境（未経験でも経験者でも無理なく活躍できる）**への橋がまだ弱い。
- ターゲットは歩合や教育を強く意識する層でもある。その関心を、骨格のどこに置くかは再検討の余地がある。

---

## ■問題の本質（重要）

- 「人生経験と共感力が強み」は結論である。その前に必要なのは、**誰に、どんな悩みに、どんなサービスを、どういう単価・時間のかけ方で提供している店なのか**という業態の映像である。
- エイジングケア特化は、抜け毛・白髪・ボリューム低下など強い悩みを扱う。通常の美容室より単価が上がりやすく、一人にかける時間も長くなる。だから技術より**ヒアリング力**が先に立つ。ヒアリングで効くのが、自分の人生経験・他者の話を重ねて相手の立場に立てることである。
- 高単価は「無理なく働ける理由」として出す数字ではない（0727）。今回使うなら、**丁寧に向き合う必然性**を説明する材料として使う。
- 「特化サロン」は働きやすさの保証ではない。売上競争・強い売り込み・教えてもらえない・短時間勤務ができない店もある。特化の説明のあと、**当店の環境**へ渡して初めて「無理なく働ける」が成立する。
- ストーリーボードの骨格は一度決めたら固定するものではない。順番も幹も、壁打ちしながら何度も組み替えてよい。

## ■ズレ（思考 or 設計）

| やりたいこと | 起きやすいズレ | 結果 |
|---|---|---|
| 人生経験・共感力の強みを伝えたい | 特化サロンの説明なしで結論へ入る | 「なぜそれが強みか」の土台が見えない |
| 丁寧に向き合える働き方を出したい | 「無理なく続く理由」と業態説明が混ざる | どちらも薄くなる |
| ヒアリングの価値を出したい | 悩みを聞くところまでで止まる | 提案メニューの映像がない |
| どこでも通用しないと注意したい | 注意だけで終わり、当店へ渡さない | 「ではどこなら」が残る |
| 骨格を固めたい | 「これでいく」と早めに決める | より伝わる順番を試せない |

- 0806は「中見出しの骨格を先に、因果でつなぐ」が主題だった。今回はその骨格の**一番前**に、特化サロンの説明が足りていない、という続きである。
- 0727の「高単価を無理なく働く理由にしない」は維持する。今回の高単価は、**丁寧接客とヒアリングが必要になる理由**としてだけ使う。

## ■改善内容（What）

### 1. 骨格の先頭に「特化サロンとは何か」を置く

人生経験・共感力の話に入る前に、次の3つを短く見せる。

```
① エイジングケア特化サロンは、どういう店か
② お客さまは、どんな人か（どんな悩みか）
③ どんなサービスを、どういう向き合い方で提供しているか
```

**業態の映像（店の実態に合わせて具体化する）：**

```
抜け毛・白髪・ボリューム低下など、
強い悩みを抱えたお客さまが来る店である。

通常の美容室より単価は上がりやすい。
一人ひとりにかける時間も、長くなりやすい。

最初から最後まで、丁寧に向き合う接客になる。
```

- 「どの店も特化すれば同じ」ではない。特化しているから、この向き合い方になる、という説明にする。
- ここで長く解説しすぎない。0806の「リードは短く、本題へ渡す」は維持する。足りないのは対比ではなく、**業態の前提**である。

### 2. 丁寧接客 → ヒアリング力 → 人生経験、の順でつなぐ

特化サロンの説明のあとに、強みの理由を置く。

**推奨の因果：**

```
高い単価で、一人に時間をかけて接する
　↓
大事になるのは、技術よりヒアリング力
　↓
ヒアリングで効くのは、人生経験と共感力
　（自分の体験に重ねる／会ってきた人の話から相手の立場に立てる）
　↓
だから、エイジングケア特化では人生経験と共感力が強みになる
```

- 最初のうち、難しい技術は先輩に任せられる、と添えてよい。ブランク・未経験の不安をここで軽く受けられる。
- 「一人のお客さまに最初から最後まで丁寧に向き合える」は、「年齢を重ねても無理なく働き続けられる理由」の中にも入れてよい。丁寧に向き合う場面で、人生経験と共感力が強みになる、と接続する。

### 3. ヒアリングの先に、悩み別のメニュー提案を置く

「これから何が似合うんだろう」「無理に若く見せたいわけではない。今の自分を素敵に見せたい」といった声を引き出したあと、**その悩みに何を出すか**まで書く。

あるあるでよい。人によって提案が変わる、と見せる。

```
このタイプの方には、このメニューを提案する
あのタイプの方には、このメニューを提案する

人によって出す内容はかなり変わる。
分かっているからこそ、その方に合った提案ができる。
```

- 「理解できるから、その方に合った提案ができる」は、このブロックに含めてよい。
- 提案ができる → 分かってもらえていると感じる → 信頼 → リピート、まで1本でつなぐ。
- ここで人生経験が価値になる、と回収する。サービス説明で終わらせない。

### 4. 「特化ならどこでも」の注意のあと、当店の環境へ渡す

特化サロンで人生経験があっても、どの店でも楽しく働けるわけではない、と一度切る。

**他店に起きやすいこと（短く）：**

```
・売上の競争が過酷
・強い売り込みをしないとならない
・未経験スタートだと、なかなか教えてもらえない
・短時間勤務で働けない
```

その直後に、当店側へ橋を渡す。

```
当店は、未経験の方でも、経験を積んだ方でも、
無理なく活躍できる環境を整えている。
```

- 0806の「注意書きは簡潔に、詳細は次セクション」は維持する。今回足すのは、**注意の直後に当店へ渡す一文**である。
- 0727の「特化一般ではなく当店の理由」と役割分担する。ここは警告と橋、次は当店固有の根拠。

### 5. 歩合・教育への関心は、配置を検証する

ターゲットは、美容業界をよく知る層で、歩合や「ちゃんと教えてくれるか」を強く意識していることが多い。

- その関心が強いなら、骨格の前の方に出してもよい。
- 「これがあるから、これなのか」と読める位置かを見る。教育（ちゃんと教えてくれる）も同じ。
- 今の並びがしっくり来ていなければ、ここも組み替える対象にする。

### 6. 骨格は決めつけず、見出しごと組み替える

ストーリーボードはアイデア出しの場である。順番を変える、幹を変える、はよくやる。

壁打ち用の確認：

```
今の骨格の先頭は「特化サロンとは何か」になっているか。
その次が「ヒアリング → 人生経験・共感力」になっているか。
注意書きのあと、当店の環境に渡っているか。
歩合・教育を前に出した方がよいか、今の位置でよいか。
```

- 「これでいく」と早めに固定しない。こっちの方がいい／こっちではない、を何度も試す。
- 今回Loomで伝えた内容をChatworkに投げて、壁打ちしながら落とし込む。

---

## ■改善理由（Why）

- 読み手が特化サロンの映像を持っていないと、「人生経験が強み」はラベルのまま終わる。業態 → 向き合い方 → ヒアリング → 経験、の順の方が、0806で求めた中見出しの因果が通る。
- 高単価を「稼げる／楽」として出すと0727の抵抗が再発する。単価は、時間をかけて聞く必然性の説明にだけ使う。
- 悩みを聞くだけで止めると、仕事の映像が「話を聞く人」で終わる。メニュー提案まで出すと、経験が成果（信頼・リピート）に変わる。
- 注意書きだけで止めると、「ではどこで働けばいいのか」が残る。当店の環境へ渡して、0727の「当店だから続く」と接続する。
- 骨格を早めに固定すると、より伝わる順番を試せない。いい線に乗っている今だからこそ、組み替えた方が伸びる。

---

## ■改善後イメージ（After）

- 先頭で、特化サロンが誰に何をしている店かが短く見える。
- そのあと、丁寧接客 → ヒアリング力 → 人生経験・共感力、と中見出しだけで理由が追える。
- 悩み別のメニュー提案があり、「分かるから提案できる → 信頼 → リピート」までつながっている。
- 「特化ならどこでも、ではない」の注意のあと、当店の環境へ自然に渡っている。
- 歩合・教育への関心が、ターゲットの読み順に合った位置にある。
- 「これで完成」ではなく、骨格を動かしながら最適な並びに落ちている。

---

## ■やりがちなミス

- 「人生経験が強み」から書き始め、特化サロンの説明を後回しにする。
- 高単価を、無理なく働ける理由として出してしまう（0727の再発）。
- ヒアリングの話で止め、悩み別の提案メニューを書かない。
- 「特化ならどこでも、ではない」で終わり、当店の環境へ渡さない。
- 難しい技術は先輩に任せられる、を省いて、未経験・ブランクの不安が残る。
- 骨格が一度通ると「これでいく」と固定し、順番の検証をやめる。
- 0806の中見出し因果を捨てて、説明文の長文化に戻す。

---

## ■他の案件でも使えるパターン

- **結論の前に業態の映像を置く。** 「なぜ強みか」は、店が何をしているかを見たあとで初めて通じる。
- **単価・時間は、働きやすさの証拠ではなく、接客の必然性の証拠として使う。**
- **聞く → 提案する → 信頼・リピート**まで1本つなぐ。聞くだけで終わらせない。
- **一般論の注意の直後に、自社の環境へ橋を渡す。** 注意だけで終わらせない。
- **骨格は仮説。** いい線でも固定せず、順番と幹を壁打ちで組み替える。

- **0806**：人生経験・共感力ブロックは中見出しの骨格を先に、因果でつなぐ。**今回**はその骨格の先頭に、特化サロンの説明という土台を足す。
