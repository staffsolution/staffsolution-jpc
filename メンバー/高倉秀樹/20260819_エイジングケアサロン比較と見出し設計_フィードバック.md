## ■現状（Before）

- 前回フィードバックをAIに読み込ませ、具体例を出しながら説明させる進め方に変わっている。作業効率が上がり、読み手の頭に映像が浮かぶ内容を作ろうとしている点はよい。
- 「エイジングケア特化サロンとは何か」から「聞くことが大切な仕事」へ進む骨格も、0815で整理した方向に沿っている。
- ただし、一般的な美容室と何が根本的に違うのかを示す前に「聞くことが大切」へ進むため、1番から2番へ少し飛んで見える。
- 「自分の髪の悩みを理解してもらい、これからどうすればよいか一緒に考えてほしい」は、まだ願望が抽象的で、40代以降のお客様が最終的にどうなりたいのかが見えにくい。
- 「5つの理由」の最初に「掛け持ちせず、一人のお客様に集中できる」を置くと、10年以上のブランクがある人には「いきなり一人で担当できるだろうか」という不安を先に起こす可能性がある。
- 1日6時間・週3日から、3ヶ月でデビューなどの具体的な数字は条件面にあるが、見出しの説得材料としてはまだ十分に使えていない。

---

## ■問題の本質（重要）

- 比較で伝えるべきなのは「一般的な美容室でも話は聞く／特化サロンも話を聞く」という行動の差ではない。お客様が求める未来、提案するサービス、仕事で優先することの違いである。
- 「聞くことが大切」は結論。その前に、お客様の悩みと願望が一般的な美容室とはどう違い、その願望をかなえるにはなぜ深く聞く必要があるのかをつなぐ。
- ブランク層に働き方の魅力を伝えるときは、「魅力的な仕事」より先に「今の自分でも始められる」を証明する。安心して始める道筋を見せたあとなら、一人のお客様に集中できることが魅力として働く。
- 数字は条件の補足ではなく、約束を信じてもらう証拠になる。見出しだけを読んでも、どの程度から始められ、いつ頃デビューを目指せるのかが分かる状態にする。

## ■ズレ（思考 or 設計）

| やりたいこと | 今のズレ | 読み手に起きること |
|---|---|---|
| 特化サロンの違いを伝える | 「聞く」を差にしている | 「一般的な美容室でも聞いていた」と感じる |
| 人生経験が強みになる理由を伝える | お客様の願望から聞く必然性への橋が短い | 1番から2番へ話が飛んで見える |
| 一人に集中できる魅力を伝える | ブランク層への安心より先に置く | 「最初から一人で任されるのか」と不安になる |
| 働きやすさを伝える | 数字を条件欄にとどめる | 約束の具体性と説得力が弱い |

---

## ■改善内容（What）

### 1. 「聞くかどうか」ではなく、お客様の目的から比較する

一般的な美容室でも、お客様の話は聞く。「こちらだけが聞く」と書くと反論されやすいので、このLPでは次の比較軸を使う。

| 比較軸 | 一般的な美容室で前面に出やすいこと | エイジングケア特化で前面に出すこと |
|---|---|---|
| お客様の悩み | 今日の髪型、色、長さ、流行 | 白髪、うねり、ボリュームなど年齢による変化 |
| 望む未来 | 希望するスタイルに仕上げたい | 毎日の手入れを楽にし、自分らしくきれいな髪を保ちたい |
| 必要な提案 | 希望する施術やスタイルを形にする | 悩み・生活・この先の希望まで聞き、続けられるケアを一緒に考える |
| 仕事の重点 | 技術や仕上がりを分かりやすく見せる | ヒアリングから、その人に合う提案へつなぐ |

「一般的な美容室は何も聞かない」と否定するのではなく、エイジングケア特化では、聞く内容と提案の時間軸が違うと見せる。

### 2. 特化サロンの説明から人生経験までを一本につなぐ

推奨の骨格は次の順。

```
エイジングケア特化サロンとは何か
　↓
来店するお客様の悩みは何か
　↓
お客様は最終的にどうなりたいのか
　↓
その未来には、悩みと生活を深く聞く必要がある
　↓
聞いた内容に合わせて提案する必要がある
　↓
だから、人生経験と共感力が強みになる
```

0815で足した「特化サロンとは何か」を、今回は一般的な美容室との比較で具体化する。0806で整理した「中見出しだけで因果が通る」状態まで落とす。

### 3. お客様の願望を、毎日の生活が見える言葉へ変える

今の「悩みを理解してもらい、これからを一緒に考えてほしい」は、途中の欲求である。その先にある願望まで書く。

```
白髪やうねり、ボリュームの変化を理解してほしい。
そのうえで、毎日の手入れがしやすく、
無理に若く見せるのではなく、
今の自分に似合うきれいな髪を、この先も保っていきたい。
```

「理解してほしい」だけで止めず、「毎朝どうなりたいか」「これから何を保ちたいか」まで出す。願望が具体になると、なぜ時間をかけて聞く必要があるのかも自然につながる。

### 4. 「5つの理由」は、ブランク層の不安が消える順へ並べる

見出しの順番は、お店が伝えたい順ではなく、10年以上のブランクがある人の頭に浮かぶ問いの順にする。

| 読み手の問い | 先に答える内容 |
|---|---|
| 今の生活でも始められるか | 1日6時間・週3日から始められる |
| 技術を戻せるか | 勤務時間内の研修とデビューまでの目安 |
| いきなり一人で任されないか | 慣れるまでは先輩のサポートがあること |
| 慣れたあとはどう働けるか | 掛け持ちせず、一人のお客様に集中できる |
| 頑張りはどう給与へ反映されるか | 給与・歩合の仕組みを、事実に沿って説明する |

現在の「掛け持ちせず、一人のお客様に集中できる」は消さない。最初に置かず、安心してスタートできる説明のあとへ移す。

先輩のサポートや歩合の内容は、実際の制度を確認してから書く。「最初はどう始まり、慣れたらどう変わるか」が見える時系列にする。

### 5. 条件の数字を見出しへ入れ、安心の根拠にする

数字は本文に埋めず、見出しを流し読みした人にも見える位置へ出す。

見出し案：

```
1日6時間・週3日から。
ブランク明けは、無理のない日数で始められます

勤務時間内の研修で、
3ヶ月デビューを目指せます

慣れるまでは先輩がサポート。
いきなり一人で任せません

慣れてからは掛け持ちなし。
一人のお客様に集中できます
```

- 「3ヶ月」は、全員に当てはまる確約なのか、目安なのかを確認して表現を決める。
- 数字と一緒に「だから何が安心か」を書く。数字だけの条件一覧にはしない。
- 見出しを並べたときに、開始 → 研修 → デビュー → その後の働き方、の時間順になっているか確認する。

### 6. AIには前回フィードバックを渡し、「反論されない比較」を作らせる

前回フィードバックを読み込ませてから壁打ちする進め方は、そのまま続けてよい。今回は、一般論の文章をそのまま採用せず、次の問いで比較の弱さを潰す。

```
この比較を読んだ美容師が、
「それは一般的な美容室でもやっていた」と
反論しそうな箇所を挙げてください。

行動の違いではなく、
お客様の悩み、最終的な願望、
提案するサービス、働き方の違いに直してください。

そのあと、中見出しだけで因果が通る順に並べてください。
```

AIの全文を先に作るより、比較軸 → 見出しの順 → 本文の順に確認する。今回はこの進め方の方が、骨格の飛びを早く見つけられる。

## ■改善理由（Why）

- 一般的な美容室でも「話を聞く」は行われるため、聞く行為だけでは差別化にならない。お客様が求める未来と提案の時間軸まで比較すると、特化の意味が立つ。
- お客様の願望が「毎日の手入れ」「今の自分らしさ」「この先も保ちたい髪」まで具体になると、ヒアリングが単なる丁寧さではなく、サービスに必要な工程として読める。
- 0815では「特化サロンとは何か」を先に置いた。今回はその説明を、一般的な美容室との違い → お客様の願望 → 聞く必然性まで深める段階である。
- ブランク層は、魅力より先に失敗のリスクを見る。週3日・1日6時間、研修、サポートを先に置くことで、「一人に集中できる」が怖さではなく未来の働き方になる。
- 数字を見出しに出すと、「無理なく始められる」が形容ではなく事実で支えられる。
- 前回フィードバックをAIへ渡す方法は効率がよい。ただし、AIが出す整った一般論に対して「一般店でも同じでは？」と反論をぶつける工程が必要である。

## ■改善後イメージ（After）

- 一般的な美容室と特化サロンの違いが、お客様の悩み・願望・提案・働き方の4軸で見える。
- 「特化サロンとは何か」から「なぜ聞くことが大切か」「なぜ人生経験が強みか」まで、見出しだけで因果を追える。
- 40代以降のお客様が望む未来が、毎日の手入れや自分らしい髪の場面として浮かぶ。
- 10年以上のブランクがある求職者が、開始条件 → 研修 → サポート → デビュー後の働き方の順で読み、「これなら始められそう」と判断できる。
- 1日6時間・週3日、3ヶ月などの数字が見出しに入り、「無理なく」という約束を証明している。
- 「掛け持ちなし」は最初の負担ではなく、慣れたあとに得られる魅力として読める。

---

## ■やりがちなミス

- 「一般的な美容室は話を聞かない」と言い切り、実務経験のある読み手から反論される。
- 「聞くことが大切」とだけ書き、お客様の願望や提案内容との因果を省く。
- 一般店と特化店の両方に当てはまる「丁寧」「寄り添う」だけで比較する。
- ブランク層への安心を出す前に、マンツーマンや掛け持ちなしを置き、責任の重さを想像させる。
- 1日6時間・週3日などの数字を条件欄だけに置き、見出しを抽象語のままにする。
- 「3ヶ月デビュー」を全員への確約のように書き、実際の制度や個人差とずらす。
- AIが作った一般的な比較文を、現場で本当に違うか検証せずに採用する。

---

## ■他の案件でも使えるパターン

- 比較は「する／しない」ではなく、顧客の悩み → 望む未来 → 必要なサービス → 働き方の順で作る。
- 結論が「聞くことが大切」なら、その前に「なぜ聞かなければ望む結果を作れないか」を置く。
- 求職者向けの理由は、始められるか → 学べるか → 任せ方はどうか → 慣れたあとの魅力、の順に並べる。
- 抽象的な願望は、朝の手入れ、仕事中の動き、帰宅後の疲れなど、毎日の場面へ変換する。
- 数字は条件欄だけでなく、約束を証明する見出しへ入れる。
- AIには答えを作らせるだけでなく、「経験者ならどう反論するか」を出させて比較の穴を探す。
