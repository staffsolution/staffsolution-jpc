## ■分類（タグ）

- LP・ストーリーボード
- 1008の続き（語りかけ・見出し）
- 年齢が近いからこその共感訴求
- 見出しだけで思い込みを外す（若さだけでなく）
- 対比の軸を合わせる（技術・評価 vs 理解）
- 「汲み取る」など難しい表現の言い換え
- 聞く内容を具体シーンまで落とす
- ボリューム削減（具体は残す）
- 0825・0918・1008の続き

---

## ■現状（Before）

- 1008で指示した「お客様と求職者の年齢が近いからこそ、あなたもこうではないですか」系の語りかけが入っている。方向はよい。
- 人生経験と共感力を見出しで分け、リードを長くしない意識も乗っている。
- 「人数やスピードを求められる働き方ではなく、一人一人に丁寧に向き合いたい」という、2ターゲット共通のコンビネーション表現も反映されている。
- 一方で、見出しだけだと「若返りイメージとの差」が弱い箇所がある。リードを読めば分かるが、読まない人もいる。
- 「汲み取る」など、全員が一瞬で分かるとは限らない表現が残っている。
- 「スピードや人数をこなす力より、これまでの人生経験がお客様を理解する力」は、対比の軸がずれている。速さ・人数と「理解する力」は、そのまま並べると噛み合わない。
- 「イメージするかもしれません」のあとに「でも」がなく、流れがぎこちない箇所がある。
- 「丁寧に聞く」だけでは他店との差が出にくい。何を、どの視点で聞くのかが足りない。
- 後半の「ただし〜無理なく長く」ブロックは、言い回しが長く、仕組みの説明も複雑になっている。
- AI壁打ちで具体シーンは良くなった。残す価値はあるが、全体ボリュームはまだ多い。

---

## ■問題の本質（重要）

- 1008で「語りかけ」「見出しでスピードよりこっち」を入れた。今回はその先で、**見出しだけで思い込みを外す**ことと、**対比の軸を正しく揃える**ことが本題である。
- エイジングケア＝若返り、という先入観はリードに書くだけでは足りない。見出しを読んだだけで「若さだけではない」と分かる状態にする。
- 対比は「速さ・人数 vs 人生経験」ではなく、**一般サロンが評価しがちな軸（速さ・人数・技術の見せ方）と、当店が評価する軸（お客様を理解する力）**を並べる。軸が揃わないと、読み手は「で、どっちが良いの？」で止まる。
- 「丁寧に聞く」は業界の決まり文句になりやすい。差は、**聞く内容の具体**と、**わかってくれる → 信頼 → 選ばれる**の因果が一文でつながることである。
- 具体シーンは残す。削るのは、同じ意味の繰り返しと、長い前置きである。

---

## ■ズレ（思考 or 設計）

| 意図 | 結果 |
|---|---|
| 若返りイメージとの差を伝えたい | 差がリード側に寄り、見出しだけでは弱い |
| 人生経験が強みだと対比したい | 「速さ・人数 vs 理解」になり、対比が噛み合わない |
| 丁寧に聞くと伝えたい | 他店も言う内容に見え、差が出ない |
| 「汲み取る」で共感を出したい | 難しい・読めない人が出る表現になる |
| 無理なく長く働ける流れへつなぎたい | 「ただし」以降が長く、仕組み説明が複雑 |
| 具体を足したい | 具体は良いが、全体が重くなる |

- 1008は「語りかけを入れる」段階だった。今回は、入れた語りかけを**見出し・対比・具体**まで磨き、ボリュームを整える段階である。

## ■改善内容（What）

### 0. 方向はそのまま、磨きどころを絞る

次は変えない。

- 一般イメージから先に入る流れ（0918）
- 「自分らしい綺麗さを一緒に作る」幹（0825）
- 「あなたもそうですよね」の語りかけ（1008）
- ファーストビューの2約束（大人女性に選ばれる／無理なく長く）
- AI壁打ちで出てきた、シーンが浮かぶ具体描写（削りすぎない）

直すのは、見出しでの思い込み外し、対比の軸、難しい言葉、聞く内容の具体、「ただし」以降の簡潔化、全体ボリュームである。

### 1. ターゲットはピンポイントのまま広げるな

「30代後半くらい」まで広げるとぼやける。共感した人が応募する設計なので、広げすぎない。

```
メインターゲット：40代以降（同世代の大人女性・同年代の美容師）
　↓
広げすぎない（ぼやける）
　↓
共感した人だけが次を読む
```

### 2. 見出しだけで「若さだけではない」が分かるようにする

リードを読まない人もいる前提で、最初の見出しに差を入れる。

| 弱い（リード頼み） | 見出しで補う方向 |
|---|---|
| 当店のエイジングケアは、自分らしい綺麗さを一緒に作る美容です | 当店のエイジングケアは、若さだけでなく、自分らしい綺麗さを一緒に作る美容です |

「若返り・若々しく保つ」という思い込みを、見出し側でも外す。

### 3. リードの流れを自然にする

「イメージするかもしれません」のあとは、「でも」でつなぐ。

```
エイジングケアと聞くと、
白髪染めや髪・頭皮のケアで若さを保つこと、
と思い込む方が多いと思います。

もちろん、それもやります。
でも、それだけではありません。

それ以上に、自分らしい綺麗さを求めている。
あなたも、そうですよね。
```

思い込みの言葉は、読み手が使う言葉にする（マイナス5歳・若返りたい、など）。

### 4. 「自分らしい綺麗さ」の具体は、髪型が浮かぶ描写に

抽象のままの「変えたいこともあれば残したいことも」だけでは弱い。経験が無い人でも「そういうことか」と分かる描写にする。

| 弱い | 強くする方向 |
|---|---|
| 自然な髪色も楽しみたい | 白髪を活かす／自然な色味でどう見せたいか、が浮かぶ一文 |
| うねりを抑えたいけどトップのボリュームは残したい | その髪型の見た目が浮かぶ描写 |
| あるあるを3つ並べる | 強いあるあるを2つに絞る（多すぎるとぼやける） |

### 5. 「汲み取る」など難しい表現を言い換える

誰もが一瞬で分かる言葉にする。

| いま | 言い換えの方向 |
|---|---|
| 気持ちを汲み取る | 話を聞く／気持ちを理解する／一緒に考える |
| 組み取る（読みにくい表記） | 使わない |

### 6. 「わかってくれる → 信頼 → 選ばれる」を一文の因果にする

「選ばれるようになるからです」だけでは弱い。流れを明示する。

```
私のことをわかってくれる
　↓
信頼される
　↓
選ばれる
```

見出し側でも、この因果が一目で分かる形にする。

### 7. 対比の軸を合わせる（速さ・人数をそのまま人生経験と並べない）

「スピードや人数をこなす力より、これまでの人生経験がお客様を理解する」は対比が噛み合わない。

| 噛み合わない対比 | 揃える対比 |
|---|---|
| 速さ・人数 vs 理解する力 | 一般サロンが評価しがちな軸 vs 当店が評価する軸 |
| 速さ vs 人生経験（そのまま） | 速さ・人数だけで価値が決まる世界観 vs 理解して提案する力にも価値がある世界観 |

本文で置くなら、次の順が分かりやすい。

```
① 一般的な美容室：速さ・人数で売上・評価が決まりやすい
　↓
② 当店：それだけでは評価しない
　↓
③ お客様を理解できる力が評価される
　↓
④ だから技術の速さ不安があっても、姿勢と理解力で選ばれる／活躍できる
　↓
⑤ （必要なら）未経験・長いブランクでも活躍の道がある
```

注意：技術がいらない、と言わない。伝えたいのは「速さ・タントリズムだけで価値が決まらない」ことである。

もう一つの注意：

```
お客様から選ばれること
と
店がスタッフを評価すること
は別軸
```

混ぜて書かない。

### 8. 「丁寧に聞く」を、聞く内容の具体まで落とす

他店も「丁寧に聞きます」と言う。差は中身である。

```
他店も言いがちな「丁寧に聞く」
　↓
当店：あらゆる視点からヒアリングする
　↓
具体的に何を聞くか（例を出す）
　↓
その積み重ねが「この人ならわかってくれる」につながる
```

2番と3番の見出しが同じことを言っているなら、まとめてよい。

### 9. 5番（年代が近い）は投げかけにする

説明口調より、確認の投げかけの方が自分ごとになる。

```
もしあなたが40代以降なら、
これまでの話に共感しているのではないでしょうか。
```

### 10. 「ただし」以降は短くする

長い言い回しと、仕組みの列挙を削る。

```
ただし、エイジングケア特化サロンだからといって、
10年以上のブランクがある方が、無理なく働けるわけではありません。

当店では、あなたの強みを活かして働けるように、
会社の仕組みを整えています。

では、具体的にどのような環境なのか。
次にご紹介します。
```

「働き方・教育・接客・売上の作り方まで」と全部並べると重い。次セクションへの橋渡しだけにする。

### 11. ボリューム：具体は残し、繰り返しを削る

AI壁打ち後の具体シーンはイメージしやすいので維持する。削るのは次である。

| 残す | 削る |
|---|---|
| 髪型・施術の場面が浮かぶ具体 | 同じ結論の言い換え |
| 対比の幹（一般サロン vs 当店の評価軸） | 対比に効かない前置き |
| 語りかけ（あなたもそうですよね） | 長いリード・長い列挙 |

### 12. 推奨の並び（1008骨格＋今回の磨き）

```
① エイジングケア＝若返り、と思い込んでいる（見出しでも外す）
　↓
② もちろんそれもやる。でもそれだけではない
　↓
③ 自分らしい綺麗さ。あなたもそうですよね
　↓
④ 自分らしい綺麗さの具体（あるある2つ・髪型が浮かぶ）
　↓
⑤ だから一人一人の話を聞き、一緒に考える（易しい言葉）
　↓
⑥ 何を聞くか具体 → わかってくれる → 信頼 → 選ばれる
　↓
⑦ 一般サロンの評価軸 vs 当店の評価軸（対比を揃える）
　↓
⑧ 40代以降なら共感しているのでは（投げかけ）
　↓
⑨ ただし特化だけでは無理なく働けるわけではない → 仕組みは次で
```

## ■改善理由（Why）

- リードは読まれない前提がある。思い込み外しは見出し側にも置く必要がある。
- 対比は、並べる言葉の種類が揃っていないと説得力が出ない。速さ・人数と「理解」をそのまま対にするより、評価の世界観で揃える。
- 「丁寧に聞く」は差別化にならない。聞く内容の具体が、わかってくれる実感を生む。
- 難しい言葉は、共感の前に離脱を生む。同世代への語りかけとセットで、言葉も易しくする。
- 具体シーンは、抽象の「自分らしい綺麗さ」を映像に変える。削るなら繰り返しから。

---

## ■改善後イメージ（After）

- 見出しだけ読んでも、「若さだけでなく、自分らしい綺麗さ」が分かる。
- 「イメージするかもしれません → でも → あなたもそうですよね」の流れが自然。
- 自分らしい綺麗さの具体が、髪型の映像として浮かぶ。
- 「汲み取る」などの難しい表現がなく、誰でも読める。
- わかってくれる → 信頼 → 選ばれる、の因果が見出しと本文で通る。
- 一般サロンの評価軸と当店の評価軸が対比として噛み合う。
- 「ただし」以降が短く、次の環境セクションへ自然につながる。
- 具体シーンは残りつつ、全体はスピーディーに読める。

---

## ■やりがちなミス

- 思い込み外しをリードだけに置き、見出しが結論だけになる
- 「速さ・人数 vs 人生経験」のように、軸の違うものを対比にする
- 「丁寧に聞く」で止め、何を聞くかを書かない
- 「汲み取る」など、一見きれいに見えるが伝わりにくい言葉を残す
- 技術不要、と読める書き方にする（速さだけで価値が決まらない、が本意）
- お客様に選ばれる話と、店がスタッフを評価する話を混ぜる
- ターゲットを広げて共感を薄める
- 具体を全部残そうとして、繰り返しまで残す
- 「ただし」以降で仕組みを全部説明し、次セクションの役割を奪う

```

　↓

```

```
　↓

```

```
シーンが浮かぶ具体 → 残す
同じ結論の言い換え → 削る

```

## ■1008・0918・0825との関係

- **0825**：幹を「自分らしい綺麗さ」に一本化。
- **0918**：幹の前に、エイジングケア＝老化対策・若返りの先入観を置く。
- **1008**：ストレートな言葉と「あなたもそうですよね」、見出しでスピードより傾聴。
- **今回**：語りかけが入った前提で、見出しでの思い込み外し・対比軸の揃え・聞く内容の具体・易しい言葉・ボリューム調整まで磨く。方向転換ではなく、伝わり方の精度上げである。
