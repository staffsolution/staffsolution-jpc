## ■分類（タグ）

- ピンク塗りつぶしブロック（専門家・書籍からの学び〜ヘッドスパ説明）
- 「頭皮ケア→育毛」の**なぜ**が抜けている
- 日常シャンプーでは足りない理由 → 美容室での解決策
- クリニック／専門店との差（重い症状 vs 軽い症状）
- 「他店もやっている」は証拠にならない（資格・合法で示す）
- 施術フロー：頭皮チェック → セラピスト作業 → 美容師同席のなぜ
- 専門用語の平易化（ローション／揉み出しクレンジング）
- お客様の話を聞く／自宅ケアを伝える、を分ける
- デビューまでの流れ（未経験／経験済みで分岐）
- 1001・0914・0830・0330の続き（意図ではなく結果）

---

## ■現状（Before）

- 1001では育毛提案設計（望み・時系列・専門店差・結果・求人）を直す段階だった。今回は、その周辺にある**ピンク塗りつぶしのブロック**（専門家や書籍から学んだあと〜ヘッドスパ説明）を見ている。
- 「専門家や書籍から学ぶと、頭皮のケアは美容室でできるケアだった」までは書けているが、**それがなぜなのか**が抜けている。
- 大半の読み手は、「頭皮ケアが育毛につながる」こと自体を知らない。薬を買う／毎日シャンプーしているから大丈夫、と思っている層が残る。
- 対象層の説明は上の箱ですでに書いているのに、**同じ情報をまた載せている**箇所がある。
- 「比較不要で対応できる理由」で、**育毛専門店でもやっている**系の書き方が出ている。これは証拠として弱い（他店がやっている＝正しい、は通用しない）。
- 施術の流れで、頭皮チェックのあと「美容師と一緒に」が突然出て、**セラピストが何をするのか／なぜ美容師が同席するのか**が弱い。
- 「105のローション」「揉み出しクレンジング」など、未経験には意味が取れない用語が残っている。ローションを使う理由、シャンプーとの違いも書かれていない。
- 「お客様の話を聞き、自宅ケアの大切さを伝える」が**1つに固まっている**。聞くことと伝えることは別の作業。
- 「経験に合わせて理論・実技・実践」が、別箱と重複しやすく、「経験に合わせて」だけでは未経験／経験済みの流れが分からない。

---

## ■問題の本質（重要）

- この箱の役割は「学んだことの列挙」ではない。**読み手が持っている思い込み（毎日シャンプーしていれば大丈夫）→ なぜそれでは足りないか → だから美容室の頭皮ケアが解決策になる → クリニック向き／美容室向きの線引き → 施術で何をするか（なぜその手順か）→ 覚える流れ**、を一本で追えるようにすること。
- 「頭皮ケアは美容室でもできる」は結論。先に必要なのは、**なぜ頭皮ケアをすると育毛につながるのか**。ここが無いと、結論だけが浮く。
- 比較の証拠は「他店もやっている」ではない。**資格があるから合法にできる／資格が要らない作業はセラピストができる**、という線で示す。
- 用語は店側には当たり前でも、求職者・未経験には初めて。**意図（正確に書きたい）ではなく結果（小学5〜6年生が追えるか）**で見る（0330）。
- 見るのは「直したつもり」ではなく、**このピンク箱だけ読んで「なぜ美容室で頭皮ケアするのか」が通るか**。

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| 頭皮ケアは美容室でもできる、と伝えたい | 「なぜ育毛につながるのか」が無く、結論だけが残る |
| 対象をはっきりさせたい | 上の箱と重複し、同じ話が続く |
| 専門店・クリニックとの差を出したい | 「他店もやっている」になり、証拠として弱い |
| 施術の流れを示したい | 頭皮チェックのあと美容師同席が突然で、セラピスト作業の塊が見えない |
| ローションやクレンジングを正確に書きたい | 番号付き専門語・業界語のまま、なぜ・シャンプー差分が無い |
| カウンセリングの大切さを伝えたい | 「聞く」と「自宅ケアを伝える」が1文に混ざる |
| 学び方を示したい | 「経験に合わせて」で止まり、未経験／経験済みの分岐が無い |

- 「上に書いたから大丈夫」「用語は業界では普通」は、**いま読んでいる箱の結果**には反映されない（0330と同型）。

## ■改善内容（What）

### 0. 進め方

```
【維持】
・専門家／書籍から学んだ、という入口
・頭皮ケアが育毛に効く層への美容室提案（1001の方向）
・上の箱ですでに書いた対象の説明は、ここでは繰り返さない

【直す（今回の本題）】
・なぜ頭皮ケア→育毛なのか、を先に置く
・毎日シャンプーでも足りない理由 → 美容室でできる解決策
・クリニック向き／美容室向き（重い症状 vs 軽い症状）
・「他店も」ではなく、資格・合法で示す
・施術フローをセラピスト作業の塊＋美容師同席のなぜ、に直す
・ローション／揉み出しクレンジングを平易化し、なぜ・シャンプー差分を書く
・「聞く」と「自宅ケアを伝える」を分ける
・デビューまでの流れを、未経験／経験済みで分岐する
```

### 1. 「なぜ頭皮ケア→育毛か」を先に書く

読み手の思い込みを先に置き、橋を渡す。

```
① 多くの人は「毎日シャンプーしている／薬を買えば大丈夫」と思っている
② でも、ちゃんと流せていない汚れ・乾燥が、髪が生える土台に悪影響を与える
③ だから、頭皮のケアをすると育毛につながる
④ そのケアは、いつも通う美容室でもできる
```

「専門家や書籍から学んだ → 美容室でもできる」のあいだに、②〜③を必ず入れる。結論だけを置かない。

### 2. 上の箱と重複する対象説明は削る

対象層・悩みの説明は、すでに上で話しているなら**同じ情報を載せない**。  
この箱では「なぜ頭皮か／なぜ美容室か／施術で何をするか」に集中する。

### 3. クリニック／専門店との差は「症状の重さ」で線引きする

| 向き | 書き方のイメージ |
|---|---|
| クリニック向き | 重い症状。専門治療が必要な層 |
| 美容室向き | 軽い症状。わざわざクリニックへ行く必要はない層 |

クリニック側が「そこまでやらない」事実があれば、差がより立つ。  
1001の「誰向きか」と同じ軸で、ここでは**症状の重さ**を明示する。

### 4. 「他店もやっている」は証拠にしない

```
【弱い】
育毛専門店でもやっている → だから大丈夫

【強い】
美容師資格が必要な行為／不要な行為を分ける
　↓
資格が要ることは美容師が担う
　↓
資格が要らない頭皮ケアはセラピストができる（違法ではない）
```

「他のお店がやっているから」は、違法・不適切な真似にも見える。  
**なぜ自店で合法にできるのか**を書く。

### 5. 施術フローを「作業の塊」にする

推奨の並び：

```
① 頭皮をチェックする
② セラピストがケアする（ローション・汚れを浮かす、など）
③ 口頭で説明する（状態・自宅ケア）
④ 必要なら美容師と共有する（なぜ共有するかも書く）
```

「美容師と一緒に対応」だけ先に置かない。  
**セラピストが行う作業として並べたあと**、「なぜ美容師が同席／共有するのか」を足す。

### 6. 用語を平易化し、「なぜ」と「シャンプー差分」を書く

| いま | 直し方 |
|---|---|
| 105のローション | 「ローション」だけにする。**なぜローションを使うか**を一文足す |
| 揉み出しクレンジング | 「何を揉み出すのか／何をクレンジングするのか」を分解する |
| （差分なし） | 指の腹で汚れを浮かす、が**普通のシャンプーと何が違うか**を書く |

未経験の求職者が「シャンプーと何が違うの？」と止まる前提で書く。

### 7. 「聞く」と「自宅ケアを伝える」を分ける

| 作業 | なぜ必要か | そのあと |
|---|---|---|
| お客様の話を聞く（質問する） | 信頼関係を築くため | 状態に合った説明ができる |
| 自宅ケアの大切さを伝える | 自宅ケアを軽く見ている人が多いから | 「どうやるの？」と聞かれたら使い方を教える |

1文に混ぜない。**聞く → なぜ自宅ケアが必要か → 具体的な使い方**、の順にする。

### 8. デビューまでの流れを、未経験／経験済みで分岐する

大項目は「デビューするまでの流れ」にする。

```
【ヘッドスパ未経験の方】
この順で覚える（理論→実技→実践、など店の実態に合わせる）

【ヘッドスパ経験済みの方】
この順で覚える（別ルート）
```

「経験に合わせて」の一言でまとめない。  
理論・実技・実践が**別箱にすでに入っている**なら、ここでは重複させず、分岐の見出しだけにする。

---

## ■改善理由（Why）

- 「なぜ頭皮ケア→育毛か」が入ると、美容室提案が**結論の押しつけ**ではなく、思い込みを崩したあとの答えになる。
- 上の箱との重複を削ると、この箱の役割（なぜ・施術・習得）がはっきりする。
- 症状の重さで線引きすると、1001の「誰向きか」が施術説明側でも同じ軸で読める。
- 「他店も」をやめると、求職者・お客様の両方に**合法で安全な根拠**が残る。
- セラピスト作業を塊にすると、「誰が何をするか」が一目で分かる。美容師同席のなぜも後から足せる。
- 用語を平易化すると、未経験求職者が止まらなくなる（0830と同型）。
- 「聞く」と「伝える」を分けると、関係構築と自宅ケア教育の両方が立つ。
- 未経験／経験済みで分岐すると、「経験に合わせて」の曖昧さが消え、デビューまでの道筋が見える。

---

## ■改善後イメージ（After）

- ピンク箱だけ読んで、「毎日シャンプーしていれば大丈夫」→「汚れ・乾燥が土台を壊す」→「だから頭皮ケア」→「美容室でもできる」、が通る。
- 対象の説明が上と重複していない。
- クリニック向き／美容室向きが、症状の重さで一言で分かる。
- 「他店もやっている」ではなく、資格・合法の説明になっている。
- 頭皮チェック → セラピストのケア作業 → 説明 → 美容師共有（なぜ）、の順で読める。
- ローション・汚れを浮かす作業が、普通のシャンプーとの差つきで理解できる。
- 「聞く」と「自宅ケアを伝える」が別行で、それぞれのなぜがある。
- デビューまでの流れが、未経験／経験済みで分かれている。

## ■やりがちなミス

- 「美容室でもできる」だけ書いて、「なぜ育毛につながるか」を足さない。
- 上の箱と同じ対象説明を、安心のためにまた書く。
- 「専門店でもやっている」を根拠にしてしまう。
- 「美容師と一緒に」を先に置き、セラピストの作業リストが消える。
- 商品名・番号付きローション・業界用語を残したまま、「分かりやすくした」つもりになる。
- 揉み出しクレンジングを用語のまま置き、シャンプーとの差を書かない。
- 「話を聞き、自宅ケアも伝える」を1文にまとめる。
- 「経験に合わせて理論・実技・実践」で済ませ、未経験／経験済みの分岐を作らない。
- 意図（説明を足した・用語を残した）で返し、箱だけ読んで通るかは見ない（0330）。

---

## ■他の案件でも使えるパターン

- **結論の前に「なぜ」**を置く。思い込み → なぜそれでは足りないか → だからこの手段。
- **同じ情報の二度書き**は削る。箱の役割が違うなら、前の箱を参照する前提で進む。
- **他社事例は証拠にしない。** 自社で合法・安全にできる理由（資格・基準）で示す。
- **誰が何をするか**は、作業の塊で並べてから、同席・共有のなぜを足す。
- **業界用語は分解する。** 何をするか／なぜか／日常の何と違うか、の3点。
- **1文に2目的を混ぜない。** 聞くことと教えることは別行。
- **習得ルートは分岐で書く。** 「経験に合わせて」は、未経験／経験済みの2本に落とす。

## ■一言まとめ（本質）

👉 **ピンク箱では「美容室でもできる」の前に、なぜ頭皮ケアが育毛につながるかを書く。他店事例ではなく資格・合法で根拠を示し、施術はセラピスト作業の塊＋美容師同席のなぜ、用語は平易化してシャンプーとの差まで書く。聞く／自宅ケア／デビューまでの流れは、混ぜずに分ける。**

## ■1001・0914・0830・0330との関係

- **1001**：望みの具体・専門店に行かない心理・誰向きか・求人の具体。**今回**はその続きで、ピンク箱の**なぜ頭皮ケアか／施術の中身／根拠の出し方**を固める。
- **0914**：学び→専門店との違い→延長→2メニュー。**今回**の症状の線引き・資格根拠は、その違いの肉付け。
- **0830**：ヘッドスパ説明の平易化・一文多要素の分解。**今回**のローション／揉み出しクレンジングも同型。
- **0330**：意図ではなく結果。説明を足したつもりではなく、**この箱だけ読んで通るか**で見る。
