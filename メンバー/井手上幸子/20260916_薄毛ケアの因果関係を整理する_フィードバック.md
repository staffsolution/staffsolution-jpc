## ■分類（タグ）

- 緑マーク箱（薄毛・育毛の生まれた経緯）の**因果の飛び**
- お客様の悩みが**浅い／唐突**（深い悩みの描写不足）
- 「そこまで深くない悩み」→**美容室の延長＋α**への接続
- 育毛専門店の**費用・二重通い**を悩み側に置く
- 「自宅で頭皮をきれいに」への**飛び**／なぜ頭皮をきれいにするとよいかの欠落
- 毎日シャンプーしているのに何が問題か
- 進行度による**育毛スキャルプ／ニードル**の振り分け
- 発毛サイクル等の**専門情報は不要**（小学5〜6年生レベル）
- お客様の声・ベネフィットの**置き場**
- 0914・0909・0330の続き（意図ではなく結果）

---

## ■現状（Before）

- 0914で「学び→頭皮・毛根が必要→専門店／治療との違い→ヘッドスパ延長→2メニュー」の骨格を出している。今回は、その前段にあたる**緑マークの箱（悩み〜学び〜サービス誕生）**を見ている。
- 「お客様の悩みを聞き、髪型を整えるだけでいいのだろうか」から、いきなり「専門家や書籍から学んだ」「頭皮と毛根のケアが必要だと分かった」へ飛んでいる。**唐突**で、悩みの深掘りが足りない。
- 幹の付け方（どこへ相談したらいいかわからない、など）も、読み手が追える因果になっていない。
- 前回までで共有していた前提——40代後半〜60代の悩みは「専門店に通うほど深くない／周りもそうだからまあいいか、でも良くなるならいいかな」——が、文章に落ちていない。
- 「自宅で頭皮をきれいに整える方がよいか」も、前段のリーズナブル・1回でケア、から**飛んで**いる。
- 「なぜ頭皮をきれいにするとよいのか」が抜けている。必要な説明が無く、発毛サイクルなど**あまり必要ない専門情報**が入っている。
- お客様の声・ベネフィットの置き場が、箱の役割とずれている。

---

## ■問題の本質（重要）

- この箱の役割は、専門知識の羅列ではない。**悩みの実態 → カット／カラー／パーマだけでは足りない → だから学んだ → 頭皮ケアが必要 → でも専門店は大げさ・高い → だから美容室の延長＋αでできる → 来店で教わり自宅で続ける → 進行度でメニューを分ける**、を一本で追えるようにすること。
- お客様は、問題を認識していない／認識していても解決策を知らない、のどちらか。**問題がどこで、どうすれば解決できるか**が先。手段（メニュー・商品）は、そのあとに置く。
- ポジションは「本格専門店ほどではないが、普段の美容室の延長でケアできる」。悩みの深さを盛りすぎると専門店向きになり、浅すぎると「髪型の話だけ」で終わる。**前回確認した心理の深さ**に合わせる。
- 「説明を足した／学んだことを書いた」は意図。見るのは**この箱だけ読んで因果が通るか**という結果（0330）。

| 意図（考えていること） | 結果（文章に起きていること） |

| 頭皮・毛根ケアの必要性を伝えたい | 「なぜきれいにするとよいか」が抜け、飛ぶ |
| リーズナブルにケアできると示したい | 専門店の費用・二重通いが悩み側に無い |

- 0914で直した「学び→違い→延長→メニュー」の**手前**が、今回の本題。前段の因果が飛ばないと、後ろをいくら直しても土台が揺れる。

## ■改善内容（What）

### 0. 進め方

```
【維持（前回までのOK方向）】
・専門家／書籍から学んで分かった、という方向
・頭皮ケアが軸、という結論
・育毛スキャルプ／ニードルの2メニュー構成
・小学5〜6年生でも読めるトーン（0914）

【直す（今回の本題）】
・悩みを「映像が浮かぶ具体」まで深掘りする
・カット等だけでは足りない → 学んだ、の接続
・「そこまで深くない」心理 → 美容室の延長＋α、への接続
・専門店の費用・二重通いを悩み側に置く
・自宅ケアへの飛びを埋め、「なぜ頭皮をきれいに」を足す
・進行度でスキャルプ／ニードルを振り分ける
・発毛サイクル等の不要情報を削る
・お客様の声・ベネフィットの置き場を直す
```

### 1. 推奨の並び（緑マーク箱の骨格）

```
① お客様の悩みを具体で書く
   （抜け毛が増えた／分け目が目立つ／トップがペタンとして老けて見える、など）
② それでも「専門店ほどではない」心理もある
   （周りもそう／気になるけどまあいいか／良くなるならいいかな）
③ カット・カラー・パーマだけでは、この悩みは根本から解決しにくい
④ だから専門家や書籍から学んだ → 頭皮と毛根のケアが必要だと分かった
⑤ 一方、育毛専門店だと費用・期間・美容室との二重通いが重い
⑥ 本音は、髪がふさふさできれいになりたい。できればリーズナブルな美容室で、
   1回の来店で「きれい」と「ケア」を同時にしたい
⑦ そのためには、頭皮をきれいに保ち続ける必要がある
⑧ 進行が進んでいなければ、頭皮をきれいにするだけで前の状態に戻りやすい
⑨ だから当店でやり方を教え、家で続けられる状態をつくる
⑩ 進行が進んでいる人にはニードル側、そこまででない人にはスキャルプ側
```

①〜③が薄いと、④以降が全部唐突に見える。

### 2. 悩みブロック：具体 → カットだけでは足りない

| NG寄り | OK方向 |
|---|---|
| 悩みを聞き、髪型だけでいいのかと感じた（抽象） | 抜け毛・分け目・トップのペタンなど、映像が浮かぶ悩みを先に書く |
| すぐ専門家から学んだ | その悩みはカット／カラー／パーマだけではどうにもならない、と一度置く |
| 「どこへ相談していいかわからない」だけが幹 | 相談先の迷いより、悩みの中身と「根本原因が必要」を先に |

### 3. ポジション：専門店ほどではない → 美容室の延長＋α

前回までの共有どおり、ターゲットは「すごく深い悩みで専門店に行く層」ではない。

```
気になる／周りもそう／まあいいか
　↓
でも良くなるならやりたい
　↓
専門店ほど大げさでなくてよい
　↓
普段の美容室の延長＋αの金額でケアできる、が刺さる
```

ここで専門店の**費用・どのくらい通うか・美容室と両方に通う二重負担**を、悩み側に短く入れる。差別化の土台になる。

### 4. 「自宅で頭皮をきれいに」への飛びを埋める

```
リーズナブルに、1回の来店で育毛ケアにつなげるには
　↓
常に頭皮をきれいにしておく必要がある
　↓
進行が進んでいなければ、きれいにするだけで戻りやすい
　↓
だから店でやり方・使うものを教え、家で続ける
　↓
毎月通いながら少しずつ育毛につながる
```

「自宅ケアが大事」単体で出さない。**リーズナブル／1回で、の条件から導く**。

### 5. 「なぜ頭皮をきれいにするとよいか」を足す

多くの人は毎日シャンプーしている。それでも何が問題なのか、をここに置く（0914の自宅ケア因果と同型）。

```
毎日シャンプーしている人がほとんど
　↓
それでも起きる問題（洗い残し・頭皮の状態、など。難語は避ける）
　↓
だから、こうすべきだと分かった
　↓
そのやり方は一度お店でレクチャーが必要 → 家で続ける形に変えた
```

手段（商品名の押し出し）は、この因果の**あと**。問題認識が無い状態で「これがいいですよ」と言っても入らない。

### 6. 進行度で2メニューを振り分ける

| 状態 | 案内 |
|---|---|
| そこまで進行していない | 育毛スキャルプで十分、という位置づけ |
| より気になる／このぐらい進んでいる | ニードル育毛の方がよい |

ニードル側は「きれいにするだけでなく、頭皮に刺激を与えてより育毛につながる」程度でよい。専門解説は増やさない。

### 7. 削るもの・置き場を変えるもの

| 扱うもの | 扱い |
|---|---|
| 毛の生え変わる4つの周期 | **不要**。伝えても「それで何？」になりやすい |
| その他、小学5〜6年生では追えない専門説明 | 削る／言い換える |
| お客様の声 | 「2メニューが生まれた」箱とは**別カテゴリ**、または各メニュー内に分ける |
| ベネフィット（やってもらってこうなった） | お客様の声側に寄せると分かりやすい |

## ■改善理由（Why）

- 学びやメニューの説明を足しても、**悩みと「なぜ頭皮か」が飛ばなければ、後ろが全部唐突**になる。
- ターゲットの悩みの深さを盛りすぎると専門店向きになり、浅すぎると髪型の話で終わる。**前回確認した心理**に合わせないとポジションが崩れる。
- 専門店の負担を悩み側に置かないと、「じゃあ専門店でいいのでは」を潰せない。
- お客様は問題認識が薄いことが多い。**問題→解決の型**が先で、手段はそのあと（コピーの基本）。
- 0914の「小学5〜6年生」「因果が通るか」と同じ見方。今回はその見方を**箱の前段**に適用する段階。

---

## ■改善後イメージ（After）

- 悩みの具体 → カット等だけでは足りない → 学んで頭皮・毛根が必要、が一本で読める。
- 「専門店ほどではないが、良くなるならやりたい」心理から、美容室の延長＋αが自然に出る。
- 専門店の費用・二重通いが短く対比され、当店の位置が立つ。
- 自宅ケアが唐突でなく、「リーズナブルに続けるには頭皮をきれいに」から導かれている。
- 進行度でスキャルプ／ニードルが選べる。
- 発毛サイクル等の難語が消え、お客様の声は別枠／メニュー内に整理されている。

---

## ■やりがちなミス

- 「髪型だけでいいのか」から、すぐ「専門家から学んだ」へ飛ばす
- 悩みを抽象のままにして、抜け毛・分け目・トップの映像を書かない
- 「深い悩み」に盛りすぎて、専門店向きの文章にしてしまう（前回の共有と矛盾）
- 専門店の費用・二重通いを書かず、自社のよさだけを並べる
- 「自宅で頭皮をきれいに」を、リーズナブル条件から導かずに突然出す
- 「なぜきれいにするとよいか」を飛ばし、メニューや商品の話に入る
- 発毛サイクルなど、正しそうだが読み手が追えない情報を残す
- お客様の声を「生まれた経緯」と同じ箱に混ぜる
- 「説明を増やしたから分かりやすい」と思い、因果の通しを後回しにする

## ■他の案件でも使えるパターン

### パターンA：悩み箱は「具体 → 既存手段では足りない → だから学んだ」

```
映像が浮かぶ悩み
　↓
今の手段（カット等）では根本から解決しにくい
　↓
だから調べた／学んだ
　↓
何が必要だと分かった
```

### パターンB：悩みの深さ＝ポジションの深さ

```
専門店に行くほど深い悩みか？
　↓ No
美容室の延長＋αが刺さる
　↓
専門店の負担（費用・期間・二重通い）を悩み側に置く
```

### パターンC：自宅ケアは「条件から導く」

```
リーズナブルに／1回で、やりたい
　↓
そのためには常に〇〇が必要
　↓
店で教えて家で続ける
```

### パターンD：手段は問題認識のあと

```
問題はどこか
　↓
どうすれば解決できるか
　↓
だからこのメニュー／このやり方
```

問題認識の前に「これがいいですよ」を置かない。
