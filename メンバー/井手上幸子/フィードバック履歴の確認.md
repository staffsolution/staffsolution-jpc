# フィードバック履歴の確認

最終更新：2026年9月16日

このページは、これまでのフィードバックで  
何度も出ていることと、進んでいることを  
一覧で確認するためのものです。

判定の軸は、次の1つだけです。

「こう考えて書いた」ではなく、  
この箱だけ読んで、因果が通るか。

---

## 1. 何度も出ていること

| 内容 | 出てきた時期の例 | 9/16の回でも出たか |
|---|---|---|
| 因果が飛ぶ／話が唐突 | 3月〜9月（ほぼ毎回） | 出た |
| 「なぜそうなるか」が書かれていない | 3月・4月・8月・9月 | 出た |
| 他との比較が弱い（自社のよさだけ並ぶ） | 3月・5月・6月・7月・9月 | 出た |
| 読み手の悩みより、店側の話が先になる | 通年・特に6月以降も継続 | 出た |
| 「直したつもり」でも、読み手が止まる箇所が残る | 3月明示・7月・9月各回 | 出た |
| 必要な説明が薄いのに、難しい専門情報が入る | 6月・8月・9月 | 出た |

題材（未経験／待ち時間／育毛など）は変わっています。  
指摘の型は、3月から9月まで同じものが続いています。

---

## 2. できていること（進んでいる点）

| できていること | 例 |
|---|---|
| 提出と修正の着手が続いている | 履歴が途切れず積み上がっている |
| 指示どおりに箱を分ける作業ができる | 育毛箱からニードルを分ける、ヘッドスパをリラク側へ、など |
| 前回の方向に寄せられる回がある | 9/1 お客様中心・メニュー差、など |

作業や方向寄せはできています。  
次に定着させたいのは、「この箱だけで因果が通るか」の自己確認です。

---

## 3. これから定着させたいこと

| 確認すること |
|---|
| この箱だけ読んで、因果が通るか（自分で止まれるか） |
| 「わかりません」と言われた箇所を、説明ではなく結果の文章で直す |
| 読み手の悩み・不安を先に置き、答えは後に置く |
| 他店・専門店・一般との違いを書く |
| 小学5〜6年生でも追える言葉にする |
| 前回話し合った内容を、次の提出の文章に必ず入れる |

---

## 4. 直近（2026年9月・育毛／頭皮ケア）

| 日付 | 進んだ点 | 残った点 |
|---|---|---|
| 9/1 | お客様中心の方が伝わる、と整理できた | 原点接続・因果のずれ |
| 9/2 | 前回復調が機能した | 経緯の抜け・箱の分離 |
| 9/7 | 頭皮中心の方向は出た | 「なぜ頭皮か」の前段が弱い |
| 9/9 | ヘッドスパを外す方向はよい | 毛根への一段、「考えた」が残る |
| 9/14 | ニードルを分ける方向はよい | 因果の飛び、ヘッドスパが唐突、専門店との差 |
| 9/16 | （前段の骨格を直す段階） | 悩みが薄い、学びが唐突、自宅ケアへ飛ぶ |

9月は、箱を分ける・方向を寄せる動きはあります。  
まだ残っている幹は、次の3つです。

- 因果が飛ぶ
- 「直したつもり」と、読み手が止まる結果がずれる
- 読み手の悩みより、店側の話が先になる

---

## 提出前の3つだけ

次の提出の前に、これだけ確認してください。

1. この箱だけ音読して、どこかで「なぜ？」と止まらないか  
2. 悩み → なぜ今の手段では足りないか → だから学んだ／こうする、の順か  
3. 難しい専門語を足すより、必要な橋（なぜ）が入っているか
