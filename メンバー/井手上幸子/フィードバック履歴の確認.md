# フィードバック履歴の確認

最終更新：2026年11月19日

このページは、これまでのフィードバックで  
何度も出ていることと、進んでいることを  
一覧で確認するためのものです。

判定の軸は、次の1つだけです。

「こう考えて書いた」ではなく、  
この箱だけ読んで、因果が通るか。

---

## 1. 何度も出ていること

| 内容 | 出てきた時期の例 | 11/19の回でも出たか |
|---|---|---|
| 因果が飛ぶ／話が唐突 | 3月〜11月（ほぼ毎回） | 出た（着目・雰囲気のあと、仕事像が繋がらない／覚え方がふわっと） |
| 「なぜそうなるか」が書かれていない | 3月・4月・8月・9月・10月・11月 | 出た（循環・浮腫の理屈や着目が先で、何をするかが後景） |
| 他との比較が弱い（自社のよさだけ並ぶ） | 3月・5月・6月・7月・9月・10月・11月 | 出た（やりがいが薄く、他リラクではやれない厚みが無い） |
| 読み手の悩みより、店側の話が先になる | 通年・特に6月以降も継続 | 出た（専門説明・雰囲気が先で、仕事の映像が弱い） |
| 「直したつもり」でも、読み手が止まる箇所が残る | 3月明示・7月・9月・10月・11月 | 出た（AIまとめ後も「セラピストは何をするか」が伝わりにくい） |
| 必要な説明が薄いのに、難しい専門情報や重複が入る | 6月・8月・9月・10月・11月 | 出た（血の巡り・浮腫・循環／続けやすさ・未経験・働く場所が重複） |

題材（未経験／待ち時間／育毛／自社リサーチ全体／エステ部門など）は変わっています。  
指摘の型は、3月から11月まで同じものが続いています。

---

## 2. できていること（進んでいる点）

| できていること | 例 |
|---|---|
| 提出と修正の着手が続いている | 履歴が途切れず積み上がっている |
| 指示どおりに箱を分ける作業ができる | 育毛箱からニードルを分ける、ヘッドスパをリラク側へ、など |
| 前回の方向に寄せられる回がある | 9/1 お客様中心・メニュー差、など |
| やりがいの方向自体はよい | 11/19で方向は評価、厚みと集約が次の課題 |

作業や方向寄せはできています。  
次に定着させたいのは、「この箱だけで因果が通るか」の自己確認です。

---

## 3. これから定着させたいこと

| 確認すること |
|---|
| この箱だけ読んで、因果が通るか（自分で止まれるか） |
| 「わかりません」と言われた箇所を、説明ではなく結果の文章で直す |
| 読み手の悩み・不安を先に置き、答えは後に置く |
| 他店・専門店・一般との違いを書く（誰向きかの線引き） |
| 小学5〜6年生でも追える言葉にする |
| 前回話し合った内容を、次の提出の文章に必ず入れる |

---

## 4. 直近（2026年9月〜11月・育毛／頭皮ケア → 自社リサーチ全体 → エステ部門）

| 日付 | 進んだ点 | 残った点 |
|---|---|---|
| 9/1 | お客様中心の方が伝わる、と整理できた | 原点接続・因果のずれ |
| 9/2 | 前回復調が機能した | 経緯の抜け・箱の分離 |
| 9/7 | 頭皮中心の方向は出た | 「なぜ頭皮か」の前段が弱い |
| 9/9 | ヘッドスパを外す方向はよい | 毛根への一段、「考えた」が残る |
| 9/14 | ニードルを分ける方向はよい | 因果の飛び、ヘッドスパが唐突、専門店との差 |
| 9/16 | （前段の骨格を直す段階） | 悩みが薄い、学びが唐突、自宅ケアへ飛ぶ |
| 10/1 | 育毛系列の続きとして提出継続 | 「良くなる」が抽象、心理が点在、解決策の順番前後、誰向きかが薄い、結果が散在、求人の具体不足 |
| 10/5 | 1001の続きとしてピンク箱を提出 | なぜ頭皮→育毛が抜け、他店事例が根拠、用語が難しい、聞く／自宅ケアが混在、習得分岐が無い |

9〜11月は、箱を分ける・方向を寄せる動きはあります。  
まだ残っている幹は、次の3つです。

- 因果が飛ぶ
- 「直したつもり」と、読み手が止まる結果がずれる
- 読み手の悩みより、店側の話が先になる

---

## 提出前の3つだけ

次の提出の前に、これだけ確認してください。

1. この箱だけ音読して、どこかで「なぜ？」と止まらないか  
2. 悩み → なぜ今の手段では足りないか → だから学んだ／こうする、の順か  
3. 難しい専門語や詳細を足すより、必要な橋（なぜ）が入っているか
