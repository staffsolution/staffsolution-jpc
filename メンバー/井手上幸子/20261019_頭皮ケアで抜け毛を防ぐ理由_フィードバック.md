- 1005・1001・0914・0330の続き（意図ではなく結果）

## ■現状（Before）

- 1005ではピンク箱の「なぜ頭皮ケア→育毛か／施術の中身／根拠」を直す段階だった。今回は、その続きにあたる**青い部分**（抜け毛・薄毛の理由から、美容室で頭皮ケアを取り入れた話）を見ている。
- 「頭皮をきれいに整えると改善が見込める」方向は出ているが、**読み手の思い込み（年齢・ストレスだから抜けている）を先に置いていない**。いきなり頭皮の話に入りやすい。
- 「毎日シャンプーしているから頭皮はきれい」という第二の思い込みも弱い。普通のシャンプーでは毛穴まわりの汚れが落ちにくい、という**なぜ**が、専門的で長い文章のまま残っている。
- 「皮脂・古い角質が残る → ベタつき・かゆみ・ふけ」までは書けても、それが**抜け毛・薄毛にどうつながるか（炎症→抜け毛）**までの結果が弱い。読み手が「抜け毛の話なのに、かゆみの話？」と止まりやすい。
- 「そこで取り入れているのは美容室の頭皮ケアです」が先に来やすい。**どうすれば解決できるか**のきっかけを置いてから、当店のケアにつなぐ順番になっていない。
- 揉み出し・ローション・専門技術が必要な理由が薄い。家でもできることと、美容室で見る価値（状態を見極めて適切にケアする）の線引きも、そのままではインパクトが弱い。
- 必要性の説明と、施術のやり方・セラピストの仕事内容が、同じ箱に混ざりやすい。専門用語もまだ多い。

---

## ■問題の本質（重要）

- この青い箱の役割は「頭皮の汚れの説明」や「施術メニューの列挙」ではない。**読み手が信じている原因（年齢・ストレス／毎日洗っているから大丈夫）→ 実は頭皮の状態も大きい → なぜ普通のシャンプーだけでは足りないか → 汚れが残るとどうなるか（炎症→抜け毛）→ だから頭皮ケアが必要 → 当店では美容室ケアと自宅ケアでこうする**、を一本で追えるようにすること。
- 「思い込みの情報」は使い勝手がよい。先に置くと、「確かにそうだよね」と乗せてから、頭皮の話に入れる。
- 揉み出しやローションは、用語を正確に書くことが目的ではない。**普通の洗い方では足りない問題を解決するための手段**として、なぜ必要かが読めることが目的。
- 解決策（施術の詳細）は、必要性のあとで**別項目**にした方がよい。必要性の箱でやり方まで詰め込むと、因果がまた途切れる。
- 見るのは「説明を足したつもり」ではなく、**この青い箱だけ読んで「なぜ毎日シャンプーだけではダメで、頭皮ケアが抜け毛対策になるのか」が通るか**（0330）。

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| 頭皮ケアが抜け毛に効くと伝えたい | 年齢・ストレスの思い込みが先に無く、頭皮の話が唐突に見える |
| 毎日洗っている人も対象にしたい | 「毎日シャンプーでもダメ」のなぜが長く専門的で、止まって読まれる |
| 汚れの話を丁寧に書きたい | かゆみ・ふけで止まり、抜け毛・薄毛までの結果が弱い |
| 美容室の頭皮ケアを紹介したい | 「どう解決するか」の前に、当店のケアが先に出る |
| 揉み出し・ローションを正確に書きたい | なぜその手技・なぜプロか、が薄いまま用語が残る |
| 家でもできることと差別化したい | 「美容室でしかできない」に寄りすぎるか、逆にインパクトが弱い説明になる |
| 施術と必要性をまとめて伝えたい | 必要性とやり方が同じ箱に混ざり、セラピスト仕事も追いにくい |

- 「後で詳しく書いてある」「AIで長く説明した」は、**いま読んでいる箱の結果**には反映されない（0330と同型）。

## ■改善内容（What）

### 0. 進め方

```
【維持】
・頭皮を整えると改善が見込める、という方向
・1005で示した「なぜ頭皮ケアか」の延長として青い箱を扱う
・専門用語を減らす方向（分かりやすい案をベースにする）

【直す（今回の本題）】
・思い込み①：年齢・ストレスだけが原因だと思っている
・思い込み②：毎日シャンプーしているから頭皮はきれい
・普通のシャンプーでは足りない理由を、短く・誰でも分かる言葉で
・汚れが残った「結果」まで書く（炎症 → 抜け毛・薄毛）
・解決のきっかけ → それが当店の頭皮ケア、の順番
・必要性と施術詳細は別項目
・揉み出し／ローション／プロがやる理由を、問題解決に結びつける
・美容室ケア＋自宅ケアの両方
・セラピストの仕事内容も同じ流れに合わせて平易化
```

### 1. 思い込み①を先に置く（年齢・ストレス）

読み手が「自分の抜け毛の説明」だと思っている話から入る。

```
① 多くの人は「年齢のせい／ストレスのせい」で抜け毛・薄毛になると思っている
② 実はそれだけが原因ではない
③ 頭皮の状態によって抜け毛が進んでいるケースも多い
④ 頭皮をきれいに整えると、改善が見込める可能性がある
```

「確かにそうだよね」と乗せてから、頭皮の話に入る。結論だけ先に置かない。

### 2. 思い込み②を入れる（毎日シャンプーで大丈夫）

頭皮を整える、と言った直後に、第二の思い込みを崩す。

```
① 「毎日シャンプーしているから、頭皮はきれい」と思っている人が多い
② でも、普通の洗い方だけでは足りない場合がある
③ なぜなら（次の項の短い理由）
④ だから、その問題を解決するケアが頭皮ケア（揉み出しなど）になる
```

揉み出しは「用語の紹介」ではなく、**②③の問題を解く手段**として結びつける。

### 3. 「普通のシャンプーではダメな理由」を短く・平易に書く

専門的で長い説明は削る。誰が読んでも分かる一文〜二文にする。

```
【弱い（長い・専門的）】
頭皮には皮脂や古い角質、シャンプーや育毛料の残りなどが重なり…
髪を囲む小さなくぼみになっていて、簡単に落ちにくい場合があります…
（長く続く）

【強い（短い・結果が読める）】
髪が生えている入り口は小さなへこみになっていて、
皮脂や古い角質がたまると、いつもの洗い方では落としきれないことがある。
```

「もっとシンプルに、こうだからダメなんだよ」が伝わる長さにする。AI壁打ちで短くしてよい。

### 4. 汚れの「結果」を抜け毛までつなぐ

かゆみ・ふけで止めない。抜け毛・薄毛までの橋を書く。

```
① 落としきれない汚れが残る
② 頭皮のかゆみや炎症につながることがある
③ その結果、抜け毛・薄毛が進みやすくなる（断定せず「可能性がある」でよい）
④ 毛穴まわりの汚れをきちんと落とすと、髪が育つ土台が整い、自然と増えやすくなる可能性がある
```

「ベタつき・かゆみ・ふけ」だけで終わると、抜け毛の箱なのに因果が途切れる。

### 5. 解決のきっかけ → 当店の頭皮ケア、の順番にする

```
① どうすれば解決できるか（汚れを落とし切り、頭皮の土台を整える）
② それを行うのが、当店で取り入れている頭皮ケア
③ （詳細なやり方は次の箱）
```

「そこで取り入れているのは美容室の頭皮ケアです」を、解決の前に置かない。

### 6. 必要性と施術詳細は別項目にする

| 箱 | 入れるもの | 入れないもの |
|---|---|---|
| 必要性（今回の青の主戦場） | 思い込み→なぜシャンプーだけでは足りない→結果→だからケアが必要 | 手技の細かい手順の全部 |
| 当店の頭皮ケア（別項目） | 美容室で何をするか／なぜそのやり方か／自宅ケアも含む | 必要性の話の繰り返し |

「なぜ当店で頭皮ケアを取り入れたのか」は、必要性のあとに置く。やり方の詳細は別項目がよい。

### 7. 揉み出し・ローション・プロの「なぜ」を問題に結びつける

| 手段 | 書くべきなぜ |
|---|---|
| 指の腹で優しく動かす（揉み出し） | 普通のシャンプーでは落ちにくい汚れを浮かせるため |
| ローション | なぜローションが必要か（汚れを浮かせる／整える、など店の実態に合わせる） |
| 専門的な技術を持つ人が行う | 頭皮の状態を見極めて、適切な強さ・方法でケアするため |

「美容室でなければ絶対にできない」と言い切るより、**状態を見極めて適切にケアしてもらうこと**を価値にする方が説得力が出る（家でも部分的にできることとの線引き）。インパクトが弱いと感じたら、必要性の箱で「結果（炎症→抜け毛）」を厚くしてから、施術箱で差を見せる。

### 8. 美容室ケア＋自宅ケアの両方を書く

当店の頭皮ケアの箱では、店で行うケアだけでなく、**家で行うケア**も含めて説明する。  
1005の「聞く／自宅ケアを伝える」と同じ軸。店だけ完結させない。

### 9. セラピストの仕事内容を同じ流れに合わせる

必要性→解決→当店ケア、の流れが通ったら、**セラピストが行う仕事内容**もその順番で平易に直す。

```
例：状態を見る → 汚れを落とすケアをする → 説明・自宅ケアを伝える →（必要なら美容師と共有）
```

シャンプーが美容師しかできないか等の法規・実態は、店の事実に合わせて調整する（フィードバック側で断定しない）。

### 10. 専門用語を極力使わない案をベースにする

長く専門的な案より、**誰が読んでも分かる案**を正とする。番号付きローション名・業界語は、なぜが書けてから必要最小限にする（1005同型）。

## ■改善理由（Why）

- 思い込みを先に置くと、頭皮の話が「突然の結論」ではなく、読み手の頭の中の説明を書き換える流れになる。
- 「毎日シャンプーでもダメ」のなぜが短いと、揉み出し・頭皮ケアが「余計なメニュー」ではなく「足りない洗い方の補完」として読める。
- 炎症→抜け毛まで書くと、かゆみ・ふけの話が抜け毛箱の中で迷子にならない。
- 解決のきっかけを先に置くと、当店の頭皮ケアが売り込みではなく答えになる。
- 必要性と施術詳細を分けると、箱ごとの役割がはっきりし、因果がまた飛ばなくなる。
- 家でもできることとの線引きを「見極め」に置くと、「他店もやっている」「うちだけできる」の弱い根拠に戻りにくい（1005の続き）。
- 自宅ケアまで含めると、店の施術だけで終わらない現実のケアになる。
- セラピスト仕事を同じ流れにすると、求職者にも「自分が何をするか」が追える。
- 専門用語を減らすと、未経験・お客様の両方で止まりにくくなる（0830・1005と同型）。

## ■改善後イメージ（After）

- 青い箱だけ読んで、「年齢・ストレスだと思っている」→「実は頭皮も大きい」→「毎日シャンプーでも足りない理由」→「汚れが残ると炎症→抜け毛」→「だから頭皮ケア」→「それが当店のケア（詳細は次）」が通る。
- 普通のシャンプーではダメな理由が、短くて小学5〜6年生でも追える。
- かゆみ・ふけで止まらず、抜け毛・薄毛までの結果がある。
- 「美容室の頭皮ケアです」が、解決のきっかけのあとに来る。
- 必要性と施術のやり方が別項目になっている。
- 揉み出し・ローション・プロがやる理由が、問題（落としきれない汚れ）に結びついている。
- 美容室ケアと自宅ケアの両方がある。
- セラピストの仕事内容が、同じ順番で平易に読める。

## ■やりがちなミス

- 頭皮の説明から入り、年齢・ストレスの思い込みを先に置かない。
- 「毎日シャンプーでもダメ」と書いて、なぜかを長く専門的に書く（または書かない）。
- ベタつき・かゆみ・ふけで止め、炎症→抜け毛までの結果を書かない。
- 「そこで当店の頭皮ケアです」を、解決のきっかけより先に置く。
- 必要性の箱に、揉み出し・ローションの手順まで全部詰め込む。
- 「美容室でしかできない」と言い切るか、逆に差が分からない説明で終わる。
- 揉み出し・ローションの用語は残すが、なぜ必要かが無い。
- 自宅ケアを書かず、店の施術だけで完結させる。
- セラピストの仕事だけ別フォーマットになり、全体の流れとずれる。
- 意図（詳しく書いた・AIで直した）で返し、箱だけ読んで通るかは見ない（0330）。

## ■他の案件でも使えるパターン

- **思い込みを先に置く。** 読み手が信じている説明 → 実はそれだけではない → だからこの話。
- **「日常でやっていることでは足りない」のなぜを短く書く。** 長い専門説明より、一発で分かる理由。
- **症状の途中で止めず、案件のゴール（抜け毛・応募・定着など）まで結果をつなぐ。**
- **解決のきっかけ → 自社の手段**の順。手段の商品名を先に出さない。
- **必要性とやり方は箱を分ける。** 混ぜると因果が飛ぶ。
- **家でもできることとの差は「絶対できない」より「見極め・適切さ」で示す。**
- **店の施術＋自宅の行動**の両方を書く。
- **用語は、問題を解く手段としてから出す。** 用語紹介が先に来ない。
