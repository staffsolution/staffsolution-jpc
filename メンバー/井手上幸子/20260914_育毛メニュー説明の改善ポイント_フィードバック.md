- 育毛専門店・治療との**違いが無い**（ちゃんとした所へ行きたくなる）
- 「考えた」＝生み出した印象 → **学んで分かった**に直す
- 頭皮ケアと毛根ケアの**まとめ方**／発毛サイクルの意味

- 毎日のケア：市販シャンプーの**何がまずいか**の因果
- 「コーティング成分」「残留」など**難しい語**を削る

## ■現状（Before）

- 0909で「頭皮→毛根→抜けづらい／育つ」「考えた・整えるを具体に」「専門っぽい語を避ける」方向が出た。今回は、アンチエイジング／育毛メニューからニードルを外し、説明を足したあとの**ニードル・スキャルプ側の箱**を見ている。
- ニードル説明を追加したこと自体は方向としてよい。問題は、足した文の**因果がつながっていない**こと。
- ヘッドスパの話が**唐突に出てくる**。前段に「なぜヘッドスパの話をするのか」がなく、読み手は「なぜ急にヘッドスパ？」で止まる。
- 「余分な皮脂や古い汚れを取り除き、頭皮を清潔に保つことが必要だと考えた」のように、**「考えた」で止まっている**。専門家や書籍から学んだ結果「分かった」のに、文章だと**自分で生み出した**ように読める。
- 育毛専門店・治療でやっていることとの**違いが書かれていない**。違いが見えないと、「ちゃんとした専門店や治療に行った方がいい」になりやすい。
- 「発毛サイクルを整える」と「頭皮・毛根のケア」が並ぶが、**頭皮ケア＝毛根ケア**としてまとめられるのに、分かれて重複し、サイクルの意味も薄い。
- 全体のトーンが**専門的・治療寄り**になっている。本来の立ち位置は「治療は怖い／薬は飲みたくない」「専門店は大げさ」な人向けの、もっとフランクな路線のはず。
- 毎日のケア側は、市販シャンプーの「滑らかにする成分・コーティング成分」など**分かりにくい成分説明**が主役になっている。洗い残しが頭皮に残ると**どう悪くなるか**の因果が弱い。
- 「残留した汚れ・皮脂だけを取り除く」など、**小学校高学年では追いにくい言い回し**が残っている。

---

## ■問題の本質（重要）

- この箱の役割は、ニードルやスキャルプの専門説明を増やすことではない。**学び → 頭皮・毛根が必要だと分かった → 専門店／治療との違い → ヘッドスパの延長でできる → だからこの2メニュー**、を一本で追えるようにすること。
- ヘッドスパは「経歴の自慢」ではなく、**専門機材や資格がなくても、美容室のメニュー延長で頭皮ケアできる**という証拠の置き場所。唐突に出すと、その役割が消える。
- ポジションは「治療・専門店の代替として、もっと気軽に通える」側。文章が治療っぽい専門用語だらけだと、**読み手が求めている安心と真逆**になる。
- 「考えた」は店側の意図の言葉。読み手が欲しいのは**何を学んで、何が分かり、何をするか**の結果（0330：意図ではなく結果）。
- 自宅ケアは成分名の講義ではなく、**市販だと何が起き、サロンシャンプーだとどう違うか**の因果。

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| ニードル説明を足して分かりやすくする | 因果が飛ばず、ヘッドスパが唐突に出る |
| ヘッドスパ歴を強みにしたい | 「なぜヘッドスパの話か」が無く、経歴だけが降ってくる |
| 頭皮・毛根ケアの必要性を伝えたい | 「考えた」で止まり、学び→分かった、になっていない |
| 専門店・治療と違うと示したい | 違いが無く、「ちゃんとした所へ」と思われる余地が残る |
| 発毛サイクルと頭皮ケアを伝えたい | 言い方が分かれ、サイクルの意味と比較が薄い |
| 気軽に通える育毛として見せたい | 治療・専門店っぽい難語が残り、フランクさが消える |
| 自宅シャンプーの重要性を伝えたい | 成分名・残留など難語が主役で、問題の連鎖が見えない |
| 洗い方も大事だと伝えたい | 難しすぎる技術習得の話に見えやすい（要点だけに絞れていない） |

- 0909で直した「毛根は突然出さない」「考えたを具体に」が、今回は**学び→必要性→手段**の一段と、**専門店との差**に落ちる段階。
- 「説明を増やしたから分かりやすい」ではなく、**この箱だけ読んで因果が通るか**で見る（0909・0907と同型）。

## ■改善内容（What）

### 0. 進め方

```
【維持（今回のOK方向）】
・育毛メニューからニードルを分けて説明を足したこと
・頭皮・毛根のケアが必要、という結論の方向
・毎日のケア（シャンプー）と来店ケアをつなぐ発想

【直す（今回の本題）】
・ヘッドスパが唐突 → 学び→必要性→延長線、の前置き
・専門店・治療との違いを明示
・「考えた」→「学んで分かった」
・発毛サイクル／頭皮・毛根を1本にまとめる
・小学5〜6年生レベルまで落とす（治療っぽい語を削る）
・2メニュー＝頭皮に働く／毛根に働く、の役割分け
・市販シャンプーの「何がまずいか」の因果（成分名講義は捨てる）
```

AIに「小学5〜6年生でも読める言葉に」「因果が A→B になるように」と壁打ちしながら直す。

### 1. 推奨の並び（ニードル／スキャルプ箱の骨格）

```
① お客様の悩みが増え、髪型を整えるだけでは足りないと感じた
② 専門家や書籍から育毛を学んだ
③ 今ある髪だけでなく、土台の頭皮・毛根のケアが必要だと分かった
④ ただし専門店・治療だと、資格・機材・大げさ・怖い、と思われやすい
⑤ 実はヘッドスパの延長で、美容室の通常メニューから頭皮ケアができる
⑥ だから当店は、頭皮に働くメニュー／毛根に働くメニューの2つにたどり着いた
⑦ 来店のケア ＋ 毎日のシャンプー（市販の問題 → サロンシャンプー）
```

①は短くてよい。「髪型だけでいいのか／悩みを解決したい→調べた→ここにたどり着いた」程度。重い前置きは削る。

### 2. 「考えた」を「学んで分かった」に直す

| NG | OK方向 |
|---|---|
| 清潔に保つことが必要だと考えた | 専門家や書籍から学び、必要だと分かった |
| ヘッドスパを土台に考えたメニュー | ヘッドスパを長年やってきたからこそ、このメニューにたどり着いた |

「考えた」は**発明した印象**になる。事実は「学んで分かった／たどり着いた」。

### 3. 専門店・治療との違いを必ず出す

読み手が頭に浮かぶ比較対象を先に置く。

| よくある選択肢 | お客様が感じやすい印象 | 当店の位置 |
|---|---|---|
| 治療・薬 | 怖い／飲みたくない | そこまで大げさにしなくてよい |
| 育毛専門店 | 少し大げさ | 美容室のメニュー延長でできる |
| 当店 | （ここに書く） | ヘッドスパの延長で頭皮・毛根ケア |

違いが無いと、「ちゃんとした専門の所へ行った方がいい」になる。**何が違うのか**を短く示す。

### 4. 発毛サイクル／頭皮／毛根を1本にまとめる

- 頭皮のケアと毛根のケアは、**まとめられるなら1つにまとめる**（言い換えの重複をやめる）。
- 「発毛サイクルを整える」は、**どういうことか**を1〜2文で置く（名前だけ置かない）。
- そのうえで、**専門店・治療側の「頭皮ケア」と何が違うか**を短く対比する。

### 5. 2メニューの役割分け

イメージしやすい分け方：

| メニュー | 働きかける先 | 読み手が持つ映像 |
|---|---|---|
| 育毛スキャルプ側 | 頭皮 | 頭皮を清潔・整える |
| ニードル育毛側 | 毛根 | 細い針でやさしく刺激する |

「針で刺激する」は、毛根に働きかける映像が持ちやすい。抽象語でまとめない。

### 6. 毎日のケア：成分名を捨て、問題の連鎖を書く

```
多くの人は毎日シャンプーしている
　↓
でも市販のシャンプーだと、洗い残しが頭皮に残りやすい（何が起きるか）
　↓
それが続くと、次にこういう問題が起きる
　↓
だからサロンで扱っているシャンプーの方がよい
　（多少残っても頭皮を傷つけにくい、など）
```

- 「滑らかにする成分」「コーティング成分」「残留した」は**削る／言い換える**。
- 洗い方は「ここだけ守ってね」の**要点だけ**。難しい技術習得・毎回の指導が必要、のように書かない。

### 7. トーン：小学5〜6年生でも通る言葉

- 治療・専門店っぽい難語を並べない。
- 立ち位置は「フランクに通える」側。文章が難しすぎると、その約束が破れる。
- AIに「この段落を小学5〜6年生向けに言い換えて」と投げてよい。

## ■改善理由（Why）

- ニードル説明を足しても、**因果が飛ばなければ増えた分だけ迷子が増える**。足す量より、並びが先。
- ヘッドスパは「なぜこの店でできるか」の答え。唐突に出すと経歴自慢に見え、専門店との差も消える。
- 「考えた」は意図。「学んで分かった」は結果。読み手が追えるのは後者だけ（0330・0909と同型）。
- 気軽に通えるポジションなのに治療っぽい語が並ぶと、**ターゲットの不安（大げさ・怖い）を増やす**。
- 自宅ケアは「何の成分か」ではなく「残るとどう悪くなり、サロンシャンプーだとどう違うか」。日常の体験とつながる因果が必要。

---

## ■改善後イメージ（After）

- 学び → 頭皮・毛根が必要 → 専門店／治療との違い → ヘッドスパ延長でできる、が一本で読める。
- 「考えた」が消え、「分かった／たどり着いた」になっている。
- 2メニューが「頭皮に働く／毛根に働く」で一瞬で分かる。
- 専門用語が減り、フランクに通える店の文章になっている。
- 毎日のケアは、市販の問題連鎖 → サロンシャンプー、で着地する。

---

## ■やりがちなミス

- ヘッドスパを**前置きなしで突然出す**
- 「清潔が必要だと考えた」のまま、**学び→分かった**に直さない
- 専門店・治療との**違いを書かず**、説明だけ増やす
- 発毛サイクル・頭皮・毛根を**別言い回しで重複**させる
- 治療・専門店っぽい難語を残し、**気軽さのポジションを壊す**
- 2メニューの差を書かず、**どちらも同じ頭皮ケア**に見える
- 「コーティング成分」「残留」など、**映像が浮かばない語**を主役にする
- 洗い方を**難しすぎる技術**のように書いてしまう
- 「説明を増やしたから分かりやすい」と思い、**因果の通しを後回し**にする

### パターンA：専門メニューは「学び→必要性→なぜ自社でできるか」

```
調べた／学んだ
　↓
何が必要だと分かった
　↓
一般には専門店・治療だと思われやすい
　↓
でも自社では〇〇の延長でできる
　↓
だからこのメニュー
```

### パターンB：「考えた」を結果の動詞に変える

| 意図語 | 結果語の例 |
|---|---|
| 考えた | 学んで分かった／たどり着いた |
| 整える | 洗う／刺激する／清潔にする |
| 専門的に行う | （具体の動作に落とす） |

### パターンC：ポジションとトーンを一致させる

```
ターゲットの本音：治療は怖い／専門店は大げさ
　↓
文章もフランクで分かる言葉にする
　↓
治療っぽい難語が並ぶと、約束が破れる
```

### パターンD：自宅ケアは「成分名」より「問題の連鎖」

```
多くの人がやっていること（毎日シャンプー）
　↓
それでも起きる問題
　↓
次に起きる問題
　↓
だから店の提案（サロンシャンプー）
```
