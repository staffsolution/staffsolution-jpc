---

## ■現状（Before）

- 1027で骨格（ターゲット → 実態 → リラク&Beauty）を戻したあとの、**エステ部門・やりがい・長く続けやすい理由**まわりの肉付けを見ている。
- 「顔の血の巡りに着目した美容ケア」とあるが、**具体的に何をするのか**が読み手に伝わらない。通常エステとの違い（座った状態で体の下へ流す、など）も、エステ未経験者には前提が分からない。
- 「流れきらずに止まって浮腫になり、体全体の循環に影響する」といった説明も、**なんとなくしか分からない**層がいる前提で書かれていない。
- 「お顔の美容と身体のリラクケアを続きに考え、美しさと心地よさを一緒に提供」は、**雰囲気だけ**でまとまって見える。
- 「セラピストはどんな仕事をするのか」「未経験はどう覚えるのか」も、ヒアリングは美容師／顔〜首肩の血の巡りケアはセラピスト、まずは基本のリラクケア、など断片はあるが、**仕事の像がふわっとしたまま**。
- 壁打ちでAIにまとめてもらった結果でも、核心は同じ。**肝心のセラピストは何をする仕事なのかが伝わりにくい**。
- 「この仕事のやりがい」は方向としてよいが、**あっさりしすぎ**。一般にない体制の美容室なので、他のリラクゼーションサロンではやれないこと・やりがいの厚みがもっとあるはず、という指摘。
- 「リラクやエステの仕事を安心して長く続けやすい4つの理由」はごちゃついており、その下の「未経験から始めても技術を増やせる」「美容や自分の仕事が好きなら働く場所にも目を」などと**かぶっている**。大きな項目を4つの理由に集約する方向がよい。

---

## ■問題の本質（重要）

- エステ部門の箱の役割は「専門っぽい言葉で雰囲気を出す」ことではない。**セラピスト候補が、自分が何をする仕事かを一読で描けること**がゴール。
- ターゲットはメインがセラピスト（未経験／資格はあるが実務なし／エステ経験・興味あり）。その中に**エステ未体験の人**がいる前提で書く。業界語や循環の理屈だけでは止まらない文章にする。
- やりがいは「いい方向」で止めない。**他のリラクではやれないこと**まで書くと、特殊体制の価値が結果として見える。
- 長く続けやすい理由・未経験・働く場所への目線が別箱で並ぶと、読み手は同じ話の繰り返しに見える。**大きな幹は4つの理由に集約し、エステ部門の仕事像もその中で回収できるか**を先に決める。
- 判定は常に「意図では分かっている」ではなく、**この箱だけ読んで、仕事・やりがい・続けやすさが通るか**（0330）。

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（マップ・文章に起きていること） |
|---|---|
| 血の巡りに着目したケアを伝えたい | 「何をするか」が具体に落ちず、着目点だけが残る |
| 通常エステとの違いを言いたい | 座位・流す技術などが出ても、未体験者には前提が分からない |
| 顔と身体を一連で考える思想を伝えたい | 「美しさと心地よさ」など雰囲気のまとめに見える |
| 役割分担を説明したい | 美容師／セラピストの境界が推測頼みでふわっとする |
| やりがいを示したい | 方向はよいが薄く、他リラクとの差が出ない |
| 続けやすさ・未経験・働く場所を厚くしたい | 箱が増えて重複し、4つの理由がごちゃつく |
| AIでまとめたから直った | 核心（セラピストが何をするか）はまだ伝わりにくい |

- 「説明を足した／まとめた」でも、読み手が止まる箇所が残るのは、意図ではなく結果で見る同型（0330・1027）。

## ■改善内容（What）

### 0. 進め方

```
【維持】
・やりがいの方向そのもの（薄いので削る対象ではない）
・長く続けやすい理由を軸にする発想
・壁打ちで「何が伝わりにくいか」を言語化したこと

【直す（今回の本題）】
・エステ部門：セラピストが何をするかを具体にする
・未体験者でも追える言葉にする（循環・浮腫の理屈だけにしない）
・美容師／セラピストの役割を一文で分かる形にする
・未経験の覚え方を「ふわっ」から手順・段階に落とす
・やりがいを他リラクではやれないことまで肉付けする
・重複箱を「長く続けやすい4つの理由」に集約する（エステ部門も回収）
```

### 1. エステ部門：着目点ではなく「何をするか」から書く

「血の巡りに着目」は入口のラベルであって、仕事内容ではない。次の順で書く。

```
① セラピストは、お客様に対して何をする人か（行為・範囲）
② 通常のエステと何が違うか（座位・体の下へ流す、など）
③ なぜそのやり方なのか（結果：むくみ・循環・顔の印象、を小学生でも追える言葉で）
④ 美容師との役割分担（ヒアリング／施術の境界）
```

**判定：** この箱だけ読んで、「自分がその場で何をするか」が映像になるか。着目・思想・雰囲気だけで止まっていないか。

### 2. 未体験者前提の言葉にする

ターゲットにエステ未体験が混ざる前提で、次を避ける／直す。

| 弱い（今起きやすい） | 強い（寄せたい） |
|---|---|
| 血の巡り・浮腫・循環の理屈が先 | 何を手で／体でやるかが先 |
| 「続きに考え」「美しさと心地よさ」 | 顔のケアと身体のリラクをどうつなぐかの手順・役割 |
| 専門っぽい一文でまとめたつもり | 未体験の人が「ああ、そういう仕事か」と言える具体 |

壁打ちのAIまとめをベースにしてよい。ただし最終確認は、**「セラピストは何をする仕事か」が一文で言えるか**。

### 3. やりがい：方向は残し、厚みを足す

- 今のやりがいは「とてもよい」方向。消さない。
- 足りないのは、**一般のリラクゼーションサロンではやれないこと**まで書けているか。
- 特殊体制の美容室なので、やりがいを感じるポイントはもっとあるはず、という前提で肉付けする。
- 候補の一例（必須ではない・実態に合わせる）：女性として**自分自身も美容で綺麗になれる**、など。美容師側で強く伝えている要素なら、セラピスト側の項目に入れるか・4つの理由のどこかに入れるかを決める。
- 肉付け結果が長くなったら、**見出しを入れて整理**する（長い一文の羅列にしない）。

### 4. 大きな項目を「長く続けやすい4つの理由」に集約する

現状のかぶりやすい箱の例：

- リラクやエステの仕事を安心して長く続けやすい4つの理由
- 未経験から始めても、自分に合った技術を少しずつ増やしていける
- 美容や自分の仕事が好きなら、働く場所にも目を向けてみませんか
- エステ部門の説明（仕事像がふわっとしている部分）

**推奨：**

1. 大きな幹は **4つの理由** に集約する（壁打ちでも「全て集約」が推奨）
2. 未経験・働く場所・エステ部門の核は、4つの中のどの理由に入るかを先に決める
3. 下に別見出しで同じ話を重複させない
4. 4つに入らない細部は削る／補助の一文に落とす

```
【集約のイメージ】
4つの理由
 ├ 理由1：…（例：未経験でも段階的に覚えられる、など）
 ├ 理由2：…（例：他リラクではやれない仕事・やりがい、など）
 ├ 理由3：…
 └ 理由4：…
※エステ部門の「何をするか」は、仕事内容の箱か、理由の中の具体例で回収する
```

数字の3つ／4つにこだわらず、**重複が消えて幹が一本になること**が目的。

---

## ■改善理由（Why）

- セラピスト募集なのに「何をするか」がふわっとだと、ターゲットは自分ごと化できない（0504・1027と同型）。
- エステ未体験の読み手がいるのに循環の理屈や雰囲気でまとめると、「なんとなく分かったつもり」で止まる。結果として応募の決断材料にならない。
- やりがいが薄いと、特殊体制の価値が「一般のリラクと同じ＋少し違う」に見える。他ではやれないことまで書くと比較が機能する。
- 続けやすさ・未経験・働く場所が別箱で重複すると、1027で直した骨格のあとも、また「箱が増えて幹がぼやける」状態に戻る。
- AIまとめは道具。最終判定は「セラピストは何をする仕事か」が一読で言えるか（意図ではなく結果）。

---

## ■改善後イメージ（After）

- エステ部門の箱だけ読んで、「セラピストは顔〜首肩などのケアで何をする人か／美容師との分かれ／通常エステとの違い」が映像になる。
- 未体験の人でも、「着目」や「思想」より先に、やる行為が分かる。
- やりがいは残したまま、他リラクではやれない厚みがある（必要なら自分も綺麗になれる等も項目化）。
- 「長く続けやすい4つの理由」に、未経験・働く場所・エステの核が集約され、下の重複見出しが消えている。
- マップ全体として、1027の幹（ターゲット → 実態 → 自社）の上に、仕事像と続けやすさが一本で載っている。

---

## ■やりがちなミス

- 「血の巡りに着目」などラベルを足して、仕事内容が具体になったと思い込む。
- 通常エステとの違いを専門家向けの言葉で書き、未体験者を置いてけぼりにする。
- 「美しさと心地よさ」など雰囲気の一文で、顔と身体のつながりの説明を終わらせる。
- 美容師／セラピストの役割を推測できる程度にしか書かず、ふわっとしたままにする。
- やりがいの方向はよいのに、薄いまま「これで十分」にする。
- 続けやすさ・未経験・働く場所を別箱で増やし、同じ話を繰り返す。
- AIにまとめてもらった文章を貼って、「伝わりにくさ」が消えたと判定する（結果を読まない）。
- 1027で骨格を戻したあと、枝の説明だけふわっと増やして幹を再びぼやかす。

---

## ■他の案件でも使えるパターン

- **部門説明は「着目・思想」より先に「何をするか」。** ラベルは後でよい。
- **業界未体験の読み手が混ざる前提で書く。** 専門の正しさより、一読で映像になるか。
- **やりがいは方向がよくても薄いと弱い。** 他ではやれないことまで書くと比較になる。
- **似た箱が並んだら大きな理由に集約する。** 厚み＝箱の数ではない。
- **AIまとめは下書き。最終判定は「この箱だけで仕事が言えるか」。**

## ■1027・0504・0330との関係

- **1027**：自社リサーチ全体の骨格（ターゲット → 実態 → 自社）。**今回**はその上のエステ部門・やりがい・続けやすさの肉付け。骨格を戻したあとに、仕事像がふわっ／重複で幹がぼやけると同型の戻り方になる。
- **0504**：求職者目線。**今回**も「店が言いたい専門説明」ではなく、セラピスト候補が自分の仕事を描けるかが軸。
- **0330**：意図ではなく結果。壁打ちでまとめたつもりでも、**セラピストは何をするかが伝わりにくいまま**なら直っていない。
