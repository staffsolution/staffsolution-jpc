# 育毛は頭皮ケアが鍵（フィードバック）

2026年9月7日

**フィードバック動画：** <a href="https://www.loom.com/share/2a4ca845ab664fd08add08ddb18bcff8" target="_blank" rel="noopener noreferrer">Loomで見る</a>

---

## ■分類（タグ）

- 育毛ブロック：**頭皮ケア中心**への理由が弱い
- 頭皮状態の確認 → 抜け毛・薄毛・ボリューム減の原因 → 頭皮お手入れしかない、の因果
- 「美容室にいるときだけ」問題ではない → **自宅ケア**まで含める
- 育毛目的の箱から**ヘッドスパ（疲れほぐし）を外す**（リラク側へ）
- メニューは**頭皮洗浄＋ニードル育毛**の2つ＋毎日のお手入れ
- 「髪と頭皮・育毛まで一緒に」の整理（店の考え方）
- 冒頭文の意味の伝わりにくさ・ジレンマ文の凹凸
- 0902・0901・0330の続き（意図ではなく結果）

---

## ■現状（Before）

- 0902で育毛スキャルプ→ニードル育毛の**進化の線**と名前の意味を直す方向が出た。その続きとして、育毛ブロック全体の**なぜ頭皮ケアか**を見ている。
- 「年齢とともに変化する髪の状態をもっとケアする頭皮…」系の冒頭は、**文章として意味が伝わりづらい**。言い換えが必要。
- 「美容師にも髪型を立てるだけでいいのだろうというジレンマがあった」付近は、**凹凸・間が空いた感じ**で、前の文とのつなぎが弱い。
- 「当店で育毛サービスを提供する際、頭皮のお手入れを中心に」「研究・専門家・書籍から学んだ結果、頭皮に力を入れることで根本解決できるようになった」までは書けているが、**ここが弱い**。
  - 頭皮の**状態を確認**して、
  - **どういう問題が起きているから髪が生えづらい／抜け毛・薄毛・ボリュームが減る**のか、
  - それを解決するには**頭皮のお手入れをやるしかない**（髪をいろいろいじっているだけではどうにもならない）、
  - という行き着きが足りない。
- 「頭皮のケアは目的に合わせて…」の箱は、**もっと肉が必要**。
- 「頭皮と育毛が美容室にいたときだけ良ければよい問題ではなかった」は、配置を変えて整理した方がよい。
  - 頭皮ケアが必要
  - 美容室に来たときだけでなく、**自宅でのお手入れも必要**
  - その両方をやれるメニューを作った → このメニュー、という流れが自然。
- その流れの中に**ヘッドスパ（疲れをほぐす）**が入っている。育毛（薄毛・抜け毛の悩み解決）と関係しないなら、**この箱から省き、リラク側へ移す**。育毛箱は**2メニューに絞る**。
- 「ヘッドスパをやってきたからこそ頭皮の問題が分かった」は**背景として入れてよい**が、**メニュー内容の列挙の中に入れるのは違う**。
- 残すメニューはおおむね **頭皮をきれいにする（頭皮洗浄）＋ニードル育毛**。加えて、**自宅ケアをどう提供しているか**を入れるとよい。
- 「髪と頭皮、育毛まで一緒に考えることは？」は、「育毛に関しては頭皮と日常のお手入れを一緒に考えるのが当店の考え方」の方がスッキリする。お客様の意見・目的に合わせて2つ＋毎日のお手入れ、でまとめ、そのあと**お客様の変化（結果）**へ。

---

## ■問題の本質（重要）

- 育毛ブロックの役割は「メニュー名を並べること」ではなく、**薄毛・抜け毛の悩みを持つ人が、なぜ頭皮ケアに行き着くか**を追えるようにすること。
- 「専門家から学んだ」「頭皮に力を入れた」は**店側の結論**。読み手が欲しいのは、その前段の**頭皮の状態 → だから髪に問題が起きる → 髪いじりだけではダメ → 頭皮お手入れ**の因果。
- 育毛の箱の目的は**薄毛・抜け毛の悩み解決**。ヘッドスパの「疲れほぐし」は別目的なので、同じ箱に置くと0901・0902で直した**メニュー差・箱の役割**が崩れる。
- 「美容室にいるときだけ」では足りない、は正しい。**店内ケア＋自宅ケア**まで一気に見せると、店の考え方が立つ。
- 0330の視点：**意図として「頭皮中心にした」と書いているつもりでも、結果として「なぜ頭皮か」が弱いと読み手は止まる**。意図の説明ではなく、結果で直す。

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| 頭皮ケアが育毛の鍵だと伝えたい | 「学んだ結果・根本解決」だけで、頭皮状態→原因→手入れしかない、が薄い |
| ジレンマや思いを冒頭に置きたい | 意味が伝わりづらい／凹凸で止まって見える |
| 育毛まわりのメニューをまとめたい | 疲れほぐしのヘッドスパが混ざり、育毛目的がぼやける |
| 店にいるとき以外も大事だと伝えたい | 「だけではない」の位置が弱く、自宅ケアまで一本でつながっていない |
| ヘッドスパ歴を強みにしたい | メニュー内容の中に背景が混ざる |
| 髪と頭皮・育毛を一緒に考えたい | 問いかけのまま止まり、店の考え方として整理しきれていない |

- 0901・0902で「メニュー差」「箱の役割」「名前の意味」は直す方向が出た。今回のズレは、その**前段の因果（なぜ頭皮か）**と、**育毛箱の境界（ヘッドスパを外す）**。
- 「前にヘッドスパの説明があるから足りる」ではなく、**この育毛箱だけ読んで悩み解決の線が通るか**で見る（0902パターンEと同型）。

## ■改善内容（What）

### 0. 進め方

```
【維持（0901・0902でOK方向）】
・スキャルプ／ニードルの名前の意味・メニュー差の意識
・お客様中心の構成
・ヘッドスパ歴は「背景」としては使える

【直す】
① 冒頭・ジレンマ文の言い換え（意味が通る文に）
② なぜ頭皮ケアか：状態確認→原因→髪いじりだけではダメ→お手入れ
③ 「店だけではない」→自宅ケア必要→両方できるメニュー、の順
④ 育毛箱からヘッドスパ（疲れほぐし）を外し、リラク側へ
⑤ メニューは頭皮洗浄＋ニードル育毛の2つ＋自宅ケアの提供の仕方
⑥ 「髪と頭皮・育毛」＝店の考え方として1文でまとめ、結果（お客様変化）へ
```

### 1. 冒頭・つなぎの文を直す

- 「年齢とともに変化する髪の状態をもっとケアする頭皮…」系は、**読み手が一読で意味が取れる文**に変える。
- 「髪型を立てるだけでいいのだろうというジレンマ」付近は、前の文との**間・凹凸**をなくす。ジレンマを残すなら、次の「だから頭皮に目を向けた」まで1本でつなぐ。

**イメージ（言い回しは店の実態に合わせる）：**

```
年齢とともに髪の状態は変わる。
見た目の髪型だけでは、根本の悩みに届かない。
　↓
頭皮の状態まで見る必要がある、という認識へ
```

### 2. 「なぜ頭皮のお手入れか」を厚くする（今回の本丸）

「専門家や書籍から学んだ」「頭皮に力を入れれば根本解決」だけでは弱い。**理由の箱**として、次を入れる。

**推奨の因果：**

```
頭皮の状態を確認する
　↓
抜け毛・薄毛・ボリューム減が起きている人に、
どんな頭皮の問題があるかを見る
　↓
髪をいろいろいじっているだけではどうにもならない
　↓
解決するには頭皮のお手入れをやるしかない、と行き着く
　↓
その道があると知り、提供できるようにしていった
```

- 「育毛の問題解決を頭皮のお手入れにした理由」として、**ここをもっと入れてよい**。
- 結論（根本解決できるようになった）は、上記の**あと**に置く。

### 3. 店内だけでなく自宅ケアまでつなぐ

「美容室にいたときだけ良ければよい問題ではなかった」は、次の順で整理する。

```
頭皮をケアする必要がある
　↓
美容室に来たときだけでなく、自宅でのお手入れも必要
　↓
その両方をやれるメニューを作った
　↓
（育毛目的の）この2つのメニュー＋自宅ケア
```

- この流れの方が自然。**「だけではない」を先に置き、メニュー列挙に着地**させる。

### 4. 育毛箱からヘッドスパを外す

| 置く場所 | 内容 |
|---|---|
| **育毛箱（今回）** | 薄毛・抜け毛の悩み解決。頭皮洗浄＋ニードル育毛＋自宅ケア |
| **リラク箱** | ヘッドスパの「疲れをほぐす」 |

- ヘッドスパをやってきたからこそ頭皮の問題が分かった、は**行き着きの背景**として1文なら入れてよい。
- **メニュー内容の説明の中にヘッドスパを混ぜない**。

### 5. メニュー2つ＋自宅ケア

```
【育毛メニュー】
1. 頭皮をきれいにする（頭皮洗浄）
2. ニードル育毛

【毎日のお手入れ】
自宅ケアをどういう形で提供しているか（短く具体）
```

- 0902の「ニードル・スキャルプの名前の意味」はそのまま活かす。
- 自宅ケアは「必要です」だけで終わらせず、**提供の形**（アドバイス／商品／フォロー等、実態に合わせて）を1段落。

### 6. 「髪と頭皮・育毛まで一緒に」の整理

問いかけのまま長くしない。店の考え方としてまとめる。

```
育毛に関しては、
頭皮と日常のお手入れを一緒に考えるのが当店の考え方。

お客様の意見・目的に合わせて
・メニュー2つ
・毎日のお手入れ
がある。

→ 結果：お客様の変化
```

- このあと**お客様の変化**へ進むとスッキリする。

### 7. セルフチェック（結果だけ）

| チェック | Yes / No |
|---|---|
| 冒頭を読んで、一読で意味が取れるか | |
| 「なぜ頭皮か」に状態→原因→髪いじりだけではダメ、があるか | |
| 店内だけでなく自宅ケアまで一本でつながっているか | |
| 育毛箱にヘッドスパ（疲れほぐし）が混ざっていないか | |
| メニューが頭皮洗浄＋ニードルの2つ＋自宅ケアになっているか | |
| 「一緒に考える」が店の考え方として1文で分かるか | |
| この箱だけ読んで、薄毛・抜け毛の人の悩み解決の線が通るか | |

## ■改善理由（Why）

- 「学んだ結果・根本解決」は店側の結論。読み手が止まるのは、その前の**頭皮の状態と悩みの因果**がないとき。0901の「洗浄後ベネフィットの理由」、0902の「名前の意味」と同型で、**なぜその答えか**を足す段階。
- ヘッドスパを育毛箱に残すと、箱の目的が「薄毛解決」と「疲れほぐし」の二重になり、0901・0902で直した**メニュー差・箱分離**が戻る。
- 「店にいるときだけではない」は正しい洞察。**自宅ケアの必要性→提供の形**までつなぐと、店の考え方が結果として見える。
- 「ヘッドスパ歴があるから分かった」は強みだが、**メニューの列挙に混ぜると読み手が迷子になる**。背景1文とメニュー説明を分ける。
- 0330：**「頭皮中心にしたつもり」ではなく、この箱を読んで薄毛の人が「だから頭皮か」と納得するか**で判断する。

---

## ■改善後イメージ（After）

- 冒頭が凹凸なく読め、髪型だけでは足りない → 頭皮、へ自然につながる。
- 「なぜ頭皮か」が、状態確認→抜け毛・薄毛・ボリューム減の原因→髪いじりだけではダメ→お手入れ、で追える。
- 店内だけでなく自宅ケアも必要 → 両方できるメニュー、が一本。
- 育毛箱は頭皮洗浄＋ニードル育毛＋自宅ケア。ヘッドスパの疲れほぐしはリラク側。
- 「頭皮と日常のお手入れを一緒に考える」が店の考え方として立ち、お客様の変化へ進む。

## ■やりがちなミス

- 「専門家から学んだ」「根本解決」だけで終わり、**頭皮の状態と悩みの因果**を書かない
- 冒頭・ジレンマを残したまま、**意味が通らない文**を放置する
- 育毛箱に**ヘッドスパ（疲れほぐし）**を戻して混ぜる
- 「店にいるときだけではない」と書いて、**自宅ケアの提供の形**まで書かない
- ヘッドスパ歴を**メニュー内容の中**にねじ込む
- 「髪と頭皮・育毛まで一緒に」を問いかけのまま長くし、**店の考え方1文**にまとめない
- 0902で直したニードル説明を消して、また**名前だけのメニュー列挙**に戻す
- 「別箱にヘッドスパがあるから」と、**この箱の境界**を曖昧にする

## ■他の案件でも使えるパターン

### パターンA：結論の前に「なぜその手段か」を置く

```
状態を見る
　↓
どんな問題が起きているか
　↓
表層の対処だけでは足りない
　↓
だからこの手段（頭皮お手入れ）
　↓
提供できるようにした
```

### パターンB：箱の目的でメニューを振り分ける

```
育毛箱 … 薄毛・抜け毛の悩み解決に効くものだけ
リラク箱 … 疲れほぐし・待ち時間・個室 など
背景の経歴 … メニュー列挙の外に1文
```

### パターンC：店内＋自宅で「続き」を見せる

```
店でやるケア
　↓
家でも必要
　↓
両方をやれる設計（メニュー＋毎日のお手入れ）
```

### パターンD：店の考え方は1文で言い切る

```
問いかけで長くしない
　↓
「〇〇と△△を一緒に考えるのが当店の考え方」
　↓
メニュー／ケアの数
　↓
お客様の変化
```

### パターンE：意図ではなく結果（0330・0901・0902共通）

「頭皮中心にしたつもり」「前に説明した」ではなく、**この箱だけ読んで悩み解決の線が通るか**で編集する。
