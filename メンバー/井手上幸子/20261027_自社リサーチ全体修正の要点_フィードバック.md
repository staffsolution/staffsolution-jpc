## ■分類（タグ）

- 自社リサーチ・全体修正（セラピスト募集）
- ITマインドマップサンプルに沿った骨格
- ターゲット設定の復帰（ぶれない幹）
- リラク／エステの実態 → 継続の難しさ
- リラク&Beauty美容室とは（問題を解く業種説明）
- 店の説明は補助・メインにしない
- 誕生秘話は簡潔／エステ要素も入れる
- 未経験でも大丈夫 → なぜ → 仕事内容の順
- 0602・0504・0330の続き（全体骨格・求職者視点・結果で見る）

---

## ■現状（Before）

- 今回は育毛・頭皮ケアの箱ではなく、**セラピスト募集向け自社リサーチの全体修正版**を見ている。
- 店の説明（どんな美容室か）は書けているが、**美容室の話がメイン**になってしまっている。募集はセラピストなので、読み手は「リラク／エステで働こうとしている人」に近い。
- **ターゲット設定**がマップから落ちている（以前の版にはあった。履歴を追うと途中から消えている）。ターゲット無しで店の説明・メニュー説明が進むと、誰に何が魅力かが追えない。
- 一般的なリラクゼーションサロン／エステティックサロンの**実態（継続の難しさ）**と、「だからリラク&Beautyという選択肢がある」までの橋が、全体の主線になっていない。
- 誕生秘話や店の成り立ちの説明が長く、**悩み→解決の業種説明**より店自慢・店説明に寄っている。
- 「どんな仕事をするか／3つの専門部門」の前に、**未経験でも始められる／なぜできるか**が弱いと、仕事内容が唐突に見える。
- 骨組みがぶれたまま肉付けすると、箱を増やしても全体がめちゃくちゃになる（今回、運営側で骨格を並べ直した）。

---

## ■問題の本質（重要）

- この自社リサーチの役割は「うちの美容室の紹介」ではない。**セラピスト候補のターゲットを頭に入れたうえで、その人が検討している業界の実態 → 継続しづらい理由 → 逃れる選択肢としてのリラク&Beauty → その業種／会社で何ができるか**を一本で追えるようにすること。
- 店の説明はあってよい。ただし**メインにしてはいけない**。メインはターゲットに対する会社の特徴と、一般のリラク／エステとの違い。
- 特殊な業態なので「業種説明＝会社説明」でまとめてよい。それでも順番は、**ターゲット → 実態 → 解決する業種**から崩さない。
- 肉付けの前に、**骨格がぶれていないか**を先に見る。骨格が崩れたままAIで直すと、また美容室説明メインに戻る。

---

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（マップ・文章に起きていること） |
|---|---|
| 店の独自性を伝えたい | 美容室の説明が主線になり、セラピスト募集の流れが弱くなる |
| 全体を修正したい | ターゲット設定が落ちたまま、枝だけ直している |
| リラク&Beautyを説明したい | 実態（継続の難しさ）の前に店の話が来て、解決策が唐突になる |
| 誕生秘話を丁寧に書きたい | 説明が長く、悩み→解決の橋より店の経緯が厚い |
| 仕事内容を紹介したい | 未経験でも大丈夫／なぜ、の前に仕事の箱が来る |
| 特殊だから詳しく書く | ITサンプルの幹（ターゲット→実態→自社）から外れる |

- 「特殊だから店の説明が必要」は正しい。ただし**必要＝メイン**ではない（0330：意図ではなく結果）。

---

## ■改善内容（What）

### 0. 進め方

```
【維持】
・店の説明があること自体（特殊業態の補助として）
・リラクだけでなくエステ要素も扱う方向
・全体を一度に見ながら直す姿勢

【直す（今回の本題）】
・ITマインドマップサンプルに戻す（セラピスト募集の幹）
・ターゲット設定を戻し、ぶれない幹にする
・リラク／エステの実態 → 継続の難しさ → リラク&Beautyとは、の順
・店説明をメインから外す（ターゲットに響く内容へ調整）
・誕生秘話は簡潔／悩みの列挙過多を削る
・未経験でも大丈夫 → なぜ → 仕事内容（3部門）の順
・大きな3ブロックを先に通す（細部は後）
```

### 1. 骨格をこの順番に固定する（ぶれない）

セラピスト募集の自社リサーチとして、次の順を正とする。

```
① ターゲット設定（セラピスト候補）
② 業種の実態（リラクゼーション／エステの継続の難しさ）
③ リラク&Beauty美容室とは（その問題を解く選択肢・業種＝会社説明で可）
   ・誕生秘話（簡潔）
   ・3つのケアが生まれた理由
   ・安心して働ける4つの理由
④ 未経験でも働き始められる／なぜできるか
⑤ どんな仕事をするか（3つの専門部門など）
⑥ 勤務地など確認事項
```

①が落ちたら②③が「店のパンフ」になる。①を頭に入れた状態で②③を書く。

### 2. ターゲット設定を戻す

- 以前の版にあったターゲット情報を、**削らず幹に戻す**。
- 細かい周辺情報は省いてよい。残すのは「誰向けの募集か」が分かる核だけ。
- これ以降の箱は、すべて「このターゲットが読むとどう感じるか」で判定する。

### 3. 実態 → 解決の業種、の橋を主線にする

```
① このターゲットが検討しがちな業界（リラク／エステ）
② そこで働くと、継続が難しい実態がある（注意）
③ そこから逃れる選択肢として、リラク&Beautyという道もある
④ だから、その業種／会社が何かを説明する
```

「うちはこんな美容室です」から入らない。**問題のあとに答え**を置く。

### 4. 店の説明は補助にする（AIへの直し指示の軸）

全体修正するときは、次の観点で文章を寄せる。

| 弱い（今起きやすい） | 強い（寄せたい） |
|---|---|
| 美容室がメインの説明 | ターゲット（リラク／エステ志望）に響く説明 |
| 店の独自性の羅列 | 一般のリラク／エステとの違い |
| メニュー・店紹介が厚い | 継続しづらい実態を解く理由が厚い |

「他ではなかなかない業種」でも、自慢ではなく**ターゲットの逃げ道**として書く。

### 5. 誕生秘話・経緯は簡潔にする

- 約10年かけて形にしてきた、等の核は残してよい。
- 悩みの列挙や店説明の重複は削る。「本当に簡潔に」で足りる。
- リラクだけでなく、**エステに関することも**「とは」の箱に入れる（リラクだけに閉じない）。

### 6. 未経験 → なぜ → 仕事内容、の順にする

```
① 未経験の方でも働き始められる
② なぜ未経験でもできるのか
③ そのうえで、どんな仕事をするか（3つの専門部門など）
```

仕事紹介を先に置くと、「自分でもできるか」が分からないまま詳細に入る。

### 7. 大きな3ブロックを先に通す

細部の色・文言より先に、次の3つがつながっているかを見る。

1. ターゲット設定  
2. 実態（継続の難しさ）→ リラク&Beautyとは  
3. 未経験の安心 → 仕事内容  

ここが通れば、肉付けしても全体が崩れにくい。骨組みがぶれると肉付けがめちゃくちゃになる。

---

## ■改善理由（Why）

- セラピスト募集なのに美容室説明が主線だと、読み手（リラク／エステ志望）の頭に入らない（0504・0330と同型）。
- ターゲットが落ちると、比較も魅力も「店側が言いたいこと」だけになり、誰向きかが消える。
- 実態→解決の順にすると、リラク&Beautyが売り込みではなく「逃げ道」として読める。
- 特殊業態でも、ITサンプルの幹（ターゲット→実態→自社）を守ると、箱が増えても迷子にならない。
- 誕生秘話を短くすると、経緯の説明が因果の橋を奪わない。
- 未経験の安心を仕事の前に置くと、「自分ごと」になってから詳細が読める。
- 骨格を先に通すと、AI壁打ちも「美容室パンフ化」に戻りにくい。

---

## ■改善後イメージ（After）

- マップだけ見て、「誰向けか → リラク／エステの実態 → だからリラク&Beauty → 未経験でも大丈夫／なぜ → 仕事内容」が通る。
- 店の説明はあるが、メインではない。ターゲットに対する魅力と比較が主線。
- ターゲット設定が幹に戻り、以降の箱がその人向けに揃っている。
- 誕生秘話は短く、エステ要素も「とは」に入っている。
- 仕事の箱の前に、未経験でもできる理由がある。
- 大きな3ブロックがつながったあとで、細部を詰めている。

---

## ■やりがちなミス

- 特殊だからと、美容室の説明をメインにしてしまう。
- 全体修正なのに、ターゲット設定を戻さず枝だけ直す。
- 実態（継続の難しさ）の前に、店の誕生秘話やメニュー説明を厚くする。
- リラクだけの説明に閉じ、エステ志望への橋を書かない。
- 誕生秘話・悩みを丁寧に書きすぎて、解決の業種説明が後景になる。
- 「どんな仕事か」を先に置き、未経験の安心となぜを後にする。
- ITサンプルの幹を見ずに、自前の美容室ストーリーで組み直す。
- 骨組みがぶれたままAIに「うまく書いて」と頼み、また店説明メインに戻る。
- 「意図ではターゲット向け」と言い、マップ上では店の話が先、を結果として見ない（0330）。

---

## ■他の案件でも使えるパターン

- **募集の自社リサーチは、店紹介ではなくターゲット起点。** 誰向けか → その人が検討する業界の実態 → 自社という選択肢。
- **店の説明は補助。メインにしてはいけない。** 特殊でも同じ。
- **比較は「一般の同業のきつさ」と並べてから、自社の逃げ道を出す。**
- **未経験訴求は、仕事内容の前に「大丈夫／なぜ」を置く。**
- **骨組みがぶれたら肉付けしない。** 大きな3ブロックを先に通す。
- **サンプルの幹を正とし、自前の店ストーリーで幹を置き換えない。**

## ■一言まとめ（本質）

👉 **セラピスト募集の自社リサーチは、美容室説明をメインにしない。ターゲット設定を幹に戻し、リラク／エステの実態 → 継続の難しさ → リラク&Beautyという選択肢 → 未経験でも大丈夫／なぜ → 仕事内容、の順で骨格を固定してから肉付けする。**

## ■0602・0504・0330・1019との関係

- **0602**：全体再構成。**今回**も全体の骨格を戻す回。箱の中身より、マップ全体の主線。
- **0504**：求職者目線。**今回**はセラピスト候補の頭に入るかが判定軸（店側の説明力ではない）。
- **0330**：意図ではなく結果。特殊だから詳しく書いたつもりでも、**マップだけ見てターゲット→実態→自社が通るか**で見る。
- **1019**：頭皮ケア青い箱の続きではない。題材は育毛から自社リサーチ全体へ戻るが、**読み手より店の話が先／なぜが弱い**は同型。
