## ■分類（タグ）

- ヘッドスパ／育毛スキャルプの説明改善
- 専門用語の平易化（小学校高学年レベル）
- 一文の多要素分解（なぜ→どうなる）
- 洗浄後のベネフィット追加
- 毎日ケアの「なぜ大事か」
- フェイシャルの原点→20年の変化→現在の接続
- 0829マインドマップ微調整の続き
- 0330：意図ではなく結果／一文に複数要素を混ぜない

---

## ■現状（Before）

- 0829の指摘を踏まえ、追加点を含めブロックを**シンプルにまとめ直した**段階。全体は以前より良く、今回は**微調整**。
- 「朝起きても疲れが取れていない」「疲れて見える」などの共感は、方向として良い。深刻さは「良くなったらいいな／こんなもんだろう」寄りで、過度に煽らなくてよい。
- 頭皮・毛根をきれいにする商材との出会い → 育毛スキャルプマッサージとして提供、までは良い。
- 足りないのは、**毛根・頭皮をきれいにすると「どうなるのか」（ベネフィット）**。洗浄の事実で止まりやすい。
- 「頭皮を洗浄して髪の土台となる頭皮環境を整え、髪毛サイクルを正常に整え、次に成長する髪を育てる技術」は、**一文に複数要素が混ざり、専門的すぎる**。
- 「普段の家での手入れの仕方も教える」「毎月通うと徐々に土台ができる」「当店のお客様に合うケアだけ取り入れる」「個室・最長時間でも追加料金なし」は**めちゃくちゃ良い**。
- フェイシャル側で、**20年以上かけて…の直後にフェイシャルが突然出る**。「20年以上前の原点が何か」「そこからどう変化したか」が抜けて飛んで見える。

---

## ■問題の本質（重要）

- 読み手が知りたいのは技術名ではなく、**洗浄したら自分の髪・頭皮に何が起きるか**。商材との出会いのあとに、ベネフィットを必ず置く。
- **専門知識をそのまま書くと、店側には正しくても読み手には伝わらない。** 目安は「小学校高学年にもわかる言葉」。意図（正確に説明したい）と結果（読めない）は別物。
- **一文に「土台」「サイクル正常化」「次の髪を育てる」を詰めない。** なぜ土台が大切か → サイクルを整えるとは何か → 洗浄するとそれが整う → だから次の髪が育ちやすい、と**2〜3文に分解**する（0330・0829と同型）。
- 毎日ケア・毎月来店は良い。ここに**「1回だけでは意味が薄い／日常ケアが大事」**のなぜを足すと、教え方の価値が立つ。
- フェイシャルは**原点（何をやろうとしたか）→ 20年以上の変化（シンプルに）→ 今やっていること**の一本線が要る。途中が抜けると「いきなりフェイシャル」に見える。

---

## ■ズレ（思考 or 設計）

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| 頭皮洗浄の技術を正確に伝えたい | 一文が専門的・多要素で、読み手が止まる |
| 商材との出会いがきっかけだと書きたい | 洗浄後に「どうなるか」が抜け、ベネフィットが弱い |
| 毎日ケア・毎月通いの良さを出したい | 中身は良いが、「なぜ日常ケアが大事か」が薄い |
| 20年以上の実績を出したい | 原点と変化の説明が抜け、フェイシャルが突然出る |

- 「後で詳しく／別の箱に書いてある」ではなく、**いま読んでいるこの文が小学校高学年に通じるか**で判断する（0330：意図ではなく結果）。
- 店側には当たり前の用語でも、求職者・初めての読み手には初めて。**自分視点の省略**が出やすい（0829と同じ）。

---

## ■改善内容（What）

### 0. 進め方

全体は大きく直さない。**ヘッドスパ説明の平易化・分解**と、**フェイシャルの原点→変化→現在の接続**を直す。良い部分（毎日ケア・毎月・合うケアだけ・個室時間）は残す。

### 1. 頭皮洗浄：出会い → どうなるか → だからこの施術名

```
頭皮・毛根をきれいにする商材と出会った
　↓
頭皮を洗浄すると、こうなる（ベネフィットを書く）
　↓
だから育毛スキャルプマッサージとして提供するようになった
```

「きれいにする」で止めず、**洗浄によって何が良くなるか**を一文入れる。

### 2. 専門文を「小学校高学年」向けに分解する

今の一文（例）：

```
頭皮を洗浄してこれからの髪の土台となる頭皮環境を整え、
髪毛サイクルを正常に整え、次に成長してくる髪を育てる技術
```

**直し方：**

1. AIに「小学校高学年にもわかる言葉に翻訳して」と渡してよい
2. 要素を**2〜3文**に分ける

**分解の骨格：**

```
① 髪の土台となる頭皮環境が、なぜ大切なのか
② 「髪のサイクルを正常に整える」とはどういうことか
③ 洗浄するとそれが整う → 次に生えてくる髪を育てやすくなる
```

専門用語を残すなら、直後に**やさしい言い換え**を付ける。一文に三つ以上の専門概念を並べない。

### 3. 毎日ケア・毎月来店（良い部分の強化）

残す：

- 普段の家での手入れの仕方も教える
- 来店時は今の状態をきれいに見せるセット
- 毎月通うと当日の相談ができ、徐々に頭皮が良くなり、髪が生える土台ができる
- 当店のお客様に合うケアだけ取り入れる（合わないものは入れない）
- 個室でスペシャルな体験／最長時間でも追加料金なし（すぐ帰らされない）

足す：

```
1回やっただけではあまり意味がない
　↓
普段の毎日のお手入れが大事
　↓
そのやり方もお伝えする
```

「教える」だけでなく、**なぜ毎日ケアが必要か**を短く先に置く。毎月の話は、もう少し平易な言葉に整える程度でよい。

### 4. フェイシャル：原点 → 20年の変化 → 今

飛びをなくす並び：

```
20年以上前の原点
　（例：顔の血流マッサージ。メーカー指導者・美容師などから考え方と形を学んだ）
　↓
そこから研究・変化してきた（複雑な過程は書かなくてよい。最初はこう → 今はこう、で十分）
　↓
現在のフェイシャル（いま何をして、どうなっているか）
```

- 「20年以上かけて」の**直後に現在のメニュー名だけ**を置かない。
- すでにマップ内の別箱にある「原点」の内容は、**この時間軸の箱へ移してつなぐ**。
- 複雑な変遷は不要。**最初 → 変化 → 今**が読めればよい。

### 5. セルフチェック（結果だけで見る）

書き直したら、意図の説明はせず、次だけ確認する。

| チェック | Yes / No |
|---|---|
| 頭皮洗浄のあとに「どうなるか」があるか |
| 専門文が小学校高学年でも追えるか |
| 一文に要素が3つ以上詰まっていないか |
| 毎日ケアに「なぜ大事か」があるか |
| フェイシャルが「原点→変化→今」で途切れないか |

---

## ■改善理由（Why）

- ベネフィットがないと、商材との出会いは**店のストーリー**で終わり、読み手の「だから自分に何がいいのか」に届かない。
- 専門文の一文化は、0330・0829で繰り返し出ている**「複数要素を一度にまとめようとする」**と同じズレ。分解すると因果が追える。
- 「小学校高学年」は厳しすぎる基準ではなく、**自分視点の省略を外すためのものさし**。
- 毎日ケアのなぜは、教え方の価値を「サービス項目」から「継続しないと効果が出ない理由」に変える。
- フェイシャルの時間軸がつながると、「20年以上」が実績として効く。途切れると数字だけ浮く。

---

## ■改善後イメージ（After）

- ヘッドスパブロック：出会い → 洗浄するとこうなる → だからこの施術、の順で読める。
- 技術説明が、やさしい言葉の**短い文が2〜3本**になり、初めての人でも止まらない。
- 毎日ケア・毎月・合うケアだけ・個室時間は残り、毎日ケアには「1回だけでは足りない」が先にある。
- フェイシャルは、原点の学び → 20年の変化 → 今の施術、が一続きで読める。
- 全体は微調整のまま、**読み手視点の穴**だけが埋まっている。

---

## ■やりがちなミス

- 技術を正確に書こうとして、**一文に用語を詰め込む**（意図は正しいが結果は読めない）。
- 「洗浄する」で止め、**どうなるか**を書かない。
- 専門文をAIに渡さず、自分の言葉のまま残す。
- 毎日ケアを「教える」だけで、「なぜ日常が大事か」を省略する。
- フェイシャルの原点が別箱にあるのに、**時間軸の箱へ移さず**「20年以上」だけ先に置く。
- 指摘に対し「意図としてはこう考えて書いた」と返し、**結果の読みやすさ**を見ない（0330）。

## ■他の案件でも使えるパターン

### パターン1：出会い・事実のあとに必ずベネフィット

```
きっかけ・商材・技術
　↓
それによってどうなるか（読み手の得）
　↓
だからこのメニュー名／提供
```

### パターン2：専門文は「高学年翻訳」＋2〜3文分解

一文に「なぜ／何／だから」が三つ以上入ったら分解する。AI翻訳を使ってよい。

### パターン3：教える内容には「なぜ教える必要があるか」を先に置く

```
1回だけでは効果が続きにくい
　↓
毎日の手入れが大事
　↓
そのやり方も伝える
```

### パターン4：実績年数は「原点→変化→今」とセット

「○年以上」単体では飛ばない。何から始まり、どう変わり、今何をしているかを短くつなぐ。

### パターン5：意図ではなく結果でチェックする

「正しく書いたか」ではなく、「初めての人が止まらず読めるか」で Yes/No する。
