## ■分類（タグ）

- 育毛ブロック：発毛サイクル文の**重複**
- 頭皮の状態を見る → **毛根** → 抜けづらい／ちゃんと育つ状態、の抜け
- 「考えた」「整える」など**動詞が抽象**で具体が分からない
- ヘッドスパ土台 → 育毛スキャルプへ、の**何を引き継いだか**が無い
- カテゴリ名「頭のケア」→「頭皮のケア」
- 対象者の切り口（硬さ・状態／ベタつき・汚れ）が**自分で選べない**
- 事前の頭皮チェック → メニュー選択、の導線
- 「針のようなスタンプ」「考えて行う」の分かりにくさ
- 汚れ説明：酸化より**洗い方・シャンプー**の因果
- 0907・0902・0330の続き（意図ではなく結果）

---

## ■現状（Before）

- 0907で「なぜ頭皮か」「育毛箱からヘッドスパを外す」「洗浄＋ニードル＋自宅ケア」の方向が出た。今回は、修正後の赤文字（ヘッドスパをリラク側へ移したあとの、頭皮ケア3つの箱）を見ている。
- ヘッドスパをリラク側へ外したこと自体は**OK方向**。問題は、残った育毛・頭皮ケア側の**因果と具体**。
- 「髪には生えて育って抜けて、また新しい髪へつながる流れがある」「今見えている髪だけでなく、次に育っていく髪まで考えてケアする」は方向として正しいが、**同じことを言い直している段落が続く**。読み手は「また同じ話？」で止まる。
- 「髪が生えて育っていく頭皮の状態を見ていく必要がある」「だから髪が育つ土台である頭皮からお手入れ」も、上と**同じ結論の繰り返し**になっている。
- そのあと「長年取り組んできたヘッドスパを土台に、毛根・頭皮のことを考えた育毛スキャルプへ」と進むが、ここで**いきなり「毛根」が出る**。前段に毛根の説明がない。
- 頭皮の状態を見ると、**どうすべきか／毛根がどうなると抜けづらい・ちゃんと育つのか**が載っていない。抜けづらい状態 → ボリュームが増える、までつなぐ線が薄い。
- 「頭皮のことを考えた」「頭皮を整える」は、**何を考え・何を整えるのか**が分からない。「考えた」で止まると読み手が「何？」になる。
- ヘッドスパを土台にした、と書いているが、**ヘッドスパの何を取り入れて育毛スキャルプができるようになったのか**が抜けている。
- カテゴリが「頭のケア」だと広い。「頭皮のケア」に揃えた方が箱の役割がはっきりする。
- 「頭皮の硬さや状態が気になる方」「頭皮のベタつきや汚れが気になる方」は、**お客様が自分で判断できるか**が怪しい。硬さ・状態の意味も曖昧。
- ニードル側の「細かな針のようなスタンプ」はスタンプが分からない。「考えて行う」も抽象。汚れの「積み重なって酸化する」は、毎日シャンプーしている人ほど「なんで？」になりやすい。

## ■問題の本質（重要）

- 育毛ブロックの役割は「頭皮が大事です」を繰り返すことではなく、**頭皮を見ると何が分かり、毛根がどうなれば抜けづらく・ちゃんと育ち、だからどのメニューで何をするか**を一本で追えるようにすること。
- 「発毛サイクル」「次の髪まで考える」「頭皮からお手入れ」は**同じ結論を別の言い方で並べている**状態。0907で足した「なぜ頭皮か」が、言い換えの重複に戻っている。
- 「毛根」は重要な中間概念。**出る前に、頭皮の状態 → 毛根の状態 → 抜けづらい／育つ、を置かないと、名前だけが突然降ってくる**。
- 「考えた」「整える」「考えて行う」は店側の意図の言葉。読み手が欲しいのは**何を洗浄する／何を刺激する／どう変わるか**の結果。
- メニュー対象の切り口は、**お客様が自分で当てはめられる言葉**か、**事前チェックで示してから選ばせる**かのどちらかがないと機能しない。
- 0330の視点：**意図として「頭皮と毛根を考えた」つもりでも、結果として「何をするか・なぜ毛根か」が読めないなら直す対象**。意図の説明ではなく、結果で見る。

| 意図（考えていること） | 結果（文章に起きていること） |
|---|---|
| 発毛サイクルと次の髪まで伝える | 同じ結論が複数段落で重複している |
| 頭皮が土台だと伝えたい | 「見ていく必要がある」「頭皮からお手入れ」の言い換えで止まる |
| 毛根まで考えた育毛だと示したい | 毛根が突然出る。頭皮→毛根→抜けづらい／育つ、が無い |
| ヘッドスパ歴を土台にしたい | 「何を引き継いだか」が無く、土台という言葉だけ |
| 頭皮を整えるメニューだと伝えたい | 「考えた」「整える」で具体（洗浄・刺激など）が出ない |
| 硬さ／ベタつきでメニューを分けたい | お客様が自分で状態を判断できない切り口になっている |
| ニードルの施術を説明したい | 「スタンプ」「考えて行う」で映像が浮かばない |
| 汚れが落ちない理由を伝えたい | 「酸化」で止まり、洗い方・シャンプーの因果が弱い |

- 0907で直した「なぜ頭皮か」の厚みを、今回は**毛根までの一段**と**メニュー具体**に落とす段階。重複を削らないと、厚みがまた「同じ話の繰り返し」に見える。
- 「前に書いたから分かる」ではなく、**この箱だけ読んで頭皮→毛根→メニューが通るか**で見る（0902パターンE・0907と同型）。

## ■改善内容（What）

### 0. 進め方

```
【維持（0907でOK方向）】
・ヘッドスパ（疲れほぐし）をリラク側へ外したこと
・頭皮洗浄＋ニードル＋自宅ケアの箱の骨格
・発毛サイクル・「次に育つ髪」まで見る視点（中身は1回だけ）

【直す】
① 発毛サイクル〜頭皮お手入れの重複を1本に削る
② 頭皮の状態を見る → 毛根 → 抜けづらい／ちゃんと育つ、を入れる
③ 「考えた」「整える」を、洗浄・刺激など具体動詞に変える
④ ヘッドスパ土台＝何を引き継いだかを1文で足す
⑤ カテゴリ名を「頭皮のケア」に揃える
⑥ 対象者：事前チェックで状態を示してから選ばせる／切り口を具体化
⑦ ニードル表現・汚れ説明を、映像が浮かぶ因果に直す
```

### 1. 発毛サイクル〜頭皮お手入れを1回にまとめる

同じことを3回書かない。**1ブロックで結論まで着地**させる。

**推奨の並び（重複なし）：**

```
髪には、生えて育って抜けて、また新しい髪へつながる流れがある
　↓
今見えている髪だけでなく、次に育っていく髪まで見る必要がある
　↓
髪が生えてくるのは頭皮からなので、頭皮の状態を良くする
```

- 「だから頭皮からお手入れ」「土台である頭皮」は、上の**最後の1行に吸収**する。別段落で言い直さない。

### 2. 毛根の一段を入れる（今回の本丸）

「頭皮の状態を見ていく必要がある」で止めない。**見ていくと何が分かるか**まで書く。毛根はこの位置で初めて出す。

**推奨の因果：**

```
頭皮の状態を見る
　↓
毛根がどうなっているかを見る
　↓
毛根がどうなると、抜けづらい状態になるか
毛根がどうなると、細い髪ではなくちゃんと育つか
　↓
その状態ができると、抜けにくくなり、ボリュームが増えていく
　↓
その状態を作るために、育毛スキャルプ（頭皮洗浄＋ニードル）がある
```

- 「いきなり毛根」にしない。**頭皮を見る → その先に毛根**、の順。
- 「抜けづらい」だけでなく、**ちゃんと太い髪に育つ**まで書くと、ニードル側の「これから生えて育っていく髪」とつながる。

### 3. 「考えた」「整える」を具体にする

| 弱い（今） | 強くする（例・実態に合わせる） |
|---|---|
| 頭皮のことを考えた | 頭皮の汚れを洗浄する／頭皮をやさしく刺激する |
| 頭皮を整える | 頭皮についた汚れを落とす／頭皮の状態をほぐす など、何をどうするか |
| 考えて行う | （削る）これから生えて育つ髪が〇〇になる、と結果で書く |

- 「育毛スキャルプ」側は、おおむね **頭皮の汚れを洗浄する** が分かりやすい着地。
- 「最も相談の多いのは抜け毛や頭皮」「現在の根拠も…」など、**前後とつながらない一文は省く**。

### 4. ヘッドスパ土台＝何を引き継いだか

「長年取り組んできたヘッドスパを土台に」だけで終わらせない。

```
長年のヘッドスパで培った〇〇（例：頭皮の見方／ほぐし／状態の読み方）を活かし、
育毛スキャルプ（洗浄＋ニードル）へ移行した
```

- 背景として1文でよい。**メニュー説明の中にヘッドスパを戻さない**（0907と同じ境界）。

### 5. カテゴリ名とメニュー対象

- 「頭のケア」→ **「頭皮のケア」** に揃える（箱の中身が頭皮だから）。
- 「硬さや状態が気になる方」は、**どんな状態か**を具体にするか、切り口を見直す。硬さだけだと意味が取りにくい。
- 「ベタつきや汚れが気になる方」は方向として分かりやすいが、**自分では分からない人**がいる前提を置く。

**導線の推奨：**

```
事前に頭皮の状態をチェックし、お客様に今の状態を示す
　↓
ベタつき・汚れがある／硬い・ほぐしが必要 などが見える
　↓
そのうえでメニューを選んでもらう
```

- チェック無しで「気になる方」だけだと、選べない人が残る。

### 6. ニードル表現を映像にする

| 弱い | 強い |
|---|---|
| 細かな針のようなスタンプ | 細かい針で頭皮をやさしく刺激する |
| これから生えて育っていく髪まで考えて行う | これから生えて育っていく髪が〇〇になる（具体の変化） |
| 今ある髪だけではなく…（重複なら） | 省いてよい（上の発毛サイクルと重複するため） |

- 「考えて行う」は削り、**どうなるのか**を具体語で書く。

### 7. 汚れ説明：酸化より洗い方・シャンプー

「積み重なって酸化する」だけだと、毎日シャンプーしている人ほどつながらない。

**推奨の因果：**

```
市販シャンプーでも、洗い方を間違えると汚れは落ちにくい
　↓
どんなシャンプーを使うかも大事
　↓
よいシャンプーでも、洗い方が違うと汚れは落とせない
　↓
汚れが残り、頭皮の状態が悪くなりやすい
　↓
だから、シャンプーの仕方・洗い方・お手入れを美容師と確認し、自宅でも続けられるようにする
```

- 「酸化」は残すなら、**洗い方・シャンプーのあと**の補足程度にする。主役にしない。

### 8. セルフチェック（結果だけ）

| チェック | Yes / No |
|---|---|
| 発毛サイクル〜頭皮お手入れが、言い換え重複なしで1本か | |
| 毛根が「突然」ではなく、頭皮のあとに因果で出ているか | |
| 抜けづらい／ちゃんと育つ → ボリューム、までつながっているか | |
| 「考えた」「整える」が、洗浄・刺激など具体になっているか | |
| ヘッドスパ土台で「何を引き継いだか」が1文あるか | |
| カテゴリが「頭皮のケア」になっているか | |
| メニュー選択の前に、状態チェックの導線があるか | |
| スタンプ／考えて行う／酸化だけで止まっていないか | |
| この箱だけ読んで、頭皮→毛根→メニューが通るか | |

## ■改善理由（Why）

- 「頭皮が大事」は0907で方向が出た。今回止まっているのは、その先の**毛根まで含む因果**と、**メニューで何をするかの具体**。結論の言い換えを増やしても説得力は増えない。
- 「毛根」は専門語に近い。**名前を出す前に、頭皮を見ると毛根の状態が分かり、それが抜け・育ちに効く**と置かないと、読み手はついていけない。
- 「考えた」「整える」は意図の言葉。結果として文章を読む人は**行動と変化**しか追えない（0330：意図ではなく結果）。
- ヘッドスパ歴は強みだが、「土台」だけだと0907と同じく**経歴がメニューの代わりになる**。何を引き継いだかを1文で切り分ける。
- 対象者の切り口は、店側の分類ラベルではなく、**お客様が選べる情報**になって初めて機能する。選べないなら事前チェックが必要。
- 汚れの説明は「なぜ落ちないか」への答え。酸化より、**洗い方・シャンプー**の方が日常の体験とつながりやすい。

## ■改善後イメージ（After）

- 発毛サイクル〜次の髪〜頭皮お手入れが、**重複なしの1本**で読める。
- 頭皮の状態を見る → 毛根 → 抜けづらい／ちゃんと育つ → ボリューム、まで追える。
- 「考えた」「整える」が消え、**洗浄する／刺激する**など具体になっている。
- ヘッドスパ土台で、**何を活かして育毛スキャルプへ移ったか**が1文で分かる。
- カテゴリが「頭皮のケア」。メニューは、状態チェックのあとに選べる。
- ニードルは「細かい針でやさしく刺激」。汚れは洗い方・シャンプーの因果で自宅ケアへ着地する。

## ■やりがちなミス

- 「次の髪まで」「頭皮が土台」「頭皮からお手入れ」を**別段落で言い直す**
- 毛根を名前だけ突然出し、**頭皮→毛根の一段**を飛ばす
- 「抜けづらい」まで書いて、**ちゃんと育つ／ボリューム**を飛ばす
- 「考えた」「整える」「考えて行う」のまま、**何をするか**を書かない
- 「ヘッドスパを土台に」だけで、**何を引き継いだか**を書かない
- 育毛箱にヘッドスパ（疲れほぐし）を**戻して混ぜる**
- 「硬さや状態が気になる方」のまま、**お客様が選べない切り口**を放置する
- 「スタンプ」「酸化」など、**映像・日常体験につながらない語**を残す
- つながらない一文（相談が多い、根拠も…）を**省かずに残す**

## ■他の案件でも使えるパターン

### パターンA：同じ結論の言い換えを1本に削る

```
サイクルの説明
　↓
だから次の髪まで見る
　↓
だから頭皮を見る
（ここで止める。同じ結論を別段落で繰り返さない）
```

### パターンB：中間概念（毛根）は「突然出さない」

```
見えるもの（頭皮の状態）
　↓
中間（毛根がどうなっているか）
　↓
結果（抜けづらい／ちゃんと育つ／ボリューム）
　↓
手段（洗浄・ニードル）
```

### パターンC：意図動詞 → 結果動詞

```
考えた／整える／考えて行う
　↓
洗浄する／刺激する／〇〇になる
```

### パターンD：選べない切り口にはチェックを前に置く

```
自分では分からない状態
　↓
事前に状態を示す
　↓
そのうえでメニューを選ぶ
```

### パターンE：汚れ・習慣の説明は日常体験から

```
毎日シャンプーしているのに落ちない、と言われそうな説明は弱い
　↓
洗い方・使うシャンプー、の因果に置き換える
```

## ■0907・0902・0330との関係

- **0907**：なぜ頭皮か、育毛箱からヘッドスパを外す、洗浄＋ニードル＋自宅ケア。**今回**はその続きで、**毛根までの一段**と**具体動詞・対象者導線・汚れ説明**を肉付けする。ヘッドスパ外し自体はOK。
- **0902**：メニュー差・名前の意味・箱の境界。**今回**の「スタンプが分からない」「考えて行う」は、名前・説明が抽象で差が見えない同型。
- **0330**：**意図（考えた・土台にした）ではなく、結果として因果と具体が読めるか**で直す。同じ指摘の繰り返しにならないよう、今回は「毛根の一段」と「動詞の具体化」に焦点を絞る。
