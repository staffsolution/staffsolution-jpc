## ■現状（Before）

- 0716で「大項目の箱を正しく切る」「なぜ個室・なぜ骨盤チェア」を指摘した続き。今回は「3の幹」までを見ていく段階。
- 「美容室の流れの中で受けられる短時間メニュー」の箱の中に、「全体の仕組み」が入っている。箱と中身が合っていない。
- 「リラクメニューのみ」側に、ほぼ美容がない内容（セットメイドの髪のお直し中心）が混在し、パッと見で「リラクだけ／美容＆リラク」の差が掴みにくい。
- 本格リラク（施術の前・後）と、待ち時間に受ける短時間メニューが、同じ並びで見え、違いが一瞬で分からない。
- カラーはシャンプー台、パーマは美容椅子、など場所の違いは書いてあるが、「だからできる施術が違う」理由が足りない。見ればわかる前提になっている。
- ヘッドスパがカラーの流れでできないのか／別メニューなのかなど、「なんで？」が残る箇所がある。
- 個室・骨盤チェアまわりは、メリット列挙寄り。顧客層（忙しい世代・年齢）→ 設備選定 → 結果、の因果が弱い。一般ベッドとの比較も薄い。
- 「中腰が続きにくい」「一重まぶたは目に負担が少ない」など、イメージがつきにくい／無理やり感のある表現が残っている。

---

## ■問題の本質（重要）

- 今回の本質も文章のうまさより先に、カテゴリの箱が正しいか。短時間メニューの中に全体の仕組みを入れると、読み手は「この箱は何の話？」で止まる。
- メニュー説明は「何ができるか」の列挙だけでは足りない。シャンプー台と椅子で差が出るなら、「姿勢・空間の制約 → だからここまでできる／ここはできない」を書く。見ればわかる、は読み手の仕事ではない。
- 個室・骨盤チェアは店の自慢ではなく、顧客層の悩みへの答え。忙しい世代・周りの目・長時間のうつ伏せ／仰向け負担、を先に置き、だからこの設備、の順にする。
- 意図ではなく結果で見る。書いた側の「こう考えて配置した」より、パッと見で箱が分かれるか／なぜが残らないか、が評価基準（0330の続き）。

---

## ■ズレ（思考 or 設計）

| やりたいこと | 起きていること | 結果 |
|---|---|---|
| 短時間メニューを説明する | 箱の中に「全体の仕組み」が入る | カテゴリが壊れる |
| リラクと美容の差を出す | リラクのみ側に髪のお直しが混ざる | 箱のラベルと中身がずれる |
| 待ち時間の価値を伝える | 本格リラクと待ち時間が同じ見え方 | 違いが一瞬で伝わらない |
| 場所ごとの施術差を示す | 差はあるが「なぜ」がない | 「見ればわかるでしょ」になる |
| 個室・骨盤チェアを説明する | メリット先行・比較なし | 選定理由が弱い |
| スタッフ負担の表現 | 「中腰が続きにくい」など抽象 | 映像が浮かばない |

- 0612で指摘した待ち時間の軸（カラー・パーマの待ち＝雑誌／スマホ vs 当店のハンド・フット等）は、今回の「待ち時間短時間メニュー」箱と直結する。箱名を直すだけで、過去の指摘ともつながる。
- 「これ見ればわかる」は、自分視点の説明。読み手は初めて見る前提で書く。

---

## ■改善内容（What）

### 0. 進め方（0716と同じ）

今回も「3の幹」まで。形になる前に次へ広げない。

1. まずカテゴリの箱を直す
2. 箱ごとに「なぜ」を足す
3. 関係のない枝（髪を切らなきゃ、等）は外す

### 1. カテゴリの箱を切り直す

推奨イメージ：

```
【リラクメニューのみ（ほぼ美容なし）】
・セットメイドの髪のお直し中心
・希望によりシャンプー・ブロー

【美容＆リラク】
・施術の前／後に本格リラク
・待ち時間で受けられる短時間メニュー（カラー＝シャンプー台／パーマ＝美容椅子）
```

ポイント：

- 「短時間メニュー」の箱に「全体の仕組み」を入れない。全体は全体の箱へ。
- 待ち時間側の見出しは「待ち時間で受けられる短時間メニュー」に直す。
- 本格リラク（前後）と待ち時間メニューは、別枝で並べる。パッと見で差が立つようにする。

### 2. シャンプー台 vs 美容椅子：できることの「なぜ」を書く

| 場所 | できる例 | なぜそれができる／できない |
|---|---|---|
| シャンプー台（カラー等） | フット／ハンド／デコルテ | 足を伸ばして休める・腕も広げられる姿勢が取れる |
| 美容椅子（パーマ等） | ハンド中心 | 座ったままのため腕・足の範囲が限られる（構造上の制約） |

書き方の型：

```
シャンプー台では ○○ ができる。
なぜなら、足を伸ばして休める姿勢が取れるから。

美容椅子では △△ まで。
なぜなら、座ったままの姿勢では □□ が難しいから。
```

「見ればわかる」で終わらせない。足をやらない理由も、構造上の制約として一文入れる。

### 3. 「なんで？」が残る箇所を先に潰す

壁打ち・確認リスト：

- カラーの流れでヘッドスパはできるのか／別メニューなのか
- 椅子の構造上、これしかできない、という制約はあるか
- 時間帯の説明は必要か（あるなら因果で）

読み手が「なんで？」と思う場所は、店側の当たり前を言語化する場所。解消するまで次の枝を増やさない。

### 4. 個室の説明：顧客の一日 → ご褒美 → 周りの目 → 個室

関係の薄い「そろそろ髪を切らなきゃ」は外す。髪の話はこの箱の役割ではない。

推奨の並び：

```
仕事・家事・家族で毎日忙しい
→ 自分のことは後回しになりがち
→ 美容室に来たときぐらいは自分へのご褒美にしたい
→ でも周りの目があるとリラックスできない
→ だから個室で、気にせず癒される時間を用意している
```

「周りを気にせず」は結果の一言。その前に、なぜ気になってしまう顧客なのかを置く。

### 5. 骨盤チェア：一般ベッド比較 → なぜこの椅子 → 長時間でも楽

顧客層（年齢・長時間のうつ伏せ／仰向けが負担）を先に置く。

推奨の並び：

```
【一般的なリラクのベッド／マットだと】
長時間のうつ伏せ・仰向けが体に負担になる
（なぜ負担か：年齢・関節・呼吸など、店の実態に合わせて1文）

【骨盤チェアだと】
体への負担が少ない姿勢が取れる
→ 長時間でも痛くなりにくい・疲れにくい
→ ゆったり癒される時間になる
```

「体の負担が少ない」だけで止めず、なぜ骨盤チェアならそれが言えるのかを書く。

### 6. イメージがつかない表現は直すか外す

| 表現 | 扱い |
|---|---|
| 中腰の姿勢が続きにくい | 映像が浮かばない。座って施術なのか／立ってなのかを具体化。無理なら削る |
| 一重まぶたの方は目に負担が少ない | 無理やり感が強い。納得できる因果が書けないなら外す |

スタッフ側メリットを書くなら、「椅子を使った施術で、どのような姿勢になるか」が再生できる文にする。

## ■改善理由（Why）

- 箱が正しいと、0612の待ち時間訴求も0716の特徴整理も、同じ地図の上に載る。箱が壊れたまま中身を足すと、また全部が中途半端になる。
- 「なぜ」を書くと、意図の説明ではなく結果の説明になる。読み手は初めて見る前提なので、店の当たり前を言語化する必要がある。
- 個室・骨盤チェアは比較（一般／他の受け方）があって初めて選定理由が立つ。メリット列挙だけだと「だから何？」が残る。
- 一つずつ形にするのは、スキル習得の進め方そのもの。幹が定まる前に枝を増やさない。

---

## ■改善後イメージ（After）

- 「リラクのみ」と「美容＆リラク」が一目で分かれる。
- 待ち時間メニューと本格リラクが別枝になり、カラー待ちの価値が伝わる。
- シャンプー台／椅子の差に「なぜ」があり、ヘッドスパ等の「なんで？」も解消されている。
- 個室・骨盤チェアは、忙しい世代・年齢の悩みから読めて、一般ベッドとの差まで追える。
- イメージできない表現が消え、AI壁打ちも「この箱／このなぜ」に集中できる。

---

## ■やりがちなミス

- 短い箱の中に全体の仕組みを入れてしまう
- 「見ればわかる」で「なぜ」を省略する
- 本格リラクと待ち時間を同じ見え方のままにする
- 個室・チェアをメリットだけ並べ、顧客層と比較を飛ばす
- 髪の話など、箱の役割と違う枝を残す
- 意図（こう考えた）を説明して、結果のわかりにくさを正当化する

---

## ■他の案件でも使えるパターン

- 箱のラベルと中身が一致しているか、先にチェックする
- 差があるなら「場所／姿勢の制約 → できること」で書く
- 設備は「顧客の悩み → 選定 → 結果」、一般手段との比較を先に置く
- 「なんで？」が残る箇所は、店の当たり前の言語化リストにする
- イメージがつかない一文は、具体化か削除（無理やり残さない）

## ■一言まとめ（本質）

👉 短時間メニューの箱を直し、リラクのみ／美容＆リラク／待ち時間を分離したうえで、シャンプー台と椅子・個室・骨盤チェアはすべて「なぜ」と比較で書く。見ればわかる、は読み手の仕事ではない。

## ■0716・0612・0330との関係

- 0612：待ち時間（カラー・パーマ）が一般美容室との差の芯。今回の「待ち時間短時間メニュー」箱はその続き。
- 0716：大項目の箱・なぜ個室・なぜ骨盤チェア・一つずつ形にする。今回はメニュー側の箱と「なぜ」の実装。
- 0330：自分視点／意図の説明ではなく、結果（パッと見・なぜが残るか）で直す。今回の「見ればわかる」はまさにその症状。
